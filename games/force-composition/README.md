# 力的合成与分解

课堂互动演示（人教版必修第一册 第三章 第 4 节）。直接打开 `index.html`，无网络依赖；按一体机横屏 16:9 设计，整页不滚动。

## 五个演示

- **合成**：拖动 F₁、F₂ 的箭头端点，实时显示平行四边形、合力 F、夹角 θ 和合力与 F₁ 的夹角 φ。可切换“三角形定则”（F₂ 平移到 F₁ 末端的动画）；“扫描夹角”让 F₂ 大小不变、夹角从 0° 转到 180° 再转回，右下角同步画出 F–θ 图像；合力范围条显示 |F₁ − F₂| ≤ F ≤ F₁ + F₂。预设：垂直 3 N 与 4 N、等大夹角 120°、同向、反向。
- **多力合成**：三个力分三步逐次合成（先 F₁、F₂ 合成 F₁₂，再与 F₃ 合成），或切换为首尾相接的多边形；显示三力大小不变时合力的范围。
- **按效果分解**：斜向上拉物体、斜面上的物体、挡板挡住的球、两绳悬挂物体四个情境，滑杆改变角度，分力数值与公式同步；“任意两个方向”可拖动 F 和两条分解方向线。情境中按 0.5 倍比例画 20 N 的重力。
- **分解的唯一性**：已知 F₁ 的方向（与 F 夹角 α）和 F₂ 的大小，以 F 末端为圆心、F₂ 为半径画圆，显示无解、一解（相切，F₂ 最小）、两解、一解（F₂ ≥ F）四种情况。
- **正交分解**：三个力可拖动，坐标轴可转动；表格列出各分量与合计，显示 F 与 φ。可一键让 x 轴沿 F₁。

吸附默认开启：力的大小按 0.5 N、方向按 5° 取整。快捷键：`1`–`5` 切换演示，`R` 重置当前演示。

## 公式与符号

页面上的公式由 MathJax 预先排版成 SVG（`js/formulas.js`），画布上的物理量用斜体字母加真正的下标绘制。

## 文件

- `index.html`
- `css/style.css`
- `js/physics.js`（计算，不依赖 DOM）
- `js/formulas.js`（预排版公式）
- `js/main.js`（绘图与交互）
- `tests/physics.test.js`

## 验证

运行 `node tests/physics.test.js`：余弦定理与矢量相加一致（含 60 N、60 N 夹角约 67° 合力约 100 N）；两力、三力合力范围；沿两方向分解能还原原力、共线方向无解；唯一性四种情况及解的正确性；正交分解例题（合力 20 N、与 x 轴成 53°）且转动坐标轴合力不变；四个按效果分解情境的数值。
