分子力 F–r 曲线

每个点是一对相邻粒子此刻的间距和相互作用力。F > 0 为斥力，F < 0 为引力。

要点

1弹性形变

粒子只偏离平衡位置 r0 一点点，邻居没有变。受压处表现为斥力，受拉处表现为引力，都指回 r0；在 r0 附近 F 与 Δr 近似成正比，宏观上就是胡克定律。撤去外力后复原：动能 → 分子势能 → 动能，近似弹性碰撞。

2塑性形变

力再大些，一层粒子整体滑过一个间距，停在新的平衡位置，换了邻居（图中绿色的键）。但任何时刻都有键连着，所以不裂。回不到原位，形成永久弯曲；一部分动能变成粒子的无规则振动（内能），是非弹性碰撞。

3断裂

某处间距被拉过 rm（引力最大处）。过了 rm，距离越大引力反而越小，外力一旦超过最大引力，就再也找不到平衡位置，越拉越开。注意裂纹从板的下表面开始：那里受拉。断裂是“拉断”，不是“压碎”。

金属与玻璃

两种材料用的是同一条 F–r 曲线。区别只在于：金属中靠近的粒子都会相互吸引，可以和新邻居重新结合，所以能滑移、能弯；玻璃中的键一旦断开就不会再接上，没有塑性阶段，直接从弹性形变到断裂。

模型说明

二维示意模型，约 370 个粒子；F–r 曲线形状与教材一致，数值为示意。小球视为刚体，撞击前粒子静止（忽略原有的热运动）。真实材料里有缺陷，往往在缺陷处先断，所需的力远小于这里的理想值。
