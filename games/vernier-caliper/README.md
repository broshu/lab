# Vernier Caliper Reading

Open `index.html` to drag the slider (or the measured block) and read the caliper.
Switch between 10-, 20- and 50-division verniers (0.1 / 0.05 / 0.02 mm). A magnifier
shows which vernier line coincides with a main-scale line, and the readout breaks the
result into main scale + vernier.

The folder follows the same structure as `games/oscilloscope-principle/`:

- `index.html`
- `css/style.css`
- `js/main.js`
