观察中的物理

① 水平方向动量守恒

mvx + MV = mv0

地面光滑，系统没有水平外力。滑块上爬时，把一部分水平动量传给底座。

② 最高点：相对速度为零

vx = V = mv0 / (m + M)

最高点可能在曲面上，也可能在空中。两种情况下滑块相对底座瞬时静止，对地仍向右运动；此时仍有水平动能。

③ 离开入口后

vx = (m − M)v0 / (m + M)

离开入口时竖直速度为零，随后只受重力作用，做平抛运动；若水平速度恰为零，则竖直下落。离地高度降至 0 时结束。

什么时候会飞出？

圆弧半径 R = 1.50 m，弧长 πR/2 ≈ 2.36 m，尺寸固定。只有 v0 > √[2gR(m + M)/M] 才会从顶端飞出；等于临界值时，滑块恰好到达顶端后返回。顶端切线竖直，所以飞出时滑块与底座的水平速度相同，滑块落下后会重新进入曲面。

模型约定：滑块视为质点，不考虑转动；地面与曲面均光滑，g = 9.8 m/s²。曲面为固定的四分之一圆弧，入口切线水平、出口切线竖直。飞行阶段只受重力，底座匀速移动；滑块落回顶端时与曲面相切，平滑接续下滑，不引入碰撞能量损失。入口离地 0.40 m，滑块离开入口后继续运动，直到首次接触地面；结束帧显示触地瞬间，不模拟碰撞与反弹。重力势能以地面为零，y 是离地高度，预测上升高度 h 从入口算起。画面按每次实验的完整运动范围等比例缩放，物理尺寸不变。
