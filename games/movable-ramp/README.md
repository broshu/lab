# 滑块与有限曲面

直接打开 `index.html`，无网络依赖。沿用 Physics Lab 的深蓝标题栏、浅灰背景和白色面板。

- 滑块从左向右进入固定的四分之一圆弧，底座可在光滑地面上平移。
- 调整 m（0.2–10 kg）、M（0.2–20 kg）、v₀（0.5–10 m/s）。改变初始条件会重置。
- 曲面半径、高度均为 1.50 m，弧长约 2.36 m，不随参数变化。
- 初速度超过临界值时从竖直切线方向飞出，随后落回顶端，沿曲面滑回入口。
- 只保留一个播放按钮，同一按钮切换播放、暂停与重新播放；保留时间轴回看和播放速度调节。
- 不提供质量比较预设、飞出演示、重置、逐帧或最高点跳转。
- 入口离地 0.40 m，滑块滑回入口后继续平抛，直到真正接触地面；水平速度为零时竖直下落。
- 对地轨迹、对地速度箭头、水平速度图、能量分配和总动量；速度图标出顶端飞行和最终平抛区间。
- 空格播放/暂停；输入框操作不触发快捷键。

## 物理模型

质点滑块，无摩擦、无转动；g = 9.8 m/s²。θ 从入口处的 0 增加到顶端的 π/2。相对入口坐标为 q = R sinθ，h = R(1−cosθ)。令 α = m/(m+M)、β = M/(m+M)、ω = dθ/dt：

    θ′ = ω
    ω′ = −[α sinθ cosθ ω² + (g/R) sinθ] / [β + α sin²θ]
    X = α(v₀t − R sinθ)
    V = α(v₀ − R cosθ ω)

四阶 Runge–Kutta 积分的步长为 min(1/1200, 0.002√β/v₀) s；轻底座、高速度时缩小步长以解析快速变化。事件时刻用二分定位。

飞出条件为 v₀ > √(2gR/β)。飞出时 V = vₓ = αv₀，vᵧ = √(βv₀²−2gR)。飞行期间底座匀速，滑块遵循解析抛体轨迹；相对底座的水平位置一直为 R，所以经过 2vᵧ/g 后落回曲面顶端。再入速度沿竖直切线向下，接续曲面运动，无碰撞能量损失。临界速度恰好到顶后直接沿曲面返回。

最高上升高度（包含空中阶段）h_max = βv₀²/(2g)。回到入口时 vₓ = (m−M)v₀/(m+M)，V = 2mv₀/(m+M)。此后底座保持匀速，滑块从入口高度 H = 0.40 m 做平抛运动：x = x_exit + vₓτ，离地高度 y = H − gτ²/2，τ = √(2H/g) 时接触地面并结束。触地帧保留碰撞前速度，不模拟碰撞或反弹。势能改以地面为零，总机械能为 mv₀²/2 + mgH。曲面尺寸固定，只调整画面的等比例缩放以容纳完整轨迹。
