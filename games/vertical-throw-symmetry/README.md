# 竖直上抛的对称性

直接打开 `index.html`，无网络依赖。沿用 Physics Lab 的深蓝标题栏、浅灰背景和白色面板。

研究竖直上抛的两种对称：

1. **时间对称（等时性）**：上升通过一段位移 AB 与下降通过 BA 所用时间相等。
2. **速度对称**：经过同一点时，上升与下降的速度大小相等、方向相反。

## 页面结构

- **抛出条件**：初速度 v₀（5–40 m/s）、g（10 或 9.8）。显示最大高度 H、上升时间、总时间。改变 v₀ 或 g 时，A、B 按比例随 H 缩放，动画回到抛出前。
- **选取位移 AB**：滑杆 / 数字框，或直接在动画中上下拖动 A、B 线（右侧圆形手柄）。A 始终在 B 下方。
- **运动观察**：小球在中间运动；左列记录上升经过 A、B 时的速度箭头，右列记录下降时的；两列用同一比例，箭头等长即速度等大。两侧括号为通过 AB 的实时计时。
- **播放**：一次完整播放从抛出到落地，不中途暂停；可随时暂停或拖动时间轴回看。
- **直接显示完整分析**：不看动画，直接显示全部图线标注与表格数值。
- **对比表**：上升 / 下降通过 AB 的用时、经过 A、B 的速度，两列都出现后打 ✓。
- **v–t 图像**：斜率 −g 的直线；绿色虚线为对称轴 t = v₀/g；橙、蓝阴影宽度相等（等时）、面积一正一负且大小都等于 AB；±v_A、±v_B 虚线显示速度大小相等。下方括号标出 Δt上、Δt下。
- **y–t 图像**：A、B 两条水平线与抛物线各交两次，交点关于 t = v₀/g 对称。
- **为什么对称？**：速度对称 |v| = √(v₀² − 2gy)；时间对称 Δt = (v_A − v_B)/g；v–t 图像中心对称。数字随参数实时更新。

## 物理模型

地面抛出，向上为正：y = v₀t − ½gt²，v = v₀ − gt。高度 y 处速度大小 √(v₀² − 2gy)；经过 y 的两个时刻 t = [v₀ ∓ √(v₀² − 2gy)]/g，两者之和恒为 2v₀/g。

## 验证

运行 `node tests/physics.test.js`：默认数据（v₀ = 20 m/s，A = 8.75 m，B = 18.75 m，t₁…t₄ = 0.5、1.5、2.5、3.5 s，Δt = 1 s，v_A = 15 m/s，v_B = 5 m/s），以及 10 组 v₀/g × 231 段 AB 的等时性、速度大小相等、方向相反、时刻关于 v₀/g 对称。
