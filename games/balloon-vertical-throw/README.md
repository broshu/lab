# 气球下的重物（竖直上抛）

直接打开 `index.html`，无网络依赖。沿用 Physics Lab 的深蓝标题栏、浅灰背景和白色面板。

题目来源：2026 三维设计 · 物理必修第一册（人教版 ZJ）第二章 专题强化 3 竖直上抛运动，例 1。

> 气球下悬挂一重物，以 v₀ = 10 m/s 匀速上升，当到达离地面 h = 175 m 处时悬挂重物的绳子突然断裂，那么重物经多少时间落到地面？落地的速度多大？（空气阻力不计，g 取 10 m/s²）
>
> 答案：t = 7 s，v = 60 m/s（竖直向下）。

## 页面结构

- **初始条件**：v₀（0–30 m/s）、h（10–300 m）、g（10 或 9.8）可调；「恢复例题数据」回到原题。改参数会回到绳断瞬间。
- **先预测，再观察**：三道预测题——绳断瞬间速度（针对"立即下落"的迷思概念）、落地时间、落地速度。答错时针对常见错误给出提示（如把 √(2h/g) 当作答案、只算了下降时间），不直接泄露答案。
- **运动观察**：「剪断绳子」开始播放；每 1 s 的频闪点（上升段在左、下降段在右）、速度箭头、断绳处与最高点参考线；时间轴可拖动回看，空格键播放/暂停。
- **v–t 图像**：随时间填充面积，橙色为上升位移（正）、蓝色为下降位移（负），代数和即全程位移 −h。
- **y–t 图像**：离地高度抛物线，标出最高点 H 与落地时刻。
- **解题过程**：分段法 / 全程法两个标签页，逐步展开；每一步可跳到动画对应时刻。数字随参数实时重算。

## 物理模型

取竖直向上为正，t = 0 为绳断瞬间：

    x = v₀t − ½gt²，v = v₀ − gt
    t₁ = v₀/g，h₁ = v₀²/(2g)，H = h + h₁
    t₂ = √(2H/g)，T = t₁ + t₂ = [v₀ + √(v₀² + 2gh)]/g
    v_land = √(v₀² + 2gh)

绳断后气球按原速度匀速上升，仅作参照，不参与计算。
