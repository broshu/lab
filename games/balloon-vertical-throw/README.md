# 气球下的重物（竖直上抛）

直接打开 `index.html`，无网络依赖。沿用 Physics Lab 的深蓝标题栏、浅灰背景和白色面板。

题目来源：2026 三维设计 · 物理必修第一册（人教版 ZJ）第二章 专题强化 3 竖直上抛运动，例 1。

> 气球下悬挂一重物，以 v₀ = 10 m/s 匀速上升，当到达离地面 h = 175 m 处时悬挂重物的绳子突然断裂，那么重物经多少时间落到地面？落地的速度多大？（空气阻力不计，g 取 10 m/s²）
>
> 答案：t = 7 s，v = 60 m/s（竖直向下）。

## 页面结构

- **初始条件**：v₀（0–30 m/s）、h（10–300 m）、g（10 或 9.8）可调；「恢复例题数据」回到原题。改参数会回到绳断瞬间。
- **先预测，再观察**：三道预测题——绳断瞬间速度（针对"立即下落"的迷思概念）、落地时间、落地速度。答错时针对常见错误给出提示（如把 √(2h/g) 当作答案、只算了下降时间），不直接泄露答案。
- **运动观察**：「播放」从气球带着重物在地面起飞开始——匀速上升阶段（t < 0）先快进，绳断前 1.5 s 恢复正常速度；到达断绳高度时绳子自动断裂（t = 0），之后完整播放到落地。「跳到绳断前 2 s」可直接看关键段。
  - 左侧**全景**（地面到最高点），右侧**断绳处附近放大**（默认约 ×6），放大区在全景中以橙色虚框标出。
  - 放大图中气球与重物的速度箭头同一比例并排显示：绳断前两者等长；绳断后气球不变、重物逐渐变短并反向——直观体现惯性。
  - 频闪点每 1 s 一个：绳断前（灰）间距相等，绳断后上升（橙）间距变小、下降（蓝）间距变大。时间轴前 25% 为绳断前，后 75% 为绳断后；空格播放/暂停。
- **v–t 图像**：包含绳断前 2 s（灰色区域，v = v₀ 水平线），绳断处速度连续不突变；绳断后随时间填充面积，橙色为上升位移（正）、蓝色为下降位移（负），代数和即全程位移 −h。
- **y–t 图像**：绳断前为倾斜直线，绳断后为抛物线，标出最高点 H 与落地时刻。
- **解题过程**：分段法 / 全程法两个标签页，逐步展开；每一步可跳到动画对应时刻。数字随参数实时重算。

## 物理模型

取竖直向上为正，t = 0 为绳断瞬间：

    x = v₀t − ½gt²，v = v₀ − gt
    t₁ = v₀/g，h₁ = v₀²/(2g)，H = h + h₁
    t₂ = √(2H/g)，T = t₁ + t₂ = [v₀ + √(v₀² + 2gh)]/g
    v_land = √(v₀² + 2gh)

绳断前（−h/v₀ ≤ t < 0）：y = h + v₀t，v = v₀。绳断后气球按原速度匀速上升，仅作参照，不参与计算。
