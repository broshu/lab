# Particle Stream Between Plates

Canvas game for charged particles entering parallel plates with a square-wave voltage.

## Features
- Continuous particle stream from source A
- Highlighted release phase from `0` to `T`
- Presets for `0`, `T/8`, and `T/4`
- Fixed `UPQ` square wave matching the problem
- Shows motion, exit point, `UPQ-t`, and `vy-t`

## Usage
Open `index.html` in a browser.
