# Particle Between Plates

Canvas game for one charged particle entering parallel plates with a square-wave voltage.

## Features
- One released particle from source A
- Release phase from `0` to `T`
- Presets for `0`, `T/8`, and `T/4`
- Fixed `UPQ` square wave matching the problem
- Shows motion, exit point, `UPQ-t`, and `vy-t`

## Usage
Open `index.html` in a browser.
