带电粒子在电场中运动的综合问题

模型 方法 练习

核心模型

带电粒子在匀强电场中的运动，本质是“受恒力的曲线运动”。先判受力方向，再把运动分解到两个互相垂直的方向。

  • 受力 F = qE，正电荷受力沿电场方向，负电荷受力反向。
  • 加速度 a = qE / m，方向由 q 的正负决定。
  • 类平抛 沿初速度方向匀速，沿电场力方向匀加速。
  • 能量 电场力做功 W = qU，对应动能变化。

交互演示

解题步骤

  1. 画出电场方向，标出粒子电性，确定电场力方向。
  2. 选择坐标轴：一个方向沿初速度，一个方向沿电场力。
  3. 列分运动方程，通常 x = v0t，y = 1/2 at²。
  4. 用几何条件、时间条件或能量条件联立求解。

易错点

  1. 负电荷受力方向与电场方向相反，不能只看场线方向。
  2. 电势能变化和电场力做功符号要分清。
  3. 离开电场后，粒子通常做匀速直线运动，不再继续弯曲。
  4. 偏转距离和偏转角分别对应位移关系与速度关系。

课堂追问

  1. 若只把粒子电性改为负，轨迹如何改变？
  2. 若电场强度加倍，离开电场时偏转距离如何变化？
  3. 若初速度加倍，粒子在电场中运动时间如何变化？
  4. 什么时候用运动分解更方便，什么时候用动能定理更方便？
