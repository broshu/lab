## 1. 讲义题目 · 例1　力传感器与木板（经典高考）

**题目**

多选（经典高考）如图（a），物块和木板叠放在实验台上，物块用一不可伸长的细绳与固定在实验台上的力传感器相连，细绳水平。$t = 0$ 时，木板开始受到水平外力 $F$ 的作用，在 $t = 4\u{s}$ 时撤去外力。细绳对物块的拉力 $f$ 随时间 $t$ 变化的关系如图（b）所示，木板的速度 $v$ 与时间 $t$ 的关系如图（c）所示。木板与实验台之间的摩擦可以忽略。重力加速度取 $10\u{m/s^2}$。由题给数据可以得出（　　）A. 木板的质量为 $1\u{kg}$
B. $2$～$4\u{s}$ 内，力 $F$ 的大小为 $0.4\u{N}$
C. $0$～$2\u{s}$ 内，力 $F$ 的大小保持不变
D. 物块与木板之间的动摩擦因数为 $0.2$

![例1　力传感器与木板（经典高考）原题图](assets/olympiad3/z3-q1.png)

**答案：AB**

**解析**

AB

木板受到的摩擦力 $f' = f$。

$0$～$2\u{s}$，木板静止，$F = f'$，$F$ 逐渐增大，所以 C 错误。

$4$～$5\u{s}$，由 $v$–$t$ 图像可知木板加速度大小 $a_{2} = \dfrac{0.4 - 0.2}{1}\u{m/s^2} = 0.2\u{m/s^2}$，对木板 $f' = ma_{2} = 0.2\u{N}$，得 $m = 1\u{kg}$，A 正确。

$2$～$4\u{s}$，对木板 $F - f' = ma_{1}$，得 $F = 0.2\u{N} + 1 \times \dfrac{0.4 - 0}{2}\u{N} = 0.4\u{N}$，B 正确。

由于无法确定物块的质量，尽管知道滑动摩擦力大小，仍无法确定动摩擦因数，D 错误。

思路点拨：图像时间对应

![例1　力传感器与木板（经典高考）解答图](assets/olympiad3/z3-a1.png)

## 2. 讲义题目 · 迁移应用1　斜面上的 v–t 图像

**题目**

［2025·浙江舟山开学考］多选如图甲所示，质量 $m = 2\u{kg}$ 的物块在平行斜面向上的拉力 $F$ 作用下从静止开始沿斜面向上运动，$t = 0.5\u{s}$ 时撤去拉力，其在 $0$～$1.5\u{s}$ 内的速度随时间变化的关系如图乙所示，$g$ 取 $10\u{m/s^2}$。则下列判断正确的是（　　）A. 物块与斜面间的动摩擦因数为 $0.1$
B. 拉力大小为 $12\u{N}$
C. $1.5\u{s}$ 后物块一定静止
D. 物块沿斜面上滑的距离为 $1.5\u{m}$

![斜面上的 v–t 图像原题图](assets/olympiad3/z3-q2.png)

**答案：BD**

**解析**

BD

由图乙知，各阶段加速度的大小为 $a_{1} = 4\u{m/s^2}$、$a_{2} = 2\u{m/s^2}$。设斜面倾角为 $\theta$，物块与斜面间的动摩擦因数为 $\mu$，根据牛顿第二定律：

$0$～$0.5\u{s}$ 内，$F - \mu mg\cos\theta - mg\sin\theta = ma_{1}$；

$0.5$～$1.5\u{s}$ 内，$\mu mg\cos\theta + mg\sin\theta = ma_{2}$；

联立解得 $F = 12\u{N}$，但无法求出 $\mu$ 和 $\theta$，故 A 错误，B 正确；

不清楚 $\tan\theta$ 与 $\mu$ 的大小关系，无法判断物块能否静止在斜面上，故 C 错误；

由 $v$–$t$ 图线与横轴围成的面积表示位移，上滑距离 $x = \dfrac{1.5 \times 2}{2}\u{m} = 1.5\u{m}$，故 D 正确。

![斜面上的 v–t 图像解答图](assets/olympiad3/z3-a2.png)

## 3. 讲义题目 · 例2　斜面上的 A、B

**题目**

如图所示，质量分别为 $m_{A}$、$m_{B}$ 的 $A$、$B$ 两物块用轻质细线连接，放在倾角为 $\theta$ 的斜面上，用始终平行于斜面向上、大小恒定的拉力 $F$ 拉 $A$，使它们沿斜面匀加速上升，$A$、$B$ 与斜面间的动摩擦因数均为 $\mu$。为了增加细线上的张力，可行的办法是（　　）A. 增大 $A$ 物块的质量
B. 增大 $B$ 物块的质量
C. 增大倾角 $\theta$
D. 增大动摩擦因数 $\mu$

![例2　斜面上的 A、B原题图](assets/olympiad3/z3-q3.png)

**答案：B**

**解析**

B

对 $A$、$B$ 组成的系统应用牛顿第二定律：

$$F - (m_{A} + m_{B})g\sin\theta - \mu(m_{A} + m_{B})g\cos\theta = (m_{A} + m_{B})a$$
隔离物块 $B$：

$$F_{\mathrm T} - m_{B}g\sin\theta - \mu m_{B}g\cos\theta = m_{B}a$$
联立解得 $F_{\mathrm T} = \dfrac{m_{B}}{m_{A} + m_{B}}F$，$F_{\mathrm T}$ 与 $\theta$、$\mu$ 无关；$m_{B}$ 越大、$m_{A}$ 越小，$F_{\mathrm T}$ 越大，故 B 正确。

![例2　斜面上的 A、B解答图](assets/olympiad3/z3-a3.png)

## 4. 讲义题目 · 迁移应用2　A 对 B 的作用力

**题目**

［2024·浙江嘉兴一中月考］质量分别为 $2m$、$m$ 的 $A$、$B$ 两物块，在恒力 $F$ 作用下沿光滑的水平地面一起向右做匀加速运动。下列情形中 $A$ 对 $B$ 的作用力最大的是（　　）A.
B.
C.
D.

![A 对 B 的作用力原题图](assets/olympiad3/z3-q4.png)

**答案：D**

**解析**

D

选项 A：整体 $F = (2m + m)a$，对 $B$ 有 $N_{1} = ma$，得 $N_{1} = \dfrac{F}{3}$；同理选项 B 中 $N_{2} = \dfrac{2F}{3}$。

选项 C：$A$、$B$ 间静摩擦力 $f_{1} = \dfrac{F}{3}$，$A$、$B$ 间作用力 $F_{1} = \sqrt{\left(\dfrac{F}{3}\right)^{2} + (mg)^{2}}$。

选项 D：$A$、$B$ 间静摩擦力 $f_{2} = \dfrac{2F}{3}$，$A$、$B$ 间作用力 $F_{2} = \sqrt{\left(\dfrac{2F}{3}\right)^{2} + (2mg)^{2}}$。

故选 D。

## 5. 讲义题目 · 例3　动滑轮与斜面体

**题目**

［2024·浙江台州一中月考］如图所示，质量为 $M$、倾角为 $30\deg$ 的斜面体置于水平地面上，一轻绳绕过两个轻质滑轮连接着固定点 $P$ 和物体 $B$，两滑轮之间的轻绳始终与斜面平行，物体 $A$、$B$ 的质量分别为 $m$、$2m$，$A$ 与斜面体间的动摩擦因数为 $\dfrac{\sqrt{3}}{3}$，重力加速度大小为 $g$，将 $A$、$B$ 由静止释放，在 $B$ 下降的过程中（物体 $A$ 未碰到滑轮），斜面体静止不动。下列说法正确的是（　　）A. 轻绳对 $P$ 点的拉力大小为 $\dfrac{4}{3}mg$
B. 物体 $A$ 的加速度大小为 $\dfrac{1}{3}g$
C. 地面对斜面体的支持力大小为 $Mg + 2mg$
D. 增大 $A$ 的质量，再将 $A$、$B$ 由静止释放，则 $B$ 有可能上升

![例3　动滑轮与斜面体原题图](assets/olympiad3/z3-q5.png)

**答案：B**

**解析**

B

相同时间内 $B$ 的位移是 $A$ 的 2 倍，则 $B$ 的加速度是 $A$ 的 2 倍。设 $A$ 的加速度大小为 $a$，则 $B$ 的为 $2a$，绳的拉力为 $T$，由牛顿第二定律：

$2T - mg\sin 30\deg - \mu mg\cos 30\deg = ma$，$2mg - T = 2m\cdot 2a$，解得 $T = \dfrac{2}{3}mg$，$a = \dfrac{1}{3}g$，故 A 错误，B 正确；

对斜面体、$A$、$B$ 整体，在竖直方向根据牛顿第二定律得

$$(M + 3m)g - F_{\mathrm N} - T\sin 30\deg = 2m\cdot 2a - ma\sin 30\deg$$
解得 $F_{\mathrm N} = \left(M + \dfrac{3}{2}m\right)g$，故 C 错误；

假设 $B$ 上升，则 $A$ 下滑，$A$ 所受滑动摩擦力沿斜面向上，此时 $mg\sin 30\deg < \mu mg\cos 30\deg + 2T_{1}$，$A$ 无法下滑，假设不成立，故 D 错误。

![例3　动滑轮与斜面体解答图](assets/olympiad3/z3-a5.png)

## 6. 讲义题目 · 例4　旋转一周的外力 F

**题目**

［2025·浙江衢州一中联考］一质量为 $m$ 的物块在水平地面上向右运动，物块与水平地面间的动摩擦因数为 $\mu = \dfrac{\sqrt{3}}{3}$。现对物块施加一个大小为 $F = \dfrac{1}{2}mg$ 的外力，在外力 $F$ 保持大小不变且逆时针旋转一周（$\theta$ 从 $0\deg$ 增大到 $360\deg$）的过程中物块一直向右运动。下列说法正确的是（重力加速度为 $g$）（　　）A. 当外力 $F$ 水平向右时，物块向右做加速运动
B. 当外力 $F$ 水平向左时，物块具有向左的最大加速度
C. 物块向左的最大加速度为 $\dfrac{2\sqrt{3}}{3}g$
D. 当 $\theta = 30\deg$ 时，物块的加速度大小为 $0.5g$

![例4　旋转一周的外力 F原题图](assets/olympiad3/z3-q6.png)

**答案：C**

**解析**

C

当 $F$ 水平向右时，由于 $F < \mu mg$，物块向右做减速运动，A 错误。

竖直方向：$mg = F\sin\theta + F_{\mathrm N}$；水平方向（以向左为正）：$\mu F_{\mathrm N} - F\cos\theta = ma$，联立解得

$$a = -\frac{F}{m}(\mu\sin\theta + \cos\theta) + \mu g = -\frac{\sqrt{3}}{3}g\sin(\theta + 60\deg) + \frac{\sqrt{3}}{3}g$$
当 $\theta = 30\deg$ 时加速度最小，$a_{\min} = 0$，D 错误；

当 $\theta = 210\deg$ 时加速度最大，$a_{\max} = \dfrac{2\sqrt{3}}{3}g$，此时 $F$ 与水平方向成 $30\deg$ 斜向左下方，B 错误，C 正确。

![例4　旋转一周的外力 F解答图](assets/olympiad3/z3-a6.png)
