## 1. 讲义题目 · 例1　工件滑上传送带

**题目**

如图所示，水平传送带两端相距 $x = 8\u{m}$，工件与传送带间的动摩擦因数 $\mu = 0.6$，工件滑上 $A$ 端时的速度 $v_{A} = 10\u{m/s}$，设工件到达 $B$ 端时的速度大小为 $v_{B}$（取 $g = 10\u{m/s^2}$）。
（1）若传送带静止不动，求 $v_{B}$。

（2）若传送带顺时针转动，工件还能到达 $B$ 端吗？若不能，说明理由；若能，求 $v_{B}$。

（3）若传送带以 $v = 13\u{m/s}$ 的速率逆时针匀速转动，求 $v_{B}$ 及工件由 $A$ 到 $B$ 所用的时间（结果保留 2 位有效数字）。

![例1　工件滑上传送带原题图](assets/olympiad3/z4-q1.png)

**答案：（1）$2\u{m/s}$ （2）能，$2\u{m/s}$ （3）$13\u{m/s}$，$0.67\u{s}$**

**解析**

（1）$2\u{m/s}$　（2）能，$2\u{m/s}$　（3）$13\u{m/s}$，$0.67\u{s}$

（1）$\mu mg = ma$，则 $a = \mu g = 6\u{m/s^2}$，由 $v_{B}^{2} - v_{A}^{2} = -2ax$，解得 $v_{B} = 2\u{m/s}$。

（2）传送带顺时针转动时，工件受力不变，加速度不变，仍然始终做匀减速运动，故 $v_{B} = 2\u{m/s}$。

（3）$\mu mg = ma'$，得 $a' = 6\u{m/s^2}$。工件速度达到 $13\u{m/s}$ 所用时间 $t_{1} = \dfrac{v - v_{A}}{a'} = 0.5\u{s}$，位移 $x_{1} = v_{A}t_{1} + \dfrac{1}{2}a't_{1}^{2} = 5.75\u{m} < 8\u{m}$，

工件到达 $B$ 端前就与传送带共速，此后相对静止，先匀加速后匀速：$x_{2} = x - x_{1} = 2.25\u{m}$，$t_{2} = \dfrac{x_{2}}{v} \approx 0.17\u{s}$，总时间 $t = t_{1} + t_{2} = 0.67\u{s}$。

![例1　工件滑上传送带解答图](assets/olympiad3/z4-a1.png)

## 2. 讲义题目 · 例2　物块随传送带上行

**题目**

［2025·浙江衢州二中高三月考］如图所示，倾角为 $\theta$、长度 $l$ 未知的传送带，沿顺时针方向以 $v_{0}$ 做匀速转动，将一个质量为 $m$ 的小物块由静止放置在传送带的底端，此后小物块随着传送带上行直至离开传送带。已知小物块和传送带之间的动摩擦因数为 $\mu$，在此过程中，下列说法正确的是（重力加速度为 $g$）（　　）A. 小物块在加速的过程中处于失重状态
B. 小物块能够在加速阶段滑离传送带的条件为 $l \le \dfrac{v_{0}^{2}}{2(\mu g\sin\theta - g\cos\theta)}$
C. 若 $l$ 一定，只增大倾角 $\theta$，则小物块滑离传送带上端的时间会变长
D. 若 $l$ 一定，增大倾角 $\theta$，要使小物块滑离传送带上端的时间不变，需要减小 $\mu$

![例2　物块随传送带上行原题图](assets/olympiad3/z4-q2.png)

**答案：C**

**解析**

C

小物块加速过程中加速度有竖直向上的分量，处于超重状态，A 错误。

加速过程：$\mu mg\cos\theta - mg\sin\theta = ma$，$a = \mu g\cos\theta - g\sin\theta$，加速到共速的距离 $x = \dfrac{v_{0}^{2}}{2a} = \dfrac{v_{0}^{2}}{2(\mu g\cos\theta - g\sin\theta)}$，故在加速阶段滑离的条件为 $l \le \dfrac{v_{0}^{2}}{2(\mu g\cos\theta - g\sin\theta)}$，B 错误。

若 $l$ 一定，只增大 $\theta$，加速度减小：若一直加速，由 $l = \dfrac{1}{2}at^{2}$ 知时间变长；若先加速后匀速，加速时间 $t_{1} = \dfrac{v_{0}}{a}$ 变长，由右侧 $v$–$t$ 图像可知总时间变长，C 正确。

要使时间不变，需加速度不变，由 $a = \mu g\cos\theta - g\sin\theta$ 可知需要增大 $\mu$，D 错误。
