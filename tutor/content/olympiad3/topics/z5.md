## 1. 讲义题目 · 例1　抽出薄木板

**题目**

［2025·浙江瑞安中学模拟］如图甲所示，在桌面上有一薄木板，板上放置了 3 个木块，其中 $m_{A} = m$，$m_{B} = 2m$，$m_{C} = 3m$，$A$ 可视为质点，$B$、$C$ 大小不可忽略，且开始 $A$ 叠放在 $B$ 的正上方，现用水平外力将薄木板沿垂直于 $B$、$C$ 连线方向拉出（图乙为俯视图）。已知木块与木块间、木块与薄木板间动摩擦因数均为 $\mu$，木块与桌面间动摩擦因数为 $2\mu$，重力加速度大小为 $g$。则从静止开始计时，三个木块的速度—时间图像可能为（$A$、$B$ 最终分离，忽略木块自身高度）（　　）

A.
B.
C.
D.

![例1　抽出薄木板原题图](assets/olympiad3/z5-q1.png)

**答案：B**

**解析**

B

未离开薄木板时，以 $A$、$B$ 整体为研究对象：$\mu(m_{A} + m_{B})g = (m_{A} + m_{B})a_{1}$，$a_{1} = \mu g$，$A$、$B$ 一起以 $\mu g$ 匀加速。

离开薄木板后，$A$、$B$ 间发生相对运动：对 $A$，$\mu m_{A}g = m_{A}a_{A2}$；对 $B$，$2\mu(m_{A} + m_{B})g - \mu m_{A}g = m_{B}a_{B2}$，解得 $a_{A2} = \mu g$，$a_{B2} = 2.5\mu g$，两者均匀减速。

$A$ 从 $B$ 上滑离后：$2\mu m_{A}g = m_{A}a_{A3}$、$2\mu m_{B}g = m_{B}a_{B3}$，$A$、$B$ 各自以 $2\mu g$ 匀减速，故 A、C 错误，B 正确。

对 $C$：未离开薄木板时 $\mu m_{C}g = m_{C}a_{C1}$，以 $\mu g$ 匀加速；离开后 $2\mu m_{C}g = m_{C}a_{C2}$，以 $2\mu g$ 匀减速，故 D 错误。

## 2. 讲义题目 · 迁移应用　a–F 图像与板块

**题目**

如图（a）所示，一质量为 $M = 2\u{kg}$ 的长木板静置在粗糙水平面上，其上放置一质量未知的小滑块，且长木板与小滑块之间接触面粗糙。小滑块受到水平拉力 $F$ 作用时，用传感器测出小滑块的加速度 $a$ 与水平拉力 $F$ 的关系如图（b）实线所示。已知地面与长木板间的动摩擦因数为 $0.2$，重力加速度 $g = 10\u{m/s^2}$，下列说法正确的是（　　）A. 小滑块与长木板之间的动摩擦因数为 $0.6$
B. 当水平拉力增大时，小滑块比长木板先相对地面发生滑动
C. 小滑块的质量为 $3\u{kg}$
D. 当水平拉力 $F = 12\u{N}$ 时，长木板的加速度大小为 $2\u{m/s^2}$

图（a）

图（b）

![a–F 图像与板块原题图](assets/olympiad3/z5-q2.png)

**答案：A**

**解析**

A

设小滑块与长木板之间的动摩擦因数为 $\mu_{1}$，小滑块质量为 $m$。相对滑动后，对小滑块 $F - \mu_{1}mg = ma$，由 $a$–$F$ 图像纵截距得 $-\mu_{1}g = -6\u{m/s^2}$，$\mu_{1} = 0.6$，A 正确；

拉力为 $F_{0}$ 时二者恰好相对滑动，加速度相同，大小为 $2\u{m/s^2}$。对长木板：$\mu_{1}mg - \mu_{2}(m + M)g = Ma_{0}$，解得 $m = 2\u{kg}$；对小滑块：$F_{0} - \mu_{1}mg = ma_{0}$，$F_{0} = 16\u{N}$。

因为 $\mu_{1}mg = 12\u{N} > \mu_{2}(m + M)g = 8\u{N}$，拉力增大时二者相对地面同时滑动，B、C 错误；

$F = 12\u{N}$ 时不发生相对滑动，整体 $F - \mu_{2}(m + M)g = (m + M)a'$，$a' = 1\u{m/s^2}$，D 错误。

## 3. 讲义题目 · 例2　光滑平板与滑块

**题目**

如图所示，在倾角 $\theta = 37\deg$ 的固定斜面上放置一质量 $M = 1\u{kg}$、长度 $L = 3\u{m}$ 的薄平板 $AB$。平板的上表面光滑，其下端 $B$ 与斜面底端 $C$ 的距离为 $16\u{m}$。在平板的上端 $A$ 处放一可视为质点、质量 $m = 0.6\u{kg}$ 的滑块，开始时使平板和滑块都静止，之后将它们无初速度释放。设平板与斜面间、滑块与斜面间的动摩擦因数均为 $\mu = 0.5$，求滑块与平板下端 $B$ 到达斜面底端 $C$ 的时间差 $\Delta t$。（$\sin 37\deg = 0.6$，$\cos 37\deg = 0.8$，$g = 10\u{m/s^2}$）

![例2　光滑平板与滑块原题图](assets/olympiad3/z5-q3.png)

**答案：$\Delta t = 2\u{s}$**

**解析**

$\Delta t = 2\u{s}$

由于 $Mg\sin 37\deg < \mu(M + m)g\cos 37\deg$，滑块在平板上滑动时，平板静止不动。滑块在平板上的加速度 $a_{1} = g\sin 37\deg = 6\u{m/s^2}$，到达 $B$ 点时速度 $v = \sqrt{2a_{1}L} = 6\u{m/s}$。

之后滑块在斜面上运动的加速度 $a_{2} = g\sin 37\deg - \mu g\cos 37\deg = 2\u{m/s^2}$，设运动时间为 $t$：$L_{BC} = vt + \dfrac{1}{2}a_{2}t^{2}$，解得 $t = 2\u{s}$。

对平板，滑块滑离后才开始运动，加速度 $a_{3} = g\sin 37\deg - \mu g\cos 37\deg = 2\u{m/s^2}$，设滑至 $C$ 所用时间为 $t'$：$L_{BC} = \dfrac{1}{2}a_{3}t'^{2}$，解得 $t' = 4\u{s}$。

时间差 $\Delta t = t' - t = 2\u{s}$。

![例2　光滑平板与滑块解答图](assets/olympiad3/z5-a3.png)
