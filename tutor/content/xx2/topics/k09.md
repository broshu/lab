## 1. 单选 · 一定存在静摩擦力的磁场方向

**题目**

（2026·北京海淀高二期末）如图所示，导体棒$ab$置于倾角为$\theta$的粗糙导轨上且与导轨垂直，整个装置处于匀强磁场中，磁场方向垂直于导体棒。闭合开关S，导体棒处于静止状态。下列磁场方向中，导体棒与导轨之间一定存在静摩擦力的是（　　）

- A．竖直向上
- B．水平向左
- C．垂直于导轨平面向上
- D．垂直于导轨平面向下

![第 1 题原题图。](assets/xx2/k09-q01-stem1.png)

**答案：D**

**解析**

![第 1 题解析配图。](assets/xx2/k09-q01-1.png)

分析导体棒受力如图（$a$端截面，安培力需要判定未画出）。磁场方向竖直向上时，由左手定则可得导体棒所受安培力水平向右，此时，水平向右安培力有可能与重力、弹力的合力平衡，不一定存在静摩擦力，故A错误；磁场方向水平向左时，由左手定则可得导体棒所受安培力竖直向上，此时，若安培力恰好等于重力时，则弹力为零，不需要静摩擦力作用导体棒即可处于平衡状态，故B错误；磁场方向垂直于导轨平面向上时，由左手定则可得导体棒所受安培力沿斜面向上，此时，安培力有可能与重力、弹力的合力平衡，不一定存在静摩擦力，故C错误；磁场方向垂直于导轨平面向下时，由左手定则可得导体棒所受安培力沿斜面向下，此时，必须存在静摩擦力以平衡安培力、重力、弹力的合力，故D正确。

**问答脚本**

本题考点：左手定则判断安培力方向（磁场方向不同时）；平衡条件下静摩擦力“可能有、一定有”的判断。
已知：导体棒 $ab$ 在倾角为 $\theta$ 的粗糙导轨上静止，磁场垂直于导体棒；四个选项分别给出磁场方向（按图中电流方向用左手定则）。
提问路线（每次只问一个问题）：
1. 问：判断“一定存在静摩擦力”的思路是什么？ → 期望：看不要摩擦力时，重力、支持力、安培力三个力能否平衡；能平衡就“不一定有”，不能平衡就“一定有”。
2. 问：磁场竖直向上时，安培力朝哪？它和重力、支持力能平衡吗？ → 期望：安培力水平向右，可以与重力、支持力平衡，不一定有摩擦力，A 错。
3. 问：磁场水平向左时，安培力朝哪？什么情况下不需要摩擦力？ → 期望：安培力竖直向上，与重力相等时支持力为零也能平衡，不一定有摩擦，B 错。
4. 问：磁场垂直导轨平面向上时，安培力朝哪？能不能不要摩擦力？ → 期望：安培力沿斜面向上，大小合适时可与重力分力平衡，不一定有摩擦，C 错。
5. 问：磁场垂直导轨平面向下时，安培力沿斜面向下，和重力沿斜面的分力同向，没有摩擦力能平衡吗？ → 期望：不能，必须有沿斜面向上的静摩擦力，选 D。
常见错误：
- 认为只要有安培力就一定有摩擦。追问：没有摩擦力时，三个力能不能构成封闭的力三角形？
- 安培力方向判错。追问：用左手定则时，磁感线穿掌心、四指指向电流方向，拇指指向哪里？
总结句：判断静摩擦力是否一定存在，就看去掉摩擦力后其余各力能否平衡。

## 2. 单选 · 上下两磁场中粒子回到出发点

**题目**

（2026·河南高考）如图，间距为$l$的两虚线$a$、$b$间存在方向垂直于纸面向外的匀强磁场，虚线$b$上方存在方向垂直于纸面向里的匀强磁场。一带电粒子在纸面内垂直于虚线$a$从$O$点射入磁场，一段时间后又从$O$点射出磁场。已知该粒子在下方磁场中运动的圆轨迹半径为$\dfrac{5}{3}l$，不计重力，则上、下磁场的磁感应强度大小之比为（　　）

- A．2∶1
- B．3∶1
- C．4∶1
- D．5∶1

![第 2 题原题图。](assets/xx2/k09-q02-stem1.png)

**答案：C**

**解析**

![动画演示：两段圆弧在边界上相切，轨迹左右对称回到 O](assets/xx2/k09-q02-anim.svg)

根据运动的对称性，可得粒子在磁场中的运动轨迹，如图所示带电粒子在磁场中运动时，由洛伦兹力提供向心力，有$qvB=\dfrac{m{v}^{2}}{r}$，整理得磁感应强度$B=\dfrac{mv}{qr}$，由于粒子的$\dfrac{mv}{q}$不变，因此磁感应强度$B$∝$\dfrac{1}{r}$，即$\dfrac{{B}_{\text{上}}}{{B}_{\text{下}}}=\dfrac{{r}_{\text{下}}}{{r}_{\text{上}}}$，由几何关系，可知△$O_{2}BC$与△$BO_{1}A$相似，则$\dfrac{{r}_{\text{下}}}{{r}_{\text{上}}}=\dfrac{{O}_{1}A}{BC}$，由勾股定理得$O_{1}A=\sqrt{{r}_{\text{下}}^{2}-{l}^{2}}=\dfrac{4l}{3}$，且$BC=AO=r_{\text{下}}-O_{1}A=\dfrac{l}{3}$，联立解得$\dfrac{{B}_{\text{上}}}{{B}_{\text{下}}}=\dfrac{{O}_{1}A}{BC}=\dfrac{4}{1}$，故选C。

![第 2 题解析配图。](assets/xx2/k09-q02-1.png)

**问答脚本**

本题考点：两个反向磁场中的轨迹衔接（公切点、速度方向）；对称性；相似三角形与勾股定理；$B\propto\dfrac1r$。
已知：两虚线 $a$、$b$ 间距 $l$，之间磁场向外；$b$ 上方磁场向里；粒子垂直 $a$ 从 $O$ 射入，最后又从 $O$ 射出；下方磁场中半径 $r_{下}=\dfrac53l$。
提问路线：
1. 问：粒子速率在两个磁场中变吗？上下两个磁场的 $B$ 与半径是什么关系？ → 期望：速率不变，$B=\dfrac{mv}{qr}$，所以 $\dfrac{B_上}{B_下}=\dfrac{r_下}{r_上}$。
2. 问：粒子从 $O$ 出发又回到 $O$，整个轨迹有什么对称性？在上方磁场中的圆心在哪条线上？ → 期望：轨迹关于过 $O$ 且垂直边界的直线对称，上方轨迹的圆心在这条对称线上。
3. 问：在下方磁场中，粒子垂直 $a$ 从 $O$ 射入，圆心 $O_1$ 在虚线 $a$ 上，$OO_1=r_{下}$。设粒子在虚线 $b$ 上的穿越点为 $B$，$B$ 在 $a$ 上的垂足为 $A$，则 $BA=l$。用勾股定理求 $O_1A$。 → 期望：$O_1A=\sqrt{r_{下}^2-l^2}=\dfrac43l$。
4. 问：$B$ 点到对称线（过 $O$ 的竖直线）的距离 $BC$ 是多少？ → 期望：$BC=OA=r_{下}-O_1A=\dfrac l3$。
5. 问：两段圆弧在 $B$ 点相切，上方圆心 $O_2$、$B$、$O_1$ 共线，$\triangle O_2BC\sim\triangle BO_1A$，半径之比是多少？$B_上:B_下$ 呢？ → 期望：$\dfrac{r_{下}}{r_{上}}=\dfrac{O_1A}{BC}=4$，$B_上:B_下=4:1$，选 C。
常见错误：
- 认为上方轨迹半径与下方相同。追问：两边磁感应强度相同吗？
- 不会利用对称性。追问：粒子最后回到出发点，上方的轨迹弧关于哪条线对称？
总结句：粒子在两个相邻磁场中穿越时，两段圆弧在边界点相切、两圆心与该点共线；利用对称性和相似三角形求半径比。

## 3. 计算 · 洛伦兹力演示仪中的电子

**题目**

（2026·云南高考）洛伦兹力演示仪示意图如图甲所示，玻璃泡处于励磁线圈产生的磁场中。玻璃泡内有一垂直磁场的竖直圆面，图乙为其放大示意图，其圆心为$O$、半径为$R$、最高点为$P$，区域内的磁场视为匀强磁场。电子枪将电子从$O$点正下方0.8$R$处的$S$点以速度$v$水平向左射出，电子在圆面内运动一段时间后到达$P$点。已知电子质量为$m$、电荷量为$e$，不计电子的重力和电子之间的相互作用。求：

（1）匀强磁场的磁感应强度大小和方向；

（2）电子从$S$点第一次到达$P$点所用的时间。

![第 3 题原题图。](assets/xx2/k09-q03-stem1.png)

**答案：（1）$\dfrac{10mv}{9eR}$　垂直纸面向里　（2）$\dfrac{9\pi R}{10v}$**

**解析**

（1）根据洛伦兹力提供向心力有

$evB=m\dfrac{{v}^{2}}{r}$

可得$r=\dfrac{mv}{eB}$

根据几何关系可得

$r=\dfrac{R+0.8R}{2}=\dfrac{9}{10}R$

联立可得$B=\dfrac{10mv}{9eR}$

根据左手定则可知磁感应强度方向垂直纸面向里。

（2）根据$T=\dfrac{2\pi r}{v}$结合$r=\dfrac{9}{10}R$可得电子做圆周运动的周期$T=\dfrac{9\pi R}{5v}$

电子从$S$点第一次到达$P$点转过的圆心角为180°，则电子从$S$点第一次到达$P$点所用的时间

$t=\dfrac{180°}{360°}\cdot T$

联立可得$t=\dfrac{9\pi R}{10v}$。

**问答脚本**

本题考点：由轨迹的两个端点求半径；左手定则（电子）判断磁场方向；时间与圆心角。
已知：圆面半径 $R$，最高点 $P$，电子从 $O$ 点正下方 $0.8R$ 处的 $S$ 点以速度 $v$ 水平向左射出，后到达 $P$ 点。
提问路线：
1. 问：电子在 $S$ 点速度水平，到达最高点 $P$。$S$ 和 $P$ 在同一竖直线上吗？$SP$ 有多长？ → 期望：在同一竖直线上，$SP=R+0.8R=1.8R$。
2. 问：电子在 $S$ 点速度水平，圆心在过 $S$ 的竖直线上；$P$ 也在这条线上，所以 $SP$ 是轨迹的什么？半径多大？ → 期望：$SP$ 是直径，$r=0.9R$。
3. 问：由 $evB=m\dfrac{v^2}{r}$ 求 $B$。 → 期望：$B=\dfrac{mv}{er}=\dfrac{10mv}{9eR}$。
4. 问：电子向左运动后向上偏到 $P$，在 $S$ 点受力向上，用左手定则（电子）判断磁场方向。 → 期望：垂直纸面向里。
5. 问：（2）从 $S$ 到 $P$ 转过多少度？周期和时间各多少？ → 期望：$180^\circ$；$T=\dfrac{2\pi r}{v}=\dfrac{9\pi R}{5v}$，$t=\dfrac T2=\dfrac{9\pi R}{10v}$。
常见错误：
- 把玻璃泡圆面的半径 $R$ 当成轨迹半径。追问：电子的轨迹圆和玻璃泡的圆面是同一个圆吗？
- 磁场方向判反。追问：电子带负电，左手四指应指向哪里？
总结句：速度在两端点都垂直于两点连线时，连线就是轨迹直径；电子用左手定则时四指指向运动的反方向。

## 4. 单选 · 同步加速器的磁场调节

**题目**

（2025·广东高考）某同步加速器简化模型如图所示，其中仅直通道$PQ$内有加速电场，三段圆弧内均有可调的匀强偏转磁场$B$。带电荷量为＋$q$、质量为$m$的离子以初速度$v_{0}$从$P$处进入加速电场后，沿顺时针方向在加速器内循环加速。已知加速电压为$U$，磁场区域中离子的偏转半径均为$R$。忽略离子重力和相对论效应，下列说法正确的是（　　）

- A．偏转磁场的方向垂直纸面向里
- B．第1次加速后，离子的动能增加了2$qU$
- C．第$k$次加速后，离子的速度大小变为$\dfrac{\sqrt{{m}^{2}{v}_{0}^{2}+kqUm}}{m}$
- D．第$k$次加速后，偏转磁场的磁感应强度大小应为$\dfrac{\sqrt{{m}^{2}{v}_{0}^{2}+2kqUm}}{qR}$

![第 4 题原题图。](assets/xx2/k09-q04-stem1.png)

**答案：D**

**解析**

直通道$PQ$有电势差为$U$的加速电场，离子带正电，离子沿顺时针方向运动，由左手定则可知，偏转磁场的磁感应强度方向垂直纸面向外，故A错误；根据题意，由动能定理可知，加速一次后，带电粒子的动能增量为$qU$，由于洛伦兹力不做功，则加速$k$次后，带电粒子的动能增量为$kqU$，加速$k$次后，由动能定理有$kqU=\dfrac{1}{2}mv^{2}-\dfrac{1}{2}m{v}_{0}^{2}$，解得$v=\sqrt{{v}_{0}^{2}+\dfrac{2kqU}{m}}=\dfrac{\sqrt{{m}^{2}{v}_{0}^{2}+2kqUm}}{m}$，故B、C错误；粒子在偏转磁场中运动的半径为$R$，则有$qvB=m\dfrac{{v}^{2}}{R}$，联立解得$B=\dfrac{mv}{qR}=\dfrac{\sqrt{{m}^{2}{v}_{0}^{2}+2kmqU}}{qR}$，故D正确。

**问答脚本**

本题考点：左手定则判断偏转磁场方向；每次加速动能增加 $qU$；动能定理与半径公式联立。
已知：离子 $+q$、$m$，初速度 $v_0$，沿顺时针方向循环，每次经过 $PQ$ 被加速一次，电压 $U$；偏转半径始终为 $R$。
提问路线：
1. 问：离子顺时针运动，在圆弧中受力指向圆心（指向内侧），用左手定则判断磁场方向。 → 期望：垂直纸面向外，A 错。
2. 问：每经过一次加速电场，动能增加多少？ → 期望：$qU$，B 错（不是 $2qU$）。
3. 问：第 $k$ 次加速后速度多大？ → 期望：$kqU=\dfrac12mv^2-\dfrac12mv_0^2$，$v=\dfrac{\sqrt{m^2v_0^2+2kqUm}}{m}$，C 错（少了 2）。
4. 问：半径保持 $R$，这时磁感应强度应为多少？ → 期望：$B=\dfrac{mv}{qR}=\dfrac{\sqrt{m^2v_0^2+2kqUm}}{qR}$，选 D。
常见错误：
- 磁场方向判反。追问：离子沿顺时针转，向心力指向哪里？
- 忽略初速度 $v_0$。追问：离子进入加速电场时有没有初速度？
总结句：同步加速器与回旋加速器不同，半径保持不变，速度增大时必须同步增大 $B$：$B=\dfrac{mv}{qR}$。
