## 1. 单选 · 磁场增强时矩形线框的感应电流

**题目**

（2026·浙江丽水期中）矩形导线框$ABCD$竖直放置，当垂直于线框平面向外的磁场的磁感应强度逐渐变大时（　　）

- A．线框中无感应电流
- B．线框中有感应电流，方向为$D$→$C$→$B$→$A$→$D$
- C．线框中有感应电流，方向为$D$→$A$→$B$→$C$→$D$
- D．无法确定线框中有无感应电流

![第 1 题原题图。](assets/xx2/k12-q01-stem1.png)

**答案：C**

**解析**

由楞次定律可知，磁通量增加，线框中感应电流的磁场阻碍原磁场磁通量增加，由安培定则可知感应电流方向为$D$→$A$→$B$→$C$→$D$。故选C。

**问答脚本**

本题考点：感应电流产生条件；楞次定律“增反减同”；安培定则。
已知：线框 $ABCD$ 在纸面内，$A$ 左上、$B$ 右上、$C$ 右下、$D$ 左下；磁场垂直纸面向外且增强。
提问路线（每次只问一个问题）：
1. 问：线框是闭合的，穿过它的磁通量变不变？有没有感应电流？ → 期望：磁通量增大，有感应电流，A、D 错。
2. 问：由“增反减同”，感应电流的磁场朝哪？ → 期望：与原磁场相反，垂直纸面向里。
3. 问：用安培定则，向里的磁场对应线框中顺时针还是逆时针电流？按字母写出方向。 → 期望：顺时针，即 $D\to A\to B\to C\to D$，选 C。
常见错误：
- 认为磁场方向向外，感应电流磁场也向外。追问：磁通量在增加还是减少？“增”对应“反”还是“同”？
- 顺时针按字母写反。追问：从 $D$ 出发顺时针，下一个点是 $A$ 还是 $C$？
总结句：楞次定律四步：原磁场方向 → 磁通量增减 → 感应磁场方向（增反减同）→ 安培定则得电流方向。

## 2. 多选 · 条形磁体旁三个圆环的磁通量与电流

**题目**

〔多选〕（2026·浙江湖州期中）如图所示，空间固定一条形磁体（其轴线水平），以下说法正确的是（　　）

- A．圆环a沿磁体轴线向右运动，靠近磁体N极时感应电流为顺时针方向（从左往右看）
- B．圆环b竖直下落时，穿过圆环b的磁通量不变
- C．圆环c经过磁体右边的位置2时磁通量最大
- D．圆环c经过位置2前后一小段时间内感应电流方向不变

![第 2 题原题图。](assets/xx2/k12-q02-stem1.png)

**答案：AD**

**解析**

当圆环a沿磁体轴线向右运动靠近磁体N极时，穿过圆环的磁通量向左且增大，则根据楞次定律可知，感应电流产生的感应磁场方向向右，所以再由安培定则可知，圆环a中的感应电流为顺时针方向（从左往右看），A正确；圆环b竖直下落时，穿过圆环b的磁通量减小，B错误；圆环c经过磁体右边的位置2时磁通量为0，C错误；圆环c经过位置2前后一小段时间内，磁通量先是向下减小，然后是向上增大，所以根据楞次定律和安培定则可知，感应电流均为顺时针方向（从上向下看），即圆环c经过位置2前后一小段时间内感应电流方向不变，D正确。

**问答脚本**

本题考点：条形磁体磁感线分布；磁通量变化；楞次定律与安培定则；对称位置磁通量为零。
已知：磁体 N 极在左、S 极在右，轴线水平；圆环 a 在左侧沿轴线向右靠近 N 极；圆环 b 在磁体下方竖直下落；圆环 c 水平放置，从位置 1 经位置 2（磁体中轴线的延长线所在高度，位于磁体右侧）落到位置 3。
提问路线：
1. 问：a 向右靠近 N 极，穿过 a 的磁场朝哪？磁通量怎样变？ → 期望：从 N 极出来向左，磁通量增大。
2. 问：感应磁场朝哪？从左往右看电流是顺时针还是逆时针？ → 期望：感应磁场向右；从左往右看为顺时针，A 对。
3. 问：b 在磁体下方竖直下落，离磁体越来越远，磁通量变不变？ → 期望：减小，B 错。
4. 问：c 在位置 2 时环面与磁感线是什么关系？磁通量是多少？ → 期望：磁感线在该处水平，与环面平行，磁通量为零，不是最大，C 错。
5. 问：经过 2 之前和之后，磁通量的方向和变化分别怎样？感应电流方向变不变？ → 期望：之前向下减小、之后向上增大，感应磁场都向下，电流方向不变，D 对。选 AD。
常见错误：
- 认为 c 在位置 2 磁通量最大。追问：此处磁感线是穿过环面还是沿着环面？
- 认为经过 2 前后电流反向。追问：“向下减小”和“向上增大”，感应磁场方向分别是什么？
总结句：磁通量从一个方向减小到零再从反方向增大，感应电流方向不变。

## 3. 单选 · 线框进出磁场的电流与安培力方向

**题目**

如图所示，一个有界匀强磁场区域，磁场方向垂直纸面向外，一个矩形闭合导线框$abcd$，沿纸面由位置甲（左）匀速运动到位置乙（右），则（　　）

- A．导线框进入磁场时，感应电流方向为$a$→$b$→$c$→$d$→$a$
- B．导线框离开磁场时，感应电流方向为$a$→$d$→$c$→$b$→$a$
- C．导线框离开磁场时，受到的安培力方向水平向右
- D．导线框进入磁场时，受到的安培力方向水平向左

![第 3 题原题图。](assets/xx2/k12-q03-stem1.png)

**答案：D**

**解析**

由右手定则可判断出导线框进入磁场时，感应电流方向为$a$→$d$→$c$→$b$→$a$，导线框离开磁场时，感应电流方向为$a$→$b$→$c$→$d$→$a$。由左手定则可判断导线框进入磁场时，受到的安培力水平向左，导线框离开磁场时受到的安培力水平向左，故D正确。

**问答脚本**

本题考点：右手定则（或楞次定律）判断感应电流方向；左手定则判断安培力；“来拒去留”。
已知：磁场垂直纸面向外，线框 $abcd$（$a$ 左上、$b$ 左下、$c$ 右下、$d$ 右上）从左向右匀速通过磁场区域。
提问路线：
1. 问：进入磁场时，哪条边在切割磁感线？用右手定则判断这条边中电流方向。 → 期望：右边 $dc$ 切割，电流由 $d$ 流向 $c$，整个线框中为 $a\to d\to c\to b\to a$，A 错。
2. 问：离开磁场时，哪条边在切割？电流方向怎样？ → 期望：左边 $ab$ 切割，电流方向为 $a\to b\to c\to d\to a$，B 错。
3. 问：进入和离开时，安培力朝哪？可以用“来拒去留”快速判断吗？ → 期望：都阻碍相对运动，都向左，C 错、D 对。选 D。
常见错误：
- 离开时认为安培力向右“拉”线框。追问：安培力阻碍线框的运动还是帮助线框运动？
- 右手定则用成左手。追问：判断切割产生的电流方向用哪只手？
总结句：线框进出磁场时感应电流方向相反，但安培力都阻碍运动（来拒去留）。

## 4. 多选 · 转动铜盘中的电流方向

**题目**

〔多选〕如图所示，竖直向下的匀强磁场中，有一个带铜轴的铜盘，用铜刷把盘边缘和轴连接，外接一电流表，当铜盘按图示匀速转动，则（　　）

- A．电流表 G 中有$a$→$b$的电流
- B．电流表 G 中有$b$→$a$的电流
- C．盘面磁通量不变，不产生感应电流
- D．有从盘边缘向盘中心的电流

![第 4 题原题图。](assets/xx2/k12-q04-stem1.png)

**答案：BD**

**解析**

沿铜盘半径方向的“铜棒”切割磁感线，由右手定则可判定B、D正确。

**问答脚本**

本题考点：转动圆盘等效为无数沿半径的导体棒切割磁感线；右手定则；外电路电流方向。
已知：磁场竖直向下，铜盘按图中箭头方向转动，铜刷连盘边缘和轴，经电流表 G（两端为 $a$、$b$）连成回路。
提问路线：
1. 问：圆盘的磁通量不变，为什么还会有电流？可以把圆盘看成什么？ → 期望：看成无数根沿半径的“铜棒”，转动时切割磁感线产生电动势，C 错。
2. 问：用右手定则判断一根“铜棒”中电流方向：从中心流向边缘，还是从边缘流向中心？ → 期望：从边缘流向中心，D 对。
3. 问：铜盘相当于电源，电流从中心（轴）流出到外电路，经过电流表是 $a\to b$ 还是 $b\to a$？ → 期望：按图中接线为 $b\to a$，B 对。选 BD。
常见错误：
- 认为磁通量不变就没有电流。追问：导体切割磁感线也能产生感应电动势吗？
- 外电路方向判反。追问：电源内部电流从负极流向正极，盘中心是正极还是负极？
总结句：转动圆盘相当于沿半径的导体棒切割磁感线，用右手定则定方向。

## 5. 单选 · 电吉他线圈中的感应电流

**题目**

电吉他的工作原理是在琴身上装有线圈，线圈附近被磁化的琴弦振动时，会使线圈中的磁通量发生变化，从而产生感应电流，再经信号放大器放大后传到扬声器。其原理简化示意图如图所示，当图中琴弦向右靠近线圈时（　　）

- A．穿过线圈的磁通量减小
- B．线圈中不产生感应电流
- C．琴弦受到向左的力的作用
- D．线圈有扩张趋势

![第 5 题原题图。](assets/xx2/k12-q05-stem1.png)

**答案：C**

**解析**

当题图中琴弦向右靠近线圈时，线圈中磁通量增大，从而导致线圈中产生感应电流，故A、B错误；根据楞次定律可知，线圈产生的感应电流会阻碍琴弦向右靠近线圈，即琴弦会受到向左的力的作用，并且线圈会有收缩趋势，故C正确，D错误。

**问答脚本**

本题考点：磁通量变化产生感应电流；楞次定律推论“来拒去留”“增缩减扩”。
已知：琴弦被磁化，向右靠近线圈。
提问路线：
1. 问：琴弦靠近线圈，穿过线圈的磁通量怎样变？有感应电流吗？ → 期望：增大，有感应电流，A、B 错。
2. 问：由“来拒去留”，线圈对靠近的琴弦有什么作用？琴弦受力朝哪？ → 期望：阻碍靠近，琴弦受到向左的力，C 对。
3. 问：磁通量增大时，线圈有扩张还是收缩的趋势？ → 期望：收缩趋势（增缩减扩），D 错。选 C。
常见错误：
- 认为线圈扩张。追问：线圈面积变大，磁通量会更大还是更小？楞次定律要阻碍的是什么？
总结句：楞次定律的推论：来拒去留，增缩减扩——都是在阻碍磁通量的变化。

## 6. 单选 · 磁体靠近或远离悬挂铝环

**题目**

（2026·浙江台金七校联盟期中）如图所示，用绳吊起一个铝环，用条形磁体的N极去靠近或者远离铝环，下列判断正确的是（　　）

- A．磁体向右靠近铝环时，铝环向左摆动
- B．使铝环摆动的力是磁场对铝环的安培力
- C．若磁体向左远离铝环，铝环一定不会摆动
- D．磁体向右靠近铝环时，从右向左看铝环产生逆时针的感应电流

![第 6 题原题图。](assets/xx2/k12-q06-stem1.png)

**答案：B**

**解析**

根据楞次定律可知，磁体向右靠近铝环时，铝环向右摆动，选项A错误；磁体靠近或者远离铝环时，穿过铝环的磁通量发生变化从而在铝环中产生感应电流，从而受到安培力作用，使铝环摆动的力是磁场对铝环的安培力，选项B正确；根据楞次定律可知，若磁体向左远离铝环，铝环一定向左摆动，选项C错误；磁体向右靠近铝环时，穿过铝环的磁通量向右增加，根据楞次定律可知，从右向左看铝环产生顺时针的感应电流，选项D错误。

**问答脚本**

本题考点：楞次定律推论“来拒去留”；感应电流在磁场中受安培力；感应电流方向。
已知：磁体 N 极朝右，铝环挂在磁体右侧。
提问路线：
1. 问：磁体向右靠近铝环，由“来拒去留”，铝环向哪摆？ → 期望：远离磁体，向右摆，A 错。
2. 问：铝环摆动是因为受到了什么力？ → 期望：铝环中有感应电流，受到磁场的安培力，B 对。
3. 问：磁体向左远离，铝环会怎样？ → 期望：被“留”，向左摆，C 错。
4. 问：靠近时穿过铝环的磁场朝哪、怎样变？感应磁场朝哪？从右向左看电流方向？ → 期望：向右增大，感应磁场向左；从右向左看为顺时针，D 错。选 B。
常见错误：
- 认为铝环被吸过去。追问：靠近时楞次定律要阻碍的是靠近还是远离？
- 从右向左看方向判反。追问：感应磁场向左，是背离还是指向站在右侧的观察者？用安培定则对照一下，背离观察者的磁场对应观察者看到的顺时针电流。
总结句：磁体靠近，环被推开；磁体远离，环被拉住；推拉的力就是感应电流受到的安培力。

## 7. 单选 · 带电圆环转动对外线圈的影响

**题目**

（2026·浙江湖州期末）如图所示，一带正电的圆形线圈A沿顺时针方向转动，另一导体线圈B跟它在同一水平面内，下列说法正确的是（　　）

- A．穿过线圈B的磁场方向垂直于纸面向外
- B．若线圈A匀速转动，线圈B中产生顺时针方向的感应电流
- C．若线圈A加速转动，线圈B中产生逆时针方向的感应电流
- D．若线圈A减速转动，线圈B中产生逆时针方向的感应电流

![第 7 题原题图。](assets/xx2/k12-q07-stem1.png)

**答案：C**

**解析**

线圈A中的电流方向为顺时针方向，由安培定则可知，线圈B中的磁场方向垂直于纸面向里，故A错误；若线圈A匀速转动，线圈B中的磁通量不变，则不会产生感应电流，故B错误；若线圈A加速转动，线圈B中的磁场方向垂直于纸面向里且磁通量增大，根据楞次定律推论“增反减同”可知，线圈B中产生逆时针方向的感应电流，故C正确；若线圈A减速转动，穿过线圈B的磁场方向垂直于纸面向里且磁通量减小，根据楞次定律推论“增反减同”可知，线圈B中产生顺时针方向的电流，故D错误。

**问答脚本**

本题考点：带电体转动形成等效电流；安培定则；楞次定律；匀速时磁通量不变。
已知：A 带正电，顺时针转动，B 在同一平面内且包围 A。
提问路线：
1. 问：带正电的 A 顺时针转动，形成的等效电流沿什么方向？在 A 内部和 B 包围的区域，磁场主要朝哪？ → 期望：顺时针电流；线圈内部磁场垂直纸面向里，穿过 B 的净磁通量向里，A 错。
2. 问：A 匀速转动，电流和磁通量变吗？B 中有感应电流吗？ → 期望：不变，没有感应电流，B 错。
3. 问：A 加速转动，穿过 B 的磁通量怎样变？B 中感应电流方向？ → 期望：向里增大，感应磁场向外，B 中逆时针，C 对。
4. 问：A 减速转动呢？ → 期望：向里减小，感应磁场向里，B 中顺时针，D 错。选 C。
常见错误：
- 把转动方向直接当成负电荷电流。追问：正电荷运动方向与电流方向相同还是相反？
- 认为匀速转动也有感应电流。追问：感应电流的条件是磁通量存在还是磁通量变化？
总结句：转动的带电体相当于环形电流，转速变化才会使磁通量变化、产生感应电流。

## 8. 单选 · 关窗时金属边框中的感应电流

**题目**

（2026·北京朝阳区期末）

北京某学校教室墙上有一扇朝北的平开玻璃窗，窗扇由玻璃加闭合矩形铝合金边框构成，如图所示，窗扇的转轴为竖直方向，另一侧装有开（关）窗手柄。假设窗扇已经向外（北）推开（开角小于90°），某同学站在室内面向窗户水平拉动关窗手柄，将窗扇关闭的过程中，下列说法正确的是（　　）

- A．窗扇金属边框中没有感应电流
- B．从关窗者的角度看，窗扇金属边框中的感应电流方向是逆时针方向
- C．从关窗者的角度看，窗扇金属边框中的感应电流方向是顺时针方向
- D．穿过矩形窗扇的地磁场的磁通量减小

![第 8 题原题图。](assets/xx2/k12-q08-stem1.png)

**答案：B**

**解析**

北京市在北半球，地磁场的水平分量由南向北，将窗扇关闭的过程中，穿过窗扇金属边框的磁通量逐渐增大，根据楞次定律，穿过窗扇金属边框的磁通量增大时，从关窗者的角度看，窗扇金属边框中产生的感应电流的方向为逆时针。故选B。

**问答脚本**

本题考点：地磁场水平分量方向；窗扇转动时磁通量的变化；楞次定律。
已知：北京在北半球，地磁场水平分量由南指向北；窗朝北，关窗过程中窗扇由打开（与墙面成一定角度）转到与墙面平行（垂直于南北方向），关窗者在室内面向北。
提问路线：
1. 问：地磁场水平分量朝哪个方向？ → 期望：由南指向北。
2. 问：关窗时窗扇平面与南北方向的夹角怎样变？穿过窗扇的磁通量怎样变？ → 期望：窗扇逐渐垂直于南北方向，磁通量增大，D 错，有感应电流，A 错。
3. 问：原磁场（水平分量）由南向北，即背离关窗者向前；磁通量增大，感应磁场朝哪？ → 期望：由北向南，指向关窗者。
4. 问：感应磁场指向关窗者，用安培定则，从关窗者的角度看电流是顺时针还是逆时针？ → 期望：逆时针，B 对。选 B。
常见错误：
- 认为窗扇关闭时磁通量减小。追问：关好时窗扇与地磁场水平分量垂直还是平行？
- 忽略竖直分量的影响。追问：窗扇是竖直的，地磁场的竖直分量穿过窗扇吗？
总结句：先找出穿过线圈的那部分磁场（这里是地磁场水平分量），再判断磁通量增减，最后用楞次定律。

## 9. 多选 · 下落磁铁对导轨上金属棒的作用

**题目**

〔多选〕（2026·云南玉溪期末）如图所示，金属棒$ab$、$cd$放在水平导轨上，条形磁铁自由下落，在加速接近导轨时，金属棒$ab$、$cd$未滑动，下列说法正确的是（　　）

- A．磁铁加速度小于$g$
- B．金属棒$ab$受到向右的摩擦力
- C．导轨对金属棒的支持力大于金属棒的重力
- D．金属棒$cd$中有$c$指向$d$的感应电流

![第 9 题原题图。](assets/xx2/k12-q09-stem1.png)

**答案：ACD**

**解析**

当条形磁铁从高处下落接近回路时，穿过回路的磁通量增加，根据楞次定律可知感应电流的磁场总是阻碍原磁通量的变化，磁铁受到向上的磁场力作用，所以合力小于重力，磁铁的加速度一定小于$g$，故A正确；根据楞次定律可知感应电流的磁场总是阻碍原磁通量的变化，可知金属棒$ab$、$cd$将互相靠拢，金属棒$ab$有向右运动趋势，故其受到向左的摩擦力，故B错误；根据楞次定律可知感应电流的磁场总是阻碍原磁通量的变化，磁铁受到向上的磁场力作用，金属棒受到向下的作用力，故导轨对金属棒的支持力大于金属棒的重力，故C正确；根据楞次定律可知感应电流产生磁场方向与原磁场方向相反，金属棒$cd$电流从$c$指向$d$，故D正确。

**问答脚本**

本题考点：楞次定律推论（来拒去留、增缩减扩）；感应电流方向；受力分析。
已知：条形磁铁 N 极向下，自由下落加速接近导轨，$ab$ 在左、$cd$ 在右，两棒未滑动。
提问路线：
1. 问：磁铁靠近回路，回路对磁铁有什么作用？磁铁的加速度与 $g$ 比较？ → 期望：阻碍其靠近，对磁铁有向上的力，加速度小于 $g$，A 对。
2. 问：磁通量增大，两根金属棒有靠拢还是远离的趋势？$ab$ 受到的摩擦力朝哪？ → 期望：靠拢（增缩），$ab$ 有向右运动的趋势，摩擦力向左，B 错。
3. 问：磁铁受向上的力，由牛顿第三定律回路受什么方向的力？支持力与重力比较？ → 期望：回路受向下的力，支持力大于重力，C 对。
4. 问：向下的磁通量增大，感应磁场朝哪？$cd$ 中电流方向？ → 期望：感应磁场向上，回路中电流从上往下看逆时针，$cd$ 中由 $c$ 流向 $d$，D 对。选 ACD。
常见错误：
- 摩擦力方向弄反。追问：$ab$ 想往哪边动？静摩擦力与运动趋势方向相同还是相反？
- 认为支持力不变。追问：磁铁与回路之间的力是相互作用力吗？
总结句：磁铁靠近闭合回路时：磁铁受阻力，回路“收缩”并被向下压；用楞次定律推论可以快速判断。

## 10. 多选 · 电梯电磁缓冲装置

**题目**

〔多选〕（2026·浙江温州期中）高层建筑中的电梯系统安装了电磁缓冲装置。在电梯轿厢底部对称安装了8个永磁铁，磁铁S极均朝上，电梯井道内壁上铺设若干金属线圈，当电梯轿厢超速下降时会迅速启动缓冲系统，使线圈立即闭合。当电梯轿厢超速下降到如图所示位置时，下列说法正确的是（　　）

- A．轿厢上下方线圈对轿厢均有阻碍作用
- B．轿厢上方与下方金属线圈中感应电流方向相同
- C．上、下方线圈都有扩张的趋势
- D．上方线圈有扩张的趋势，下方线圈有收缩的趋势

![第 10 题原题图。](assets/xx2/k12-q10-stem1.png)

**答案：AD**

**解析**

电梯轿厢底部安装了永磁铁，上、下方线圈在电梯轿厢超速下降时会产生感应电流，根据楞次定律可知，从上往下看，上方线圈电流方向为顺时针，下方线圈电流方向为逆时针，B错误；上、下方线圈均对轿厢有阻碍作用，轿厢向下运动，远离上方线圈，上方线圈有扩张的趋势，轿厢靠近下方线圈，下方线圈有收缩的趋势，A、D正确，C错误。

**问答脚本**

本题考点：楞次定律推论“来拒去留”“增缩减扩”；感应电流方向。
已知：轿厢底部磁铁 S 极朝上（N 极朝下），轿厢超速下降，位于上方线圈和下方线圈之间。
提问路线：
1. 问：上方和下方线圈中都有感应电流吗？它们对轿厢的作用都是阻碍下降吗？ → 期望：都有，都阻碍轿厢相对运动，A 对。
2. 问：轿厢远离上方线圈、靠近下方线圈，两个线圈的磁通量分别怎样变？ → 期望：上方减小，下方增大。
3. 问：磁通量一个增一个减，感应电流方向相同吗？ → 期望：相反（上方顺时针、下方逆时针，从上往下看），B 错。
4. 问：由“增缩减扩”，上、下方线圈分别有什么趋势？ → 期望：上方扩张，下方收缩，D 对、C 错。选 AD。
常见错误：
- 认为两个线圈电流方向相同。追问：两个线圈的磁通量都在增大吗？
- 认为远离的线圈不起阻碍作用。追问：“来拒去留”中的“留”是不是阻碍作用？
总结句：靠近的线圈“拒”且收缩，远离的线圈“留”且扩张，都在阻碍相对运动。

## 11. 单选 · 变化电流旁线框的磁通量与受力

**题目**

（2026·浙江嘉兴期末）如图甲所示，一长直导线与闭合金属线框位于同一竖直平面内，长直导线中的电流$i$随时间$t$的变化关系如图乙所示（以水平向右为电流的正方向），则在0~$t_{2}$时间内，下列说法正确的是（　　）

- A．穿过线框的磁通量先增大后减小
- B．线框中始终产生顺时针方向的感应电流
- C．线框先有扩张的趋势后有收缩的趋势
- D．线框所受安培力的合力方向始终向上

![第 11 题原题图。](assets/xx2/k12-q11-stem1.png)

**答案：C**

**解析**

长直导线中的电流先减小后增大，所以穿过线框的磁通量先减小后增大，A错误；0~$t_{1}$时间内电流方向水平向右且减小，穿过线框的磁场向外，磁通量减小，由楞次定律可知线框中产生逆时针方向的感应电流；$t_{1}$~$t_{2}$时间内电流方向水平向左且增大，穿过线框的磁场向里，磁通量增大，由楞次定律可知线框中产生逆时针方向的感应电流，B错误；穿过线框的磁通量先减小后增大，由“增缩减扩”可知，线框先有扩张的趋势后有收缩的趋势，C正确；由左手定则可知0~$t_{1}$时间内线框所受安培力的合力方向向下，$t_{1}$~$t_{2}$时间内线框所受安培力的合力方向向上，D错误。

**问答脚本**

本题考点：直线电流磁场分布；电流变化引起磁通量变化；楞次定律；“增缩减扩”；安培力合力方向。
已知：线框在长直导线上方同一竖直平面内；电流以向右为正，$0\sim t_1$ 由 $i_0$ 减小到 0，$t_1\sim t_2$ 反向增大到 $-i_0$。
提问路线：
1. 问：电流先减小后反向增大，穿过线框的磁通量怎样变？ → 期望：先减小后增大，A 错。
2. 问：$0\sim t_1$ 电流向右、导线上方磁场朝哪？磁通量减小，感应电流方向？ → 期望：向外减小，感应磁场向外，逆时针。
3. 问：$t_1\sim t_2$ 电流向左，上方磁场朝哪？磁通量增大，感应电流方向？ → 期望：向里增大，感应磁场向外，仍然逆时针，所以 B 错。
4. 问：由“增缩减扩”，线框的形变趋势？ → 期望：先扩张后收缩，C 对。
5. 问：线框所受安培力合力方向始终向上吗？ → 期望：磁通量减小时线框被吸向导线（向下），增大时被推离（向上），D 错。选 C。
常见错误：
- 认为电流方向改变感应电流方向也改变。追问：两段时间的感应磁场方向分别是什么？
- 合力方向判断错误。追问：靠近导线的下边和远离导线的上边，哪条边处磁场强？受力大？
总结句：感应电流方向看感应磁场方向，不看原电流方向；磁通量减小时线框向导线靠拢、增大时远离。

## 12. 多选 · 人工心脏无线充电线圈

- 认为受电线圈扩张。追问：磁通量增大时，面积变大会让磁通量更大还是更小？

## 13. 多选 · 摆动磁铁下方静止圆环的受力

**题目**

〔多选〕（2026·江苏南京期中）如图所示，用轻绳将一条形磁铁竖直悬挂于$O$点，在其正下方的水平绝缘桌面上放置一铜质圆环。现将磁铁从$A$处由静止释放，经过$B$、$C$到达最低处$D$，再摆到左侧最高处$E$，圆环始终保持静止。下列说法正确的是（　　）

- A．磁铁在$A$、$E$两处的重力势能相等
- B．磁铁从$A$摆到$D$的过程中，圆环给桌面的压力大于圆环的重力
- C．磁铁从$A$到$D$和从$D$到$E$的过程中，圆环受到摩擦力方向相同
- D．磁铁从$A$到$D$的过程中，圆环中产生逆时针方向的电流（从上往下看）

![第 13 题原题图。](assets/xx2/k12-q13-stem1.png)

**答案：BC**

**解析**

由于有部分机械能转化为电能，故磁铁在$A$、$E$两处的重力势能不相等，故A错误；磁铁从$A$摆到$D$的过程中，圆环中产生的感应电流有使圆环远离磁铁的趋势，故给桌面的压力大于圆环受到的重力，故B正确；由楞次定律的推论“来拒去留”可知，磁铁从$A$到$D$和从$D$到$E$的过程中，圆环受到摩擦力方向均向右，故C正确；磁铁从$A$到$D$的过程中，圆环中的磁场向上且磁通量增大，根据“增反减同”可判断产生顺时针方向的电流（从上往下看），故D错误。

**问答脚本**

本题考点：电磁感应中的能量转化；来拒去留；摩擦力方向；楞次定律判断电流方向。
已知：磁铁 N 极在上、S 极在下（下端靠近圆环），从右侧 $A$ 处释放，经 $B$、$C$ 到最低点 $D$，再摆到左侧最高处 $E$；圆环始终静止。
提问路线：
1. 问：摆动过程中圆环中产生了电能，磁铁的机械能守恒吗？$A$、$E$ 两处重力势能相等吗？ → 期望：机械能减少，$E$ 处低于 $A$ 处，A 错。
2. 问：从 $A$ 到 $D$ 磁铁靠近圆环，圆环有远离磁铁（向下、向左）的趋势吗？对桌面的压力与重力比较？ → 期望：圆环被向下推，压力大于重力，B 对。
3. 问：从 $A$ 到 $D$（靠近，从右往左）和从 $D$ 到 $E$（远离，向左），圆环受到磁铁的水平作用分别朝哪？摩擦力朝哪？ → 期望：靠近时被向左推，远离时被向左拉，水平作用都向左，摩擦力都向右，C 对。
4. 问：从 $A$ 到 $D$ 穿过圆环的磁场朝哪（S 极在下）？怎样变？从上往下看感应电流方向？ → 期望：磁场向上（磁感线进入 S 极）且增大，感应磁场向下，从上往下看为顺时针，D 错。选 BC。
常见错误：
- 认为摩擦力方向相反。追问：远离时“留”，圆环被磁铁往哪边拉？
- 把 S 极下方的磁场判成向下。追问：磁感线从 N 极出发回到 S 极，在 S 极附近磁感线是进入还是离开 S 极？
总结句：来拒去留：靠近时推、远离时拉，作用方向都跟着磁铁的运动方向；能量上，机械能部分转化为电能。
