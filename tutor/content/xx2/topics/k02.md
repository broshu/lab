## 1. 多选 · 通电圆线圈在磁铁 N 极旁的运动

**题目**

〔多选〕把轻质的导电线圈用绝缘细线挂在磁铁的N极附近，磁铁的轴线穿过线圈中心且与线圈平面在同一平面内，如图所示。当线圈通过图示电流时，线圈将（　　）

- A．发生转动同时离开磁铁
- B．发生转动同时靠近磁铁
- C．静止不动
- D．从上往下看顺时针转动

![第 1 题原题图。](assets/xx2/k02-q01-stem1.png)

**答案：BD**

**解析**

**等效法：** 把环形电流看成一个小磁针（小磁体）。由安培定则（右手螺旋定则），图示电流方向下，线圈朝纸外的一面相当于 S 极、朝纸里的一面相当于 N 极。

线圈的“S 极面”要转向磁铁的 N 极（异名磁极相互吸引），所以线圈会转动——从上往下看沿顺时针方向转动；转到 S 极面正对 N 极后，异名磁极相互吸引，线圈同时靠近磁铁。

故选 **BD**。

**问答脚本**

本题考点：环形电流的等效磁体（安培定则）；磁极间相互作用；判断“转动 + 平动”。
已知：线圈平面在纸面内，磁铁轴线在线圈平面内并穿过线圈中心，N 极靠近线圈；图中线圈左侧电流向上，即从纸外看电流沿顺时针方向。
提问路线（每次只问一个问题）：
1. 问：一个通电圆线圈可以等效成什么？ → 期望：一个小磁针（小磁体），两个面分别是 N 极和 S 极。
2. 问：从纸外看电流顺时针，用安培定则，朝纸外的那一面是 N 极还是 S 极？ → 期望：朝纸外的一面是 S 极，朝纸里的一面是 N 极。
3. 问：现在线圈的两个磁极面都没有对着磁铁的 N 极，线圈会怎样运动才能让异名磁极相对？ → 期望：线圈绕悬线转动，让 S 极面转向磁铁的 N 极；从上往下看是顺时针转动。
4. 问：转到 S 极面正对 N 极以后，线圈和磁铁之间是吸引还是排斥？所以选哪两项？ → 期望：异名磁极相互吸引，线圈同时靠近磁铁，选 BD。
常见错误：
- 认为线圈静止不动（选 C）。追问：线圈的磁场方向（垂直纸面）和磁铁的磁场方向（水平）一致吗？小磁针放在这样的磁场里会转吗？
- 认为线圈离开磁铁（选 A）。追问：转过来以后正对 N 极的是哪个极？异名磁极吸引还是排斥？
- 安培定则用错：四指、拇指对应搞反。追问：环形电流用安培定则时，四指弯曲方向表示什么？拇指指向什么？
总结句：环形电流等效为小磁体，先转动使异名磁极相对，再相互吸引；或用电流元法分段判断受力。

## 2. 单选 · 两垂直导线的相互作用

**题目**

两条导线互相垂直，如图所示，但相隔一小段距离，其中$AB$是固定的，$CD$能自由活动，当直流电流按图示方向通过两条导线时，导线$CD$将（从纸外向纸内看）（　　）

- A．顺时针方向转动，同时靠近导线$AB$
- B．逆时针方向转动，同时靠近导线$AB$
- C．逆时针方向转动，同时远离导线$AB$
- D．顺时针方向转动，同时远离导线$AB$

![第 2 题原题图。](assets/xx2/k02-q02-stem1.png)

**答案：B**

**解析**

**结论法：** 两根不平行的直线电流相互作用时，有转到相互平行且电流方向相同的趋势。

$AB$ 中电流向上，$CD$ 中电流向右。$CD$ 逆时针转过 $90^\circ$ 后电流也向上，与 $AB$ 同向，所以 $CD$ 逆时针转动；转到接近平行时，同向电流相互吸引，$CD$ 同时靠近 $AB$。

故选 **B**。

**问答脚本**

本题考点：两不平行直线电流相互作用的规律（转向平行、同向吸引）。
已知：$AB$ 固定，电流向上；$CD$ 可自由转动和移动，电流向右；从纸外向纸内看。
提问路线：
1. 问：两根平行导线，电流同向时相互吸引还是排斥？反向时呢？ → 期望：同向吸引，反向排斥。
2. 问：两根不平行的电流，相互作用后有转到什么状态的趋势？ → 期望：转到相互平行且电流方向相同。
3. 问：$CD$ 电流向右，要变成与 $AB$ 同向（向上），它应顺时针转还是逆时针转？ → 期望：逆时针转 $90^\circ$。
4. 问：转到接近平行、电流同向时，$CD$ 会靠近还是远离 $AB$？选哪项？ → 期望：同向吸引，靠近，选 B。
可用的分段验证（学生不信结论时用）：$AB$ 中电流向上，它在左侧产生的磁场垂直纸面向外，在右侧产生的磁场垂直纸面向里；$CD$ 电流向右，由左手定则，左半段受力沿纸面向下，右半段受力沿纸面向上，所以 $CD$ 逆时针转动。
常见错误：
- 认为同时远离。追问：转到平行后电流是同向还是反向？同向电流吸引还是排斥？
- 转向判反。追问：电流从向右转到向上，箭头是顺时针转还是逆时针转？
总结句：两不平行电流有转到平行且同向的趋势，转到同向后相互吸引。

## 3. 单选 · 条形磁铁上方通电导线的运动

**题目**

条形磁铁固定在水平面上，其正上方有一根通电导线，电流方向向左。不考虑导线的重力，在条形磁铁产生的磁场的作用下，关于导线运动情况的说法正确的是（　　）

- A．从上向下看逆时针转90°，同时向上运动
- B．从上向下看逆时针转90°，同时向下运动
- C．从上向下看顺时针转90°，同时向下运动
- D．从上向下看顺时针转90°，同时向上运动

![第 3 题原题图。](assets/xx2/k02-q03-stem1.png)

**答案：C**

**解析**

**电流元法：** 把导线分成左、右两半分析。

- 左半段在 N 极上方，磁感线从 N 极向上穿出（斜向左上），电流向左，由左手定则，左半段受力垂直纸面向里；
- 右半段在 S 极上方，磁感线斜向右下进入 S 极，右半段受力垂直纸面向外。

所以从上向下看导线顺时针转动。转过 $90^\circ$ 时电流垂直纸面向里，导线所在处（磁铁中点正上方）的磁场水平向右（N→S），由左手定则受力竖直向下，导线同时向下运动。

故选 **C**。

**问答脚本**

本题考点：条形磁铁磁场分布；电流元法；特殊位置法（转过 $90^\circ$ 后再判断受力）。
已知：磁铁 N 极在左、S 极在右，导线在磁铁正上方，电流向左，不计导线重力。
提问路线：
1. 问：条形磁铁上方，左半边（N 极上方）和右半边（S 极上方）的磁感线大致朝什么方向？ → 期望：左半边从 N 极出来斜向左上，右半边斜向右下进入 S 极。
2. 问：电流向左，用左手定则，左半段和右半段导线分别受什么方向的力？ → 期望：左半段受力垂直纸面向里，右半段受力垂直纸面向外。
3. 问：两端受力一里一外，从上往下看导线怎样转？ → 期望：顺时针转动。
4. 问：转过 $90^\circ$ 后电流方向朝哪？此处（磁铁中点正上方）磁场朝哪？导线受力朝哪？ → 期望：电流垂直纸面向里，磁场水平向右（N→S），安培力竖直向下，导线同时向下运动，选 C。
常见错误：
- 只用中点磁场判断，得出“只受竖直力不转动”。追问：导线两端所在处的磁场方向和中点一样吗？要不要分段看？
- 转向判反。追问：左端向纸里、右端向纸外，从上往下看是顺时针还是逆时针？
- 向下/向上判反。追问：转过 $90^\circ$ 后电流垂直纸面向里，磁场向右，左手定则拇指指向哪？
总结句：判断通电导线在非匀强磁场中的运动：先用电流元法看转动，再用特殊位置法看平动。

## 4. 多选 · 电流天平测磁感应强度

**题目**

〔多选〕（2026·浙江湖州期末）如图，天平的右臂下面挂一个$N$匝矩形线圈，底边$bc$长为$L$。线圈的下部悬在匀强磁场中，磁场方向垂直于纸面。当线圈中通有大小为$I$，方向如图所示的电流时，在天平两边加上质量分别为$m_{1}$、$m_{2}$的砝码，天平平衡；当电流反向且大小变为2$I$时，右边再加上质量为$m$的砝码后，天平重新平衡。若重力加速度为$g$，则（　　）

- A．磁感应强度方向垂直于纸面向里
- B．磁感应强度方向垂直于纸面向外
- C．磁感应强度大小为$\dfrac{mg}{3NIL}$
- D．磁感应强度大小为$\dfrac{({m}_{1}-{m}_{2})g}{NIL}$

![第 4 题原题图。](assets/xx2/k02-q04-stem1.png)

**答案：BC**

**解析**

**第一步：判断磁场方向。** 电流反向后要在右边**加**砝码才能重新平衡，说明电流反向后线圈受的安培力**向上**（右盘变轻）。反向后 $bc$ 中电流向左，由左手定则，磁场垂直纸面向外。A 错，B 对。

**第二步：求 $B$。** 设线圈质量为 $m_0$。

电流反向前（安培力向下）：$m_1g=m_2g+m_0g+NBIL$；

电流反向后（安培力向上，大小 $2NBIL$）：$m_1g=m_2g+m_0g+mg-2NBIL$。

两式相减：$3NBIL=mg$，$B=\dfrac{mg}{3NIL}$。C 对，D 错（不知道线圈质量，不能用 $m_1-m_2$ 求）。

故选 **BC**。

**问答脚本**

本题考点：左手定则；电流天平；用两次平衡消去未知量（线圈质量）。
已知：右臂挂 $N$ 匝线圈，底边 $bc$ 长 $L$ 在磁场中，开始电流为 $I$（$bc$ 中向右），左盘 $m_1$、右盘 $m_2$ 平衡；电流反向变为 $2I$ 后，右盘再加 $m$ 才平衡。
提问路线：
1. 问：电流反向后要往右盘加砝码才平衡，说明这时线圈受的安培力向上还是向下？ → 期望：右边变轻了，安培力向上。
2. 问：反向后 $bc$ 中电流向左、安培力向上，用左手定则，磁场朝哪？ → 期望：垂直纸面向外，B 对，A 错。
3. 问：那么开始时（电流向右）安培力朝哪？设线圈质量 $m_0$，写出开始时的平衡式。 → 期望：向下；$m_1g=m_2g+m_0g+NBIL$。
4. 问：反向后安培力大小为多少？写出第二个平衡式。 → 期望：$2NBIL$，向上；$m_1g=m_2g+m_0g+mg-2NBIL$。
5. 问：两式相减，$B$ 等于多少？ → 期望：$3NBIL=mg$，$B=\dfrac{mg}{3NIL}$，C 对；D 用了 $m_1-m_2$ 但不知道 $m_0$，错。选 BC。
常见错误：
- 忘记 $N$ 匝线圈受力是单匝的 $N$ 倍。追问：$N$ 匝线圈的底边相当于几根导线并排通电？
- 忘了线圈自身质量，直接用 $(m_1-m_2)g=NBIL$。追问：右盘下面挂的线圈有没有重力？
- 第二次安培力只写 $NBIL$。追问：电流变成多少了？
总结句：电流天平题：先由“加减砝码”判断安培力方向，再列两次平衡式相减，消去未知的线圈质量。

## 5. 单选 · 电磁炮的受力与加速度

**题目**

根据磁场对通电导体有安培力作用的原理，人们研制出一种新型的发射炮弹的装置——电磁炮，其原理如图所示。间距为$L$的平行导轨水平放置，导轨一端接电动势为$E$、内阻为$r$的电源，可导电金属炮弹质量为$m$，垂直放在导轨上，电阻为$R$，导轨电阻不计，添加竖直方向的匀强磁场，磁感应强度大小为$B$。炮弹与导轨间的阻力忽略不计。则下列说法正确的是（　　）

- A．磁场方向为竖直向下
- B．闭合开关瞬间，炮弹的加速度大小为$\dfrac{BEL}{(R+r)m}$
- C．减小磁感应强度$B$的值，炮弹受到的安培力变大
- D．若同时将电流方向和磁场方向反向，安培力方向也会反向

![第 5 题原题图。](assets/xx2/k02-q05-stem1.png)

**答案：B**

**解析**

- A：炮弹向右加速，需要向右的安培力；由图中电源接法确定炮弹中的电流方向，再用左手定则可得磁场竖直向上，错。
- B：闭合瞬间 $I=\dfrac{E}{R+r}$，$F_{\text{安}}=BIL=\dfrac{BEL}{R+r}$，$a=\dfrac{F_{\text{安}}}{m}=\dfrac{BEL}{(R+r)m}$，对。
- C：由 $F_{\text{安}}=BIL$，$B$ 减小，安培力变小，错。
- D：电流和磁场同时反向，安培力方向不变，错。

故选 **B**。

**问答脚本**

本题考点：左手定则；闭合电路欧姆定律；牛顿第二定律；电流、磁场同时反向时安培力方向不变。
提问路线：
1. 问：炮弹要向右加速，它受的安培力朝哪？结合图中电流方向用左手定则，磁场竖直向上还是向下？ → 期望：安培力向右，磁场竖直向上，A 错。
2. 问：闭合开关瞬间电路中电流多大？安培力多大？ → 期望：$I=\dfrac{E}{R+r}$，$F=BIL=\dfrac{BEL}{R+r}$。
3. 问：炮弹的加速度多大？ → 期望：$a=\dfrac{BEL}{(R+r)m}$，B 对。
4. 问：$B$ 减小时安培力变大还是变小？电流和磁场同时反向，安培力方向怎样？ → 期望：变小，C 错；方向不变，D 错。选 B。
常见错误：
- 电流只用 $E/R$ 或 $E/r$。追问：回路里有哪些电阻是串联的？
- 认为同时反向安培力也反向。追问：只把电流反向时力怎样？再把磁场也反向呢？
总结句：电磁炮 = 电路求电流 + 安培力 + 牛顿第二定律；电流与磁场同时反向，安培力方向不变。

## 6. 单选 · 辐向磁场中悬挂导线的平衡

**题目**

如图甲，直导线$MN$被两等长且平行的绝缘轻绳悬挂于水平轴$OO$′上，其所在区域存在方向垂直指向$OO$′的磁场，与$OO$′距离相等位置的磁感应强度大小相等且不随时间变化，其截面图如图乙所示。导线通以电流$I$，静止后，悬线偏离竖直方向的夹角为$\theta$。下列说法正确的是（　　）

- A．当导线静止在图甲右侧位置时，导线中电流方向由$N$指向$M$
- B．电流$I$增大，静止后，导线对悬线的拉力不变
- C．tan $\theta$与电流$I$成正比
- D．sin $\theta$与电流$I$成正比

![第 6 题原题图。](assets/xx2/k02-q06-stem1.png)

**答案：D**

**解析**

**第一步：受力分析。** 导线受重力 $mg$、两悬线拉力的合力 $F_T$（沿悬线）、安培力 $F_{\text{安}}$。磁场沿半径指向 $OO'$，与悬线平行，所以安培力与悬线**垂直**（见下图）。

![第 6 题解析配图。](assets/xx2/k02-q06-1.png)

**第二步：判断电流方向（A）。** 导线静止在右侧时，安培力须垂直悬线斜向右上；由左手定则可得电流由 $M$ 指向 $N$，A 错。

**第三步：列平衡式。** 沿垂直悬线方向：$BIL=mg\sin\theta$；沿悬线方向：$F_T=mg\cos\theta$。

导线与 $OO'$ 距离不变，所在处 $B$ 大小不变，所以 $\sin\theta=\dfrac{BIL}{mg}$ 与 $I$ 成正比，D 对、C 错；$I$ 增大，$\theta$ 增大，$F_T=mg\cos\theta$ 减小，B 错。

故选 **D**。

**问答脚本**

本题考点：辐向磁场中安培力的方向（与悬线垂直）；共点力平衡（正交分解沿悬线和垂直悬线）。
已知：磁场沿半径指向轴 $OO'$，与 $OO'$ 距离相等处 $B$ 大小相等；导线 $MN$ 用两根等长悬线挂在轴上，静止时悬线偏角 $\theta$。
提问路线：
1. 问：导线所在处磁场沿什么方向？和悬线是什么关系？安培力与悬线是什么关系？ → 期望：磁场沿半径（沿悬线方向），安培力垂直磁场，所以安培力与悬线垂直。
2. 问：导线静止在右侧，安培力应垂直悬线指向哪边？用左手定则，电流从 $M$ 到 $N$ 还是 $N$ 到 $M$？ → 期望：垂直悬线斜向右上，电流由 $M$ 指向 $N$，A 错。
3. 问：把重力沿悬线和垂直悬线分解，分别列出两个方向的平衡式。 → 期望：垂直悬线：$BIL=mg\sin\theta$；沿悬线：$F_T=mg\cos\theta$。
4. 问：$B$ 大小不变，$\sin\theta$ 与 $I$ 是什么关系？$I$ 增大时拉力怎样变？ → 期望：$\sin\theta$ 与 $I$ 成正比，D 对，C 错；$\theta$ 增大，$F_T$ 减小，B 错。选 D。
常见错误：
- 把安培力画成水平方向，得到 $\tan\theta=\dfrac{BIL}{mg}$（选 C）。追问：这里的磁场是竖直/水平的匀强磁场吗？磁场沿哪个方向？安培力垂直于谁？
- 认为拉力不变。追问：沿悬线方向的平衡式中，拉力等于什么？$\theta$ 变大时它怎样变？
总结句：辐向磁场中安培力始终垂直于半径（悬线），正交分解要沿悬线和垂直悬线，得 $\sin\theta=\dfrac{BIL}{mg}$。

## 7. 单选 · 弹簧拉住的导体棒（电流反向）

**题目**

如图所示，两平行光滑金属导轨固定在绝缘斜面上，导轨间距为$L$，劲度系数为$k$的轻质弹簧上端固定，下端与水平直导体棒$ab$相连，弹簧与导轨平面平行并与$ab$垂直，直导体棒垂直跨接在两导轨上，空间存在垂直导轨平面斜向上的匀强磁场。闭合开关S后导体棒中的电流为$I$，导体棒平衡时，弹簧伸长量为$x_{1}$；调换图中电源极性，使导体棒中电流反向，导体棒中电流仍为$I$，导体棒平衡时弹簧伸长量为$x_{2}$。忽略回路中电流产生的磁场，则匀强磁场的磁感应强度$B$的大小为（　　）

- A．$\dfrac{k}{I}(x_{1}+x_{2}$）
- B．$\dfrac{k}{I}(x_{2}-x_{1}$）
- C．$\dfrac{k}{2IL}(x_{2}+x_{1}$）
- D．$\dfrac{k}{2IL}(x_{2}-x_{1}$）

![第 7 题原题图。](assets/xx2/k02-q07-stem1.png)

**答案：D**

**解析**

设斜面倾角为 $\alpha$，导体棒质量为 $m$。由左手定则，开始时安培力沿斜面向上：

$mg\sin\alpha=kx_1+BIL$；

电流反向后安培力沿斜面向下：

$mg\sin\alpha+BIL=kx_2$。

两式相减：$2BIL=k(x_2-x_1)$，得 $B=\dfrac{k}{2IL}(x_2-x_1)$。

故选 **D**。

**问答脚本**

本题考点：斜面上导体棒的平衡；安培力方向随电流反向而反向；两式相减消去未知量。
已知：导轨光滑，弹簧与导轨平行，磁场垂直导轨平面斜向上；电流 $I$ 时伸长 $x_1$，电流反向（仍为 $I$）时伸长 $x_2$。斜面倾角设为 $\alpha$，棒质量设为 $m$。
提问路线：
1. 问：开始时用左手定则，安培力沿斜面向上还是向下？ → 期望：沿斜面向上。
2. 问：此时沿斜面方向有哪几个力？写出平衡式。 → 期望：重力分力向下，弹簧拉力和安培力向上：$mg\sin\alpha=kx_1+BIL$。
3. 问：电流反向后安培力朝哪？平衡式怎样写？ → 期望：沿斜面向下：$mg\sin\alpha+BIL=kx_2$。
4. 问：两式相减，$B$ 等于多少？对应哪个选项？ → 期望：$2BIL=k(x_2-x_1)$，$B=\dfrac{k(x_2-x_1)}{2IL}$，选 D。
常见错误：
- 漏掉导轨间距 $L$（选 A、B）。追问：安培力公式里，导线有效长度是多少？
- 写成 $x_1+x_2$。追问：两次安培力方向相同还是相反？相减后剩下什么？
总结句：同一导体棒两次平衡、未知量（质量、倾角）相同时，列两式相减即可求 $B$。

## 8. 计算 · 斜导轨上金属棒静止的电阻范围

**题目**

（2026·浙江绍兴期中）如图所示，在倾角$\theta=37$°的斜面上，固定一宽$L=0.25$ m的平行金属导轨，在导轨上端接入电源和滑动变阻器$R$，电源电动势$E=12$ V，内阻$r=2$ Ω，一质量$m=100$ g的金属棒$ab$与两导轨垂直并接触良好。整个装置处于磁感应强度大小$B=0.8$ T、方向垂直于斜面向上的匀强磁场中。金属棒与导轨间动摩擦因数$\mu=0.5$，取最大静摩擦力等于滑动摩擦力，重力加速度$g$取10 m/$\mathrm{s}^{2}$，sin 37°=0.6，调节滑动变阻器使金属棒在导轨上保持静止，导轨与金属棒的电阻不计。求：

（1）滑动变阻器$R$接入电路中的阻值范围；

（2）满足题中要求条件下，电源$E$输出的最大功率。

![第 8 题原题图。](assets/xx2/k02-q08-stem1.png)

**答案：（1）0.4 Ω≤$R$≤10 Ω　（2）18 W**

**解析**

**准备：** $mg\sin37^\circ=0.6$ N，$mg\cos37^\circ=0.8$ N，最大静摩擦力 $F_{fm}=\mu mg\cos37^\circ=0.4$ N；安培力沿斜面向上，$F_{\text{安}}=BIL=0.2I$（N）。

**（1）** 安培力太小时棒有下滑趋势，最大静摩擦力沿斜面向上：

$F_{\text{安}}+F_{fm}=mg\sin37^\circ$，$0.2I_1=0.2$，$I_1=1$ A，$R_{\max}=\dfrac{E}{I_1}-r=10$ Ω；

安培力太大时棒有上滑趋势，最大静摩擦力沿斜面向下：

$F_{\text{安}}=mg\sin37^\circ+F_{fm}$，$0.2I_2=1.0$，$I_2=5$ A，$R_{\min}=\dfrac{E}{I_2}-r=0.4$ Ω。

所以 $0.4\ \Omega\le R\le10\ \Omega$。

**（2）** 电源输出功率 $P=I^2R=\dfrac{E^2R}{(R+r)^2}=\dfrac{E^2}{\dfrac{(R-r)^2}{R}+4r}$，当 $R=r=2$ Ω 时最大，且 2 Ω 在允许范围内：

$P_m=\dfrac{E^2}{4r}=\dfrac{144}{8}\ \text{W}=18\ \text{W}$。

**问答脚本**

本题考点：最大静摩擦力的两种方向（临界状态）；闭合电路欧姆定律；电源最大输出功率。
已知：$\theta=37^\circ$，$L=0.25$ m，$E=12$ V，$r=2$ Ω，$m=0.1$ kg，$B=0.8$ T（垂直斜面向上），$\mu=0.5$。
提问路线：
1. 问：安培力沿什么方向？重力沿斜面分力、最大静摩擦力各多大？ → 期望：沿斜面向上；$mg\sin37^\circ=0.6$ N，$F_{fm}=\mu mg\cos37^\circ=0.4$ N。
2. 问：$R$ 越大，电流和安培力越小。$R$ 最大时棒有什么运动趋势？最大静摩擦力朝哪？列式求电流。 → 期望：有下滑趋势，摩擦力沿斜面向上；$BI_1L+F_{fm}=mg\sin37^\circ$，$I_1=1$ A。
3. 问：由 $I_1=1$ A 求 $R_{\max}$。 → 期望：$R_{\max}=\dfrac{E}{I_1}-r=10$ Ω。
4. 问：$R$ 最小时棒有什么趋势？列式求 $I_2$ 和 $R_{\min}$。 → 期望：有上滑趋势，摩擦力沿斜面向下；$BI_2L=mg\sin37^\circ+F_{fm}$，$I_2=5$ A，$R_{\min}=0.4$ Ω。
5. 问：（2）电源输出功率什么时候最大？$R=r$ 在允许范围内吗？最大功率多少？ → 期望：外电阻等于内阻时最大；2 Ω 在 0.4～10 Ω 之间；$P_m=\dfrac{E^2}{4r}=18$ W。
常见错误：
- 只考虑一种摩擦力方向。追问：电流很大时棒往哪边滑？电流很小时呢？
- 把“输出功率”算成电源总功率 $EI$。追问：输出功率是哪部分电阻上的功率？
- 没检查 $R=r$ 是否在范围内就直接用最大值公式。追问：如果 2 Ω 不在允许范围内，最大功率还能取 $\dfrac{E^2}{4r}$ 吗？
总结句：求静止的电阻范围，就是找安培力的两个临界值：最大静摩擦力分别沿斜面向上和向下。

## 9. 多选 · 安培力最小与磁场竖直时的平衡

**题目**

〔多选〕如图所示，宽为$L$、电阻不计的平行光滑金属导轨与水平面成$\alpha$角放置。质量为$m$、长度为$L$、电阻为$R$的金属杆水平放置在导轨上，与导轨接触良好。已知电源的电动势为$E$，内电阻为$r$。空间存在着匀强磁场，调节电阻箱$R$′使回路总电流为$I$时，金属杆恰好能静止，重力加速度为$g$，则（　　）

- A．磁感应强度$B$最小值为$\dfrac{mg}{IL}$，此时磁场方向应垂直于金属杆水平向左
- B．磁感应强度$B$最小值为$\dfrac{mg}{IL}$sin$　\alpha$，此时磁场方向应垂直于导轨平面向上
- C．若磁场方向竖直向上，则磁感应强度$B$的大小应为$\dfrac{mg}{IL}$sin$　\alpha$
- D．若磁场方向竖直向上，则磁感应强度$B$的大小应为$\dfrac{mg}{IL}$tan$　\alpha$

![第 9 题原题图。](assets/xx2/k02-q09-stem1.png)

**答案：BD**

**解析**

金属杆受重力 $mg$、支持力 $F_N$（垂直导轨平面）和安培力。

**安培力最小：** 重力不变、支持力方向不变，第三个力与支持力垂直时最小，即安培力沿导轨向上，$F_{\min}=mg\sin\alpha$。安培力沿导轨向上时，磁场垂直导轨平面向上，$B_{\min}=\dfrac{mg\sin\alpha}{IL}$。A 错，B 对。

**磁场竖直向上：** 安培力水平，由平衡得 $BIL=mg\tan\alpha$，$B=\dfrac{mg\tan\alpha}{IL}$。C 错，D 对。

故选 **BD**。

**问答脚本**

本题考点：三力平衡的动态最小值（第三个力垂直于方向不变的力时最小）；左手定则；磁场竖直时的平衡。
已知：导轨光滑，倾角 $\alpha$，电流 $I$，杆长 $L$；杆受重力、支持力、安培力。
提问路线：
1. 问：金属杆受哪几个力？哪个力大小方向都不变？哪个力方向不变？ → 期望：重力（大小方向不变）、支持力（方向垂直导轨不变）、安培力。
2. 问：画力的三角形，安培力什么方向时最小？最小值是多少？ → 期望：安培力与支持力垂直，即沿导轨向上时最小，$F_{\min}=mg\sin\alpha$。
3. 问：安培力沿导轨向上，磁场应朝哪？$B_{\min}$ 等于多少？ → 期望：磁场垂直导轨平面向上，$B_{\min}=\dfrac{mg\sin\alpha}{IL}$，B 对，A 错。
4. 问：磁场竖直向上时安培力朝哪？列平衡式求 $B$。 → 期望：安培力水平；$BIL=mg\tan\alpha$，$B=\dfrac{mg\tan\alpha}{IL}$，D 对，C 错。选 BD。
常见错误：
- 认为安培力竖直向上、等于 $mg$ 时最小（选 A）。追问：安培力竖直向上时需要多大？沿斜面向上时只需平衡重力的哪个分力？
- 磁场竖直时写成 $BIL=mg\sin\alpha$。追问：这时安培力是沿斜面还是水平？沿斜面方向的分量是多少？
总结句：三力平衡中，一个力恒定、一个力方向不变，第三个力垂直于方向不变的力时最小。

- B．单根导线上的拉力大小为$\dfrac{mg}{cos\theta }$
- C．若电流大小加倍，再次稳定后$\theta$角也加倍

![第 10 题解析配图。](assets/xx2/k02-q10-1.png)

已知：N 极在上（磁场竖直向下），导体棒向右偏，两根细导线与竖直方向夹角均为 $\theta$。
提问路线：
1. 问：导体棒向右偏，安培力朝哪？磁场向下，用左手定则，电流从 $a$ 到 $b$ 还是 $b$ 到 $a$？ → 期望：安培力水平向右，电流由 $b$ 到 $a$，A 错。

## 11. 计算 · 斜导轨上金属棒：光滑、粗糙与突变

**题目**

如图所示，在倾角$\theta=30$°的斜面上固定一间距$L=0.5$ m的两平行金属导轨，在导轨上端接入电源和滑动变阻器$R$，电源电动势$E=12$ V，内阻$r=1$ Ω，一质量$m=20$ g的金属棒$ab$与两导轨垂直并接触良好。整个装置处于磁感应强度大小为$B=0.10$ T，方向垂直于斜面向上的匀强磁场中（导轨与金属棒的电阻不计）。最大静摩擦力等于滑动摩擦力，重力加速度取$g=10$ m/$\mathrm{s}^{2}$。

（2）若金属棒$ab$与导轨间的动摩擦因数$\mu =\dfrac{\sqrt{3}}{6}$，金属棒要在导轨上保持静止，求滑动变阻器$R$接入电路中的阻值范围；

$a=\dfrac{mg\sin30^\circ-BIL}{m}=\dfrac{0.1-0.025}{0.02}\ \text{m/s}^2=3.75\ \text{m/s}^2$。

**问答脚本**

本题考点：斜面平衡；最大静摩擦的两个临界；闭合电路欧姆定律；牛顿第二定律。
已知：$\theta=30^\circ$，$L=0.5$ m，$E=12$ V，$r=1$ Ω，$m=0.02$ kg，$B=0.10$ T（垂直斜面向上），$g=10\ \text{m/s}^2$。

1. 问：（1）导轨光滑时，棒受哪些力？安培力朝哪、等于多少？ → 期望：重力、支持力、沿斜面向上的安培力；$F=mg\sin30^\circ=0.1$ N。

3. 问：安培力最小时摩擦力朝哪？求此时的电流和电阻。 → 期望：摩擦力沿斜面向上；$F_1=0.05$ N，$I_1=1$ A，$R_1=11$ Ω。
4. 问：安培力最大时摩擦力朝哪？求此时的电流和电阻。 → 期望：沿斜面向下；$F_2=0.15$ N，$I_2=3$ A，$R_2=3$ Ω，所以 $3\ \Omega\le R\le11\ \Omega$。
5. 问：（3）$R=23$ Ω 时电流和安培力多大？与重力分力比较，棒向哪边加速？加速度多大？ → 期望：$I=0.5$ A，$BIL=0.025$ N $<0.1$ N，沿斜面向下加速；$a=\dfrac{0.1-0.025}{0.02}=3.75\ \text{m/s}^2$。
常见错误：
- 质量 20 g 没换成 0.02 kg。追问：代入公式前质量单位应换成什么？
- 摩擦力只考虑一个方向。追问：$R$ 很大和很小时，棒分别有什么运动趋势？
- （3）中仍然加摩擦力。追问：第（3）问导轨光滑还是粗糙？
总结句：先判断安培力方向，再根据运动趋势确定摩擦力方向，两个临界状态对应电阻范围的两端。
