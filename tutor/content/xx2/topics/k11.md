## 1. 实验 · 插拔磁体探究感应电流方向

**题目**

（2024·北京高考15题节选）用如图1所示的实验装置探究影响感应电流方向的因素。如图2所示，分别把条形磁体的 N极或 S极插入、拔出螺线管，观察并标记感应电流的方向。

关于本实验，下列说法正确的是　　　　（填选项前的字母）。

- A．需要记录感应电流的大小
- B．通过观察电流表指针的偏转方向确定感应电流的方向
- C．图2中甲和乙表明，感应电流的方向与条形磁体的插入端是N极还是S极有关

![第 1 题原题图。](assets/xx2/k11-q01-stem1.png)

![第 1 题原题图。](assets/xx2/k11-q01-stem2.png)

**答案：BC**

**解析**

分析实验目的可知，本实验需要通过电流表指针的偏转方向分析感应电流的方向，不需要记录感应电流的大小，故A错误，B正确；比较甲和乙，磁体的 N极和 S极分别靠近螺线管，感应电流方向相反，则感应电流的方向与条形磁体的插入端是 N极还是 S极有关，故C正确。

**问答脚本**

本题考点：实验目的（只研究方向，不研究大小）；用电流表偏转方向判断电流方向；控制变量比较甲、乙。
已知：图 2 中甲为 N 极向下插入、乙为 S 极向下插入（丙、丁为拔出），各图标出了感应电流方向，甲、乙方向相反。
提问路线（每次只问一个问题）：
1. 问：这个实验探究的是感应电流的什么——大小还是方向？需要记录大小吗？ → 期望：探究方向，不需要记录大小，A 错。
2. 问：实验中靠什么判断感应电流的方向？ → 期望：电流表指针的偏转方向，B 对。
3. 问：甲和乙哪个条件不同？感应电流方向一样吗？说明什么？ → 期望：插入端一个是 N 极一个是 S 极，电流方向相反，说明方向与插入端是 N 极还是 S 极有关，C 对。选 BC。
常见错误：
- 认为要记录大小。追问：实验题目叫“探究影响感应电流什么的因素”？
- 比较甲、乙时同时改变了两个条件。追问：甲、乙都是插入吗？唯一不同的是哪一点？
总结句：探究感应电流方向的实验只看指针偏转方向；比较时要控制变量，只让一个条件不同。

## 2. 实验 · 线圈绕法、检测挡位与指针偏转

**题目**

（2026·浙江嘉兴月考）如图所示是“探究影响感应电流方向的因素”的实验装置。

（1）判断感应电流的方向时　　　　（选填“需要”或“不需要）确定线圈的绕法，为了明确灵敏电流计指针偏转方向与电流流向的关系，可以用多用电表的　　　　（选填“电压挡”“电流挡”或“电阻挡”）进行检测。

（2）强磁铁快速插入线圈后保持静止，此过程中灵敏电流计指针的偏转情况可能是　　　　。

- A．一直在“0”刻度位置
- B．从“0”刻度开始向右偏转到最大并维持此角度不变
- C．从“0”刻度先向右偏转再向左偏转并越过“0”，最后向右偏转回到“0”位置

![第 2 题原题图。](assets/xx2/k11-q02-stem1.png)

**答案：（1）需要　电阻挡　（2）C**

**解析**

（1）判断感应电流方向时需要用到楞次定律结合安培定则进行判断，右手四指环绕的方向即为感应电流的方向，因此需要确定线圈的绕法；

多用电表内部含有直流电源的挡位为电阻挡，因此可用电表的电阻挡对电流进行检测。

（2）强磁铁快速插入线圈的过程中，穿过线圈的磁通量发生改变，回路中将产生感应电流，灵敏电流计指针将从“0”刻度开始偏转，磁铁插入线圈中保持静止后，磁通量不再改变，最终灵敏电流计指针将回到“0”刻度位置。故选C。

**问答脚本**

本题考点：用楞次定律 + 安培定则判断电流方向需要知道线圈绕法；多用电表电阻挡内有电源；磁通量变化才有感应电流。
提问路线：
1. 问：由楞次定律知道感应电流的磁场方向后，还要用什么定则才能知道线圈中电流怎么流？这需要知道线圈的什么？ → 期望：安培定则；需要知道线圈的绕法，所以“需要”。
2. 问：为了弄清“电流从哪个接线柱流入时指针向哪偏”，需要给电流计通一个已知方向的电流。多用电表哪个挡位内部有电源？ → 期望：电阻挡（欧姆挡），内部有电池。
3. 问：（2）磁铁快速插入的过程中，磁通量变不变？插入后静止时呢？ → 期望：插入过程磁通量变化，有感应电流，指针从 0 开始偏转；静止后磁通量不变，没有电流，指针回到 0。
4. 问：三个选项中，哪一个符合“插入过程中偏转、静止后回到 0”？ → 期望：只有 C 最后回到“0”刻度，选 C；A 一直不偏、B 一直保持偏转都不对。
常见错误：
- 认为指针偏到最大后保持不动（选 B）。追问：磁铁静止后，线圈中的磁通量还在变吗？
- 选电流挡。追问：电流挡内部有电源吗？能给电流计提供电流吗？
总结句：判断线圈中电流方向要知道绕法；只有磁通量变化时才有感应电流，磁铁停下指针就回零。

## 3. 实验 · 确定电流方向的器材与指针偏向

**题目**

（2026·浙江宁波期末）在“探究影响感应电流方向的因素”的实验中：

（1）为明确灵敏电流计指针的偏转方向与通过灵敏电流计的电流方向的关系，除灵敏电流计、导线、定值电阻和开关这些器材之外，还需要　　　　。

（2）实验得出，电流由“＋”接线柱流入时灵敏电流计指针向右偏转；如图所示，该同学将条形磁铁的N极从螺线管拔出的过程中，发现指针　　　　（选填“向左”或“向右”）偏转。

（3）多次实验发现：感应电流产生的磁场，总是要　　　　引起感应电流的磁通量的变化。

![第 3 题原题图。](assets/xx2/k11-q03-stem1.png)

![第 3 题原题图。](assets/xx2/k11-q03-stem2.png)

**答案：（1）C　（2）向右　（3）阻碍**

**解析**

（1）为明确灵敏电流计指针的偏转方向与通过灵敏电流计的电流方向的关系，除题中器材外，还需要直流电源确定电流的方向，故选C。

（2）将条形磁铁的N极从螺线管拔出时，由楞次定律可知，螺线管中感应电流沿顺时针方向（俯视），即电流由“＋”接线柱流入灵敏电流计，则指针向右偏转。

（3）多次实验发现：感应电流产生的磁场，总是要阻碍引起感应电流的磁通量的变化。

**问答脚本**

本题考点：确定电流计偏转方向与电流方向的关系需要电源；楞次定律（“增反减同”）；安培定则。
已知：（1）的选项是三幅图：A 条形磁铁、B 线圈、C 电池（直流电源）。电流从“＋”接线柱流入时指针右偏；N 极从螺线管中向上拔出（按图中线圈绕法和接线）。
提问路线：
1. 问：（1）要知道“电流从哪边流入指针向哪偏”，必须先让一个方向已知的电流流过电流计，需要什么器材？ → 期望：直流电源，选 C。
2. 问：（2）图中磁铁 N 极朝下、正向上拔出。螺线管中原磁场朝哪？磁通量增加还是减少？ → 期望：磁感线从 N 极出发向下进入线圈，原磁场向下；拔出时磁通量减少。
3. 问：由“增反减同”，感应电流的磁场朝哪？结合线圈绕法，电流从哪个接线柱流入电流计？指针向哪偏？ → 期望：感应磁场也向下；用安培定则得线圈中电流俯视顺时针，按图中接法电流由“＋”接线柱流入，指针向右偏。
4. 问：（3）多次实验得出的规律是什么？ → 期望：感应电流的磁场总要阻碍引起感应电流的磁通量的变化（楞次定律）。
常见错误：
- 认为还需要条形磁铁或线圈。追问：题目问的是“为了确定偏转方向与电流方向的关系”，这一步需要产生感应电流吗？
- 把“阻碍”说成“阻止”或“相反”。追问：磁通量减少时，感应电流的磁场与原磁场同向还是反向？
总结句：先用电源标定电流计的偏转方向，再用“增反减同”和安培定则判断感应电流方向。

## 4. 实验 · 由指针偏转判断磁铁运动

**题目**

（2025·浙江1月选考15题）在“探究影响感应电流方向的因素”实验中，当电流从“－”接线柱流入灵敏电流表，指针左偏；从“$\mathrm{G}_{0}$”或“$\mathrm{G}_{1}$”接线柱流入，指针右偏。如图所示是某次实验中指针偏转角度最大的瞬间，则

（1）此时磁铁的运动状态是　　　　（选填“向上拔出”“静止”或“向下插入”）。

（2）只做以下改变，一定会增大图中电流表指针偏转角度的是　　　　（多选）。

- A．磁铁静止，向上移动线圈
- B．增大（1）中磁铁运动速度
- C．将导线从接线柱“$\mathrm{G}_{1}$”移接至接线柱“$\mathrm{G}_{0}$”
- D．将一个未与电路相接的闭合线圈套在图中线圈外

![第 4 题原题图。](assets/xx2/k11-q04-stem1.png)

**答案：（1）向上拔出　（2）BC**

**解析**

（1）由题图可知，灵敏电流表指针左偏，由题意知此时电流从“－”接线柱流入灵敏电流表，根据楞次定律和安培定则可知，线圈中产生的感应磁场的方向从上到下，与线圈内原磁场方向相同，可知磁铁的N极向上拔出；

（2）磁铁静止，向上移动线圈，产生的感应电流不一定增加，则指针偏转角度不一定增大，A错误；增大（1）中磁铁运动速度，产生的感应电动势会增加，指针偏转角度增大，B正确；将导线从接线柱“$\mathrm{G}_{1}$”移接到“$\mathrm{G}_{0}$”，灵敏电流表的量程减小，由于感应电流大小一定，可知指针偏转角度增大，C正确；将一个未与电路相接的闭合线圈套在线圈外，线圈中的感应电流不变，指针偏转角度不变，D错误。

**问答脚本**

本题考点：由指针偏转方向反推电流方向和磁铁运动；感应电动势与速度的关系；电表量程（接线柱 $G_0$、$G_1$）对偏转角的影响。
已知：电流从“－”接线柱流入时指针左偏，从 $G_0$ 或 $G_1$ 流入时右偏；图中指针左偏且达到最大；N 极在下方靠近线圈（按图）。
提问路线：
1. 问：指针左偏，电流从哪个接线柱流入电流表？再结合图中线圈绕法，线圈中感应电流的磁场朝哪？ → 期望：从“－”流入；由安培定则，感应磁场在线圈中从上到下（向下）。
2. 问：磁铁 N 极在下端，线圈中原磁场朝哪？感应磁场与原磁场同向，说明磁通量在增加还是减少？磁铁怎么运动？ → 期望：原磁场向下，同向说明在减少，磁铁向上拔出。
3. 问：（2）A 中线圈向上移动，磁通量的变化率一定变大吗？ → 期望：不一定，A 错。
4. 问：磁铁运动更快，感应电动势和电流怎样变？ → 期望：变大，偏角变大，B 对。
5. 问：从 $G_1$ 换到 $G_0$，电表量程怎样变？同样的电流偏角怎样变？ → 期望：$G_0$ 量程更小，偏角更大，C 对。
6. 问：在线圈外套一个不接电路的闭合线圈，会改变原线圈中的电流吗？ → 期望：不会让它“一定增大”，D 错。选 BC。
常见错误：
- 忽略量程变化。追问：同一电流表不同接线柱对应的量程一样吗？
- 把感应磁场方向直接当成原磁场方向。追问：“增反减同”中，同向说明磁通量增加还是减少？
总结句：由偏转方向 → 电流方向 → 感应磁场方向 → 与原磁场比较得出磁通量是增是减 → 磁铁怎样运动。

## 5. 实验 · 甲乙装置与线圈 A、B 的感应电流

**题目**

（2026·浙江宁波检测）（1）探究电磁感应现象应选用如图　　　　（选填“甲”或“乙”）所示的装置进行实验。在这个现象中感应电流的方向与　　　　的方向、磁感线方向有关。

（2）如图丙所示，闭合开关后，线圈A相当于条形磁铁，下端为　　　　（选填“N”或“S”）极；实验中发现闭合开关瞬间，电流计指针向左偏。电路稳定后，若向右滑动滑片，此过程中电流计指针向　　　　（选填“左”或“右”）偏转，此时线圈B中感应电流的方向为　　　　（从上向下看，选填“逆时针”或“顺时针”）；若将线圈A抽出，此过程中电流计指针向　　　　（选填“左”或“右”）偏转。

![第 5 题原题图。](assets/xx2/k11-q05-stem1.png)

![第 5 题原题图。](assets/xx2/k11-q05-stem2.png)

**答案：（1）甲　导体切割磁感线运动　（2）N　右　顺时针　右**

**解析**

（1）探究电磁感应现象的实验装置，需要有磁铁、导体棒、电流表，不需要电源；则探究电磁感应现象应选用如图甲所示的装置进行实验。在这个现象中感应电流的方向与导体切割磁感线运动的方向、磁感线方向有关。

（2）根据安培定则，闭合开关后，线圈A相当于条形磁铁，下端为N极；因为当闭合开关时，电路中的电流增大，穿过线圈B的磁通量增加，已知此时产生的感应电流使电流计指针向左偏；电路稳定后，若向右滑动滑片，滑动变阻器接入电路阻值增大，则电流减小，穿过线圈B的磁通量减少，则此过程中电流计指针向右偏；由以上分析，穿过线圈B向下的磁通量减少，根据楞次定律和安培定则，此时线圈B中感应电流的方向为顺时针（从上向下看）；若将线圈A抽出，穿过线圈B向下的磁通量减少，则此过程中电流计指针向右偏转。

**问答脚本**

本题考点：电磁感应实验装置与通电导体受力装置的区别；楞次定律在互感中的应用；滑动变阻器改变电流。
已知：甲图为磁铁、导体棒、电流表（无电源）；乙图有电源（通电导体在磁场中受力）。丙图中线圈 A 接电源和滑动变阻器，插在线圈 B 中，B 接电流计；闭合开关瞬间指针向左偏。
提问路线：
1. 问：探究电磁感应应选有电源的装置还是没有电源的装置？为什么？ → 期望：没有电源的甲；电流应由导体运动产生，乙有电源是研究通电导体受力的。
2. 问：甲中感应电流方向与哪两个方向有关？ → 期望：导体切割磁感线的运动方向和磁感线方向。
3. 问：丙图中用安培定则判断线圈 A 下端是什么极。 → 期望：N 极。
4. 问：闭合开关瞬间，穿过 B 的磁通量怎样变？此时指针左偏。滑片向右滑，电阻和电流怎样变？磁通量呢？指针向哪偏？ → 期望：闭合时磁通量增加→左偏；滑片右移电阻增大、电流减小、磁通量减少→向右偏。
5. 问：B 中向下的磁通量减少，由“增反减同”，感应磁场朝哪？从上往下看电流是顺时针还是逆时针？ → 期望：感应磁场向下，从上往下看为顺时针。
6. 问：把线圈 A 抽出，B 中磁通量怎样变？指针向哪偏？ → 期望：减少，向右偏。
常见错误：
- 选乙。追问：乙中的电流是电源提供的还是运动产生的？
- 认为滑片右移电阻减小。追问：看图中滑片与接线柱的连接，右移时接入电路的电阻丝变长还是变短？
总结句：互感问题抓住“磁通量增加与减少使指针偏向相反”：以开关闭合时（磁通量增加）的偏转方向为参照。

## 6. 实验 · 二极管、电流计与铁芯抽出

**题目**

某兴趣小组在探究感应电流的产生条件和影响感应电流方向的因素。

（1）图a中，将条形磁铁从图示位置先向上后向下移动一小段距离，出现的现象是　　　　。

- A．灯泡A、B均不发光
- B．灯泡A、B交替短暂发光
- C．灯泡A短暂发光、灯泡B不发光
- D．灯泡A不发光、灯泡B短暂发光

**解析**

（1）条形磁铁向上移动一小段距离，穿过螺线管的磁通量减少，向下移动一小段距离，穿过螺线管的磁通量增加，移动方向不同，产生的感应电流方向不同，根据二极管具有单向导电性可知灯泡A、B交替短暂发光，故选B。

（2）电流计指针向右偏转，说明电流从正接线柱流入电流计，螺线管中的电流方向沿顺时针方向（从上向下看），由安培定则可知，螺线管中电流产生的磁场方向向下，与条形磁体的磁场方向相同，所以此时磁体向上运动。

**问答脚本**

本题考点：二极管单向导电性；楞次定律判断电流方向；滑动变阻器保护电路；互感中磁通量增减与偏转方向。
已知：图 a 中两个灯泡各串一个方向相反的二极管，并联接在螺线管两端；图 b 电流从正接线柱流入时指针右偏，磁体 N 极在下（按图）；图 c 需连成线圈 P、电源、开关、滑动变阻器串联，另一线圈接电流计。
提问路线：
1. 问：（1）磁铁先向上后向下移动，两次的感应电流方向相同吗？二极管会让哪个灯亮？ → 期望：两次方向相反，两个灯交替短暂发光，选 B。
2. 问：（2）指针右偏说明电流从正接线柱流入；结合绕法，螺线管中感应磁场朝哪？与原磁场比较，磁体向上还是向下运动？ → 期望：感应磁场向下，与原磁场同向，磁通量减少，磁体向上运动。
3. 问：（3）电路应怎样连接？ → 期望：线圈 P、电源、开关、滑动变阻器串联成一个回路；外面的大线圈与电流计组成另一个回路（见解析图）。
4. 问：（4）闭合开关前，滑动变阻器应调到电阻最大还是最小？对应哪一端？ → 期望：最大，以免电流过大，滑片在最左端。
5. 问：（5）闭合开关瞬间磁通量增加，指针左偏；抽出铁芯时磁通量怎样变？指针向哪偏？ → 期望：减少，向右偏，选 C。
常见错误：
- 认为两个灯同时亮。追问：二极管允许电流向几个方向通过？
- （5）认为不偏转。追问：抽出铁芯时，穿过外线圈的磁场变弱了吗？
总结句：感应电流方向随磁通量增减而反向；以闭合开关（磁通量增加）时的偏转为参照，磁通量减少时指针反向偏转。
