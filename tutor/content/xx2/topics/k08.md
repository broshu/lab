## 1. 单选 · 复合场中小球的能量变化

**题目**

（2026·浙江杭州期末）如图所示，带电平行板中匀强电场$E$的方向竖直向上，匀强磁场$B$的方向垂直于纸面向里，一带电小球从光滑绝缘轨道上的$A$点自由滑下，经$P$点进入板间后恰好沿水平方向做直线运动。现使小球从较低的$C$点自由滑下，经$P$点进入板间，不计空气阻力，则小球在板间运动过程中（　　）

- A．动能将会减小
- B．电势能将会减小
- C．机械能将会减小
- D．小球带负电

![第 1 题原题图。](assets/xx2/k08-q01-stem1.png)

**答案：C**

**解析**

小球从$A$点滑下进入复合场区域时沿水平方向做直线运动，则小球受力平衡，判断可知小球带正电，则有$mg=qE+qvB$，从$C$点滑下刚进入复合场区域时，其速度小于从$A$点滑下时的速度，则有$mg>qE+qv'B$，小球向下偏转，重力做正功，静电力做负功，因为$mg>qE$，则合力做正功，小球的电势能和动能均增大，根据能量守恒可知，机械能减小。故选C。

**问答脚本**

本题考点：叠加场中的直线运动（受力平衡）；速度改变后洛伦兹力改变；功能关系（静电力做功与电势能、机械能）。
已知：电场竖直向上，磁场垂直纸面向里；小球从 $A$ 滑下经 $P$ 进入板间恰好水平直线运动；改从较低的 $C$ 点滑下。
提问路线（每次只问一个问题）：
1. 问：小球在板间水平做直线运动，速度变了洛伦兹力就会变，所以这个直线运动一定是什么运动？ → 期望：匀速直线运动，受力平衡。
2. 问：小球向右运动、磁场向里，若带正电，洛伦兹力朝哪？静电力朝哪？能和重力平衡吗？若带负电呢？ → 期望：带正电时洛伦兹力、静电力都向上，可与重力平衡：$mg=qE+qvB$；带负电时两个力都向下，不能平衡。所以带正电，D 错。
3. 问：从 $C$ 点滑下，进入时速度变大还是变小？洛伦兹力怎样变？小球向哪偏？ → 期望：速度变小，洛伦兹力变小，$mg>qE+qv'B$，小球向下偏。
4. 问：向下偏时，重力和静电力分别做正功还是负功？合力做功正负如何？动能、电势能怎样变？ → 期望：重力做正功、静电力做负功；$mg>qE$，合力做正功，动能增大，A 错；静电力做负功，电势能增大，B 错。
5. 问：除重力外只有静电力做功，静电力做负功，机械能怎样变？ → 期望：机械能减小，选 C。
常见错误：
- 认为带电小球在叠加场中可以做匀加速直线运动。追问：速度变化时洛伦兹力会不会变？力变了还能保持直线吗？
- 认为电势能减小。追问：小球带正电、向下运动，静电力向上，做正功还是负功？
- 把洛伦兹力的功算进机械能变化。追问：洛伦兹力做功吗？
总结句：叠加场中带电粒子做直线运动必为匀速直线运动；机械能的变化看除重力以外的力（这里是静电力）做的功。

## 2. 单选 · 两象限不同磁场中的运动时间

**题目**

如图，在坐标系的第一象限和第二象限内存在磁感应强度大小分别为$\dfrac{1}{2}B$和$B$、方向均垂直于纸面向外的匀强磁场。一质量为$m$、电荷量为$q(q$＞0）的粒子垂直于$x$轴射入第二象限，随后垂直于$y$轴进入第一象限，最后经过$x$轴离开第一象限。粒子在磁场中运动的时间为（　　）

- A．$\dfrac{5\pi m}{6qB}$
- B．$\dfrac{7\pi m}{6qB}$
- C．$\dfrac{11\pi m}{6qB}$
- D．$\dfrac{13\pi m}{6qB}$

![第 2 题原题图。](assets/xx2/k08-q02-stem1.png)

**答案：B**

**解析**

设带电粒子进入第二象限的速度为$v$，在第二象限和第一象限中运动的轨迹如图所示，对应的轨迹半径分别为$R_{1}$和$R_{2}$，由洛伦兹力提供向心力，有$qvB=m\dfrac{{v}^{2}}{R}$，$T=\dfrac{2\pi R}{v}$，可得$　R_{1}=\dfrac{mv}{qB}$，$R_{2}=\dfrac{2mv}{qB}$，$T_{1}=\dfrac{2\pi m}{qB}$，$T_{2}=\dfrac{4\pi m}{qB}$，带电粒子在第二象限中运动的时间为$t_{1}=\dfrac{{T}_{1}}{4}$，在第一象限中运动的时间为$　t_{2}=\dfrac{\theta }{2\pi }T_{2}$，又由几何关系有cos$　\theta =\dfrac{{R}_{2}-{R}_{1}}{{R}_{2}}=\dfrac{1}{2}$，可得$t_{2}=\dfrac{{T}_{2}}{6}$，则粒子在磁场中运动的时间为$t=t_{1}+t_{2}$，联立以上各式解得$t=\dfrac{7\pi m}{6qB}$，故选B。

![第 2 题解析配图。](assets/xx2/k08-q02-1.png)

**问答脚本**

本题考点：不同磁场中半径和周期的比较；垂直进入、垂直穿过边界的几何；时间 $t=\dfrac{\theta}{2\pi}T$。
已知：第二象限磁场 $B$，第一象限磁场 $\dfrac B2$，方向都向外；粒子垂直 $x$ 轴射入第二象限，垂直 $y$ 轴进入第一象限，再从 $x$ 轴射出。
提问路线：
1. 问：两个区域中半径和周期分别是多少？ → 期望：$R_1=\dfrac{mv}{qB}$，$T_1=\dfrac{2\pi m}{qB}$；$R_2=\dfrac{2mv}{qB}=2R_1$，$T_2=\dfrac{4\pi m}{qB}$。
2. 问：在第二象限，粒子垂直 $x$ 轴进入、垂直 $y$ 轴离开，转过多少度？用时多少？ → 期望：$90^\circ$，$t_1=\dfrac{T_1}{4}=\dfrac{\pi m}{2qB}$。
3. 问：进入第一象限时速度沿 $+x$，圆心在 $y$ 轴上哪里？圆心到 $x$ 轴的距离是多少？ → 期望：圆心在进入点正下方 $R_2$ 处，进入点高度为 $R_1$，所以圆心 $O_1$ 在 $x$ 轴下方 $R_2-R_1$ 处。
4. 问：由 $\cos\theta=\dfrac{R_2-R_1}{R_2}$，粒子在第一象限转过多少度？用时多少？ → 期望：$\cos\theta=\dfrac12$，$\theta=60^\circ$，$t_2=\dfrac{T_2}{6}=\dfrac{2\pi m}{3qB}$。
5. 问：总时间是多少？ → 期望：$t=\dfrac{\pi m}{2qB}+\dfrac{2\pi m}{3qB}=\dfrac{7\pi m}{6qB}$，选 B。
常见错误：
- 两个区域用同一个周期。追问：周期 $T=\dfrac{2\pi m}{qB}$ 与 $B$ 有关吗？
- 第一象限中圆心角取 $90^\circ$。追问：粒子在第一象限是从 $x$ 轴垂直射出的吗？用圆心位置算一算。
总结句：粒子穿过不同磁场时半径、周期都要分别算，每段时间用各自的圆心角和周期。

## 3. 单选 · 水平桌面上圆周运动时加竖直电场

**题目**

如图所示，一光滑绝缘的水平桌面置于竖直向下的磁感应强度大小为$B$的匀强磁场中，有一质量为$m$，带电荷量大小为$q$的小球以速度$v$在水平桌面上做匀速圆周运动。若突然在该空间加一竖直向上的匀强电场（图中未标出），电场强度大小$E<\dfrac{mg}{q}$，则下列说法正确的是（　　）

- A．小球一定带正电
- B．小球对桌面的压力一定变小
- C．小球做匀速圆周运动的半径可能发生变化
- D．小球做匀速圆周运动的半径保持不变

![第 3 题原题图。](assets/xx2/k08-q03-stem1.png)

**答案：D**

**解析**

未加电场时，小球竖直方向重力与支持力平衡，洛伦兹力提供向心力，由于速度方向未知，则小球的电性无法判断，故A错误；加电场后，小球受静电力方向可能向上，也可能向下，则支持力可能增大，也可能减小，根据牛顿第三定律可知小球对桌面的压力可能变大，也可能变小，故B错误；由于速度不变，根据洛伦兹力提供向心力有$qvB=m\dfrac{{v}^{2}}{r}$，解得$r=\dfrac{mv}{qB}$，可知小球做匀速圆周运动的半径保持不变，故C错误，D正确。

**问答脚本**

本题考点：电性未知的讨论；加竖直电场后竖直方向受力变化；半径公式 $r=\dfrac{mv}{qB}$。
已知：光滑绝缘水平桌面，磁场竖直向下，小球做匀速圆周运动；加竖直向上的电场，$E<\dfrac{mg}{q}$。
提问路线：
1. 问：小球做圆周运动的向心力由什么提供？小球的绕行方向题目给了吗？能判断电性吗？ → 期望：洛伦兹力提供向心力；绕行方向未知，电性不能确定，A 错。
2. 问：加竖直向上的电场后，静电力的方向一定向上吗？压力一定变小吗？ → 期望：正电荷受力向上、负电荷受力向下，压力可能变小也可能变大，B 错。
3. 问：静电力是竖直方向的，会不会改变小球的水平速度？$E<\dfrac{mg}{q}$ 说明小球会离开桌面吗？ → 期望：不改变水平速度；静电力小于重力，小球不会离开桌面。
4. 问：速度和 $B$ 都不变，半径会变吗？ → 期望：$r=\dfrac{mv}{qB}$ 不变，D 对，C 错。选 D。
常见错误：
- 默认小球带正电。追问：图中标出小球是顺时针还是逆时针转了吗？
- 认为加电场后半径改变。追问：竖直方向的力对水平面内的运动有影响吗？
总结句：竖直方向的电场只改变压力，不改变水平面内的速度和洛伦兹力，半径不变。

## 4. 单选 · 斜杆上带电小环的受力与位移

**题目**

（2026·浙江舟山期中）如图所示，一根足够长的光滑绝缘杆$MN$，与水平面的夹角为37°，固定在竖直平面内，磁感应强度大小为$B$、方向垂直于纸面向里的匀强磁场充满杆所在的空间，杆与磁场方向垂直。质量为$m$的带电小环沿杆下滑到图中的$P$处时，对杆有垂直于杆向下的压力作用，压力大小为0.4$mg$。已知小环的电荷量为$q$，重力加速度大小为$g$，sin 37°=0.6，下列说法正确的是（　　）

- A．小环带正电
- B．小环滑到$P$处时的速度大小$v_{P}=\dfrac{2mg}{5qB}$
- C．当小环的速度大小为$v=\dfrac{mg}{qB}$时，小环对杆没有压力
- D．当小环与杆之间没有正压力时，小环到$P$的距离$L=\dfrac{{m}^{2}g}{5{q}^{2}{B}^{2}}$

![第 4 题原题图。](assets/xx2/k08-q04-stem1.png)

**答案：B**

**解析**

根据题意，假如没有磁场，由平衡条件及牛顿第三定律可知，小环对杆的压力大小为$mg$cos 37°=0.8$mg$，然而此时小环对杆的压力大小为0.4$mg$，说明小环受到垂直于杆向上的洛伦兹力作用，根据左手定则可知，小环带负电，故A错误；设小环滑到$P$处时的速度大小为$v_{P}$，在$P$处，小环的受力如图甲所示根据平衡条件得$qv_{P}B+F_{N}=mg$cos 37°，由牛顿第三定律得，杆对小环的支持力大小0.4$mg$，联立解得$v_{P}=\dfrac{2mg}{5qB}$，故B正确；设在小环由$P$处下滑到$P$′处时，对杆没有压力，此时小环的速度大小为$v$′，则在$P$′处，小环的受力如图乙所示由平衡条件得$qv'B=mg$cos 37°，变形解得$v'=\dfrac{4mg}{5qB}$，在小环由$P$处滑到$P$′处时，由动能定理得$mgL$sin 37°=$\dfrac{1}{2}mv'^{2}-\dfrac{1}{2}m{v}_{P}^{2}$，代入解得$L=\dfrac{2{m}^{2}g}{5{q}^{2}{B}^{2}}$，故C、D错误。

![第 4 题解析配图。](assets/xx2/k08-q04-1.png)

![第 4 题解析配图。](assets/xx2/k08-q04-2.png)

**问答脚本**

本题考点：用压力大小判断洛伦兹力方向和电性；垂直杆方向的平衡；动能定理求位移。
已知：杆光滑，倾角 $37^\circ$，磁场向里，小环下滑到 $P$ 处时对杆的压力垂直杆向下、大小 $0.4mg$。
提问路线：
1. 问：如果没有磁场，小环对杆的压力是多少？现在只有 $0.4mg$，说明洛伦兹力朝哪？ → 期望：$mg\cos37^\circ=0.8mg$；现在小了，洛伦兹力垂直杆向上。
2. 问：小环沿杆向下运动，洛伦兹力垂直杆向上，用左手定则判断电性。 → 期望：带负电，A 错。
3. 问：在 $P$ 处垂直杆方向列平衡式，$v_P$ 是多少？ → 期望：$qv_PB+0.4mg=0.8mg$，$v_P=\dfrac{2mg}{5qB}$，B 对。
4. 问：对杆没有压力时速度是多少？ → 期望：$qv'B=mg\cos37^\circ$，$v'=\dfrac{4mg}{5qB}$，C 错。
5. 问：从 $P$ 到无压力处，用动能定理求距离 $L$。 → 期望：$mgL\sin37^\circ=\dfrac12mv'^2-\dfrac12mv_P^2$，$L=\dfrac{2m^2g}{5q^2B^2}$，D 错。选 B。
常见错误：
- 无压力时写 $qvB=mg$。追问：洛伦兹力垂直于杆，它要平衡的是重力的哪个分力？
- 动能定理中加入洛伦兹力或支持力做功。追问：这两个力与速度方向是什么关系？
总结句：先用“有无磁场时压力的差别”判断洛伦兹力方向；洛伦兹力和支持力不做功，沿杆用动能定理。

## 5. 多选 · 加速后进入有界磁场的粒子

**题目**

〔多选〕一带负电粒子的质量为$m$、电荷量为$q$，空间中一平行板电容器两极板$\mathrm{S}_{1}$、$\mathrm{S}_{2}$间的电压为$U$。将此粒子在靠近极板$\mathrm{S}_{1}$的$A$处无初速度释放，经电场加速后，经$O$点进入磁感应强度大小为$B$、方向垂直纸面向里的有界匀强磁场（右边界平行于$\mathrm{S}_{2}$），图中实线$Ox$垂直于极板$\mathrm{S}_{2}$，当粒子从$P$点离开磁场时，其速度方向与$Ox$方向的夹角$\theta=60$°，如图所示，整个装置处于真空中，不计粒子所受重力，则（　　）

- A．极板$\mathrm{S}_{1}$带正电
- B．粒子到达$O$点的速度大小为$\sqrt{\dfrac{2qU}{m}}$
- C．此粒子在磁场中运动的时间$t=\dfrac{\pi m}{3qB}$
- D．若改变右侧磁场（左边界位置不变）宽度，使粒子经过$O$点后恰好不能从右侧离开该有界磁场，则该有界磁场区域的宽度$d=\sqrt{\dfrac{Um}{q{B}^{2}}}$

![第 5 题原题图。](assets/xx2/k08-q05-stem1.png)

**答案：BC**

**解析**

带负电粒子向右加速，所受静电力向右，电场强度向左，说明极板$\mathrm{S}_{1}$带负电，故A错误；设粒子到达$O$点的速度大小为$v$，由动能定理可得$qU=\dfrac{1}{2}mv^{2}$，解得$v=\sqrt{\dfrac{2qU}{m}}$，故B正确；由几何关系可知粒子运动的圆心角为$\theta=60$°，此粒子在磁场中运动的时间$t=\dfrac{1}{6}T=\dfrac{1}{6}\times \dfrac{2\pi m}{qB}=\dfrac{\pi m}{3qB}$，故C正确；若改变右侧磁场（左边界位置不变）宽度，使粒子经过$O$点后恰好不能从右侧离开该有界磁场，画出临界轨迹如图所示，根据洛伦兹力提供向心力，并结合牛顿第二定律可得$qvB=m\dfrac{{v}^{2}}{r}$，把A选项中求得的速度大小代入可得$r=\sqrt{\dfrac{2Um}{q{B}^{2}}}$，则该有界磁场区域的宽度$d=r=\sqrt{\dfrac{2Um}{q{B}^{2}}}$，故D错误。

![第 5 题解析配图。](assets/xx2/k08-q05-1.png)

**问答脚本**

本题考点：电场加速（动能定理）；有界磁场中的偏转角与圆心角；恰好不穿出的临界条件。
已知：负电粒子从 $S_1$ 附近 $A$ 处由静止加速，电压 $U$，从 $O$ 垂直进入向里的磁场，从 $P$ 射出时速度与 $Ox$ 夹角 $60^\circ$。
提问路线：
1. 问：负电粒子向右加速，受的静电力朝右，电场朝哪？$S_1$ 带什么电？ → 期望：电场向左，$S_2$ 电势高，$S_1$ 带负电，A 错。
2. 问：粒子到 $O$ 点的速度多大？ → 期望：$qU=\dfrac12mv^2$，$v=\sqrt{\dfrac{2qU}{m}}$，B 对。
3. 问：速度偏转了 $60^\circ$，圆心角是多少？运动时间多少？ → 期望：圆心角 $60^\circ$，$t=\dfrac T6=\dfrac{\pi m}{3qB}$，C 对。
4. 问：恰好不从右边界离开时，轨迹与右边界什么关系？磁场宽度等于什么？ → 期望：相切，宽度等于半径 $r=\dfrac{mv}{qB}=\sqrt{\dfrac{2Um}{qB^2}}$；D 中少了 2，错。选 BC。
常见错误：
- 偏转角与圆心角混淆。追问：速度方向转过的角度和轨迹所对圆心角有什么关系？
- D 中把宽度当成直径。追问：粒子垂直左边界进入，轨迹最远到达离左边界多远处？
总结句：速度偏转角 = 圆心角；垂直边界射入时，恰不穿出的宽度等于轨迹半径。

## 6. 多选 · 电场偏转后进入磁场打到原点

**题目**

〔多选〕如图所示的$xOy$坐标系中，$y$轴左侧存在场强为$E$的匀强电场，电场方向平行于$x$轴向右，$y$轴右侧存在垂直坐标系所在平面向外的匀强磁场。一个比荷为$k$的带正电粒子从$x$轴上的$M$点以某一初速度平行于$y$轴向上运动，经电场偏转后从$y$轴上的$P$点进入磁场，进入磁场时速度方向与$y$轴正方向成60°角，粒子经磁场偏转后打到坐标原点$O$上。已知$M$点到$O$点的距离为$L$，不计粒子的重力，下列说法正确的是（　　）

- A．$P$与$O$的距离为$\dfrac{\sqrt{3}}{3}L$
- B．粒子的轨迹半径为$\dfrac{\sqrt{3}}{3}L$
- C．粒子初速度大小为$\dfrac{\sqrt{6kEL}}{3}$
- D．磁场的磁感应强度大小为$\sqrt{\dfrac{6E}{kL}}$

![第 6 题原题图。](assets/xx2/k08-q06-stem1.png)

**答案：CD**

**解析**

粒子的运动轨迹如图所示，根据类平抛运动推论有$\dfrac{L}{s}=\dfrac{1}{2}$tan 60°，解得$P$与$O$的距离$s=\dfrac{2\sqrt{3}}{3}L$，A错误；由几何关系有$s=2R$sin 60°，解得$R=\dfrac{2}{3}L$，B错误；根据$s=v_{0}t$，$L=\dfrac{1}{2}at^{2}$，$qE=ma$，$\dfrac{q}{m}=k$，联立解得$v_{0}=\dfrac{\sqrt{6kEL}}{3}$，C正确；粒子在$P$点的合速度$v=\dfrac{{v}_{0}}{\cos 60°}=2v_{0}$，由$R=\dfrac{2}{3}L=\dfrac{mv}{qB}$，解得$B=\sqrt{\dfrac{6E}{kL}}$，D正确。

![第 6 题解析配图。](assets/xx2/k08-q06-1.png)

**问答脚本**

本题考点：类平抛运动的推论（速度反向延长线过水平位移中点）；磁场中弦长与半径；比荷 $k$ 的运用。
已知：$y$ 轴左侧电场 $E$ 向右，右侧磁场向外；比荷 $k$ 的正粒子从 $M(-L,0)$ 沿 $+y$ 射出，到 $P$ 时速度与 $y$ 轴正方向成 $60^\circ$，在磁场中偏转后打到 $O$。
提问路线：
1. 问：粒子在电场中做什么运动？哪个方向匀速、哪个方向匀加速？ → 期望：类平抛；沿 $y$ 方向匀速 $v_0$，沿 $x$ 方向匀加速。
2. 问：设 $OP=s$。到 $P$ 时速度与 $y$ 轴夹角 $60^\circ$，由类平抛推论 $\tan60^\circ=\dfrac{2L}{s}$，$s$ 等于多少？ → 期望：$s=\dfrac{2\sqrt3}{3}L$，A 错。
3. 问：粒子在磁场中从 $P$ 到 $O$，弦 $PO=s$，弦与速度的夹角为 $60^\circ$，半径是多少？ → 期望：$s=2R\sin60^\circ$，$R=\dfrac23L$，B 错。
4. 问：由 $s=v_0t$、$L=\dfrac12\cdot kE\cdot t^2$ 求 $v_0$。 → 期望：$v_0=\dfrac{\sqrt{6kEL}}{3}$，C 对。
5. 问：进入磁场的速度多大？$B$ 多大？ → 期望：$v=\dfrac{v_0}{\cos60^\circ}=2v_0$；由 $R=\dfrac{v}{kB}$ 得 $B=\sqrt{\dfrac{6E}{kL}}$，D 对。选 CD。
常见错误：
- 速度分解用错角：把 $60^\circ$ 当作与 $x$ 轴的夹角。追问：题目说的是与哪条轴成 $60^\circ$？匀速方向是哪个方向？
- 进入磁场的速度仍用 $v_0$。追问：在 $P$ 点粒子还有沿 $x$ 方向的速度吗？
总结句：电场中类平抛求出进入磁场的速度大小和方向，再在磁场中用弦长与半径的关系；两段在 $P$ 点衔接。

## 7. 单选 · 交变磁场中离子垂直射出的条件

**题目**

（2026·浙江台州期中）如图甲所示，M、N为竖直放置彼此平行的两块平板，板间距离为$d$，两板中央各有一个小孔$O$、$O$′正对，在两板间有垂直于纸面方向的磁场，磁感应强度随时间的变化如图乙所示。有一群正离子在$t=0$时垂直于M板从小孔$O$射入磁场。已知离子质量为$m$、带电荷量为$q$，离子在磁场中做匀速圆周运动的周期与磁感应强度变化的周期都为$T_{0}$，不考虑由于磁场变化而产生的电场的影响，不计离子所受重力。若要使离子从$O$′垂直于N板射出磁场，则离子射入磁场时的速度$v_{0}$可能为（　　）

- A．$\dfrac{\pi d}{4{T}_{0}}$
- B．$\dfrac{3\pi d}{4{T}_{0}}$
- C．$\dfrac{\pi d}{5{T}_{0}}$
- D．$\dfrac{3\pi d}{5{T}_{0}}$

![第 7 题原题图。](assets/xx2/k08-q07-stem1.png)

**答案：A**

**解析**

![动画演示：每个周期前进 4R，两个周期后从 O′ 垂直射出](assets/xx2/k08-q07-anim.svg)

要使正离子从$O$′孔垂直于N板射出磁场，$v_{0}$的方向变化可能如图所示两板之间正离子只运动一个周期即$T_{0}$时，有$R=\dfrac{d}{4}$；当两板之间正离子运动$n$个周期即$nT_{0}$时，有$R=\dfrac{d}{4n}(n=1$，2，3，…）。联立解得正离子的速度大小的可能值为$v_{0}=\dfrac{{B}_{0}qR}{m}=\dfrac{\pi d}{2n{T}_{0}}(n=1$，2，3，…）。

![第 7 题解析配图。](assets/xx2/k08-q07-1.png)

当$n=2$时，$v_{0}=\dfrac{\pi d}{4{T}_{0}}$，故选A。

**问答脚本**

本题考点：周期性变化的磁场；离子运动周期与磁场变化周期相同；从 $O'$ 垂直射出的轨迹规律与多解。
已知：板间距 $d$，磁场方向每半个周期 $\dfrac{T_0}{2}$ 反向一次，离子圆周运动周期也是 $T_0$；$t=0$ 时离子从 $O$ 垂直 M 板射入。
提问路线：
1. 问：离子在磁场中转一圈用时 $T_0$，磁场每过 $\dfrac{T_0}{2}$ 反向一次。看轨迹图，离子先向哪个方向偏？磁场反向后偏转方向怎样变？ → 期望：离子每 $\dfrac{T_0}{4}$ 转过 $90^\circ$；按图中轨迹，每次磁场反向后弯曲方向反过来，轨迹呈波浪形向右推进。
2. 问：看轨迹图，离子在一个磁场周期 $T_0$ 内水平前进多远（用半径 $R$ 表示）？ → 期望：前进 $4R$。
3. 问：要从 $O'$ 垂直射出，离子在板间经历 $n$ 个周期时，$d$ 与 $R$ 是什么关系？ → 期望：$d=4nR$，$R=\dfrac{d}{4n}$（$n=1,2,3,\dots$）。
4. 问：由 $R=\dfrac{mv_0}{qB_0}$ 和 $T_0=\dfrac{2\pi m}{qB_0}$，把 $v_0$ 用 $R$、$T_0$ 表示，得到通式。 → 期望：$v_0=\dfrac{2\pi R}{T_0}=\dfrac{\pi d}{2nT_0}$。
5. 问：$n$ 取哪个值时与选项对应？ → 期望：$n=2$ 时 $v_0=\dfrac{\pi d}{4T_0}$，选 A；其他选项不满足通式。
常见错误：
- 只考虑 $n=1$，找不到选项。追问：离子可以在板间运动不止一个周期吗？
- 一个周期内前进距离算成 $2R$。追问：照着轨迹图数一数，一个周期离子经过了几个四分之一圆弧？水平方向每段前进多少？
总结句：交变磁场问题先画一个周期的轨迹，找出一个周期内的位移规律，再写出 $n$ 个周期的通式，注意多解。

## 9. 计算 · 类平抛后进入磁场恰不穿出

**题目**

如图所示，平面直角坐标系$xOy$中，第Ⅰ象限存在沿$y$轴负方向的匀强电场，第Ⅳ象限在$x$轴与$y=-d$之间的区域内存在垂直于平面向外的匀强磁场。一质量为$m$、电荷量为$q(q$＞0）的带电粒子以初速度$v_{0}$从$y$轴上$P$（0，$h$）点沿$x$轴正方向开始运动，经过电场后从$x$轴上的点$Q\left(\dfrac{2\sqrt{3}}{3}h，0\right)$进入磁场，粒子恰能从磁场的下边界离开磁场。不计粒子所受重力，求：

（1）粒子在$Q$点速度的大小$v_{Q}$和与$x$轴正方向的夹角$\theta$；

（2）匀强磁场磁感应强度的大小$B$；

（3）粒子在电场、磁场中运动的总时间。

![第 9 题原题图。](assets/xx2/k08-q09-stem1.png)

**答案：（1）2$v_{0}$　60°　（2）$\dfrac{3m{v}_{0}}{qd}$　（3）$\dfrac{2\sqrt{3}h}{3{v}_{0}}+\dfrac{2\pi d}{9{v}_{0}}$**

**解析**

![动画演示：类平抛到 Q，进入磁场转过 120°，恰好与下边界相切](assets/xx2/k08-q09-anim.svg)

（1）设粒子从$P$到$Q$的过程中，沿$y$轴方向，加速度大小为$a$，运动时间为$t$，在$Q$点进入磁场时速度$v_{Q}$沿$y$轴方向的分速度大小为$v_{y}$，且在$Q$点速度方向与$x$轴正方向夹角为$\theta$，则$\dfrac{2\sqrt{3}}{3}h=v_{0}t$，$h=\dfrac{1}{2}at^{2}$，$v_{y}=at$，$v_{Q}=\sqrt{{v}_{0}^{2}+{v}_{y}^{2}}$，tan$　\theta =\dfrac{{v}_{y}}{{v}_{0}}$，联立解得$v_{Q}=2v_{0}$，$\theta=60$°。

（2）设粒子在匀强磁场中做匀速圆周运动的半径为$R$，则$qv_{Q}B=m\dfrac{{v}_{Q}^{2}}{R}$，解得$R=\dfrac{m{v}_{Q}}{qB}$，粒子运动轨迹如图所示，又由几何关系可得$d=R+\dfrac{1}{2}R$联立解得$B=\dfrac{3m{v}_{0}}{qd}$。

![第 9 题解析配图。](assets/xx2/k08-q09-1.png)

（3）由（1）可知粒子在电场中运动的时间$t=\dfrac{2\sqrt{3}h}{3{v}_{0}}$，根据几何关系可知，粒子在磁场中转过的圆心角为$\alpha=120$°，在磁场中运动的周期$T=\dfrac{2\pi R}{{v}_{Q}}$，解得$T=\dfrac{2\pi m}{qB}=\dfrac{2\pi d}{3{v}_{0}}$，在磁场中运动的时间$t'=\dfrac{\alpha }{360°}T=\dfrac{2\pi d}{9{v}_{0}}$，粒子运动的总时间$t_{\text{总}}=t+t'=\dfrac{2\sqrt{3}h}{3{v}_{0}}+\dfrac{2\pi d}{9{v}_{0}}$。

**问答脚本**

本题考点：类平抛运动求速度大小和方向；“恰能从下边界离开”的临界几何关系；总时间。
已知：第Ⅰ象限电场沿 $-y$，第Ⅳ象限 $0>y>-d$ 区域磁场向外；粒子从 $P(0,h)$ 以 $v_0$ 沿 $+x$ 射出，经 $Q\left(\dfrac{2\sqrt3}{3}h,0\right)$ 进入磁场，恰能从下边界离开。
提问路线：
1. 问：（1）在电场中做什么运动？水平和竖直方向各满足什么方程？ → 期望：类平抛；$\dfrac{2\sqrt3}{3}h=v_0t$，$h=\dfrac12at^2$，$v_y=at$。
2. 问：解出 $v_y$、$v_Q$ 和夹角 $\theta$。 → 期望：$v_y=\sqrt3v_0$，$v_Q=2v_0$，$\tan\theta=\sqrt3$，$\theta=60^\circ$。
3. 问：（2）“恰能从下边界离开”说明轨迹与下边界是什么关系？ → 期望：轨迹恰好与下边界 $y=-d$ 相切。
4. 问：在 $Q$ 点作速度的垂线找圆心，圆心到 $x$ 轴的距离是多少？由相切列出几何关系。 → 期望：圆心在 $x$ 轴下方 $R\cos60^\circ=\dfrac R2$ 处；$d=R+\dfrac R2$，$R=\dfrac23d$。
5. 问：由 $R=\dfrac{mv_Q}{qB}$ 求 $B$。 → 期望：$B=\dfrac{3mv_0}{qd}$。
6. 问：（3）电场中的时间是多少？磁场中转过多少度？时间多少？ → 期望：$t_1=\dfrac{2\sqrt3h}{3v_0}$；转过 $120^\circ$，$T=\dfrac{2\pi R}{v_Q}=\dfrac{2\pi d}{3v_0}$，$t_2=\dfrac T3=\dfrac{2\pi d}{9v_0}$；总时间 $\dfrac{2\sqrt3h}{3v_0}+\dfrac{2\pi d}{9v_0}$。
常见错误：
- 进入磁场的速度仍用 $v_0$。追问：经过电场后速度大小变了吗？
- 几何关系写成 $d=R$ 或 $d=2R$。追问：圆心在 $x$ 轴下方多远？最低点又在圆心下方多远？
- 周期用 $\dfrac{2\pi R}{v_0}$。追问：在磁场中粒子的速率是多少？
总结句：电场 → 磁场的组合问题：电场中求出进入磁场的速度大小与方向，磁场中找圆心、用临界相切列几何关系。

带电粒子在电容器N及磁场中的运动轨迹如图所示，由几何关系得∠$OPQ=45$°，带电粒子在磁场中做匀速圆周运动，轨迹半径$r=\dfrac{d}{\cos 45°}=\sqrt{2}d$，由$qv_{P}B=m\dfrac{{v}_{P}^{2}}{r}$得$B=\dfrac{1}{d}\sqrt{\dfrac{2mU}{q}}$。

**问答脚本**

本题考点：加速电场（动能定理）；偏转电场（类平抛）；进入磁场后垂直穿过 $x$ 轴的几何关系。
已知：两电容器电压都是 $U$，粒子从 N 下极板边缘进入，恰从上极板边缘射出；N 的板间距等于 $OP=d$；粒子从 $P$ 进入磁场，最后垂直 $x$ 轴穿过。
提问路线：
1. 问：（1）粒子经 M 加速后速度多大？ → 期望：$qU=\dfrac12mv_N^2$，$v_N=\sqrt{\dfrac{2qU}{m}}$。
2. 问：（2）在 N 中沿 $y$ 方向的加速度是多少？从下极板到上极板偏移 $d$，到 $P$ 时竖直分速度多大？ → 期望：$a=\dfrac{qU}{md}$；$v_y=\sqrt{2ad}=\sqrt{\dfrac{2qU}{m}}=v_x$。
3. 问：$v_x=v_y$，速度方向与 $y$ 轴正方向的夹角是多少？速度大小呢？ → 期望：$45^\circ$，斜向右上方；$v_P=\sqrt2v_N=2\sqrt{\dfrac{qU}{m}}$。
4. 问：（3）粒子垂直穿过 $x$ 轴，说明圆心在哪里？结合 $P$ 点速度方向，半径与 $d$ 是什么关系？ → 期望：圆心在 $x$ 轴上，且在 $P$ 点速度的垂线上；$\angle OPQ=45^\circ$，$r=\dfrac{d}{\cos45^\circ}=\sqrt2d$。
5. 问：由 $qv_PB=m\dfrac{v_P^2}{r}$ 求 $B$。 → 期望：$B=\dfrac{mv_P}{qr}=\dfrac1d\sqrt{\dfrac{2mU}{q}}$。
常见错误：
- 偏转电场中的加速度用 $\dfrac{qU}{mL}$ 或漏掉板间距。追问：偏转电场的场强等于电压除以什么？
- 进入磁场的速度仍用 $v_N$。追问：经过偏转电场后，速度大小变了吗？
- 半径直接取 $d$。追问：圆心在 $x$ 轴上哪一点？它到 $P$ 的距离是多少？
总结句：粒子穿过多个场时，每一段的末速度就是下一段的初速度；进入磁场后用“速度垂线 + 已知出射条件”定圆心。
