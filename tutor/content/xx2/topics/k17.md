## 1. 单选 · 磁场增强时环管中的带电小球

**题目**

如图所示，内壁光滑的塑料管弯成的圆环平放在水平桌面上，环内有一带负电的小球，整个装置处于竖直向下的磁场中，当磁场突然增强时，小球将（　　）

- A．沿顺时针方向运动
- B．沿逆时针方向运动
- C．在原位置附近往复运动
- D．仍然保持静止状态

![第 1 题原题图。](assets/xx2/k17-q01-stem1.png)

**答案：A**

**解析**

磁感应强度的方向竖直向下，当磁场突然增强时，由楞次定律可知，感生电场沿逆时针方向，由于小球带负电，所以小球将沿顺时针方向运动，A正确。

**问答脚本**

本题考点：变化的磁场产生感生电场（涡旋电场）；楞次定律判断感生电场方向；负电荷受力与场强方向相反。
已知：磁场竖直向下（图中“×”，俯视看为垂直纸面向里），突然增强；小球带负电，在光滑环管中。
提问路线（每次只问一个问题）：
1. 问：环管里没有导线，但磁场在变，空间中会产生什么？ → 期望：变化的磁场在周围产生感生电场（涡旋电场），电场线是闭合的圆。
2. 问：设想环管位置有一圈导线，磁场向里增强，感应电流沿什么方向？感生电场就沿这个方向。 → 期望：感应电流的磁场要向外，电流沿逆时针，感生电场沿逆时针。
3. 问：小球带负电，受力方向与场强方向相同还是相反？小球怎样运动？ → 期望：相反，受力沿顺时针，小球沿顺时针运动，选 A。
常见错误：
- 认为没有导体就没有感应现象（选 D）。追问：感生电场是由什么产生的？需要导体才存在吗？
- 方向判反（选 B）。追问：楞次定律给出的是正电荷（电流）的方向，负电荷受力是同向还是反向？
- 以为小球会往复运动（选 C）。追问：感生电场沿环一直是同一个绕向吗？
总结句：变化的磁场产生感生电场，方向按“假想导线中的感应电流方向”用楞次定律判断；负电荷受力与之相反。

## 2. 单选 · 费曼圆盘：感生电场推动带电小球

**题目**

著名物理学家费曼曾设计这样一个实验装置：一块绝缘圆板可绕其中心的光滑轴自由转动，在圆板的中部有一个线圈，圆板的四周固定着一圈带电的金属小球，如图所示。当线圈接通电源后，将有图示方向的电流流过，则下列说法正确的是（　　）

- A．接通电源瞬间，圆板不会发生转动
- B．线圈中电流的增大或减小会引起圆板向相同方向转动
- C．接通电源后，保持线圈中电流不变，圆板转动方向与线圈中电流流向相同
- D．若金属小球带负电，接通电源瞬间圆板转动方向与线圈中电流流向相同

![第 2 题原题图。](assets/xx2/k17-q02-stem1.png)

**答案：D**

**解析**

线圈接通电源瞬间，变化的磁场产生电场，导致带电小球受到电场力，从而使圆板转动，故A错误；不论线圈中电流增大或减小都会引起磁场的变化，从而产生电场，使小球受到电场力，从而使圆板转动，由于小球所受电场力的方向与所带电荷正负有关，故B错误；接通电源后，保持线圈中电流不变，则磁场不变，不会产生电场，小球不受电场力作用，故C错误；接通电源瞬间小球受到电场力作用而使圆板转动，由于金属小球带负电，圆盘转动方向与线圈中电流流向相同，故D正确。

**问答脚本**

本题考点：线圈电流变化 → 磁场变化 → 感生电场；电荷正负决定受力方向；稳恒电流不产生感生电场。
已知：圆板中心有线圈，周围固定一圈带电金属小球，圆板可绕中心轴自由转动。
提问路线：
1. 问：接通电源瞬间，线圈电流从零增大，线圈的磁场怎样变？会产生什么场？小球受力吗？ → 期望：磁场增大，产生感生电场，带电小球受电场力，圆板转动，A 错。
2. 问：电流增大和减小时，感生电场方向相同吗？圆板转向相同吗？ → 期望：相反，所以转向相反，B 错。
3. 问：电流保持不变时，磁场变不变？还有感生电场吗？ → 期望：磁场不变，没有感生电场，小球不受力，圆板不会被驱动，C 错。
4. 问：电流增大时，感生电场方向与线圈电流方向相同还是相反？负电荷受力又朝哪？ → 期望：感生电场阻碍磁场增大，与线圈电流反向；负电荷受力与场强相反，即与线圈电流同向，圆板转向与电流流向相同，D 对。选 D。
常见错误：
- 认为电流恒定时也会转动。追问：感生电场的来源是“磁场”还是“磁场的变化”？
- 忽略电荷正负。追问：电场力方向与电荷的正负有关吗？
总结句：只有变化的磁场才产生感生电场；电流增大时感生电场与原电流反向，正电荷受力与原电流反向、负电荷同向。

## 3. 单选 · 缩短涡流加热时间的措施

**题目**

（2026·浙江台州期中）如图所示，在线圈上端放置一盛有冷水的金属杯，现接通交流电源，过了几分钟，杯内的水沸腾起来。若要缩短上述加热时间，下列措施可行的有（　　）

- A．增加线圈的匝数
- B．将金属杯换为陶瓷杯
- C．降低交流电源的频率
- D．交流电源换为直流电源

![第 3 题原题图。](assets/xx2/k17-q03-stem1.png)

**答案：A**

**解析**

冷水加热的原理是线圈中的电流变化，引起金属杯中任一截面的磁通量变化，在金属杯中产生涡流，涡流发热通过热传递加热冷水，陶瓷是绝缘体，不能产生感应电流，B、D错误；要想提高加热效率，应增加线圈的匝数或提高交流电源的频率，这样可增大涡流，A正确，C错误。

**问答脚本**

本题考点：涡流的产生与影响因素（磁通量变化率）；绝缘体中不能形成涡流。
已知：线圈接交流电，上端金属杯中冷水被加热。
提问路线：
1. 问：水是怎样被加热的？热量最先在哪里产生？ → 期望：交变磁场在金属杯中产生涡流，涡流发热再传给水。
2. 问：换成陶瓷杯、或者换成直流电，还能产生涡流吗？ → 期望：陶瓷是绝缘体不能形成电流；直流时磁场不变，没有感应电流，B、D 错。
3. 问：涡流的大小跟磁通量变化率有关。增加匝数、降低频率分别会让变化率怎样变？ → 期望：增加匝数使磁场更强、变化率增大，涡流增大，加热更快，A 对；降低频率使变化变慢，涡流减小，C 错。选 A。
常见错误：
- 以为热量来自线圈本身。追问：线圈和杯子没有接触，热量是怎样“传”到杯子里的？
- 选 C。追问：频率降低，磁场变化得更快还是更慢？
总结句：涡流加热需要导体和变化的磁场；磁场越强、变化越快（匝数多、频率高），涡流越大、发热越快。

## 4. 单选 · 金属薄片通过磁极时的涡电流方向

**题目**

（2025·河南高考）如图，一金属薄片在力$F$作用下自左向右从两磁极之间通过。

当金属薄片中心运动到N极的正下方时，沿N极到S极的方向看，下列图中能够正确描述金属薄片内涡电流绕行方向的是（　　）

![第 4 题原题图。](assets/xx2/k17-q04-stem1.png)

![第 4 题原题图。](assets/xx2/k17-q04-stem2.png)

![第 4 题原题图。](assets/xx2/k17-q04-stem3.png)

**答案：C**

**解析**

根据题意知，当金属薄片中心运动到N极正下方时，薄片右侧的磁通量在减小，左侧磁通量在增加，由于两极间的磁场方向竖直向下，根据楞次定律可知此时薄片右侧的涡电流方向为顺时针，薄片左侧的涡电流方向为逆时针。故选C。

**问答脚本**

本题考点：楞次定律判断涡电流方向；薄片前后两部分磁通量一增一减。
已知：两磁极间磁场竖直向下（N 在上），薄片向右运动，中心在 N 极正下方；沿 N 到 S 方向看（即从上往下看）。
提问路线：
1. 问：薄片中心在磁极正下方时，薄片右半部分正在离开磁场还是进入磁场？磁通量增大还是减小？左半部分呢？ → 期望：右半在离开、磁通量减小；左半在进入、磁通量增大。
2. 问：右半部分向下的磁通量在减小，感应电流的磁场应朝哪？从上往下看电流怎样绕？ → 期望：感应磁场向下，从上往下看顺时针。
3. 问：左半部分向下的磁通量在增大，感应电流怎样绕？哪个图对应“左逆时针、右顺时针”？ → 期望：感应磁场向上，逆时针；对应 C。
常见错误：
- 两部分方向判成相同。追问：左右两部分磁通量的变化趋势一样吗？
- 忘了观察方向是从上往下看。追问：沿 N 极到 S 极方向看，是俯视还是仰视？
总结句：导体穿过有界磁场时，进入的部分和离开的部分磁通量变化相反，涡流绕向也相反。

## 5. 单选 · 磁性小球穿过开槽铝管的时间

**题目**

（2026·浙江嘉兴期中）甲、乙、丙原为三个相同的铝管，甲、乙两管的侧壁分别开有图示的横槽和竖槽，丙管未开槽，将一个磁性小球分别由甲、乙、丙上端管口处静止释放，对小球穿过三个铝管的时间进行比较，结果为（　　）

- A．甲最短
- B．乙最短
- C．丙最短
- D．三者相同

![第 5 题原题图。](assets/xx2/k17-q05-stem1.png)

**答案：B**

**解析**

小球穿过铝管过程中，铝管中的磁通量发生变化，在铝管侧壁产生感应电流，而感应电流在磁场中受安培力阻碍小球的运动，也可以根据楞次定律来拒去留的特点可知丙管中小球受到的阻力最大，时间最长；而甲管是水平开槽，乙管是竖直开槽，由于感应电流是水平环形电流，所以开槽部分相当于断路，即竖直方向开槽以外的部分才有感应电流，这样乙管有效宽度最窄，感应电流最小，阻力最小，小球下落最快，乙管下落时间最短，选B。

**问答脚本**

本题考点：来拒去留；感应电流路径被切断时阻力减小；铝管中感应电流沿水平环形流动。
已知：甲开横槽，乙开竖槽，丙不开槽，同样的磁性小球从上端由静止释放。
提问路线：
1. 问：磁性小球在铝管中下落时，铝管的每一圈相当于一个闭合线圈，感应电流沿什么方向流？对小球有什么作用？ → 期望：沿水平环形流动，阻碍小球下落。
2. 问：乙管开竖槽，水平环形电流还能形成闭合回路吗？ → 期望：竖槽把每一圈都切断了，环形电流基本不能形成，阻力最小。
3. 问：甲管开横槽，只影响了槽所在的一小段高度，其余部分呢？丙管呢？谁用时最短？ → 期望：甲管大部分高度电流仍能流通，丙管完全闭合阻力最大；乙用时最短，选 B。
常见错误：
- 认为横槽切断电流更多。追问：感应电流是竖直流还是水平绕圈流？横槽能切断所有高度的电流吗？
- 认为三者相同（选 D）。追问：铝管不导磁，但会产生感应电流，感应电流会对小球产生力吗？
总结句：判断阻尼大小就看感应电流能不能顺畅地流成闭合回路；顺着电流方向“切断”回路，阻尼就小。

## 6. 多选 · 磁控健身车的阻力

**题目**

〔多选〕磁控健身车车轮处的结构示意图如图所示，在金属飞轮的外侧有一些磁体（与飞轮不接触），人用力蹬车带动飞轮旋转时，磁体会对飞轮产生阻碍作用，拉动旋钮拉线可以改变磁体与飞轮间的距离。下列说法正确的有（　　）

- A．飞轮受到的阻力主要来源于磁体对它的安培力
- B．飞轮转速一定时，磁体越靠近飞轮，飞轮受到的阻力越小
- C．磁体和飞轮间的距离一定时，飞轮转速越大，受到的阻力越小
- D．磁体和飞轮间的距离和飞轮转速一定时，磁体磁性越强，阻力越大

![第 6 题原题图。](assets/xx2/k17-q06-stem1.png)

**答案：AD**

**解析**

根据题意，人用力蹬车带动飞轮旋转时，磁体会对飞轮产生阻碍作用，飞轮受到的阻力主要来源于磁体对它的安培力，选项A正确；飞轮转速一定时，磁体越靠近飞轮，飞轮受到的安培力越大，即阻力越大，选项B错误；磁体和飞轮间的距离一定时，飞轮转速越大，磁通量的变化率越大，产生的安培力越大，受到的阻力越大，选项C错误，距离和转速一定时，磁体磁性越强，阻力越大，D正确。

**问答脚本**

本题考点：电磁阻尼；涡流大小与磁场强弱、相对运动速度的关系。
已知：金属飞轮外侧有磁体（不接触），旋钮可改变磁体与飞轮的距离。
提问路线：
1. 问：磁体和飞轮不接触，阻力从哪来？ → 期望：飞轮转动时在磁场中产生涡流，涡流受磁体的安培力阻碍转动，A 对。
2. 问：磁体越靠近飞轮，飞轮处的磁场越强还是越弱？涡流和阻力怎样变？ → 期望：越强，涡流越大，阻力越大，B 错。
3. 问：转速越大，磁通量变化越快还是越慢？阻力怎样变？ → 期望：越快，感应电流越大，阻力越大，C 错。
4. 问：距离和转速一定，磁体磁性越强，阻力怎样？ → 期望：越大，D 对。选 AD。
常见错误：
- 认为转速越大阻力越小。追问：感应电动势与速度有什么关系？安培力呢？
- 认为阻力是摩擦力。追问：磁体和飞轮有没有接触？
总结句：电磁阻尼的大小随磁场强度、相对运动速度增大而增大，方向总是阻碍相对运动。

## 7. 多选 · 磁铁转动带动铝盘（电磁驱动）

**题目**

〔多选〕（2026·广东佛山期中）

如图是某同学自制的简易磁力传动装置，铝制圆盘放置在可旋转底座上，圆盘正上方悬挂条形磁铁。关于该装置，从上往下看，说法正确的是（　　）

- A．当条形磁铁顺时针转动时，铝制圆盘顺时针转动
- B．当条形磁铁顺时针转动时，铝制圆盘逆时针转动
- C．当条形磁铁的转速变快时，铝制圆盘转速也变快
- D．当条形磁铁停止转动时，铝制圆盘会立即停止运动

![第 7 题原题图。](assets/xx2/k17-q07-stem1.png)

**答案：AC**

**解析**

![动画演示：铝盘跟着磁铁同向转动但总比磁铁慢，磁铁停下后铝盘逐渐停下](assets/xx2/k17-q07-anim.svg)

当条形磁铁顺时针转动时，穿过铝制圆盘的磁通量会发生变化，根据楞次定律可知，圆盘内产生的感应电流的磁场会阻碍磁通量的变化，所以铝制圆盘也顺时针转动，A正确，B错误；当磁铁的转速变快时，穿过铝制圆盘的磁通量变化加快，圆盘内产生的感应电流的磁场也会加快阻碍磁通量的变化，所以铝制圆盘转速也变快，C正确；当条形磁铁停止转动，由于铝制圆盘转动过程中仍产生感应电流，所以圆盘会逐渐减速直至停止运动，D错误。

**问答脚本**

本题考点：电磁驱动；楞次定律“阻碍相对运动”；铝盘总比磁铁转得慢。
已知：条形磁铁悬挂在铝盘正上方，铝盘放在可旋转底座上；从上往下看。
提问路线：
1. 问：磁铁顺时针转动时，铝盘和磁铁之间有相对运动吗？铝盘中会产生什么？ → 期望：有相对运动，铝盘中产生感应电流（涡流）。
2. 问：楞次定律说感应电流的效果要阻碍什么？铝盘会被带着往哪个方向转？ → 期望：阻碍两者的相对运动，铝盘被带着顺时针转，A 对 B 错。
3. 问：磁铁转得更快，相对运动和驱动作用怎样变？铝盘转速呢？ → 期望：驱动作用更强，铝盘转速也变快，C 对。
4. 问：磁铁停转后，铝盘还在转，相对运动还存在吗？铝盘会立即停下吗？ → 期望：仍有相对运动，产生阻碍铝盘转动的电磁阻尼，铝盘逐渐减速停下，不是立即停，D 错。选 AC。
常见错误：
- 认为铝盘反向转动（选 B）。追问：阻碍相对运动，是让铝盘“追”磁铁还是“背离”磁铁？
- 认为铝盘会和磁铁一样快。追问：如果一样快，还有相对运动和感应电流吗？
总结句：电磁驱动中导体总是跟着磁场同向转，但转速总小于磁场的转速；磁场停了导体会因电磁阻尼逐渐停下。

## 8. 单选 · 高速列车的电磁制动

**题目**

（2026·浙江宁波期中）如图是高速列车上使用的电磁制动装置示意图。

与传统的制动方式相比，电磁制动是一种非接触的制动方式，避免了因摩擦产生的磨损。电磁制动的原理是当金属圆盘D在磁场中运动时，会产生涡流，使圆盘受到阻碍运动的制动力。下列说法正确的是（　　）

- A．制动过程中，圆盘不会产生热量
- B．制动力的大小与圆盘运动的速度无关
- C．换用更强的磁场，制动效果更好
- D．如果改变磁场的方向，可以使圆盘获得促进它运动的动力

![第 8 题原题图。](assets/xx2/k17-q08-stem1.png)

**答案：C**

**解析**

电磁制动的原理是当金属圆盘D在磁场中运动时，会产生涡流，金属盘会产生热量，故A错误；圆盘运动的速度越大，磁通量变化越快，产生的感应电流越强，制动器对圆盘的制动力越大，故制动力的大小与圆盘运动的速度有关，故B错误；换用更强的磁场，圆盘受到的安培阻力更大，则制动效果更好，故C正确；如果改变磁场的方向，产生的涡流方向也相反，根据安培力的公式，电流和所处的磁场方向同时反向，安培力方向不变，故圆盘还是受到阻碍运动的制动力，故D错误。

**问答脚本**

本题考点：电磁制动（涡流阻尼）；能量转化；制动力与速度、磁场的关系；电流和磁场同时反向时安培力方向不变。
提问路线：
1. 问：制动时圆盘的动能转化成了什么？圆盘会发热吗？ → 期望：转化为涡流的电能，最终变成焦耳热，圆盘会发热，A 错。
2. 问：圆盘转得越快，磁通量变化越快，感应电流和制动力怎样变？ → 期望：越大，制动力与速度有关，B 错。
3. 问：换用更强的磁场呢？ → 期望：感应电流和安培力都更大，制动效果更好，C 对。
4. 问：磁场反向后，涡流方向也反向，安培力 $F=BIL$ 中两个都反向，力的方向变吗？ → 期望：不变，仍是阻力，D 错。选 C。
常见错误：
- 认为磁场反向就能变成动力。追问：楞次定律说感应电流的效果总是什么？跟磁场方向有关吗？
- 认为制动力与速度无关。追问：速度为零时还有涡流吗？
总结句：电磁制动的阻力随速度和磁场增大而增大，总是阻碍运动，与磁场方向无关；动能最终变成焦耳热。

## 10. 单选 · 电磁涡流制动的制动力

**题目**

（2026·浙江丽水期中）如图所示，电磁涡流制动是一种非接触的制动方式，其原理是当导体在通电线圈产生的磁场中运动时，会产生涡流，使导体受到阻碍运动的制动力。下列说法正确的是（　　）

- A．制动过程中，导体不会产生热量
- B．线圈电流一定时，导体运动的速度越大，制动力就越大
- C．如果导体反向转动，此装置将不起制动作用
- D．制动力的大小与线圈中电流的大小无关

![第 10 题原题图。](assets/xx2/k17-q10-stem1.png)

**答案：B**

**解析**

制动过程中，导体在磁场中运动产生涡流，涡流在导体的电阻上会产生焦耳热，因此导体会产生热量，A错误；线圈电流一定时，产生的磁场磁感应强度$B$一定。导体运动速度越大，切割磁感线产生的感应电动势越大，涡流$I$也越大。根据$F=BIL$可知，制动力（安培力）就越大，B正确；如果导体反向转动，导体切割磁感线的方向改变，涡流的方向也会改变，但安培力的方向始终与导体的运动方向相反，仍然会起到阻碍运动的制动作用，C错误；线圈中电流越大，产生的磁场磁感应强度$B$越大。在导体运动速度一定时，感应电动势$E$、涡流$I$以及制动力（安培力）$F$都会增大，因此制动力的大小与线圈中电流的大小有关，D错误。

**问答脚本**

本题考点：电磁涡流制动；制动力与速度、线圈电流（磁场强弱）的关系；阻碍作用与方向无关。
提问路线：
1. 问：导体中产生涡流时，会有焦耳热吗？ → 期望：会，A 错。
2. 问：线圈电流一定（磁场一定）时，导体转得越快，涡流和制动力怎样变？ → 期望：越大，B 对。
3. 问：导体反向转动时，涡流反向，安培力还是阻碍运动吗？ → 期望：仍是阻碍运动，仍起制动作用，C 错。
4. 问：线圈电流增大，磁场怎样变？制动力和电流有关吗？ → 期望：磁场增强，制动力增大，有关，D 错。选 B。
常见错误：
- 认为反转就失去制动作用。追问：楞次定律“阻碍”的是什么？和转动方向有关吗？
- 认为制动力与线圈电流无关。追问：线圈电流决定了哪个物理量？
总结句：涡流制动力随磁场（线圈电流）和速度增大而增大，无论朝哪个方向运动都起阻碍作用。

1. 问：紫铜薄板振动时要被阻尼，需要什么条件？ → 期望：振动时穿过薄板的磁通量发生变化，产生涡流。
2. 问：B、C、D 三种方案中磁场上下都超出薄板，薄板做微小的上下振动时，穿过它的磁通量变不变？ → 期望：不变（薄板始终整段宽度都在磁场里），对上下振动没有阻尼。
3. 问：C 中薄板左右都伸出磁场，左右振动时在磁场中的面积变吗？ → 期望：不变，C 对左右振动也无阻尼。
4. 问：A 中磁场只盖住薄板一角，跨在薄板的下边缘和右端上，薄板上下振动、左右振动时磁通量都会变吗？ → 期望：都会变，两个方向都有阻尼，最有效，选 A。
常见错误：
- 认为磁场覆盖得越多越好。追问：薄板完全处在匀强磁场中移动时，磁通量会变吗？
- 只考虑一个方向的振动。追问：题目要求同时衰减哪两个方向的振动？
总结句：要让各个方向的振动都被阻尼，磁场区域要跨在导体的边缘，使导体向任意方向运动时磁通量都变化。
