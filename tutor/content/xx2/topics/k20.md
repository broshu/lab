## 1. 单选 · 四种电磁模型的辨析

**题目**

（2026·重庆涪陵区期中）下列有关磁现象的四种模型对应的物理规律，说法错误的是（　　）

- A．图甲中用来做线圈骨架的铝框能起电磁驱动的作用
- B．图乙中磁块在铝管中下落的加速度一定小于当地的重力加速度$g$
- C．图丙中电磁炮的基本原理是电能转化为机械能，是一种安培力做正功的电动机模型
- D．图丁中的探雷器是利用涡流工作的，探测时地下的金属感应出涡流，而涡流的磁场会影响线圈中的电流，使仪器报警

![第 1 题原题图。](assets/xx2/k20-q01-stem1.png)

![第 1 题原题图。](assets/xx2/k20-q01-stem2.png)

**答案：A**

**解析**

图甲中磁电式仪表中的铝框能起电磁阻尼的作用，指针转动时铝框中会产生感应电流，铝框受安培力的阻碍作用，从而使指针迅速稳定，故A项错误；磁块在铝管中运动的过程中，穿过铝管的磁通量发生变化，产生感应电流，感应电流的磁场要阻碍原磁场磁通量的变化，所以铝管受到向下的安培力，磁块受到向上的安培力，因此磁块的加速度小于重力加速度，故B项正确；电磁炮的基本原理是电能转化为机械能，是一种安培力做正功的电动机模型，故C项正确；探雷器中有交变电流，其产生变化的磁场，其磁场会在金属物品中感应出涡流，而涡流产生的磁场又会反过来影响线圈中的电流，从而使仪器报警，故D项正确。

**问答脚本**

本题考点：电磁阻尼与电磁驱动的区别；来拒去留；电动机模型；涡流的应用。注意本题选“错误”的说法。
提问路线（每次只问一个问题）：
1. 问：本题要选正确的还是错误的说法？ → 期望：选错误的说法。
2. 问：图甲磁电式仪表中，铝框随指针转动时产生感应电流，这个电流的作用是帮助转动还是阻碍转动？叫电磁驱动还是电磁阻尼？ → 期望：阻碍转动，使指针迅速停下，是电磁阻尼，A 的说法错误。
3. 问：图乙磁块在铝管中下落，铝管中产生感应电流，磁块受到向上还是向下的力？加速度与 $g$ 比较？ → 期望：受向上的阻碍力，加速度小于 $g$，B 正确。
4. 问：图丙电磁炮中，安培力对炮弹做正功还是负功？能量怎样转化？图丁探雷器靠什么发现金属？ → 期望：安培力做正功，电能转化为机械能，是电动机模型，C 正确；探雷器利用金属中的涡流影响线圈电流，D 正确。选 A。
常见错误：
- 忘了题目选“错误”的。追问：题干最后两个字是什么？
- 把仪表铝框当成电磁驱动。追问：电磁驱动是“磁场动带导体动”，仪表中是谁先动？感应电流的作用是什么？
总结句：导体动、感应电流阻碍它是电磁阻尼；磁场动、导体被带着动是电磁驱动；通电导体受安培力做正功是电动机模型。

## 2. 单选 · 运动导体棒中电子的受力与电场

**题目**

（2026·广东广州期末）如图所示，一细金属导体棒$PQ$在匀强磁场中沿纸面由静止开始向右运动，磁场方向垂直纸面向里。不考虑棒中自由电子的热运动。下列选项正确的是（　　）

- A．电子随棒运动时不受洛伦兹力作用
- B．棒运动时，$P$端比$Q$端电势低
- C．棒加速运动时，棒中电场强度变小
- D．棒保持匀速运动时，电子最终相对棒静止

![第 2 题原题图。](assets/xx2/k20-q02-stem1.png)

**答案：D**

**解析**

由左手定则可知，电子随棒运动时受到方向沿棒向下的洛伦兹力作用，A错误；根据右手定则可知，棒向右运动时，$P$端比$Q$端电势高，B错误；$PQ$两端电势差$U=BLv$，可知棒中电场强度$E=\dfrac{U}{L}=Bv$，则棒加速运动时，棒中电场强度变大，C错误；棒保持匀速运动时，$PQ$两端电势差保持恒定，电子将集聚在导体棒下端，最终相对棒静止，D正确。

**问答脚本**

本题考点：动生电动势的微观解释：洛伦兹力使电子沿棒移动，形成电场，最终电场力与洛伦兹力平衡。
已知：棒 $PQ$ 竖直放置，向右运动，磁场垂直纸面向里，$P$ 在上、$Q$ 在下。
提问路线：
1. 问：电子随棒向右运动，在磁场中受洛伦兹力吗？方向朝哪（注意电子带负电）？ → 期望：受洛伦兹力，沿棒向下，A 错。
2. 问：电子聚集到哪一端？哪端电势高？ → 期望：电子聚到 $Q$ 端（下端），$Q$ 端带负电，$P$ 端电势高，B 错。
3. 问：最终电子受的电场力与洛伦兹力平衡：$eE=evB$，棒中场强 $E$ 等于多少？加速运动时怎样变？ → 期望：$E=vB$，速度增大，场强变大，C 错。
4. 问：棒匀速运动时，电子沿棒方向受力情况怎样？电子相对棒还会移动吗？ → 期望：电场力与洛伦兹力平衡，电子相对棒静止，D 对。选 D。
常见错误：
- 用左手定则时四指指向电子运动方向。追问：左手定则四指指的是正电荷运动方向，电子带负电该怎么办？
- 认为匀速时电子一直在移动。追问：电子聚集到一端后产生的电场会怎样阻止它继续移动？
总结句：动生电动势的本质是洛伦兹力推动自由电荷；电荷堆积形成电场，平衡时 $E=vB$，两端电压 $U=BLv$。

## 3. 单选 · 绕 P 点转动的圆环进出磁场

**题目**

（2026·浙江绍兴检测）如图，过$P$点的虚线上方存在方向垂直于纸面的匀强磁场。一金属圆环在纸面内以$P$点为轴沿顺时针方向匀速转动，$O$为圆环的圆心，$OP$为圆环的半径。则（　　）

- A．圆环中感应电流始终绕$O$逆时针流动
- B．圆环中感应电流始终绕$O$顺时针流动
- C．$OP$与虚线平行时圆环中感应电流最大
- D．圆环在磁场内且$OP$与虚线垂直时环中感应电流最大

![第 3 题原题图。](assets/xx2/k20-q03-stem1.png)

**答案：C**

**解析**

在圆环进入磁场的过程中圆环中感应电流绕$O$逆时针流动，圆环出磁场的过程中圆环中感应电流绕$O$顺时针流动，A、B错误；由几何关系可知圆环进入磁场的过程中，圆环切割磁感线的有效长度为$l=2r$cos（90°－$\omega t$），则金属圆环在纸面内以$P$点为轴沿顺时针方向匀速转动产生的感应电动势为$e=\dfrac{B\omega {l}^{2}}{2}$，即$e=\dfrac{B\omega {l}^{2}}{2}=2B\omega r^{2}\mathrm{cos}^{2}(\mathrm{90}^{0}-\omega t$），可见$OP$与虚线平行时即$\omega t=90$°或270°时圆环中感应电流最大，C正确，D错误。

**问答脚本**

本题考点：转动切割的有效长度（弦长）；$E=\dfrac12B\omega l^2$；进入与离开磁场时感应电流方向相反。
已知：虚线过 $P$ 点，上方有磁场；圆环以 $P$ 为轴顺时针匀速转动，$OP$ 为半径 $r$。
提问路线：
1. 问：圆环进入磁场时磁通量增大，离开时减小，感应电流方向一样吗？ → 期望：相反，进入时绕 $O$ 逆时针，离开时顺时针，A、B 错。
2. 问：圆环绕 $P$ 转动，在磁场中的部分相当于一根绕 $P$ 转动的什么？有效长度是哪段线段？ → 期望：相当于从 $P$ 出发的弦，有效长度是圆环与虚线交点到 $P$ 的弦长。
3. 问：弦长什么时候最长？此时 $OP$ 与虚线是什么关系？ → 期望：弦为直径 $2r$ 时最长，此时 $OP$ 与虚线平行（共线）。
4. 问：电动势 $E=\dfrac12B\omega l^2$，$l$ 最大时电流最大，对应哪个选项？ → 期望：$OP$ 与虚线平行时电流最大，C 对。圆环全在磁场中时磁通量不变，电流为零，D 错。选 C。
常见错误：
- 认为电流方向始终不变。追问：进入和离开磁场时，磁通量的变化趋势相同吗？
- 认为全部进入磁场时电流最大（选 D）。追问：圆环完全在磁场中转动时磁通量变化吗？
总结句：绕某点转动的曲线导体，有效长度是转轴到导体另一端点的连线；有效长度最长时电动势最大。

## 4. 单选 · 电磁炉的工作原理

**题目**

（2026·浙江金华检测）电磁感应在生产生活中有广泛的应用，如工业生产中使用的高频感应炉、金属探测器等。如图所示是电磁炉的原理图，下列关于电磁炉说法正确的是（　　）

- A．电磁炉可加热玻璃器皿
- B．电磁炉的锅体需选用铁、不锈钢等导磁金属材质
- C．电磁炉是通过线圈电流的热效应直接加热锅体的
- D．电磁炉工作时，线圈中的恒定电流能产生涡流实现加热

![第 4 题原题图。](assets/xx2/k20-q04-stem1.png)

**答案：B**

**解析**

玻璃是绝缘体，无法产生涡流，故A错误；铁、不锈钢等导磁金属能在交变磁场中产生涡流，利用涡流的热效应实现加热，是电磁炉锅体的合适材质，故B正确；电磁炉是利用电磁感应产生的涡流热效应加热，并非线圈电流的热效应，二者原理不同，故C错误；恒定电流产生的是恒定磁场，无法使锅体中产生感应电动势和涡流，只有变化的电流才可以，故D错误。

**问答脚本**

本题考点：电磁炉利用交变磁场在锅底产生涡流加热；锅具材料要求导电（且最好导磁）；恒定电流不能产生涡流。
提问路线：
1. 问：电磁炉的热量是在线圈中产生的，还是在锅底产生的？ → 期望：在锅底产生，靠的是涡流的热效应，不是线圈电流的热效应，C 错。
2. 问：玻璃器皿中能产生涡流吗？ → 期望：玻璃是绝缘体，不能产生涡流，不能加热，A 错。
3. 问：锅体应选用什么材料？ → 期望：铁、不锈钢等导磁金属，能在交变磁场中产生较强的涡流，B 对。
4. 问：线圈中通恒定电流时，磁场变不变？能产生涡流吗？ → 期望：磁场不变，不能产生涡流，D 错。选 B。
常见错误：
- 认为电磁炉是“电热丝”式直接加热。追问：电磁炉面板本身烫吗？热从哪里来？
- 认为任何材料都能加热。追问：涡流需要导体，玻璃、陶瓷导电吗？
总结句：电磁炉是“交变磁场 → 锅底涡流 → 焦耳热”，需要交变电流和导电（导磁）锅体。

## 5. 单选 · 磁体穿过线圈来回运动

**题目**

如图所示，右端为N极的磁体置于粗糙水平桌面上并与轻质弹簧的一端相连，弹簧另一端固定在竖直墙面上，当弹簧处于原长时，磁体的中心恰好位于接有一盏小灯泡的竖直固定线圈的圆心。用力将磁体向右拉到某一位置，撤去作用力后磁体穿过线圈来回运动，有关这个运动过程，下列说法正确的是（　　）

- A．灯泡的亮暗不会发生变化
- B．磁体靠近线圈时，线圈对磁体产生排斥力
- C．从左往右看，线圈中的电流一直沿逆时针方向
- D．若忽略摩擦力和空气阻力，磁体运动的幅度不会减小

![第 5 题原题图。](assets/xx2/k20-q05-stem1.png)

**答案：B**

**解析**

以S极靠近线圈分析，磁体速度增大，且线圈所处位置磁感应强度增大，则穿过线圈磁通量的变化率增大，感应电流增大，灯泡会变亮，故A错误；根据楞次定律“来拒去留”可知，磁体靠近线圈时，线圈对磁体产生排斥力，故B正确；当S极靠近线圈时，根据楞次定律和安培定则可知，线圈中的电流沿逆时针方向（从左往右看），当S极向右运动远离线圈时，根据楞次定律和安培定则可知，线圈中的电流沿顺时针方向（从左往右看），故C错误；若忽略摩擦力和空气阻力，磁体运动的幅度也会越来越小，原因是弹簧和磁体的机械能逐渐转化为焦耳热，故D错误。

**问答脚本**

本题考点：来拒去留；感应电流随磁通量变化率变化；电流方向随靠近/远离而改变；机械能转化为电能。
已知：磁体右端为 N 极、左端为 S 极，弹簧原长时磁体中心在线圈圆心；磁体被拉到右侧后释放，来回穿过线圈；线圈接小灯泡。
提问路线：
1. 问：磁体运动过程中速度在变，线圈处的磁场也在变，磁通量变化率一直相同吗？灯泡亮度会变吗？ → 期望：变化率在变，电流大小在变，灯泡亮暗变化，A 错。
2. 问：磁体靠近线圈时，线圈对磁体的作用是“拒”还是“留”？ → 期望：“来拒”，产生排斥力，B 对。
3. 问：同一个 S 极先靠近、后远离线圈，感应电流方向相同吗？ → 期望：相反，电流方向会变化，C 错。
4. 问：即使没有摩擦和空气阻力，灯泡发光的能量从哪来？磁体运动幅度会怎样？ → 期望：来自磁体和弹簧的机械能，幅度会逐渐减小，D 错。选 B。
常见错误：
- 认为没有摩擦振幅不变。追问：灯泡亮了，消耗的电能是哪里来的？
- 认为电流一直同向。追问：靠近时磁通量增大，远离时减小，楞次定律给出的电流方向一样吗？
总结句：来拒去留，感应电流方向随“增大/减小”而变；电磁感应过程中机械能不断转化为电能。

## 6. 单选 · 两支路的通电、断电自感

**题目**

（2026·浙江嘉兴期中）如图所示，两个相同的灯泡$\mathrm{L}_{1}$、$\mathrm{L}_{2}$，分别与定值电阻$R$和自感线圈$L$串联，自感线圈的自感系数很大，直流电阻阻值与$R$相同，闭合开关S，电路稳定后两灯泡均正常发光。下列说法正确的是（　　）

- A．闭合开关S后，灯泡$\mathrm{L}_{2}$逐渐变亮
- B．闭合开关S后，灯泡$\mathrm{L}_{1}$、$\mathrm{L}_{2}$同时变亮
- C．断开开关S后，灯泡$\mathrm{L}_{1}$ 、$\mathrm{L}_{2}$都逐渐变暗
- D．断开开关S后，灯泡$\mathrm{L}_{1}$逐渐变暗，$\mathrm{L}_{2}$立即熄灭

![第 6 题原题图。](assets/xx2/k20-q06-stem1.png)

**答案：C**

**解析**

闭合开关后，含灯泡$\mathrm{L}_{2}$的支路中没有线圈，立即变亮，含灯泡$\mathrm{L}_{1}$的支路中有线圈，逐渐变亮，A、B错误；断开开关前，两个支路电流相等，断开后，感应电流逐渐变小，灯泡$\mathrm{L}_{1}$、$\mathrm{L}_{2}$都逐渐变暗，C正确，D错误。

**问答脚本**

本题考点：通电自感；断电自感（两支路构成回路，电流从相等值开始减小）。
已知：$\mathrm L_1$ 与线圈 $L$ 串联，$\mathrm L_2$ 与电阻 $R$ 串联，$L$ 的直流电阻与 $R$ 相同，稳定后两灯正常发光。
提问路线：
1. 问：闭合 S 后，哪条支路有线圈？哪个灯逐渐变亮、哪个灯立即亮？ → 期望：$\mathrm L_1$ 支路有线圈，$\mathrm L_1$ 逐渐变亮，$\mathrm L_2$ 立即亮，A、B 错。
2. 问：稳定时两支路电阻相同，电流相等吗？ → 期望：相等。
3. 问：断开 S 后，线圈、$\mathrm L_1$、$\mathrm L_2$、$R$ 组成回路，电流从多大开始减小？两灯怎样熄灭？ → 期望：从原来的电流开始逐渐减小，两灯都逐渐变暗，不会闪亮，$\mathrm L_2$ 也不会立即熄灭，C 对 D 错。选 C。
常见错误：
- 认为断开时 $\mathrm L_2$ 立即熄灭。追问：断开后，线圈的电流能经过 $\mathrm L_2$ 形成回路吗？
- 认为 $\mathrm L_2$ 会闪亮。追问：断开前两支路电流哪个大？
总结句：断电自感中，所有与线圈构成回路的灯都会逐渐熄灭；闪不闪亮看线圈原电流是否大于该灯原电流。

## 7. 单选 · 环形螺线管上特殊线圈的电动势与焦耳热

**题目**

（2026·浙江1月选考）如图1所示，半径为$r_{1}$、横截面半径为$r_{2}(r_{2}$≪$r_{1}$）、匝数为$N$的圆环形螺线管通有电流$I$，管内产生磁感应强度$B=\alpha I(\alpha$为常量）的匀强磁场。管外磁场近似为0，小明用电阻为$R$的一段漆包线缠绕螺线管一圈后，并成双股线再缠绕螺线管两圈，最后将两端头短接，形成特殊线圈A。若电流$I$随时间$t$变化的关系如图2所示，则（　　）

- A．$t=2t_{0}$时，螺线管的自感电动势$E=N\dfrac{\pi {r}_{1}^{2}\alpha {I}_{0}}{{t}_{0}}$
- B．$t=5t_{0}$时，线圈A的感应电动势$E_{A}=3\dfrac{\pi {r}_{2}^{2}\alpha {I}_{0}}{{t}_{0}}$
- C．在0~2$t_{0}$内，通过线圈A的电荷量$q=N\dfrac{\pi {r}_{2}^{2}\alpha {I}_{0}}{R}$
- D．在0~5$t_{0}$内，线圈A产生的焦耳热$Q=3\dfrac{{(\pi {r}_{2}^{2}\alpha {I}_{0})}^{2}}{R{t}_{0}}$

![第 7 题原题图。](assets/xx2/k20-q07-stem1.png)

**答案：D**

**解析**

在$t=2t_{0}$时，螺线管电流变化率$\dfrac{\Delta I}{\Delta t}=\dfrac{0-{I}_{0}}{2{t}_{0}-{t}_{0}}=-\dfrac{{I}_{0}}{{t}_{0}}$；螺线管的自感电动势$E=N\left|\dfrac{\Delta Φ}{\Delta t}\right|=N\pi r_{2}^{2}\alpha\left|\dfrac{\Delta I}{\Delta t}\right|=N\pi r_{2}^{2}\alpha\dfrac{I_{0}}{t_{0}}$（螺线管截面半径是 $r_2$，不是 $r_1$），故A错误；在$t=5t_{0}$时，线圈A处的电流变化率$\dfrac{\Delta I}{\Delta t}=\dfrac{\left.0-(-{I}_{0}\right)}{5{t}_{0}-4{t}_{0}}=\dfrac{{I}_{0}}{{t}_{0}}$；线圈A的有效匝数是1匝，故$\dfrac{{E}_{A}}{E}=\dfrac{1}{N}$，故线圈A的感应电动势$E_{A}=\dfrac{\pi {r}_{2}^{2}\alpha {I}_{0}}{{t}_{0}}$，故B错误；在0~$t_{0}$内，通过线圈A磁通量不变，不产生感应电动势，故此时电荷量为0，$t_{0}$~2$t_{0}$内，$q=\dfrac{\Delta {Φ}_{A}}{R}=\dfrac{\pi {r}_{2}^{2}\alpha {I}_{0}}{R}$，故C错误；在0~5$t_{0}$内，线圈A仅在$t_{0}$~3$t_{0}$以及4$t_{0}$~5$t_{0}$产生焦耳热，两端产生的感应电流大小均为$I=\dfrac{{E}_{A}}{R}=\dfrac{\pi {r}_{2}^{2}\alpha {I}_{0}}{R{t}_{0}}$，则焦耳热为$Q=I^{2}R\cdot 2t_{0}+I^{2}Rt_{0}$，解得线圈A产生的焦耳热$Q=3\dfrac{(\pi {r}_{2}^{2}\alpha {I}_{0}{)}^{2}}{R{t}_{0}}$，故D正确。

**问答脚本**

本题考点：环形螺线管内匀强磁场，截面积 $\pi r_2^2$；自感电动势；双股线反向绕制抵消，特殊线圈 A 的有效匝数为 1；电荷量、焦耳热分段计算。
已知：螺线管匝数 $N$，截面半径 $r_2$，管内 $B=\alpha I$；线圈 A 先单股绕 1 圈，再双股绕 2 圈后短接，电阻 $R$；电流图像：0～$t_0$ 为 $I_0$，$t_0$～$3t_0$ 线性降到 $-I_0$，$3t_0$～$4t_0$ 保持 $-I_0$，$4t_0$ 后线性上升（$5t_0$ 时过零）。
提问路线：
1. 问：螺线管内磁场穿过的是哪个面积？是 $\pi r_1^2$ 还是 $\pi r_2^2$？ → 期望：穿过管的横截面，面积 $\pi r_2^2$。
2. 问：$t=2t_0$ 时电流变化率多大？螺线管自感电动势多大？ → 期望：$\left|\dfrac{\Delta I}{\Delta t}\right|=\dfrac{I_0}{t_0}$，$E=N\pi r_2^2\alpha\dfrac{I_0}{t_0}$，A 中用了 $r_1$，错。
3. 问：线圈 A 的双股线部分，两股中电流方向怎样？产生的电动势会抵消吗？A 的有效匝数是几匝？ → 期望：双股线中两股的电动势相互抵消，有效匝数为 1 匝。
4. 问：$t=5t_0$ 时线圈 A 的电动势是多少？ → 期望：$E_A=\pi r_2^2\alpha\dfrac{I_0}{t_0}$，B 中的 3 倍错误。
5. 问：0～$t_0$ 内电流不变，有感应电流吗？$t_0$～$2t_0$ 内通过 A 的电荷量是多少？ → 期望：0～$t_0$ 无电流；$q=\dfrac{\Delta\Phi_A}{R}=\dfrac{\pi r_2^2\alpha I_0}{R}$，没有因子 $N$，C 错。
6. 问：0～$5t_0$ 内哪些时间段 A 中有电流？电流大小相同吗？总焦耳热是多少？ → 期望：$t_0$～$3t_0$ 和 $4t_0$～$5t_0$ 共 $3t_0$，电流都是 $\dfrac{\pi r_2^2\alpha I_0}{Rt_0}$，$Q=3\dfrac{(\pi r_2^2\alpha I_0)^2}{Rt_0}$，D 对。选 D。
常见错误：
- 面积用 $\pi r_1^2$。追问：管外磁场近似为零，磁场只存在于哪里？
- 线圈 A 的匝数取 3。追问：双股线并在一起绕时，两股中的感应电动势在回路中是同向还是反向？
- 电荷量多乘 $N$。追问：$N$ 是螺线管的匝数还是线圈 A 的匝数？
总结句：先找准磁通量穿过的面积和线圈的有效匝数（双股并绕相互抵消），再分段用 $E=n\dfrac{\Delta\Phi}{\Delta t}$、$q=\dfrac{\Delta\Phi}{R}$、$Q=I^2Rt$。

## 8. 单选 · 转动金属棒的电流、电压与电容器电荷量

**题目**

（2026·浙江杭州期中）半径分别为$r$和2$r$的同心圆形导轨固定在同一水平面内，一长为$r$、电阻为$R$的均匀金属棒$AB$置于圆导轨上面，$BA$的延长线通过圆导轨中心$O$，装置的俯视图如图所示，两圆形导轨之间存在一匀强磁场，磁感应强度的大小为$B$，方向竖直向下。在两圆导轨之间接阻值为$R$的定值电阻和电容为$C$的电容器。金属棒在水平外力作用下以角速度$\omega$绕$O$逆时针匀速转动，在转动过程中始终与导轨保持良好接触。导轨电阻不计。下列说法正确的是（　　）

- A．金属棒中电流从$A$流向$B$
- B．金属棒两端电压为$\dfrac{3}{4}B\omega r^{2}$
- C．电容器的M板带负电
- D．电容器所带电荷量为$\dfrac{3}{2}CB\omega r^{2}$

![第 8 题原题图。](assets/xx2/k20-q08-stem1.png)

**答案：B**

**解析**

金属棒绕$O$逆时针匀速转动，根据右手定则可知金属棒中电流从$B$流向$A$，故A错误；金属棒转动产生的电动势为$E=Br\overline{v}=Br\dfrac{\omega r+2\omega r}{2}=\dfrac{3}{2}B\omega r^{2}$，切割磁感线的金属棒相当于电源，金属棒两端电压相当于电源的路端电压，则金属棒两端电压为$U=\dfrac{R}{R+R}E=\dfrac{3}{4}B\omega r^{2}$，故B正确；由选项A分析可知，金属棒$A$端相当于电源正极，则电容器M板带正电，故C错误；由$C=\dfrac{Q}{U}$，可得电容器所带电荷量为$Q=\dfrac{3}{4}CB\omega r^{2}$，故D错误。

**问答脚本**

本题考点：转动切割（不过圆心的一段）$E=B\cdot r\cdot\bar v$；右手定则；路端电压；电容器两端电压等于 $R$ 两端电压。
已知：棒 $AB$ 长 $r$，从半径 $r$ 到 $2r$，电阻 $R$；外接电阻 $R$ 和电容 $C$；磁场竖直向下；逆时针转动。
提问路线：
1. 问：棒上各点线速度不同，内端和外端速度各是多少？平均速度呢？电动势多大？ → 期望：$\omega r$ 和 $2\omega r$，平均 $\dfrac32\omega r$，$E=Br\cdot\dfrac32\omega r=\dfrac32B\omega r^2$。
2. 问：用右手定则判断棒中电流方向。 → 期望：从 $B$ 流向 $A$，A 错。
3. 问：棒相当于电源，内阻 $R$，外电阻 $R$（电容器所在支路稳定后无电流），棒两端电压多少？ → 期望：$U=\dfrac12E=\dfrac34B\omega r^2$，B 对。
4. 问：$A$ 端相当于正极还是负极？M 板接哪端？带什么电？电荷量多少？ → 期望：$A$ 为正极，M 板带正电，C 错；$Q=CU=\dfrac34CB\omega r^2$，D 错。选 B。
常见错误：
- 用 $\dfrac12B\omega(2r)^2$ 计算。追问：棒是从圆心开始的吗？$r$ 以内有没有导体切割？
- 电容器电压取电动势。追问：棒有内阻，电容器两端电压等于电动势还是路端电压？
总结句：不过转轴的转动棒，电动势 $E=BL\bar v$（取中点速度）；电容器稳定后相当于断路，其电压等于与之并联部分的电压。

## 10. 单选 · 电磁称重装置测质量

**题目**

如图是一种精确测量质量的装置原理示意图，竖直平面内，质量恒为$M$的称重框架由托盘和矩形线圈组成。线圈的一边始终处于垂直线圈平面的匀强磁场中，磁感应强度不变。测量分两个步骤，步骤①：托盘内放置待测物块，其质量用$m$表示，线圈中通大小为$I$的电流，使称重框架受力平衡；步骤②：线圈处于断开状态，取下物块，保持线圈不动，磁场以速率$v$匀速向下运动，测得线圈中感应电动势为$E$。利用上述测量结果可得出$m$的值，重力加速度为$g$。下列说法正确的有（　　）

- A．线圈电阻为$\dfrac{E}{I}$
- B．$I$越大，表明$m$越小
- C．$v$越大，则$E$越小
- D．$m=\dfrac{EI}{vg}-M$

![第 10 题原题图。](assets/xx2/k20-q10-stem1.png)

**答案：D**

**解析**

设线圈在磁场中的有效长度为$l$，磁场的磁感应强度大小为$B$，由题意，$I$与$E$无关，A错误；由平衡条件得$BIl=(M+m)g$，可得$m=\dfrac{BIl}{g}-M$，$I$越大，$m$越大，B错误；根据$E=Blv$，$v$越大，$E$越大，C错误；将$Bl=\dfrac{E}{v}$代入$m=\dfrac{BIl}{g}-M$得$m=\dfrac{EI}{vg}-M$，D正确。

**问答脚本**

本题考点：安培力平衡测质量；磁场运动时线圈的动生电动势 $E=Blv$；消去未知的 $Bl$。
已知：步骤①线圈通电流 $I$，框架（质量 $M$）加物块 $m$ 平衡；步骤②线圈断开，磁场以速率 $v$ 向下运动，测得电动势 $E$。
提问路线：
1. 问：步骤①中，安培力与什么平衡？写出平衡式。 → 期望：$BIl=(M+m)g$。
2. 问：由平衡式看，$I$ 越大，$m$ 越大还是越小？ → 期望：越大，B 错。
3. 问：步骤②中，磁场相对线圈运动，线圈的电动势是多少？$v$ 越大，$E$ 怎样？ → 期望：$E=Blv$，$v$ 越大 $E$ 越大，C 错。
4. 问：$E$ 和 $I$ 是同一个回路、同一时刻的量吗？能用 $\dfrac EI$ 求电阻吗？ → 期望：不是，$E$ 是断路时测的电动势，$I$ 是另一步骤中的电流，不能求电阻，A 错。
5. 问：用 $Bl=\dfrac Ev$ 代入平衡式，求 $m$。 → 期望：$m=\dfrac{EI}{vg}-M$，D 对。选 D。
常见错误：
- 用 $\dfrac EI$ 当电阻。追问：步骤②中线圈是闭合的吗？有电流吗？
- 忘记框架自身质量 $M$。追问：安培力托起的只是物块吗？
总结句：用两个步骤各得一个含 $Bl$ 的方程，联立消去 $Bl$，就能由电学量测出质量。

- 认为磁通量最大时电动势最大。追问：电动势取决于磁通量本身还是它的变化率？正弦曲线峰值处斜率是多少？
- 俯视时绕向判反。追问：感应磁场向下时，用右手螺旋定则，从上往下看电流怎样绕？
总结句：正弦变化中，$\Phi$ 最大时 $E=0$，$\Phi=0$ 时 $E$ 最大；方向用楞次定律、注意观察视角。

## 13. 多选 · ∠形导轨上匀速运动的导体棒

**题目**

如图所示，一个水平放置的“∠”形光滑金属导轨固定在方向竖直向下、磁感应强度大小为$B$的匀强磁场中，$ab$是粗细、材料与导轨完全相同的导体棒，导体棒与导轨接触良好。在外力作用下，导体棒以恒定速度$v$向右平动，导体棒与导轨一边垂直，以导体棒在图中所示位置的时刻作为计时起点，则下列关于回路中感应电动势$E$、感应电流$I$、导体棒所受外力的功率$P$和回路中产生的焦耳热$Q$随时间变化的图像正确的是（　　）

![第 13 题原题图。](assets/xx2/k20-q13-stem1.png)

![第 13 题原题图。](assets/xx2/k20-q13-stem2.png)

**答案：AC**

**解析**

设“∠”形导轨的夹角为$\theta$，经过时间$t$，导体棒的水平位移为$x=vt$，导体棒切割磁感线的有效长度$L=vt\cdot \tan \theta$，所以回路中感应电动势$E=BLv=Bv^{2}t\cdot \tan \theta$，感应电动势与时间$t$成正比，A正确；相似三角形的三条对应边长之比为定值，故组成回路的三角形导轨总长度与时间成正比，则组成回路的电阻与时间成正比，而感应电动势与时间也成正比，故感应电流大小与时间无关，为定值，B错误；导体棒匀速移动，外力$F$与导体棒所受安培力为一对平衡力，故外力的功率$P=Fv=ILBv=BIv^{2}t\cdot \tan \theta$，与时间$t$成正比，C正确；回路中产生的焦耳热$Q=I^{2}Rt$，回路电阻$R$与$t$成正比，故焦耳热$Q$与$t^{2}$成正比，D错误。

**问答脚本**

本题考点：有效长度随时间线性增大；回路电阻也随时间线性增大，电流恒定；功率与焦耳热随时间的关系。
已知：“∠”形导轨与导体棒材料、粗细相同；棒以 $v$ 匀速向右，从顶点开始；设导轨夹角为 $\theta$。
提问路线：
1. 问：经过时间 $t$，棒的有效长度是多少？电动势怎样随时间变化？ → 期望：$L=vt\tan\theta$，$E=Bv^2t\tan\theta$，与 $t$ 成正比，A 对。
2. 问：回路是一个三角形，三边长度都与 $t$ 成正比吗？回路电阻怎样随时间变化？ → 期望：相似三角形，周长与 $t$ 成正比，电阻与 $t$ 成正比。
3. 问：电动势和电阻都与 $t$ 成正比，电流怎样？ → 期望：电流恒定，B 错。
4. 问：外力功率 $P=Fv=BILv$，随时间怎样变？ → 期望：$I$ 不变、$L\propto t$，$P\propto t$，C 对。
5. 问：焦耳热是功率对时间的累积，$P\propto t$ 时 $Q$ 与 $t$ 是什么关系？ → 期望：$Q\propto t^2$，图像不是直线，D 错。选 AC。
常见错误：
- 认为电流也随时间增大。追问：回路电阻会变吗？怎样变？
- 认为 $Q$ 与 $t$ 成正比。追问：功率在增大，热量的增长会越来越快吗？
总结句：变长度切割时，电动势和电阻往往都随长度变化，要比较比值；功率随 $t$ 线性增大时，热量随 $t^2$ 增大。

## 15. 计算 · 半个正六边形框在变化磁场中的悬线拉力

**题目**

（2）金属框中感应电动势的大小；

（3）从$t=0$时刻开始，经多长时间细线的拉力为零。

**问答脚本**

本题考点：楞次定律；感生电动势 $E=\dfrac{\Delta B}{\Delta t}S$（只算磁场中的面积）；有效长度；安培力与重力平衡。

第（1）问
1. 问：$B$ 增大，向里的磁通量增大，感应电流的磁场朝哪？电流方向？ → 期望：感应磁场向外，电流沿逆时针方向。

3. 问：电动势多大？ → 期望：$E=kS=\dfrac{3\sqrt3}{4}kL^2$。
第（3）问
4. 问：磁场中的部分是一段折线，所受安培力等效于哪段直导线？有效长度多少？方向朝哪？ → 期望：等效于两端点连线（磁场边界上的对角线），长 $2L$；方向竖直向上（阻碍磁通量增大，有离开磁场的趋势）。

总结句：感生问题中电动势只算磁场内的面积；折线受力看首尾连线；$B$ 在变时安培力也随时间变化。

## 16. 计算 · 导体框的感生电流与动生减速

**题目**

（1）求$t=0.5$ s时$ad$边受到的安培力大小$F$。

（2）在图b中画出1~2 s内$B-t$图像（无需写出计算过程）。

（3）从$t=2$ s开始，磁场不再随时间变化。之后导体框解除固定，给导体框一个向右的初速度$v_{0}=0.1$ m/s，求$ad$边离开磁场时的速度大小$v_{1}$。

![第 16 题原题图。](assets/xx2/k20-q16-stem1.png)

**答案：（1）0.015 N　（2）见解析图　（3）0.01 m/s**

**解析**

（1）0~1 s内导体框中产生的感应电动势为$E=\dfrac{\Delta B}{\Delta t}\cdot \dfrac{1}{2}L^{2}$

解得$E=0.05$ V

根据闭合电路欧姆定律可知通过导体框的电流为$I=\dfrac{E}{R}$

解得$I=0.1$ A

根据图b斜率大小可知0.5 s时的磁感应强度$B_{0}$满足$\dfrac{0.2T-{B}_{0}}{0.5s}=\dfrac{0.2T-0.1T}{1s}$

解得$B_{0}=0.15$ T

$t=0.5$ s时，$ad$边受到的安培力大小为$F=B_{0}IL$

（2）由于顺时针方向为电流正方向，则由题图c知1~2 s内电流沿逆时针方向，大小为$I_{1}=0.2$ A

根据闭合电路欧姆定律可知感应电动势$E_{1}=I_{1}R$

![第 16 题解析配图。](assets/xx2/k20-q16-1.png)

（3）解法一：由（2）中分析知2 s时磁感应强度大小为$B_{2}=0.3$ T，之后磁场不随时间变化，导体框从初速度$v_{0}$开始运动，导体框切割磁感线受到的安培力为$F_{A}=B_{2}I_{t}L=B_{2}\dfrac{{B}_{2}L{v}_{t}}{R}L=\dfrac{{B}_{2}^{2}{L}^{2}{v}_{t}}{R}$

导体框速度从$v_{0}$变化至$v_{1}$，规定水平向右为正方向，根据动量定理有$\sum\left(-\dfrac{B_{2}^{2}L^{2}v_{t}}{R}\Delta t\right)=mv_{1}-mv_{0}$

结合$\Delta x=v_{t}\Delta t$、$\sum\Delta x=\dfrac{1}{2}L$

得$-\dfrac{B_{2}^{2}L^{2}}{R}\cdot \dfrac{1}{2}L=mv_{1}-mv_{0}$

解得$v_{1}=0.01$ m/s。

解法二：还可以通过积累电荷量求解，导体框速度从$v_{0}$变为$v_{1}$，规定水平向右为正方向，根据动量定理得$\sum(-B_{2}I_{t}L\Delta t)=mv_{1}-mv_{0}$，结合$\Delta q=I_{t}\Delta t$、$\sum\Delta q=q$得$-B_{2}Lq=mv_{1}-mv_{0}$

流过导体框的电荷量为

$q=\overline{I}\Delta t_{2}=\dfrac{\overline{E}}{R}\Delta t_{2}=\dfrac{\dfrac{\Delta Φ}{\Delta {t}_{2}}}{R}\Delta t_{2}=\dfrac{\Delta Φ}{R}=\dfrac{\dfrac{1}{2}{B}_{2}{L}^{2}}{R}$

解得$v_{1}=0.01$ m/s。

**问答脚本**

本题考点：感生电动势（磁场中一半面积）；由 $I-t$ 图像反推 $B-t$；动量定理求离开磁场时的速度（安培力冲量 $\propto$ 位移）。
已知：$m=1\ \text{kg}$，$R=0.5\ \Omega$，$L=1\ \text{m}$；$ab$ 边中点在磁场边界，磁场中面积 $\dfrac12L^2$；0～1 s 内 $B$ 从 0.2 T 均匀减到 0.1 T；1～2 s 内电流为逆时针 0.2 A；2 s 后磁场不变，导体框以 $v_0=0.1\ \text{m/s}$ 向右运动。

第（3）问
5. 问：2 s 后 $B_2=0.3\ \text{T}$ 不变，导体框向右运动时谁在切割？安培力与速度有什么关系？ → 期望：$ad$ 边在磁场中切割，$F=\dfrac{B_2^2L^2v}{R}$，阻碍运动。

## 17. 计算 · 弧形导轨下滑的双棒

**题目**

（12分）如图所示，两根足够长的平行光滑金属导轨$MN$、$PQ$放在水平面上，左端向上弯曲，导轨间距为$L$，电阻不计，水平段导轨所处空间存在方向竖直向上的匀强磁场，磁感应强度大小为$B$。导体棒的质量分别为$m_{a}=m$，$m_{b}=2m$，电阻值分别为$R_{a}=R$，$R_{b}=2R$。b棒静止放置在水平导轨上足够远处，与导轨接触良好且与导轨垂直；a棒在弧形导轨上距水平面$h$高度处由静止释放，运动过程中导体棒与导轨接触良好且始终与导轨垂直，重力加速度为$g$，求：

（1）a棒刚进入磁场时回路中的感应电流大小；

（2）从a棒开始下落到最终稳定的过程中，通过a棒的电荷量；

（3）从a棒开始下落到最终稳定的过程中，a棒上产生的焦耳热。

![第 17 题原题图。](assets/xx2/k20-q17-stem1.png)

**答案：（1）$\dfrac{BL\sqrt{2gh}}{3R}$　（2）$\dfrac{2m\sqrt{2gh}}{3BL}$　（3）$\dfrac{2}{9}mgh$**

**解析**

（1）a棒从开始下滑到刚进入磁场的过程，根据动能定理可得$m_{a}gh=\dfrac{1}{2}m_{a}{v}_{0}^{2}$

解得$v_{0}=\sqrt{2gh}$

a棒切割磁感线产生的感应电动势为$E=BLv_{0}$

回路中产生的电流为$I=\dfrac{E}{3R}=\dfrac{BL\sqrt{2gh}}{3R}$。

（2）最终稳定时，两棒达到共速，由动量守恒定律可得

$m_{a}v_{0}=(m_{a}+m_{b})v$

解得$v=\dfrac{1}{3}v_{0}$

对b棒由动量定理得$\overline{I}LB\Delta t=m_{b}v-0$

电荷量$q=\overline{I}\Delta t=\dfrac{{m}_{b}v}{BL}=\dfrac{2m\sqrt{2gh}}{3BL}$。

（3）从a棒开始下落到最终稳定的过程中，根据能量守恒定律可得

$Q_{\text{总}}=m_{a}g\overline{h}\dfrac{1}{2}(m_{a}+m_{b})v^{2}=\dfrac{2}{3}mgh$

a棒上产生的焦耳热为$Q_{a}=\dfrac{{R}_{a}}{{R}_{a}+{R}_{b}}Q_{\text{总}}=\dfrac{2}{9}mgh$。

**问答脚本**

本题考点：机械能守恒求进入磁场的速度；双棒动量守恒；动量定理求电荷量；能量守恒与串联分热。
已知：$m_a=m$，$m_b=2m$，$R_a=R$，$R_b=2R$；a 从高 $h$ 处由静止释放；b 静止在水平导轨足够远处；导轨光滑。
提问路线：
第（1）问
1. 问：a 刚进入磁场时速度多大？ → 期望：$v_0=\sqrt{2gh}$。
2. 问：此时电动势和回路电流多大？ → 期望：$E=BLv_0$，$I=\dfrac{BL\sqrt{2gh}}{3R}$。
第（2）问
3. 问：最终稳定时两棒怎样运动？用动量守恒求共同速度。 → 期望：共速，$mv_0=3mv$，$v=\dfrac{v_0}{3}$。
4. 问：对 b 用动量定理求电荷量。 → 期望：$BLq=2m\cdot\dfrac{v_0}{3}$，$q=\dfrac{2m\sqrt{2gh}}{3BL}$。
第（3）问
5. 问：用能量守恒求总焦耳热。 → 期望：$Q=mgh-\dfrac12\cdot3m\cdot\dfrac{v_0^2}{9}=\dfrac23mgh$。
6. 问：两棒串联，a 分到多少？ → 期望：$Q_a=\dfrac{R}{3R}Q=\dfrac29mgh$。
常见错误：
- 电流计算漏掉 b 的电阻。追问：回路总电阻是多少？
- 动量守恒中质量用错。追问：b 的质量是多少？
- 焦耳热直接给 a 全部。追问：两棒串联、电流相同，热量按什么比例分？
总结句：双棒问题：机械能守恒定初速，动量守恒定末速，动量定理定电荷量，能量守恒定总热，再按电阻分配。

- 把四个灯都当成外电路并联。追问：$\mathrm L_1$ 在哪根导线上？那根导线是电源吗？
- 平均功率用 $F\omega r_2$。追问：外力是一直作用的吗？什么时候才需要外力？
总结句：转动发电先算电动势、画等效电路（切割的那根是电源）；匀速转动时用力矩平衡求外力；间歇做功时平均功率要乘时间比例。
