## 1. 单选 · 左手定则判断安培力方向

**题目**

（2026·浙江温州期末）下列选项中正确标明了通电导线所受安培力$F$方向的是（　　）

![第 1 题原题图。](assets/xx2/k01-q01-stem1.png)

![第 1 题原题图。](assets/xx2/k01-q01-stem2.png)

**答案：C**

**解析**

**方法：** 用左手定则——磁感线垂直穿入掌心，四指指向电流方向，拇指所指就是安培力方向；电流与磁场平行时不受安培力。

- A：$B$ 垂直纸面向外，电流向右，安培力应竖直向下，图中画向上，错。
- B：$B$ 垂直纸面向里，电流垂直纸面向外，电流与磁场平行，不受安培力，错。
- C：$B$ 水平向右，电流垂直纸面向外，安培力竖直向上，对。
- D：$B$ 竖直向上，电流垂直纸面向里，安培力水平向右，图中画向上，错。

故选 **C**。

**问答脚本**

本题考点：左手定则；电流与磁场平行时不受安培力。图中“·”表示垂直纸面向外，“×”表示垂直纸面向里，⊙表示电流垂直纸面向外，⊗表示电流垂直纸面向里。
提问路线（每次只问一个问题，学生答对再往下走）：
1. 问：用左手定则判断安培力，掌心、四指、拇指分别对着什么？ → 期望：磁感线垂直穿入掌心，四指指向电流方向，拇指指向安培力方向。
2. 问：B 图中电流垂直纸面向外，磁场垂直纸面向里，两者是什么关系？导线受安培力吗？ → 期望：电流与磁场平行，不受安培力，B 错。
3. 问：A 图磁场垂直纸面向外、电流向右，安培力应朝哪？和图中画的一样吗？ → 期望：安培力竖直向下，图中画向上，A 错。
4. 问：再用同样的方法判断 C 和 D，哪个画对了？ → 期望：C 中安培力向上，画对；D 中安培力水平向右，图中画向上，画错；选 C。
选项要点（学生追问某个选项时用）：
- A：$B$ 向外、$I$ 向右，$F$ 应向下。
- B：$I$ 与 $B$ 平行，$F=0$。
- C：$B$ 向右、$I$ 向外，$F$ 向上，正确。
- D：$B$ 向上、$I$ 向里，$F$ 向右。
常见错误：
- 用成右手。追问：右手螺旋定则是判断什么的？判断“受力”应该用哪只手？
- 磁感线穿出手背、四指指成磁场方向。追问：四指应该对着电流还是磁场？磁感线从掌心进还是从手背进？
- 以为 B 图中也有安培力。追问：电流方向和磁场方向夹角是多少？$F=BIl\sin\theta$ 中 $\sin\theta$ 等于多少？
总结句：判断安培力方向用左手定则：磁感线穿掌心、四指指电流、拇指指受力；电流与磁场平行时不受力。

## 2. 单选 · 旋转的液体：电流方向与旋转方向

**题目**

（2026·浙江宁波检测）“旋转的液体”实验装置如图：装有导电液的玻璃器皿放在上端为S极的蹄形磁铁的磁场中，器皿中心的圆柱形电极与电源负极相连，内壁边缘的圆环形电极与电源正极相连，接通电源后液体旋转起来，从上往下看时 ，以下说法正确的是（　　）

- A．液体中电流由边缘流向中心，液体逆时针旋转
- B．液体中电流由边缘流向中心，液体顺时针旋转
- C．液体中电流由中心流向边缘，液体逆时针旋转
- D．如果将两磁极对换，电源正、负极对换，液体的旋转方向将改变

![第 2 题原题图。](assets/xx2/k01-q02-stem1.png)

**答案：A**

**解析**

**第一步：电流方向。** 电源外部电流从正极流向负极：边缘圆环接正极、中心电极接负极，所以液体中电流沿半径**从边缘流向中心**，C 错。

**第二步：安培力方向。** 磁铁上端为 S 极，器皿处磁场竖直向上（从下面的 N 极指向上面的 S 极）。电流沿半径指向中心、磁场向上，由左手定则，安培力沿切线方向，俯视时液体**逆时针**旋转，A 对，B 错。

**第三步：同时对换。** 磁场反向、电流也反向，安培力方向不变，旋转方向不变，D 错。

故选 **A**。

**问答脚本**

本题考点：电源外部电流方向；蹄形磁铁两极间磁场方向；左手定则判断圆周切向受力。
已知：磁铁上端为 S 极（下端为 N 极），中心电极接负极，边缘圆环接正极；从上往下看。
提问路线（每次只问一个问题）：
1. 问：电源外部电流从哪个极流向哪个极？液体里的电流是从边缘流向中心，还是从中心流向边缘？ → 期望：从正极流向负极，所以从边缘沿半径流向中心（排除 C）。
2. 问：上端是 S 极、下端是 N 极，器皿所在处的磁场朝哪个方向？ → 期望：磁感线从 N 极到 S 极，竖直向上。
3. 问：电流沿半径指向中心、磁场竖直向上，用左手定则，液体受力沿什么方向？俯视看液体怎样转？ → 期望：安培力沿圆周切线方向，俯视液体逆时针旋转，选 A。
4. 问：如果磁极对换、电源正负极也对换，电流和磁场都反向，安培力方向会变吗？ → 期望：两个都反向，安培力方向不变，旋转方向不变，D 错。
常见错误：
- 以为电流从负极流向正极（把电子运动方向当电流方向）。追问：电源外部电流规定从哪极流向哪极？
- 把磁场方向判成向下。追问：磁铁外部磁感线从 N 极出发回到哪一极？上端是哪个极？
- 认为两个都对换后转向改变。追问：只改变电流方向时受力反向，再把磁场也反向，受力又会怎样？
总结句：先定电流方向（电源外部正极到负极），再定磁场方向（N 到 S），最后用左手定则；电流和磁场同时反向，安培力方向不变。

## 3. 单选 · 由 F-I 图像斜率求 B

**题目**

（2026·浙江温州检测）在探究安培力的大小实验中，某同学将长为$L$的直导线垂直磁场方向放置于匀强磁场中，改变导线中电流的大小，得到导线所受安培力大小$F$随电流大小$I$变化的图像如图所示，若该图像斜率为$k$，则该匀强磁场磁感应强度的大小为（　　）

- A．$k$
- B．$\dfrac{L}{k}$
- C．$\dfrac{k}{L}$
- D．$kL$

![第 3 题原题图。](assets/xx2/k01-q03-stem1.png)

**答案：C**

**解析**

导线垂直磁场放置，$F=BIL=(BL)\cdot I$，所以 $F-I$ 图像是过原点的直线，斜率 $k=BL$，得 $B=\dfrac{k}{L}$。故选 **C**。

**问答脚本**

本题考点：安培力公式 $F=BIL$；用图像斜率表示物理量。
提问路线：
1. 问：导线垂直磁场放置时，安培力大小的公式是什么？ → 期望：$F=BIL$。
2. 问：把 $F=BIL$ 写成 $F=(\ \ )\cdot I$ 的形式，$F-I$ 图像的斜率 $k$ 等于什么？ → 期望：$k=BL$。
3. 问：由 $k=BL$ 能解出 $B$ 等于什么？对应哪个选项？ → 期望：$B=\dfrac{k}{L}$，选 C。
常见错误：
- 直接认为斜率就是 $B$（选 A）。追问：$F=BIL$ 里，$I$ 前面的系数除了 $B$ 还有什么？
- 选 D（$kL$）。追问：由 $k=BL$ 解 $B$，是乘 $L$ 还是除以 $L$？
总结句：把物理公式整理成“纵坐标 = 斜率 × 横坐标”的形式，斜率就等于前面的系数组合，再解出所求量。

## 4. 单选 · 折线导线的有效长度

**题目**

（2026·江苏连云港期末）如图所示，匀强磁场垂直于“√”形通电导线所在平面，已知$ab$⊥$ac$，∠$acb=60$°，$ac$段受到的安培力大小为$F$。则（　　）

- A．$bc$段受到的安培力大小为$\sqrt{3}F$
- B．$acb$整体受到的安培力大小为2$F$
- C．$ac$段受到的安培力方向垂直于$ac$向左
- D．$acb$整体受到的安培力方向垂直于$ab$向上

![第 4 题原题图。](assets/xx2/k01-q04-stem1.png)

**答案：D**

**解析**

设 $ac=L$，由 $ab\perp ac$、$\angle acb=60^\circ$ 得 $ab=\sqrt{3}L$，$bc=2L$。

- A：各段都与磁场垂直，$F_{bc}=BI\cdot 2L=2F$，错。
- B：折线 $acb$ 整体的有效长度是首尾连线 $ab=\sqrt{3}L$，$F_{acb}=BI\cdot\sqrt{3}L=\sqrt{3}F$，错。
- C：$ac$ 段电流由 $a$ 向下流到 $c$，磁场垂直纸面向里，由左手定则安培力垂直 $ac$ **向右**，错。
- D：整体等效于由 $a$ 流向 $b$ 的直导线，安培力垂直 $ab$ 向上，对。

故选 **D**。

**问答脚本**

本题考点：安培力大小 $F=BIL$；弯曲导线的有效长度（首尾连线）；左手定则。
已知：$ab\perp ac$，$\angle acb=60^\circ$，电流由 $a$ 流到 $c$ 再流到 $b$，磁场垂直纸面向里，$ac$ 段受力为 $F$。
提问路线：
1. 问：设 $ac=L$，由三角形中 $\angle acb=60^\circ$、$ab\perp ac$，$bc$ 和 $ab$ 分别多长？ → 期望：$bc=2L$，$ab=\sqrt{3}L$。
2. 问：各段都与磁场垂直，$bc$ 段受到的安培力是 $ac$ 段的几倍？ → 期望：长度是 2 倍，安培力为 $2F$，A 错。
3. 问：弯折导线 $acb$ 整体受的安培力，可以等效成哪一段直导线？有效长度是多少？ → 期望：等效于首尾连线 $ab$，有效长度 $\sqrt{3}L$，整体受力 $\sqrt{3}F$，B 错。
4. 问：$ac$ 段电流向下、磁场向里，安培力朝哪？整体等效电流从 $a$ 流到 $b$，安培力又朝哪？ → 期望：$ac$ 段受力垂直 $ac$ 向右，C 错；整体受力垂直 $ab$ 向上，选 D。
常见错误：
- 把 $ac$ 和 $bc$ 的力直接相加得到整体受力。追问：两段受力方向相同吗？力是矢量，能直接把大小相加吗？
- 有效长度取成导线总长 $L+2L$。追问：有效长度是导线实际长度还是起点到终点的连线？
- $ac$ 段受力方向判反。追问：四指沿电流向下，磁感线从掌心穿入（向里），拇指指向哪边？
总结句：弯曲导线在匀强磁场中受的安培力，等于从起点到终点的直导线所受的安培力，有效长度是首尾连线。

## 5. 单选 · 三根输电线的磁场叠加与受力

**题目**

（2026·浙江杭州期中）如图甲所示，高压输电线上a、b、c三根相互平行的水平长直导线通有大小相等且方向相同的电流$I$。$a$′、$b$′、$c$′为导线a、b、c上的三个点，连接三点构成的三角形为等腰直角三角形（$a'b'=b'c$′），且与三根导线均垂直，$O$为连线$a'c$′的中点，逆着电流方向观察得到如图乙所示的截面图。已知单独一根通电导线a在$O$处产生的磁感应强度大小为$B$，不计地磁场的影响，则下列说法正确的是（　　）

- A．$O$点的磁感应强度大小为3$B$
- B．$O$点的磁感应强度方向是从$O$指向$c$′
- C．导线b受到的安培力方向竖直向上
- D．导线b受到的安培力为零

![第 5 题原题图。](assets/xx2/k01-q05-stem1.png)

**答案：B**

**解析**

**第一步：$O$ 点磁场。** 三根导线到 $O$ 的距离相等，各自在 $O$ 处产生的磁感应强度大小都是 $B$。由安培定则（电流垂直纸面向外，磁感线逆时针）：a 在 $O$ 处的磁场竖直向上，c 在 $O$ 处的磁场竖直向下，二者抵消；b 在 $O$ 处的磁场水平向右。所以 $O$ 点合磁感应强度大小为 $B$，方向由 $O$ 指向 $c'$。A 错，B 对。

**第二步：导线 b 受力。** a、c 在 b 处的磁场大小相等，合磁场水平向左（见下图）。b 中电流垂直纸面向外，由左手定则，b 受安培力竖直**向下**，不为零。C、D 错。（也可以用“同向电流相互吸引”：a、c 都吸引 b，合力指向下方。）

![第 5 题解析配图。](assets/xx2/k01-q05-1.png)

故选 **B**。

**问答脚本**

本题考点：安培定则（直线电流的磁场）；磁感应强度的矢量叠加；左手定则（或同向电流相互吸引）。
已知：截面图中 $a'$、$b'$、$c'$ 是等腰直角三角形（直角在 $b'$），三根导线电流都垂直纸面向外、大小相等，$O$ 为 $a'c'$ 中点，单根导线在 $O$ 处产生的磁场大小为 $B$。
提问路线：
1. 问：电流垂直纸面向外，用安培定则，它周围的磁感线是顺时针还是逆时针？ → 期望：逆时针。
2. 问：$O$ 到三根导线的距离相等吗？a、b、c 各自在 $O$ 处产生的磁场分别朝哪个方向？ → 期望：距离相等，大小都是 $B$；a 产生的向上，c 产生的向下，b 产生的水平向右。
3. 问：三个磁场叠加，$O$ 点合磁场大小、方向如何？ → 期望：a、c 的抵消，只剩 b 的，大小为 $B$，方向由 $O$ 指向 $c'$；A 错、B 对。
4. 问：导线 b 受力怎么判断？a、c 对 b 是吸引还是排斥？ → 期望：同向电流相互吸引，a、c 对 b 的吸引力合成后竖直向下，所以 b 受力向下且不为零；C、D 错，选 B。
常见错误：
- 把三个磁场大小直接相加得 $3B$。追问：三个磁场方向相同吗？a、c 产生的磁场方向是什么关系？
- 把磁感应强度方向画成沿“导线到 $O$ 点”的连线。追问：直线电流的磁感线是什么形状？某点磁场方向与半径是什么关系？
- 认为 b 受力向上。追问：同向电流相互吸引还是排斥？a、c 都在 b 的哪一侧？
总结句：直线电流的磁场沿以导线为圆心的圆的切线方向，多根导线的磁场按矢量叠加；同向电流相互吸引，反向电流相互排斥。

## 6. 多选 · 磁电式电表的原理

**题目**

〔多选〕（2026·浙江宁波期中）如图甲所示是磁电式电表内部的结构示意图，蹄形磁体的两极间有一个固定的圆柱形铁芯，铁芯外面套有一个可以绕轴转动的铝框，在铝框上绕有铜线圈。电表指针固定在铝框上，可与线圈一起转动，线圈的两端分别接在两个螺旋弹簧上，被测电流经过这两个弹簧流入线圈。蹄形磁体与铁芯间的磁场可看作是均匀辐向分布的，如图乙所示，无论线圈转到什么位置，线圈平面总与线圈所在磁场的方向平行。则（　　）

- A．磁电式电表的原理是通电线圈在磁场中因受安培力而转动
- B．改变线圈中电流的方向，指针会反向偏转
- C．减少线圈的匝数可以提高电表的灵敏度
- D．用塑料框代替铝框，在使用电表时可以使指针更迅速地稳定在示数位置上

![第 6 题原题图。](assets/xx2/k01-q06-stem1.png)

**答案：AB**

**解析**

- A：通电线圈在磁场中受安培力而转动，带动指针偏转，对。
- B：电流反向，安培力反向，线圈和指针反向偏转，对。
- C：匝数减少，相同电流下安培力力矩变小，偏角变小，灵敏度降低，错。
- D：铝框转动时磁通量变化，铝框中产生感应电流，受到阻碍转动的安培力（电磁阻尼），指针能很快停下；塑料框不导电，没有这个作用，指针会来回摆动更久，错。

故选 **AB**。

**问答脚本**

本题考点：磁电式电表的工作原理；灵敏度；电磁阻尼。
提问路线：
1. 问：磁电式电表里，线圈为什么会转动？ → 期望：通电线圈在磁场中受安培力而转动，A 对。
2. 问：电流方向反过来，线圈受力和指针偏转方向会怎样？ → 期望：安培力反向，指针反向偏转，B 对。
3. 问：匝数减少，相同电流下线圈受到的安培力变大还是变小？偏角呢？ → 期望：安培力变小，偏角变小，灵敏度降低，C 错。
4. 问：铝框是导体，它随线圈在磁场中转动时会产生什么？对转动有什么影响？换成塑料框呢？ → 期望：铝框中产生感应电流，受到阻碍转动的安培力（电磁阻尼），指针很快稳定；塑料框没有这个作用，D 错。最终选 AB。
常见错误：
- 认为匝数少线圈轻、更好转，所以更灵敏。追问：灵敏度看的是相同电流下偏角大小，偏角由安培力和弹簧决定，和线圈轻重关系大吗？
- 认为塑料框更轻，指针更快稳定。追问：指针为什么会来回摆？什么力能让它很快停下来？塑料能产生感应电流吗？
总结句：磁电式电表靠通电线圈在辐向磁场中受安培力转动；匝数越多越灵敏；铝框产生的电磁阻尼让指针快速稳定。

## 7. 多选 · 提高电流表灵敏度的方法

**题目**

〔多选〕电流表的灵敏度，是指在通入相同电流的情况下，指针偏转角度的大小。偏角越大，灵敏度越高。下列方法可提高磁电式电流表灵敏度的是（　　）

- A．增强永久磁铁的磁性
- B．增大螺旋弹簧的劲度系数
- C．增大线圈的面积
- D．增加线圈的匝数

**答案：ACD**

**解析**

线圈转动时螺旋弹簧发生扭转形变，产生反抗转动的力矩；指针停在安培力力矩与弹簧力矩平衡的位置。相同电流下要让偏角更大，可以：

- 让安培力更大：增强磁铁磁性（A）、增大线圈面积（C）、增加匝数（D）；
- 让弹簧更“软”：**减小**劲度系数。B 增大劲度系数，偏角反而变小，错。

故选 **ACD**。

**问答脚本**

本题考点：磁电式电流表灵敏度；安培力力矩与弹簧力矩平衡。
提问路线：
1. 问：指针最后停在某个偏角，是哪两个作用平衡的结果？ → 期望：线圈受的安培力（力矩）与螺旋弹簧扭转产生的反抗力（力矩）平衡。
2. 问：相同电流下要让偏角变大，安培力应该变大还是变小？哪些措施能增大安培力？ → 期望：安培力变大；增强磁性、增大线圈面积、增加匝数（A、C、D）。
3. 问：弹簧劲度系数增大，同样的安培力能让线圈转过更大还是更小的角度？ → 期望：更小，B 错。所以选 ACD。
常见错误：
- 认为劲度系数大，弹簧“有劲”，指针偏得更大。追问：弹簧是帮助线圈转动，还是阻碍线圈转动？
- 漏选 C。追问：线圈面积变大，两条受力边离转轴更远还是更近？力矩怎么变？
总结句：灵敏度高 = 相同电流偏角大：增大安培力（磁场强、面积大、匝数多）或减小弹簧劲度系数。

## 8. 单选 · 辐向磁场中的线圈与磁感应强度

- B．$a$、$b$两点的磁感应强度相同

- D．$c$、$d$两点的磁感应强度大小相等

## 9. 多选 · 两平行超导导线的相互作用

**题目**

〔多选〕如图所示，有两根用超导材料制成的长直平行细导线a、b，分别通以80 A和100 A流向相同的电流，两导线构成的平面内有一点$p$，到两导线的距离相等。下列说法正确的是（　　）

- A．两导线受到的安培力大小关系为$F_{b}=1.25F_{a}$
- B．导线所受的安培力可以用$F=IlB$计算
- C．移走导线b前后，$p$点的磁感应强度方向改变
- D．在离两导线所在的平面有一定距离的有限空间内，不存在磁感应强度为零的位置

![第 9 题原题图。](assets/xx2/k01-q09-stem1.png)

**答案：BCD**

**解析**

- A：a、b 之间的安培力是一对相互作用力，大小相等，$F_b=F_a$，错。
- B：每根导线所在处的磁场（另一根导线产生）与导线垂直，可以用 $F=IlB$ 计算，对。
- C：$p$ 到两导线距离相等，b 的电流较大，在 $p$ 处的磁场更强，合磁场与 b 产生的磁场同向（垂直纸面向里）；移走 b 后只剩 a 的磁场，方向垂直纸面向外，方向改变，对。
- D：离开两导线所在平面的点，两导线产生的磁场方向不在同一直线上，不可能抵消，所以不存在磁感应强度为零的位置，对。

故选 **BCD**。

**问答脚本**

本题考点：牛顿第三定律在安培力中的应用；$F=IlB$ 的适用条件；磁场叠加；空间中磁场能否为零。
已知：a 在上、b 在下，电流都向左，a 为 80 A、b 为 100 A，$p$ 到两导线距离相等。
提问路线：
1. 问：a 对 b 的安培力和 b 对 a 的安培力是什么关系？大小一样吗？ → 期望：一对相互作用力，大小相等，A 错。
2. 问：b 在 a 处产生的磁场与 a 垂直吗？能用 $F=IlB$ 吗？ → 期望：垂直，可以用，B 对。
3. 问：$p$ 处 a、b 产生的磁场方向分别朝哪？谁更强？移走 b 后 $p$ 处磁场方向会怎样？ → 期望：a 的向外、b 的向里，b 电流大更强，合磁场向里；移走 b 只剩向外的，方向改变，C 对。
4. 问：离开两导线所在平面的点，两导线产生的磁场方向能在同一直线上并且相反吗？ → 期望：不能，两者不共线，合磁场不可能为零，D 对。选 BCD。
常见错误：
- 认为电流大的导线受力大，$F_b=1.25F_a$。追问：两根导线之间的作用力满足什么定律？
- 判反 $p$ 点磁场方向。追问：电流向左时，导线上方和下方的磁场分别朝里还是朝外？
- 以为任何地方都可能出现合磁场为零。追问：两导线平面外一点，两个磁场分别垂直于什么方向？能反向共线吗？
总结句：两导线间的安培力是一对相互作用力，必然等大；磁场叠加要先逐个定方向再合成。

## 10. 单选 · 五角星线框所受安培力

**题目**

（2026·浙江嘉兴期中）用粗细均匀的电阻丝折成一个正五角星线框$ABMN$，$A$、$B$两点与电源连接。在线框所在平面内，有一垂直于平面向里的匀强磁场，磁感应强度大小恒定，如图所示。闭合开关S后，线框$ANB$部分所受安培力大小为$F$，则整个五角星线框所受安培力的大小为（　　）

- A．$\dfrac{5}{3}F$
- B．$\dfrac{5}{2}F$
- C．0
- D．$F$

![第 10 题原题图。](assets/xx2/k01-q10-stem1.png)

**答案：A**

**解析**

**第一步：并联分流。** $ANB$ 与 $AMB$ 两部分并联接在 $A$、$B$ 之间，电压相同。设 $ANB$ 电阻为 $R$，则 $AMB$ 电阻为 $\dfrac{3}{2}R$，电流之比 $I_{ANB}:I_{AMB}=3:2$。

**第二步：有效长度。** 两部分的首尾都是 $A$、$B$，有效长度都是 $AB=L$，且电流都从 $A$ 流向 $B$，所受安培力方向相同。

**第三步：求合力。** $F_{ANB}=BI_{ANB}L=F$，$F_{AMB}=BI_{AMB}L=\dfrac{2}{3}F$，整个线框受力 $F'=F+\dfrac{2}{3}F=\dfrac{5}{3}F$。

故选 **A**。

**问答脚本**

本题考点：并联电路分流；弯曲导线的有效长度；同向安培力的合成。
已知：$ANB$ 与 $AMB$ 两部分并联在 $A$、$B$ 两点间，$ANB$ 部分受力为 $F$，$AMB$ 电阻是 $ANB$ 的 $\dfrac{3}{2}$ 倍。
提问路线：
1. 问：电流从 $A$ 到 $B$ 有几条路径？它们是串联还是并联？ → 期望：$ANB$ 和 $AMB$ 两条，并联。
2. 问：两条路径电阻之比是 $2:3$，电流之比是多少？ → 期望：电流与电阻成反比，$I_{ANB}:I_{AMB}=3:2$。
3. 问：两条路径的有效长度分别是多少？受力方向相同吗？ → 期望：有效长度都是 $AB$，电流都从 $A$ 流向 $B$，安培力方向相同。
4. 问：所以 $AMB$ 部分受力多大？整个线框受力多大？ → 期望：$F_{AMB}=\dfrac{2}{3}F$，总力 $\dfrac{5}{3}F$，选 A。
常见错误：
- 认为闭合线框受安培力为零（选 C）。追问：线框里的电流是绕线框一圈流动，还是从 $A$ 分两路流到 $B$？
- 认为两部分电流相等，总力 $2F$。追问：并联支路电阻不同，电流相等吗？
- 按实际长度算安培力。追问：弯曲导线的有效长度怎么取？
总结句：线框接入电路时先分析电流分配，再用“首尾连线”求每部分的有效长度，同向力直接相加。

## 12. 计算 · 斜导轨上导体棒的平衡与加速

**题目**

（2026·福建厦门期末）如图所示，两平行金属导轨间的距离$L=0.4$ m，导轨与水平面的夹角$\theta=37$°，在导轨所在区域内分布有垂直于导轨平面向上的匀强磁场，磁感应强度大小$B=5.0$ T，导轨的一端接有电动势$E=10$ V、内阻$r=1.0$ Ω的直流电源，一根与导轨接触良好、质量为$m=0.4$ kg的导体棒$ab$垂直放在导轨上，$ab$棒恰好静止，受到的摩擦力方向沿斜面向下。$ab$棒与导轨接触的两点间的电阻$R_{0}=4.0$ Ω，不计导轨的电阻，重力加速度$g$取10 m/$\mathrm{s}^{2}$，sin 37°=0.6，cos 37°=0.8，最大静摩擦力等于滑动摩擦力。

（1）求$ab$棒受到的安培力大小$F_{\text{安}}$；

（2）求$ab$棒与导轨间的动摩擦因数$\mu$；

（3）若仅把磁场方向反向，其他条件都不变，则导体棒开始运动时的加速度$a$多大？

![第 12 题原题图。](assets/xx2/k01-q12-stem1.png)

**答案：（1）4 N　（2）0.5　（3）12 m/$\mathrm{s}^{2}$**

**解析**

**（1）** 由闭合电路欧姆定律 $I=\dfrac{E}{R_0+r}=\dfrac{10}{4.0+1.0}\ \text{A}=2\ \text{A}$，安培力 $F_{\text{安}}=BIL=5.0\times2\times0.4\ \text{N}=4\ \text{N}$。

**（2）** 磁场垂直导轨平面向上，安培力沿斜面向上；摩擦力沿斜面向下，说明棒有沿斜面向上滑的趋势，静摩擦力达到最大值（恰好静止）。

沿斜面：$F_{\text{安}}=mg\sin37^\circ+F_f$，得 $F_f=4\ \text{N}-2.4\ \text{N}=1.6\ \text{N}$；

垂直斜面：$F_N=mg\cos37^\circ=3.2\ \text{N}$；

$\mu=\dfrac{F_f}{F_N}=\dfrac{1.6}{3.2}=0.5$。

**（3）** 磁场反向，安培力变为沿斜面向下，棒沿斜面向下加速，滑动摩擦力沿斜面向上，大小仍为 $\mu mg\cos37^\circ=1.6\ \text{N}$：

$F_{\text{安}}+mg\sin37^\circ-F_f=ma$，$4+2.4-1.6=0.4a$，得 $a=12\ \text{m/s}^2$。

**问答脚本**

本题考点：闭合电路欧姆定律；安培力；斜面上的受力平衡与最大静摩擦；牛顿第二定律。
已知：$L=0.4$ m，$\theta=37^\circ$，$B=5.0$ T，磁场垂直导轨平面向上，$E=10$ V，$r=1.0$ Ω，$R_0=4.0$ Ω，$m=0.4$ kg，棒恰好静止、摩擦力沿斜面向下。
提问路线：
1. 问：（1）回路中电流多大？安培力多大？ → 期望：$I=\dfrac{E}{R_0+r}=2$ A，$F_{\text{安}}=BIL=4$ N。
2. 问：（2）磁场垂直斜面向上，安培力沿什么方向？摩擦力沿斜面向下说明棒有什么运动趋势？“恰好静止”说明摩擦力达到什么值？ → 期望：安培力沿斜面向上；棒有向上滑的趋势；静摩擦力达到最大静摩擦力。
3. 问：沿斜面和垂直斜面分别列平衡方程，摩擦力和支持力各是多少？ → 期望：$F_{\text{安}}=mg\sin37^\circ+F_f$，$F_f=1.6$ N；$F_N=mg\cos37^\circ=3.2$ N。
4. 问：动摩擦因数等于多少？ → 期望：$\mu=\dfrac{F_f}{F_N}=0.5$。
5. 问：（3）磁场反向后安培力朝哪？棒向哪边运动？摩擦力方向和大小怎样？ → 期望：安培力沿斜面向下，棒向下加速，滑动摩擦力沿斜面向上，大小 $\mu mg\cos37^\circ=1.6$ N。
6. 问：列牛顿第二定律，加速度多大？ → 期望：$F_{\text{安}}+mg\sin37^\circ-F_f=ma$，$a=12\ \text{m/s}^2$。
常见错误：
- 电流只用 $E/R_0$，忘了内阻。追问：闭合电路中电流等于电动势除以什么？
- 安培力方向判成水平或竖直。追问：磁场垂直导轨平面、电流沿棒，安培力和磁场、电流都垂直，应在哪个平面内？
- 平衡方程中漏掉重力分力，或把支持力写成 $mg$。追问：斜面上重力要沿哪两个方向分解？
- （3）中摩擦力方向仍按沿斜面向下处理。追问：滑动摩擦力方向与相对运动方向什么关系？棒现在往哪边滑？
总结句：通电导体棒问题 = 电路（求电流）+ 安培力（定大小方向）+ 力学（平衡或牛顿第二定律）；摩擦力方向由运动趋势判断。
