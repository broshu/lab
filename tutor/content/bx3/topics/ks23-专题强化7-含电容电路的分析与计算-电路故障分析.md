## 1. 单选 · 用电压表判断断路位置

**题目**

如图所示的电路，1、4两接线柱接有电压恒为6 V的电源，发现电路接通后两小灯泡均不发光，小明用一只电压表分别接在两接线柱上时，电压表的示数分别为$U_{14}=6$ V、$U_{12}=0$、$U_{23}=6$ V、$U_{34}=0$。则下列说法正确的是（　　）

- A．由以上数据可知小灯泡$\mathrm{L}_{1}$发生了断路
- B．由以上数据可知小灯泡$\mathrm{L}_{2}$发生了断路
- C．由以上数据可知滑动变阻器发生了断路
- D．由以上数据可知电源发生了断路

![第 1 题原题图。](assets/bx3/ks23-q01-stem1.png)

**答案：C**

**解析**

![原题接线：1—2 为 L₁，2—3 为变阻器，3—4 为 L₂。](assets/bx3/ks23-q01-source.png)

**第一步：先立规矩——串联电路断路时电压怎么分布。**
串联电路一旦某处断开，回路中**电流为零**。于是：

- 完好元件上 $U=IR=0$，电压表读数为 **0**；
- **断点两端**的电压等于电源电动势（沿另一条路径绕过去，中间没有任何电压降落）。

一句话：**断在哪儿，$6\ \text{V}$ 就出现在哪儿。**

**第二步：读数据。**
题给 $U_{12}=0$、$U_{23}=6\ \text{V}$、$U_{34}=0$，说明 $6\ \text{V}$ 出现在 2、3 之间，即**滑动变阻器所在的那一段断了**。

**第三步：核对其他选项。**

- 若 $L_{1}$（1、2 之间）断路，应是 $U_{12}=6\ \text{V}$，$U_{23}=U_{34}=0$。**A 错。**
- 若 $L_{2}$（3、4 之间）断路，应是 $U_{34}=6\ \text{V}$，$U_{12}=U_{23}=0$。**B 错。**
- 若电源断路，则各段电压全为零，且 $U_{14}$ 也不会是 $6\ \text{V}$。**D 错。**

**故选 C。**

> 故障排查的两条铁律：**断路 —— 电流为零，电压全压在断点上；短路 —— 该处电压为零，电流从旁边绕过去。** 拿着电压表挨段量，读到电动势的那一段就是断点。

**问答脚本**

提问路线：
1. 问：两灯都不亮，串联电路里最可能是哪类故障？这时电路中的电流是多少？→ 期望：断路；电流为零。
2. 问：电流为零时，完好的灯泡两端电压是多少？断点两端的电压呢？→ 期望：完好元件 $U=IR=0$；断点两端电压等于电源电压 6 V。
3. 问：哪两点之间测到了 6 V？那两点之间是哪个元件？→ 期望：2、3 之间，是滑动变阻器，选 C。
4. 可选追问：如果是 $L_1$ 断了，四个读数应该分别是多少？→ 期望：$U_{12}=6\,\mathrm{V}$，其余两段为 0。
常见错误：
- 选 A 或 B：以为读数为 0 的地方是坏的。追问：一个完好的灯泡，没有电流流过时，它两端的电压是多少？
- 选 D：以为灯不亮就是电源坏了。追问：$U_{14}=6\,\mathrm{V}$ 说明电源有没有电压？
总结句：串联电路断路时，哪两点间测出电源电压，断点就在那两点之间。

## 2. 单选 · 由亮暗变化倒推故障

**题目**

（2025·浙江温州联考）如图所示，电源电动势为$E$，内阻为$r$，三个灯泡A、B、C原来都是正常发光的，电路突然发生了故障，结果灯泡C比原来暗了些，灯泡A和B比原来亮了些，假设三个灯泡灯丝的电阻恒定不变，则电路中出现的故障可能是（　　）

- A．$R_{1}$短路
- B．$R_{1}$断路
- C．$R_{2}$断路
- D．$R_{2}$短路

![第 2 题原题图。](assets/bx3/ks23-q02-stem1.png)

**答案：A**

**解析**

![原题电路：A、R₁ 与「B 并联 R₂」串联；这一整体再与灯 C 并联。](assets/bx3/ks23-q02-source.png)

**第一步：把现象翻译成电学结论。**
灯 C 变暗、灯 A 和 B 变亮。先把嵌套关系分清：**B 与 $R_{2}$ 并联**，再与 A、$R_{1}$ 串联；这个整体与灯 C 并联接在电源上。

- A、B 变亮 $\Rightarrow$ 它们那条支路的电流**增大** $\Rightarrow$ 该支路电阻**减小**；
- C 变暗 $\Rightarrow$ 路端电压**减小** $\Rightarrow$ 干路电流**增大** $\Rightarrow$ 外电路总电阻**减小**。

两条都指向「某处电阻变小」，即**短路类**故障，而不是断路。

**第二步：逐项排查。**

- **A：$R_{1}$ 短路。** A、B 支路电阻减小，总电阻减小，干路电流增大，内阻分压增大，路端电压下降 $\Rightarrow$ C 变暗；同时该支路电流 $I_{\text{支}}=I-I_{\mathrm C}$ 增大，A 变亮；$B\parallel R_{2}$ 的等效电阻不变，其电压随 $I_{\text{支}}$ 增大，B 也变亮。**与现象吻合，正确。**
- **B：$R_{1}$ 断路。** 那条支路没有电流，A、B 直接不亮。**错。**
- **C：$R_{2}$ 断路。** 总电阻增大，干路电流减小，路端电压升高，C 反而**变亮**。**错。**
- **D：$R_{2}$ 短路。** 由电路结构，$R_{2}$ 短路会把灯 B 一并短掉，B 不亮。**错。**

**故选 A。**

> 做法固定：**先把「变亮/变暗」翻译成「电流/电压如何变」，再翻译成「电阻如何变」，最后才去看是哪个元件短路或断路。** 顺序反了就会陷入盲猜。

**问答脚本**

提问路线：
1. 问：先看清电路：灯 B 和 $R_2$ 是什么关系？灯 A、$R_1$ 和它们呢？灯 C 在哪条支路？→ 期望：B 与 $R_2$ 并联，再与 A、$R_1$ 串联成一条支路；这条支路与灯 C 并联。
2. 问：C 变暗说明路端电压怎么变？干路电流和总电阻呢？→ 期望：路端电压减小 → 干路电流增大 → 总电阻减小。
3. 问：总电阻减小，是短路还是断路？可以排除哪两个选项？→ 期望：短路；排除 B、C 两个断路。
4. 问：如果 $R_2$ 短路，灯 B 会怎样？→ 期望：B 也被短接，不亮，D 错。
5. 问：如果 $R_1$ 短路，A、B 所在支路电流怎么变？两灯亮度呢？→ 期望：支路电阻减小，支路电流 $I-I_C$ 增大，A、B 都变亮。选 A。
常见错误：
- 选 C（$R_2$ 断路）：以为 B 会因此分得更多电流变亮。追问：$R_2$ 断路后总电阻变大还是变小？灯 C 会变暗吗？
- 选 D：没注意 $R_2$ 短路会把并联的 B 一起短掉。追问：两端被导线直接连接的灯，还有电流流过吗？
总结句：先由现象判断总电阻变大还是变小，从而区分断路和短路，再逐个代入检验。

## 3. 单选 · 稳定后电容器的电压与电荷量

**题目**

如图所示的电路中，电源电动势$E=3$ V，内电阻$r=1$ Ω，定值电阻$R_{1}=3$ Ω，$R_{2}=2$ Ω，电容器的电容$C=100$ μF，则下列说法正确的是（　　）

- A．闭合开关S，电路稳定后电容器两端的电压为3 V
- B．闭合开关S，电路稳定后电容器所带电荷量为$3.0\times \mathrm{10}^{-4}$ C
- C．闭合开关S，电路稳定后电容器所带电荷量为$1.5\times \mathrm{10}^{-4}$ C
- D．先闭合开关S，电路稳定后断开开关S，通过电阻$R_{1}$的电荷量为$3.0\times \mathrm{10}^{-4}$ C

![第 3 题原题图。](assets/bx3/ks23-q03-stem1.png)

**答案：C**

**解析**

![原题电路：C 与 R₁ 并联；断开 S 后，C 和 R₁ 仍构成放电回路。](assets/bx3/ks23-q03-source.png)

**第一步：电路稳定后，电容器支路不通电流。**
这是所有含电容电路题的第一句话。把电容器**当作断路**拆掉，剩下的就是普通串联电路：

$$I=\frac{E}{R_{1}+R_{2}+r}=\frac{3}{3+2+1}\ \text{A}=0.5\ \text{A}$$

![辅助图：闭合稳定后 C 支路无电流；断开 S 后，C 通过 R₁ 放电。](assets/bx3/ks23-q03-states.svg)

**第二步：看电容器并在谁两端，它的电压就等于谁的电压。**
电容器跨接在 $R_{1}$ 两端：

$$U_{C}=IR_{1}=0.5\times3\ \text{V}=1.5\ \text{V}$$

**A 错**（$3\ \text{V}$ 是电动势，不是电容器电压）。

**第三步：求电荷量。**

$$Q=CU_{C}=100\times10^{-6}\times1.5\ \text{C}=1.5\times10^{-4}\ \text{C}$$

**B 错，C 正确。**

**第四步：D——断开开关后的放电电荷量。**
断开 S 后电容器通过 $R_{1}$ 放电，放掉的电荷量就是它原来带的电荷量 $1.5\times10^{-4}\ \text{C}$，不是 $3.0\times10^{-4}\ \text{C}$。**D 错。故选 C。**

> 三步法背下来：**① 拆掉电容器求电流；② 电容器与谁并联，电压就等于谁的电压；③ $Q=CU$。** 含电容电路的题九成以上都倒在第②步——看错电容器跨接的对象。

**问答脚本**

提问路线：
1. 问：电路稳定后，电容器所在的支路有电流吗？可以怎样处理电容器？→ 期望：没有电流，当作断路拆掉。
2. 问：拆掉电容器后电路中的电流是多少？→ 期望：$I=\dfrac{3}{3+2+1}=0.5\,\mathrm{A}$。
3. 问：电容器跨接在哪个电阻两端？它的电压是多少？→ 期望：$R_1$ 两端，$U_C=0.5\times 3=1.5\,\mathrm{V}$，A 错。
4. 问：电容器带的电荷量是多少？→ 期望：$Q=CU=100\times 10^{-6}\times 1.5=1.5\times 10^{-4}\,\mathrm{C}$，C 对、B 错。
5. 问：断开开关后，电容器通过 $R_1$ 放电，放掉的电荷量是多少？→ 期望：就是原来的 $1.5\times 10^{-4}\,\mathrm{C}$，D 错。选 C。
常见错误：
- 选 A 或 B：把电动势 3 V 当成电容器电压。追问：电容器并在哪个电阻上？电阻 $R_1$ 两端分到多少电压？
- 电容单位没换算：100 μF 是多少法拉？
总结句：含电容电路稳定后，电容器当断路，它的电压等于与它并联的那部分电路的电压。

## 4. 单选 · 开关通断引起的电荷量变化

**题目**

阻值相等的四个定值电阻、电容器$C$及电池$E$（内阻可忽略）连接成如图所示电路。开关S断开且电流稳定时，电容器$C$所带的电荷量为$Q_{1}$；闭合开关S，电流再次稳定后，电容器$C$所带的电荷量为$Q_{2}$。$Q_{1}$与$Q_{2}$的比值为（　　）

- A．$\dfrac{2}{5}$
- B．$\dfrac{1}{2}$
- C．$\dfrac{3}{5}$
- D．$\dfrac{2}{3}$

![第 4 题原题图。](assets/bx3/ks23-q04-stem1.png)

**答案：C**

**解析**

![原题电路：开关 S 短接的是上方电阻，C 接在右侧两节点之间。](assets/bx3/ks23-q04-source.png)

**第一步：两种状态都先把电容器拆掉。**
电容器支路稳定后无电流，先分别画出 S 断开、S 闭合时的等效电路（如下图甲、乙所示）。四个电阻阻值都记为 $R$，电源内阻不计。

![原书等效图：甲为 S 断开，C 跨在两只串联电阻中的一只上；乙为 S 闭合，C 跨在整个并联部分。](assets/bx3/ks23-q04-equivalent.png)

**第二步：S 断开时。**
此时外电路是「一个 $R$」串联「两个 $R$ 串联后再与一个 $R$ 并联」，并联部分的阻值为

$$\frac{2R\cdot R}{2R+R}=\frac{2}{3}R$$

干路电流

$$I_{1}=\frac{E}{R+\frac{2}{3}R}$$

并联部分两端的电压为 $I_{1}\cdot\dfrac{2}{3}R$。电容器跨在那条「两个 $R$ 串联」支路的**其中一个** $R$ 上，只分得一半：

$$U_{1}=\frac{E}{R+\frac{2}{3}R}\times\frac{2}{3}R\times\frac{1}{2}=\frac{1}{5}E$$

**第三步：S 闭合时。**
开关把一个电阻短接掉，并联部分变成两个 $R$ 并联，阻值 $\dfrac{1}{2}R$，此时电容器两端电压就是这个并联部分的电压：

$$U_{2}=\frac{E}{R+\frac{1}{2}R}\times\frac{1}{2}R=\frac{1}{3}E$$

**第四步：比值。**
同一个电容器，$Q=CU$，电容不变：

$$\frac{Q_{1}}{Q_{2}}=\frac{U_{1}}{U_{2}}=\frac{\frac{1}{5}E}{\frac{1}{3}E}=\frac{3}{5}$$

**故选 C。**

> 提醒：开关的通断只改变**电阻网络**，电容器始终不参与导电。所以流程永远是「重画等效电路 $\to$ 求电容器所跨元件的电压 $\to$ $Q=CU$」。比值题连 $E$、$R$ 的具体值都不需要。

**问答脚本**

提问路线：
1. 问：两种状态下，电容器所在支路有没有电流？能不能先把电容器拆掉，分别画出 S 断开和 S 闭合时的等效电路？→ 期望：没有电流；可以拆掉画等效电路。
2. 问：S 断开时，四个电阻怎样连接？并联部分的电阻是多少？→ 期望：一个 $R$ 串联“两个 $R$ 串联后与一个 $R$ 并联”；并联部分 $\dfrac23R$。
3. 问：S 断开时，电容器跨在哪个电阻上？它的电压是电动势的几分之几？→ 期望：跨在“两个 $R$ 串联”支路中的一个 $R$ 上；$U_1=\dfrac{E}{\frac53R}\times\dfrac23R\times\dfrac12=\dfrac15E$。
4. 问：S 闭合后，哪个电阻被短接？并联部分变成多少？电容器电压是多少？→ 期望：并联部分变成两个 $R$ 并联，$\dfrac12R$；$U_2=\dfrac13E$。
5. 问：同一个电容器，电荷量之比等于什么？→ 期望：电压之比，$\dfrac{Q_1}{Q_2}=\dfrac35$，选 C。
常见错误：
- S 断开时把电容器电压当成整个并联部分的电压 $\dfrac25E$，得到 $\dfrac{Q_1}{Q_2}=\dfrac65$ 或选 A。追问：电容器两端接的是并联部分的两端，还是那条支路中一个电阻的两端？
- 电路结构认错。追问：请指出电流从电源正极出发，先经过哪个电阻，然后在哪里分叉？
总结句：开关通断前后电路结构会变，每种状态都要先拆掉电容器、重新画等效电路。

## 5. 单选 · 含电容的动态电路

**题目**

（2025·浙江温州开学考试）如图所示的电路中，电源电动势为$E$、内阻为$r$，$R_{1}$、$R_{2}$为定值电阻，$R_{3}$为滑动变阻器，$r=R_{1}$。开关闭合后，下列说法正确的是（　　）

- A．此时电容器左极板带正电
- B．仅将$R_{3}$的滑片向下滑动，电源的效率增大
- C．仅将$R_{3}$的滑片向下滑动，电容器的带电荷量增大
- D．仅将$R_{3}$的滑片向上滑动，电源的输出功率可能先增大后减小

![第 5 题原题图。](assets/bx3/ks23-q05-stem1.png)

**答案：C**

**解析**

![原题电路：C 与 R₂ 串联后跨接在 R₁ 两端，需先判断稳态时 R₂ 的电压。](assets/bx3/ks23-q05-source.png)

**第一步：A——极板带电的正负看电势高低。**
电容器两极板分别接在电路的两点上，哪一极板所接点的电势高，哪块极板就带正电。由电路结构可知左极板电势**低**，故左极板带**负**电。**A 错。**

![稳态辅助图：R₂ 无电流、无压降，因此 C 两端电压等于 R₁ 两端电压；左极板负、右极板正。](assets/bx3/ks23-q05-equivalent.svg)

**第二步：滑片向下滑，走一遍链条。**
$R_{3}$ 接入阻值**减小** $\Rightarrow$ 总电阻减小 $\Rightarrow$ 电流 $I$ **增大** $\Rightarrow$ 内电压 $Ir$ 增大 $\Rightarrow$ 路端电压 $U=E-Ir$ **减小**。

由

$$\eta=\frac{U}{E}\times100\%$$

电源效率**减小**。**B 错。**

**第三步：C——电容器电压跟着 $R_{1}$ 走。**
严格看接线，电容器与 $R_{2}$ 串联后跨接在 $R_{1}$ 两端。**稳态时该支路电流为零，$R_{2}$ 上无电压降**，因此 $U_C=U_1$。又有

$$U_{1}=IR_{1}$$

电流增大 $\Rightarrow$ $U_{1}$ 增大 $\Rightarrow$ 由 $Q=CU_{1}$ 知电荷量**增大**。**C 正确。**

**第四步：D——输出功率只会单调减小。**

$$P_{\text{出}}=I^{2}(R_{1}+R_{3})=\frac{E^{2}}{\dfrac{(R_{1}+R_{3}-r)^{2}}{R_{1}+R_{3}}+4r}$$

当 $R_{1}+R_{3}=r$ 时输出功率最大。题目给了 $R_{1}=r$，所以恒有

$$R_{1}+R_{3}\ge r$$

即电路**始终工作在峰值的右侧**。滑片向上滑，$R_{3}$ 增大，外电阻离 $r$ 越来越远，输出功率**一直减小**，不可能先增后减。**D 错。故选 C。**

> $R_{1}=r$ 这个条件是专门为 D 项设的：它把工作点锁死在输出功率曲线的单调区间上。凡是题目给出内阻与某电阻相等的「多余条件」，多半就是用来判断极值能否取到的。

**问答脚本**

提问路线：
1. 问：电容器的两块极板分别接在电路中的哪两点？哪一点电势高？左极板带什么电？→ 期望：左极板所接点电势低，带负电，A 错。
2. 问：滑片向下滑，$R_3$ 接入的阻值怎么变？电流、路端电压怎么变？电源效率呢？→ 期望：$R_3$ 减小，电流增大，路端电压减小，效率 $\dfrac UE$ 减小，B 错。
3. 问：电容器与 $R_2$ 串联后接在 $R_1$ 两端。稳定时 $R_2$ 上有电压吗？电容器电压等于什么？→ 期望：$R_2$ 中无电流、无电压，$U_C=U_1=IR_1$。
4. 问：电流增大时，电容器的电荷量怎么变？→ 期望：$U_1$ 增大，$Q$ 增大，C 对。
5. 问：外电阻 $R_1+R_3$ 和内阻 $r$ 谁大？输出功率会先增大后减小吗？→ 期望：$R_1=r$，所以 $R_1+R_3\ge r$，滑片上滑时外电阻离 $r$ 越来越远，输出功率一直减小，D 错。选 C。
常见错误：
- 认为电容器电压等于 $R_2$ 两端电压或路端电压。追问：电容器那条支路里有电流吗？没有电流时 $R_2$ 两端电压是多少？
- 选 D：只记得“输出功率先增后减”。追问：本题外电阻最小是多少？比内阻大还是小？
- 选 B：以为电阻变小效率变高。追问：效率等于路端电压除以电动势，路端电压怎么变？
总结句：电容器支路中串联的电阻在稳态时没有电压降；判断输出功率变化要先看外电阻在 $r$ 的哪一侧。

## 6. 单选 · 由两个现象锁定故障

**题目**

如图所示的电路中，闭合开关S后，灯$\mathrm{L}_{1}$、$\mathrm{L}_{2}$都能发光。后来由于某种故障使灯$\mathrm{L}_{2}$突然变亮（未烧坏），电压表的读数增大，由此可推断，这故障可能是（　　）

- A．电阻$R_{1}$断路
- B．电阻$R_{2}$短路
- C．灯$\mathrm{L}_{1}$上两接线柱间短路
- D．电阻$R_{2}$断路

![第 6 题原题图。](assets/bx3/ks23-q06-stem1.png)

**答案：D**

**解析**

![原题电路：「L₁ 并联 R₁」与「L₂ 并联 R₂」串联，V 测整个外电路的电压。](assets/bx3/ks23-q06-source.png)

**第一步：把两个现象翻译成两个必要条件。**

- **电压表读数增大** $\Rightarrow$ 路端电压增大 $\Rightarrow$ 内电压 $Ir$ 减小 $\Rightarrow$ 干路电流**减小** $\Rightarrow$ 电路总电阻**增大**。这一条立刻排除所有「短路」型故障（短路只会让总电阻减小）。
- **灯 $L_{2}$ 变亮** $\Rightarrow$ 通过 $L_{2}$ 的电流增大，即 $L_{2}$ 分得的电压增大。

必须**同时**满足这两条，才是可能的故障。

**第二步：逐项排查。**

- **A：$R_{1}$ 断路。** 总电阻增大、电流减小 ✓，但 $L_{1}$、$R_{1}$ 并联部分的电阻变大会分走更多电压，$L_{2}$ 两端电压反而减小，$L_{2}$ 变暗。**错。**
- **B：$R_{2}$ 短路。** $R_{2}$ 与 $L_{2}$ 并联，短路会把 $L_{2}$ 一起短掉，$L_{2}$ 直接不亮。**错。**
- **C：$L_{1}$ 两接线柱间短路。** 总电阻减小、电流增大、路端电压下降，电压表读数**减小**。**错。**
- **D：$R_{2}$ 断路。** 与 $L_{2}$ 并联的支路断了，这一部分电阻增大 $\Rightarrow$ 总电阻增大 $\Rightarrow$ 干路电流减小 $\Rightarrow$ 路端电压增大（电压表读数增大 ✓）；同时干路电流减小使 $L_{1}$、$R_{1}$ 并联部分分得的电压减小，剩给 $L_{2}$ 的电压增大 $\Rightarrow$ $L_{2}$ 变亮 ✓。**两条都满足，正确。**

**故选 D。**

> 多现象故障题的通法：**每个现象翻译成一个条件，用条件去「筛」选项**，而不是逐个选项从头分析到尾。先用「总电阻是增是减」这一条，通常一刀就能砍掉一半选项。

**问答脚本**

提问路线：
1. 问：电压表读数增大，说明路端电压怎么变？干路电流和总电阻呢？→ 期望：路端电压增大 → 干路电流减小 → 总电阻增大。
2. 问：总电阻增大，是断路还是短路？可以排除哪些选项？→ 期望：断路；排除 B、C 两个短路。
3. 问：$R_1$ 与谁并联？$R_1$ 断路后，这部分分到的电压变大还是变小？$L_2$ 呢？→ 期望：$R_1$ 与 $L_1$ 并联；这部分电阻变大，分压变大，$L_2$ 分压变小，变暗，A 错。
4. 问：$R_2$ 与谁并联？$R_2$ 断路后，$L_2$ 所在部分的电阻怎么变？$L_2$ 两端电压呢？→ 期望：$R_2$ 与 $L_2$ 并联；这部分电阻变大，干路电流减小，$L_1$、$R_1$ 部分分压减小，剩给 $L_2$ 的电压增大，$L_2$ 变亮。选 D。
常见错误：
- 选 B（$R_2$ 短路）：以为短路电流大，灯会变亮。追问：$R_2$ 和 $L_2$ 并联，$R_2$ 短路时 $L_2$ 两端电压是多少？
- 选 A：只满足了“电压表读数增大”，没检验 $L_2$ 的亮度。追问：$R_1$ 断路后，$L_1$ 那部分分的电压变多，留给 $L_2$ 的电压怎么变？
总结句：题目给了两个现象，每个故障都要同时满足两个现象才算可能。

## 7. 多选 · 静电计与电压表的对比

**题目**

〔多选〕如图为一电源电动势为$E$，内阻为$r$的闭合电路，电压表的内阻为10 kΩ，B为静电计，$C_{1}$、$C_{2}$分别是两个电容器，将开关S闭合一段时间，下列说法正确的是（　　）

- A．若$C_{1}>C_{2}$，则电压表两端的电势差大于静电计两端的电势差
- B．若将滑动变阻器滑片P向右滑动，则电容器$C_{2}$上带电荷量增大
- C．$C_{1}$上带电荷量为零
- D．再将开关S断开，然后使电容器$C_{2}$两极板间距离增大，则静电计张角也增大

![第 7 题原题图。](assets/bx3/ks23-q07-stem1.png)

![第 7 题原题图。](assets/bx3/ks23-q07-stem2.png)

**答案：CD**

**解析**

![原题接线：C₁ 与 V 并联，C₂ 与静电计 B 并联；电压表内阻为 10 kΩ。](assets/bx3/ks23-q07-source.png)

**第一步：分清两种「测电压」的仪器。**

- **电压表**是由电流表改装的，测量时**必须有电流通过**它才有示数；
- **静电计**的两个电极彼此绝缘，靠电荷间的静电力使指针张开，**不需要电流**，测的是两极间的电势差。

![辅助接线图：有限内阻的电压表使 C₁ 两极板在稳态时等势；C₂ 承受电源电动势 E。](assets/bx3/ks23-q07-meters.svg)

**第二步：A——先认准两组并联关系。**
$C_{1}$ 与电压表 V **并联**，$C_{2}$ 与静电计 B **并联**，两组再串联。稳定后，$C_{2}$ 隔断直流，静电计也没有持续电流，回路中电流为零。电压表内阻是有限的 $R_V=10\ \text{k}\Omega$，因此

$$U_V=I_VR_V=0,\qquad U_{C_1}=U_V=0$$

而 $C_{2}$ 两端有电压，静电计有示数。因此电压表两端的电势差**小于**静电计两端的电势差，与 $C_{1}$、$C_{2}$ 谁大无关。**A 错。**

**第三步：B——$C_{2}$ 的电压被电动势「锁住」。**
稳定后整个回路中无电流，$R$、$r$ 和 V 上的电压降均为零，$C_{2}$ 两端电压等于电源电动势，是个定值。滑动变阻器怎么滑都不改变它，电荷量 $Q=C_{2}E$ 不变。**B 错。**

**第四步：C——$C_{1}$ 根本没充上电。**
电压表示数为零意味着 $C_{1}$ 两端电压为零，故 $Q_{1}=C_{1}U=0$。**C 正确。**

**第五步：D——断开开关后拉开极板。**
S 断开后 $C_{2}$ 成为孤立带电系统，电荷量 $Q$ **不变**。极板间距增大 $\Rightarrow$ 电容 $C=\dfrac{\varepsilon_{\text{r}}S}{4\pi kd}$ **减小** $\Rightarrow$ 由

$$U=\frac{Q}{C}$$

板间电压**增大** $\Rightarrow$ 静电计张角**增大**。**D 正确。故选 CD。**

> 电容器动态问题的分水岭：**开关闭合（与电源相连）时 $U$ 不变，讨论 $Q$；开关断开（孤立）时 $Q$ 不变，讨论 $U$。** 判断清楚是哪一种，再用 $C=\dfrac{Q}{U}$ 推另一个量。

**问答脚本**

提问路线：
1. 问：电压表和静电计测电压时，需要有电流通过吗？→ 期望：电压表需要有电流才有示数；静电计不需要电流。
2. 问：$C_1$ 和谁并联？$C_2$ 和谁并联？电路稳定后回路中有电流吗？→ 期望：$C_1$ 与电压表并联，$C_2$ 与静电计并联，两组串联；$C_2$ 隔断直流，回路电流为零。
3. 问：没有电流时，电压表两端的电压是多少？$C_1$ 带多少电荷？→ 期望：$U_V=I R_V=0$；$C_1$ 电压为零，不带电，C 对。A 错（与 $C_1$、$C_2$ 大小无关）。
4. 问：回路无电流时，$C_2$ 两端电压等于多少？滑片移动会改变它吗？→ 期望：等于电动势 $E$；不会改变，$Q_2$ 不变，B 错。
5. 问：断开 S 后 $C_2$ 的电荷量会变吗？极板间距增大，电容怎么变？电压呢？→ 期望：$Q$ 不变；$C$ 减小，$U=\dfrac QC$ 增大，张角增大，D 对。选 CD。
常见错误：
- 选 A：按串联电容分压的思路去比较。追问：电压表的内阻是有限的，没有电流流过时，它两端还能有电压吗？
- 选 B：以为滑片移动会改变各部分电压。追问：回路中电流是多少？电阻上的电压降是多少？
- 漏选 D：没想到断开开关后电荷量不变。追问：开关断开后，电容器的电荷还有地方流走吗？
总结句：电压表必须有电流才有示数，静电计不需要；断开电源后电容器电荷量不变，改变间距就改变电压。

## 8. 单选 · 开关通断前后电容器的极性与电荷量

**题目**

如图所示，电源电动势$E=6$ V，内阻不计，电阻$R_{1}=2$ Ω，$R_{2}=4$ Ω，$R_{3}=6$ Ω，电容器电容$C=4$ μF，下列说法正确的是（　　）

- A．S断开时电容器的电压为2 V
- B．S断开时电容器a极板带负电
- C．S闭合，电路稳定后，电容器b极板带负电
- D．S闭合，电路稳定后，电容器所带电荷量为$8\times \mathrm{10}^{-6}$ C

![第 8 题原题图。](assets/bx3/ks23-q08-stem1.png)

**答案：D**

**解析**

![原题电路：开关 S 改变 b 极板所接节点的电势，a 极板始终接在 R₁、R₂ 的中点。](assets/bx3/ks23-q08-source.png)

![两种状态的节点电势图：a 点始终为 4 V；S 断开时 b 为 0 V，闭合时 b 为 6 V，故电容器极性翻转。](assets/bx3/ks23-q08-polarity.svg)

**第一步：S 断开时。**
开关 S 断开后，$R_{3}$ 与电容器所在支路在稳态时无电流，$R_{3}$ 上无电压降，所以 b 点与电源负极等势。电流只在 $R_{1}$、$R_{2}$ 串联回路中流动（内阻不计）：

$$I=\frac{E}{R_{1}+R_{2}}=\frac{6}{2+4}\ \text{A}=1\ \text{A}$$

电容器两端电压等于 $R_{2}$ 两端电压：

$$U_{2}=IR_{2}=\frac{ER_{2}}{R_{1}+R_{2}}=\frac{6\times4}{6}\ \text{V}=4\ \text{V}$$

**A 错**（不是 $2\ \text{V}$）。此时 a 极板所接点电势较高，a 极板带**正**电。**B 错。**

**第二步：S 闭合，电路重排。**
此时 $R_{1}$ 与 $R_{2}$ 串联后再与 $R_{3}$ 并联，一起接在电源两端（内阻不计，路端电压恒为 $6\ \text{V}$）。$R_{1}R_{2}$ 支路的电流仍是

$$I=\frac{6}{2+4}\ \text{A}=1\ \text{A}$$

而S 将 b 点直接接到电源正极，电容器此时跨接的对象变成了 $R_{1}$：

$$U_{1}=IR_{1}=1\times2\ \text{V}=2\ \text{V}$$

**第三步：极性与电荷量。**
接线关系改变后，b 极板所接点的电势高于 a 极板，**b 极板带正电**。**C 错**（说的是 b 带负电）。

$$Q=CU_{1}=4\times10^{-6}\times2\ \text{C}=8\times10^{-6}\ \text{C}$$

**D 正确。故选 D。**

> 本题的考点在于：**开关一动，电容器「盯着」的那个电阻可能就换人了**（从 $R_{2}$ 变成 $R_{1}$），极性也可能反过来。每换一个状态，都要重新看一遍电容器的两根引线分别接在哪两点上。

**问答脚本**

提问路线：
1. 问：S 断开时，$R_3$ 所在支路有电流吗？$R_3$ 上有电压吗？电容器两端相当于接在哪个电阻上？→ 期望：没有电流，$R_3$ 无电压；电容器两端电压等于 $R_2$ 两端电压。
2. 问：此时电流和电容器电压是多少？a 极板带什么电？→ 期望：$I=\dfrac{6}{2+4}=1\,\mathrm{A}$，$U=4\,\mathrm{V}$，A 错；a 极板接高电势，带正电，B 错。
3. 问：S 闭合后，b 点和电源哪一极直接相连？电容器现在跨接在哪个电阻上？→ 期望：b 点接到电源正极；跨在 $R_1$ 上。
4. 问：此时电容器电压是多少？哪块极板电势高？电荷量多少？→ 期望：$U=IR_1=2\,\mathrm{V}$；b 板电势高带正电，C 错；$Q=4\times 10^{-6}\times 2=8\times 10^{-6}\,\mathrm{C}$，D 对。
常见错误：
- 选 A：S 断开时以为电容器跨在 $R_1$ 上。追问：S 断开时 b 点和电源哪一极等电势？
- 选 C：没注意 S 闭合后 b 点的电势变了。追问：S 闭合后 b 点直接连到了哪里？它的电势是最高还是最低？
总结句：开关通断会改变电容器跨接的位置，要重新找电容器两极板各接在哪一点，再比较电势高低。

## 9. 多选 · 电桥式电路中的电容器

**题目**

〔多选〕在如图所示的电路中，$C$为电容器，$R_{1}$为0～99.00 Ω的电阻箱，电源内阻$r=5$ Ω，定值电阻$R_{2}=2$ Ω，$R_{3}=R_{4}=5$ Ω。现闭合开关S，调节$R_{1}$使其电阻从零逐渐增至最大，在此过程中（　　）

- A．电容器的a极板先带正电后带负电
- B．电容器的a极板先带负电后带正电
- C．电源的输出功率先增大后减小
- D．电容器两极板间的电压先增大后减小

![第 9 题原题图。](assets/bx3/ks23-q09-stem1.png)

**答案：AC**

**解析**

![原题电桥：C 接在两条串联支路的中点 a、b 之间，先比较两个中点的电势。](assets/bx3/ks23-q09-source.png)

**第一步：认出结构。**
$(R_{1}+R_{2})$ 是一条支路，$(R_{3}+R_{4})$ 是另一条支路，两条支路并联；电容器接在两条支路的中点之间——这是一个**电桥**。电容器不通电流，两块极板的电势分别由两条支路自己的分压决定。

**第二步：找「平衡点」。**
$R_{3}=R_{4}=5\ \Omega$，右支路的中点电势恰好把该支路电压**二等分**。左支路要想中点电势也相同，必须

$$R_{1}=R_{2}=2\ \Omega$$

**第三步：讨论 $R_{1}$ 从 $0$ 增到最大的全过程。**

- $R_{1}=0$：左支路中点直接连到电源正极一侧，电势最高，a 极板带**正**电；
- $R_{1}=2\ \Omega$：电桥平衡，两极板电势相等，电容器**不带电**，$U=0$；
- $R_{1}>2\ \Omega$：b 极板电势更高，a 极板带**负**电。

所以 a 极板**先带正电后带负电**，两极板间电压**先减小到零再增大**。**A 正确，B、D 错。**

**第四步：C——输出功率先增后减。**
外电阻是两条支路并联：

$$R_{\min}=\frac{R_{2}(R_{3}+R_{4})}{R_{2}+R_{3}+R_{4}}=\frac{2\times10}{12}\ \Omega\approx1.67\ \Omega\quad(R_{1}=0)$$

$$R_{\max}=\frac{(R_{1}+R_{2})(R_{3}+R_{4})}{R_{1}+R_{2}+R_{3}+R_{4}}=\frac{101\times10}{111}\ \Omega\approx9.1\ \Omega\quad(R_{1}=99\ \Omega)$$

内阻 $r=5\ \Omega$ **落在这个区间之内**，所以外电阻从 $1.67\ \Omega$ 增大到 $9.1\ \Omega$ 的过程中会经过 $R_{\text{外}}=r$ 这一点，输出功率**先增大后减小**。**C 正确。故选 AC。**

> 这题把两个考点缝在了一起：电桥的**平衡条件**（对臂电阻之比相等，此时中间支路电压为零）和输出功率的**极值条件**（$R_{\text{外}}=r$）。判断输出功率能否取到峰值，就看 $r$ 是否落在外电阻的变化范围内——这一步是上一节 D 类选项的正面版本。

**问答脚本**

提问路线：
1. 问：$R_1$、$R_2$ 和 $R_3$、$R_4$ 各组成什么？两条支路怎样连接？电容器接在哪两点之间？→ 期望：各自串联成两条支路，两支路并联；电容器接在两条支路的中点之间（电桥）。
2. 问：右支路 $R_3=R_4$，它的中点电势在什么位置？左支路要满足什么条件，两个中点才等电势？→ 期望：在支路电压的正中间；$R_1=R_2=2\,\Omega$。
3. 问：$R_1=0$ 时，a 极板所在点的电势比 b 高还是低？$R_1$ 很大时呢？→ 期望：$R_1=0$ 时 a 点电势高，a 板带正电；$R_1>2\,\Omega$ 后 a 点电势低，带负电。A 对、B 错。
4. 问：所以电容器两板间电压怎么变？→ 期望：先减小到零（$R_1=2\,\Omega$ 时），再增大，D 错。
5. 问：外电阻的最小值和最大值各约多少？内阻 5 Ω 在这个范围内吗？输出功率怎么变？→ 期望：约 1.67 Ω 到 9.1 Ω，5 Ω 在其中，输出功率先增大后减小，C 对。选 AC。
常见错误：
- 选 B：把电势高低关系判断反了。追问：$R_1=0$ 时，a 点直接接在电源的哪一端？
- 选 D：没意识到中间经过电桥平衡点，电压会变为零。追问：$R_1=2\,\Omega$ 时，两个中点电势有什么关系？
- C 拿不准：追问：输出功率最大的条件是什么？外电阻的变化范围包含这个值吗？
总结句：电桥中电容器两端电势由两条支路各自的分压决定，两边电阻比相等时电桥平衡，电容器不带电。

## 10. 多选 · 平行板电容器与闭合电路结合

**题目**

〔多选〕（2025·浙江9＋1高中联盟期中）如图所示的电路中，两平行金属板A、B水平放置，极板长$l=80$ cm，两板间的距离$d=40$ cm，电源电动势$E=40$ V，内电阻$r=1$ Ω，电阻$R=15$ Ω，闭合开关S，待电路稳定后，将带负电的小球从B板左端且非常靠近B板的位置以初速度$v_{0}=4$ m/s水平向右射入两板间，该小球可视为质点。若小球带电荷量$q=1\times \mathrm{10}^{-2}$ C，质量为$m=2\times \mathrm{10}^{-2}$ kg，不考虑空气阻力，电路中电压表、电流表均是理想电表。若小球恰好从A板右边缘射出，$g$取10 m/$\mathrm{s}^{2}$，则（　　）

- A．滑动变阻器接入电路的阻值为24 Ω
- B．小球飞行的加速度大小为20 m/$\mathrm{s}^{2}$
- C．电压表的示数为16 V
- D．电源的输出功率为40 W

![第 10 题原题图。](assets/bx3/ks23-q10-stem1.png)

**答案：AB**

**解析**

![原题电路：平行板与滑动变阻器并联，V 测路端电压，A 测干路电流。](assets/bx3/ks23-q10-source.png)

![受力与轨迹示意：A 板电势高，电场向下；小球带负电，电场力和加速度向上。](assets/bx3/ks23-q10-forces.svg)

**第一步：先做力学，把板间电压解出来。**
小球水平方向匀速：

$$t=\frac{l}{v_{0}}=\frac{0.8}{4}\ \text{s}=0.2\ \text{s}$$

竖直方向从 B 板边缘匀加速上移 $d$：

$$d=\frac{1}{2}at^{2}\ \Rightarrow\ a=\frac{2d}{t^{2}}=\frac{2\times0.4}{0.2^{2}}\ \text{m/s}^{2}=20\ \text{m/s}^{2}$$

**B 正确。**

**第二步：牛顿第二定律求 $U_{AB}$。**
小球带负电、向上加速，电场力向上、重力向下：

$$q\frac{U_{AB}}{d}-mg=ma$$

$$1\times10^{-2}\times\frac{U_{AB}}{0.4}-2\times10^{-2}\times10=2\times10^{-2}\times20$$

$$0.025\,U_{AB}=0.4+0.2=0.6\ \Rightarrow\ U_{AB}=24\ \text{V}$$

**第三步：回到电路。**
平行板不通电流，它与滑动变阻器并联，所以滑动变阻器两端电压

$$U_{\text{滑}}=U_{AB}=24\ \text{V}$$

回路中（电源、$R$、滑动变阻器串联）的电流

$$I=\frac{E-U_{\text{滑}}}{R+r}=\frac{40-24}{15+1}\ \text{A}=1\ \text{A}$$

$$R_{\text{滑}}=\frac{U_{\text{滑}}}{I}=\frac{24}{1}\ \Omega=24\ \Omega$$

**A 正确。**

**第四步：C、D 两个电学量。**
电压表测的是路端电压：

$$U=E-Ir=40-1\times1\ \text{V}=39\ \text{V}$$

**C 错**（不是 $16\ \text{V}$；$16\ \text{V}$ 是 $R+r$ 上的总电压降，其中 $R$ 上为 $15\ \text{V}$、$r$ 上为 $1\ \text{V}$）。

$$P_{\text{出}}=UI=39\times1\ \text{W}=39\ \text{W}$$

**D 错。故选 AB。**

> 这类「电场 $+$ 电路」综合题的桥梁是**板间电压**：力学那边用 $U$ 算电场力，电路这边把 $U$ 当作某个元件的电压。做题顺序永远是「**力学定 $U$ $\to$ 电学算电流和电阻**」，反过来会卡住。

**问答脚本**

提问路线：
1. 问：小球在水平方向做什么运动？在板间飞行多长时间？→ 期望：匀速直线运动；$t=\dfrac{0.8}{4}=0.2\,\mathrm{s}$。
2. 问：小球从 B 板边缘到 A 板边缘，竖直方向移动了多少？加速度是多少？→ 期望：移动 $d=0.4\,\mathrm{m}$；$a=\dfrac{2d}{t^{2}}=20\,\mathrm{m/s^2}$，B 对。
3. 问：小球受哪些力？用牛顿第二定律求板间电压。→ 期望：向上的电场力、向下的重力；$q\dfrac{U}{d}-mg=ma$，$U_{AB}=24\,\mathrm{V}$。
4. 问：平行板和滑动变阻器什么关系？电路中的电流是多少？变阻器阻值多大？→ 期望：并联，变阻器电压 24 V；$I=\dfrac{40-24}{15+1}=1\,\mathrm{A}$；$R_{\text{滑}}=24\,\Omega$，A 对。
5. 问：电压表测什么？读数是多少？电源输出功率呢？→ 期望：路端电压 $40-1\times 1=39\,\mathrm{V}$，C 错；$P=39\,\mathrm{W}$，D 错。选 AB。
常见错误：
- 求加速度时忽略重力，直接用 $qE=ma$。追问：小球受到的力只有电场力吗？
- 选 C（16 V）：把 $R$ 和 $r$ 上的电压当成电压表读数。追问：电压表接在哪两点之间？
- 选 D：用 $EI=40\,\mathrm{W}$ 当输出功率。追问：输出功率要不要扣掉内阻上的损耗？
总结句：先用力学求出板间电压，再回到电路；平行板电容器不通电流，它的电压等于与之并联部分的电压。

## 11. 计算 · 含电容与电动机的电路

**题目**

（2025·浙江绍兴期末）如图所示，电源电动势$E=8.0$ V，内阻$r=1.0$ Ω，定值电阻$R_{1}=5.0$ Ω，$R_{2}=4.0$ Ω，电容器的电容$C=4\times \mathrm{10}^{-5}$ F，电动机线圈的电阻$R=1.0$ Ω，电压表为理想电表。

（1）闭合开关$\mathrm{S}_{1}$，断开开关$\mathrm{S}_{2}$，求稳定后电压表的示数$U$；

（2）同时闭合开关$\mathrm{S}_{1}$和$\mathrm{S}_{2}$，稳定后，电动机正常工作，流过电阻$R_{1}$的电流$I_{1}=0.6$ A，

①求电容器的带电荷量$q$；

②求电动机的输出功率$P$。

![第 11 题原题图。](assets/bx3/ks23-q11-stem1.png)

**答案：（1）$U=3.2\ \text{V}$　（2）① $q=1.6\times10^{-4}\ \text{C}$　② $P=1.04\ \text{W}$**

**解析**

![原题电路：R₂ 与 C、V 两端的节点相同；S₂ 闭合后电动机才接入。](assets/bx3/ks23-q11-source.png)

![两种稳态的等效电路：S₂ 断开时 R₁、R₂ 串联；S₂ 闭合时 R₁ 与电动机并联，再与 R₂ 串联。](assets/bx3/ks23-q11-states.svg)

**（1）$S_{1}$ 闭合、$S_{2}$ 断开时。**
电动机支路断开，电容器支路不通电流，回路是 $E$、$r$、$R_{1}$、$R_{2}$ 串联。电压表测 $R_{2}$ 两端电压：

$$U=\frac{R_{2}}{R_{1}+R_{2}+r}E=\frac{4.0}{5.0+4.0+1.0}\times8.0\ \text{V}=3.2\ \text{V}$$

**（2）① 两个开关都闭合时的电容器电荷量。**
此时电动机与 $R_{1}$ **并联**，这一并联组合再与 $R_{2}$、$r$ 串联。已知流过 $R_{1}$ 的电流 $I_{1}=0.6\ \text{A}$：

$$U_{1}=I_{1}R_{1}=0.6\times5.0\ \text{V}=3.0\ \text{V}$$

这也是电动机两端的电压。剩下的电压由 $R_{2}$ 和 $r$ 分担，故干路电流

$$I=\frac{E-U_{1}}{R_{2}+r}=\frac{8.0-3.0}{4.0+1.0}\ \text{A}=1.0\ \text{A}$$

电容器与 $R_{2}$ 并联：

$$U_{2}=IR_{2}=1.0\times4.0\ \text{V}=4.0\ \text{V}$$

$$q=CU_{2}=4\times10^{-5}\times4.0\ \text{C}=1.6\times10^{-4}\ \text{C}$$

**② 电动机的输出功率。**
干路电流在并联处分流，流过电动机的电流

$$I_{2}=I-I_{1}=1.0-0.6\ \text{A}=0.4\ \text{A}$$

电动机是非纯电阻元件，输入功率减去线圈发热就是输出：

$$P=U_{1}I_{2}-I_{2}^{2}R=3.0\times0.4-0.4^{2}\times1.0\ \text{W}=1.2-0.16\ \text{W}=1.04\ \text{W}$$

> 这道题把本专题的三条主线都串了起来：**电容器支路不通电（先拆掉求电流）、并联分流（$I_2=I-I_1$）、非纯电阻元件的能量分配（输出 $=UI-I^{2}R$）**。注意电动机的电压要取它自己那一支的 $U_{1}=3.0\ \text{V}$，别误用路端电压。

**问答脚本**

提问路线（分步推进）：
1. 问：第（1）问，$S_2$ 断开时，电动机支路和电容器支路有电流吗？电路是怎样的？→ 期望：都没有电流；$E$、$r$、$R_1$、$R_2$ 串联。
2. 问：电压表测哪个电阻的电压？读数是多少？→ 期望：测 $R_2$；$U=\dfrac{4.0}{10.0}\times 8.0=3.2\,\mathrm{V}$。
3. 问：第（2）问，两个开关都闭合后，电动机和 $R_1$ 是什么关系？$R_1$ 两端电压是多少？→ 期望：并联；$U_1=0.6\times 5.0=3.0\,\mathrm{V}$，这也是电动机电压。
4. 问：剩下的电压由谁分担？干路电流是多少？→ 期望：由 $R_2$ 和 $r$ 分担；$I=\dfrac{8.0-3.0}{4.0+1.0}=1.0\,\mathrm{A}$。
5. 问：电容器并在哪个电阻上？电荷量是多少？→ 期望：并在 $R_2$ 上，$U_2=4.0\,\mathrm{V}$，$q=CU_2=1.6\times 10^{-4}\,\mathrm{C}$。
6. 问：流过电动机的电流是多少？电动机输出功率怎么求？→ 期望：$I_2=1.0-0.6=0.4\,\mathrm{A}$；$P=U_1I_2-I_2^{2}R=1.2-0.16=1.04\,\mathrm{W}$。
常见错误：
- 用欧姆定律 $I=\dfrac{U_1}{R}$ 求电动机电流（得 3 A）。追问：电动机在转动时是纯电阻吗？能用 $U=IR$ 吗？
- 电动机输出功率写成 $U_1I_2$。追问：线圈电阻发热的功率要不要扣掉？
- 第（1）问把 $r$ 漏掉。追问：电源有内阻，串联回路的总电阻是多少？
总结句：先确定开关状态下的电路结构，电容器看它并在谁两端；电动机电流用分流关系求，输出功率等于输入减去发热。
