# k25a · 问答脚本

## 1
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：机器人在斜坡上不下滑，沿坡与法向重力分量各是什么？ → 期望：mgsinθ与mgcosθ。
2. 问：最大摩擦至少满足什么条件？ → 期望：μmgcosθ≥mgsinθ。
3. 问：最陡30°时μ至少多少？ → 期望：tan30°=√3/3，选B。
常见错误：
- 用sin30°直接当μ。追问：摩擦上限乘的是重力还是法向压力？
总结句：斜面临界稳定条件为μ≥tanθ。

## 2
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：两条对称绳的张力相同吗？水平分量怎样？ → 期望：相同，水平抵消。
2. 问：每条绳与竖直成60°，竖直平衡如何写？ → 期望：2Tcos60°=mg。
3. 问：T是多少？ → 期望：mg，选B。
常见错误：
- 两条绳就各分mg/2。追问：各绳拉力是否都竖直？
总结句：重量由两绳的竖直分量分担。

## 3
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：先只看货船S，两绳与行进方向夹30°，张力T如何满足平衡？ → 期望：2Tcos30°=f，T=f/√3。
2. 问：对一艘拖船，发动机动力需要平衡哪些力？ → 期望：水阻f与缆绳拉力T的合力。
3. 问：这两个力夹30°，合成大小是多少？ → 期望：√(f²+T²+2fTcos30°)=√21 f/3，选B。
常见错误：
- 把两阻力直接作标量相加。追问：水阻与缆绳张力方向是否相同？
总结句：先求货船绳张力，再隔离拖船作矢量合成。

## 4
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：无风时巨石作用力F1如何平衡重力？ → 期望：竖直向上，F1=mg。
2. 问：有水平风力F而仍静止，巨石总作用要平衡哪两个力？ → 期望：重力与风力的合力。
3. 问：F2大小与方向怎样，哪项正确？ → 期望：√((mg)²+F²)>F1，斜向上，选A。
常见错误：
- 压力仍只等于mg。追问：新增的水平风力由谁平衡？
总结句：接触总作用可随其他外力改变，并不总等于重力。

## 5
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：足球受重力、墙支持和绳拉力，绳与竖直夹θ，竖直平衡怎样？ → 期望：Tcosθ=G。
2. 问：水平方向怎样？ → 期望：N=Tsinθ。
3. 问：由0<θ<90°，T与G、N各如何比较？ → 期望：T>G、T>N，选C。
常见错误：
- T=G。追问：平衡G的是整个斜拉力还是它的竖直分量？
总结句：斜绳的张力大于其竖直分量，也大于水平分量。

## 6
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：球与杆接触的法线过哪里？墙支持方向是什么？ → 期望：过球心；墙支持水平。
2. 问：接触点距墙1.8R，几何关系给sinα多少、cosα多少？ → 期望：0.8与0.6。
3. 问：杆支持的竖直分量平衡mg，压力多大？ → 期望：Ncosα=mg，N=5mg/3，球对杆压力等大，选D。
常见错误：
- 把sinα直接用于竖直投影。追问：α是与竖直还是水平的角？
总结句：先由接触几何求法线方向，再求支持与反作用压力。
