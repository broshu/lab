# k25 · 问答脚本

## 1
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：隔离a，它受向右F而静止，b给的摩擦如何？ → 期望：F向左。
2. 问：把a、b整体看待，两外推力合力是多少？ → 期望：零。
3. 问：地面还需提供摩擦吗？哪些项正确？ → 期望：不需要，摩擦零，选AD。
常见错误：
- 把上层的摩擦直接传给地面。追问：整体上两个外推力是否已经抵消？
总结句：内部接触力用隔离法，地面外力用整体法。

## 2
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：地面光滑，若墙给整体水平弹力，有力能平衡它吗？ → 期望：没有，墙弹力为零，墙摩擦也为零。
2. 问：隔离A，与B接触处需要哪些力？ → 期望：支持与静摩擦，加重力共3个。
3. 问：隔离B再数力，总共几个？ → 期望：重力、A压力与摩擦、地面支持，共4个，选B。
常见错误：
- 墙粗糙就必有摩擦。追问：墙与A是否存在挤压？
总结句：先用整体平衡排除墙作用，再数各物体接触力。

## 3
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：每个50 g配重使c、d中张力是多少？ → 期望：0.5 N。
2. 问：将两球整体，c、d等大反向，a需承担多少？ → 期望：两球总重1 N。
3. 问：隔离A，b的水平竖直分量各多少？合成得多大？ → 期望：0.5cos30°与0.5-0.5sin30°，合成0.5 N，选D。
常见错误：
- 将c、d两拉力的竖直分量相加。追问：两条拉力在图上朝同向还是反向？
总结句：先整体消去内力，再隔离求连接绳张力。

## 4
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：整体匀速，地面支持力和滑动摩擦力各是多少？ → 期望：(M+m)g、μ(M+m)g。
2. 问：小块相对斜面静止，它的摩擦力是什么类型？ → 期望：静摩擦力。
3. 问：小块支持与摩擦各怎样由平衡求？ → 期望：mgcosθ、mgsinθ，选AB。
常见错误：
- 给小块静摩擦套μN。追问：小块与斜面是否相对滑动？
总结句：整体与内部接触的摩擦类型可以不同。

## 5
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：光滑钩子上同一绳的张力由哪个物体确定？ → 期望：由悬物确定，始终mg。
2. 问：两段绳夹角θ减小时，对钩合力2mgcos(θ/2)怎样？ → 期望：增大。
3. 问：轻杆平衡，手作用力大小与方向如何？ → 期望：等大反向于绳合力，增大而非始终水平，选C。
常见错误：
- 把手移动方向当力方向。追问：轻杆受两个力时，它们应怎样平衡？
总结句：位移方向不决定力方向，绳张力固定而合力可变。

## 6
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：灯水平平衡时，两绳拉力怎样关联？ → 期望：F1cos45°=F2cos60°，F1=(√2/2)F2。
2. 问：竖直平衡联立后，两力与G怎样比较？ → 期望：F2=(√3-1)G，F1约0.52G，均小于G，选B。
3. 问：换绳仅方向平行就能保持灯姿态吗？ → 期望：不能，还要保持作用线；CB改方向，CD改变作用线。
常见错误：
- 只管合力不管物体转动。追问：灯是质点还是有尺寸的物体，平移作用线会怎样？
总结句：求大小用平衡，保持有尺寸物体姿态还需考虑作用线。

## 7
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：两金属杆总支持作用与重力是什么关系？ → 期望：始终等大反向，合力mg不变。
2. 问：半径R增大，sinθ=(d/2)/(r+R)和θ怎样？ → 期望：都减小，支持力夹角减小。
3. 问：N=mg/(2cosθ)怎样变？ → 期望：减小，选D。
常见错误：
- 香肠更粗所以支持更大。追问：质量不变，支持力方向更竖直后需要更大大小吗？
总结句：总支持不变，方向变化可使每个支持力改变。

## 8
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：B点的力三角形与ABC几何三角形能否相似？ → 期望：能，G/AC=N/AB=T/BC。
2. 问：AC与AB不变，杆力N怎样？BC缩短时T怎样？ → 期望：N不变，T减小。
3. 问：工人水平绳力由地面摩擦平衡，摩擦怎样？ → 期望：减小，选BC。
常见错误：
- 杆转动就认为杆力变。追问：相似比例中决定杆力的是哪两条固定边？
总结句：用力与几何的相似三角形，把动态变化转为边长变化。

## 9
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：字典静止，沿斜面与法向的两个力怎样写？ → 期望：f=mgsinθ，N=mgcosθ。
2. 问：倾角增加时，f与N分别怎样？ → 期望：f增大，N减小。
3. 问：最大倾角满足什么，μ=√3/3得几度？ → 期望：tanθ=μ，30°，选AC。
常见错误：
- 静摩擦取μmgcosθ随角减小。追问：未到临界时静摩擦是否等于最大值？
总结句：实际静摩擦由平衡求，临界角才使用摩擦上限。

## 10
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：哪个力大小方向固定，哪个力仅方向固定？ → 期望：mg固定，OM方向固定。
2. 问：ON从水平转到竖直，矢量三角形中哪时ON张力最小？ → 期望：ON垂直OM时；OM张力持续减小至零。
3. 问：起末ON张力各是多少，能断言末态最大吗？ → 期望：mg tanθ与mg，不能，取决于θ，选AB。
常见错误：
- 两绳张力同时最小。追问：ON最小时OM是否已到最后零张力状态？
总结句：固定一个力的方向，变向力最小时常与其垂直。

## 11
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：B固定而A向右滑，B相对A向哪？所受摩擦多大、朝哪？ → 期望：向左相对滑，受2 N向右摩擦。
2. 问：A受B反作用摩擦和地面摩擦，各多大、朝哪？ → 期望：2 N与0.2×30=6 N，都向左。
3. 问：匀速抽出所需拉力至少多少？ → 期望：8 N。
常见错误：
- 地面压力只用A的20 N。追问：B的10 N重量通过谁传给地面？
总结句：分别核对两个接触面的压力与滑动方向。

## 12
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：两球整体的水平与竖直平衡怎样列？ → 期望：TABsin30°=TCDsin60°；TABcos30°+TCDcos60°=2G。
2. 问：联立两外侧绳的张力是多少？ → 期望：TAB=√3G，TCD=G。
3. 问：隔离C，BC绳的水平和竖直分量之比是多少？θ多大？ → 期望：(Gsin60°)/(G-Gcos60°)=√3，θ=60°。
常见错误：
- 整体受力图再放BC内力。追问：BC对两球的作用在整体中是否相互抵消？
总结句：整体求外绳，隔离求中间绳方向。
