# 选修二问答脚本

选择性必修第二册（三维设计）作业本。正式上线内容在 `content/xx2/topics/`，章节顺序见 `content/xx2/chapters.txt`（按教参目录）。

每题包含：题目（大屏显示）、答案、解析（答案页显示）、问答脚本（只交给大屏 AI）。

## 问答脚本的写法

每题一个 `## 题号` 小节，依次写：

- **本题考点 / 已知**：让 AI 不看图也知道题目条件（图中方向、角度、哪个点在哪）；
- **提问路线**：`1. 问：… → 期望：…`，每次只问一个问题，复合题按小问顺序推进；“期望”写到具体结论或数值，AI 用它判断对错；
- **选项要点**（选择题需要时）：学生追问某个选项时 AI 的依据；
- **常见错误**：每条“错误想法 + 追问”，学生说出错误想法时 AI 用追问引导；
- **总结句**：学生自己总结后 AI 用来点评。

改脚本后运行：

```
python3 tutor/guides/insert_guides.py xx2/k01 xx2/k02 ...
python3 tutor/build.py
```

## 新增一章的流程

1. `python3 tutor/tools/docx_to_topics.py xx2 k11=教师用书/….docx k12=…` 生成草稿（题目、答案、原书解析、配图）；
2. 补每题小标题（`## 题号. 题型 · 小标题`），核对答案和解析，删掉混进来的说明文字和多余配图；
3. 写 `guides/xx2/<id>.md`，插入问答脚本；
4. 需要动画的题在 `tutor/tools/animations/anim.py` 里加一个函数，生成 `assets/xx2/<id>-qNN-anim.svg`，在解析开头插入 `![动画演示：…](assets/xx2/…-anim.svg)`；
5. `python3 tutor/build.py`。
