# 选修二 k05 · 问答脚本

## 1
本题考点：带电粒子在匀强磁场中的三种运动形式（$v\parallel B$、$v\perp B$、斜交）；洛伦兹力不做功。
提问路线（每次只问一个问题）：
1. 问：质子速度方向与磁场平行时，受洛伦兹力吗？做什么运动？ → 期望：不受力，做匀速直线运动，C 可能。
2. 问：速度与磁场垂直时做什么运动？ → 期望：匀速圆周运动，洛伦兹力提供向心力。
3. 问：速度与磁场斜交时呢？所以 D“只能做匀速圆周运动”对吗？ → 期望：做等距螺旋线运动，D 错。
4. 问：洛伦兹力大小不变、方向总与速度垂直，能产生恒定加速度（匀变速、类平抛）吗？ → 期望：不能，洛伦兹力方向随速度改变，不是恒力，A、B 错。选 C。
常见错误：
- 认为质子在磁场中一定受力。追问：$F=qvB\sin\theta$，$\theta=0$ 时 $F$ 等于多少？
- 认为可能做类平抛。追问：类平抛需要恒力，洛伦兹力的方向会变吗？
总结句：匀强磁场中：$v\parallel B$ 匀速直线，$v\perp B$ 匀速圆周，斜交为螺旋线；洛伦兹力不是恒力，不做功。

## 2
本题考点：两根平行反向电流在中线处的磁场；洛伦兹力方向；洛伦兹力不做功。
已知：图 1 中上导线电流向右、下导线电流向左，粒子沿中线向右；图 2 是截面图，上方电流垂直纸面向外、下方垂直纸面向里，粒子沿中线向右。
提问路线：
1. 问：图 1 中，上方向右的电流在它下方产生的磁场朝哪？下方向左的电流在它上方产生的磁场朝哪？中线上合磁场朝哪？ → 期望：都垂直纸面向里，合磁场向里。
2. 问：正粒子向右运动，磁场向里，洛伦兹力朝哪？速度大小变吗？ → 期望：向上，向上偏转；洛伦兹力不做功，速率不变。A 错，C 对。
3. 问：图 2 中，上方垂直纸面向外的电流和下方向里的电流，在中线上产生的磁场分别朝哪？合磁场朝哪？ → 期望：都水平向右，合磁场向右。
4. 问：粒子速度向右、磁场也向右，受洛伦兹力吗？做什么运动？ → 期望：速度与磁场平行，不受力，匀速直线运动，B、D 错。选 C。
常见错误：
- 认为图 1 中两导线的磁场在中线上抵消。追问：电流反向，在中线上（一个在上、一个在下）的磁场方向是相同还是相反？
- 认为图 2 中粒子速度会变化。追问：粒子受力吗？没有力速度会变吗？
总结句：先用安培定则找粒子所在处的合磁场，再判断速度与磁场的夹角；洛伦兹力只改变方向不改变速率。

## 3
本题考点：洛伦兹力不做功；半径公式 $r=\dfrac{mv}{qB}$；非匀强磁场中半径随 $B$ 变化。
已知：图乙磁场越靠右越强，粒子垂直磁场运动。
提问路线：
1. 问：洛伦兹力方向与速度方向是什么关系？磁场可能对粒子做功吗？ → 期望：始终垂直，一定不做功，B 对，A 错。
2. 问：粒子做圆周运动的半径公式是什么？ → 期望：$qvB=m\dfrac{v^2}{r}$，$r=\dfrac{mv}{qB}$。
3. 问：粒子从右侧到左侧，速率变吗？$B$ 怎样变？半径怎样变？ → 期望：速率不变，$B$ 变小，半径增大，C 对，D 错。选 BC。
常见错误：
- 认为磁场变化时会做功。追问：粒子受的磁场力是洛伦兹力，它始终与速度垂直吗？
- 半径变化判反。追问：$r$ 与 $B$ 成正比还是反比？
总结句：洛伦兹力永不做功，速率不变；$r=\dfrac{mv}{qB}$，磁场越弱半径越大。

## 4
本题考点：直线电流磁场的方向与强弱；左手定则（电子）；半径与 $B$ 的关系。
已知：导线中电流向左，电子在导线正下方，初速度向左（与电流同向）；路径 $a$ 向下弯离导线，路径 $b$ 向上弯向导线。
提问路线：
1. 问：电流向左，导线下方的磁场朝哪？离导线越远磁场怎样变？ → 期望：垂直纸面向外；越远越弱。
2. 问：电子向左运动，磁场向外，用左手定则（电子要反向），电子受力朝哪？走哪条路径？ → 期望：受力向下，向下弯，沿路径 $a$。
3. 问：电子越走离导线越远，$B$ 怎样变？由 $r=\dfrac{mv}{eB}$，半径怎样变？ → 期望：$B$ 减小，$r$ 越来越大，选 B。
常见错误：
- 认为轨迹是圆（选 A）。追问：电子所在处的磁场大小处处相同吗？
- 受力方向判反走 $b$。追问：电子带负电，左手定则中四指应指向哪？
总结句：非匀强磁场中半径随 $B$ 变化：$B$ 越小半径越大；电子受力方向与正电荷相反。

## 5
本题考点：已知入射方向和出射点找圆心；勾股定理求半径；$r=\dfrac{mv}{qB}$ 求比荷。
已知：粒子从 $P_1(0,a)$ 沿 $+x$ 射入，从 $P_2(2a,0)$ 射出，磁场向外，带正电。
提问路线：
1. 问：粒子在 $P_1$ 速度沿 $+x$，圆心一定在哪条线上？ → 期望：在过 $P_1$ 且垂直速度的直线上，即 $y$ 轴上（$P_1$ 下方）。
2. 问：设半径为 $R$，圆心到 $P_2$ 的距离也是 $R$。用 $O'$、$O$、$P_2$ 组成的直角三角形列方程。 → 期望：$(R-a)^2+(2a)^2=R^2$。
3. 问：解出 $R$。 → 期望：$R=\dfrac{5a}{2}$。
4. 问：由 $qv_0B=m\dfrac{v_0^2}{R}$ 求比荷。 → 期望：$\dfrac{q}{m}=\dfrac{v_0}{BR}=\dfrac{2v_0}{5aB}$，选 B。
常见错误：
- 把圆心放在 $O$ 点或 $P_1P_2$ 中点。追问：圆心到入射点的连线必须与入射速度是什么关系？
- 方程写成 $(R-a)^2+a^2=R^2$。追问：$P_2$ 的横坐标是多少？
总结句：找圆心：入射点处作速度的垂线，圆心在垂线上；再用“圆心到入射点、出射点距离都等于半径”列勾股方程。

## 6
本题考点：$r=\dfrac{mv}{qB}$（半径与速率成正比）；周期 $T=\dfrac{2\pi m}{qB}$ 与速率无关；时间 $t=\dfrac{\theta}{2\pi}T$ 由圆心角决定。
已知：三个粒子质量、电荷量相同，沿 $AO$ 射入圆形磁场，a 偏转最多（轨迹最弯），c 偏转最少。
提问路线：
1. 问：三条轨迹中哪个半径最大、哪个最小？ → 期望：c 最直，半径最大；a 最弯，半径最小。
2. 问：半径与速率什么关系？谁速率最大？谁受洛伦兹力最小？ → 期望：$v=\dfrac{qBr}{m}$，c 速率最大，a 速率最小、受力最小；A、B 错。
3. 问：周期与速率有关吗？三个粒子周期什么关系？ → 期望：$T=\dfrac{2\pi m}{qB}$，相等，D 错。
4. 问：运动时间由什么决定？谁转过的圆心角最大？ → 期望：由圆心角决定，a 转过的圆心角（等于速度偏转角）最大，时间最长，选 C。
常见错误：
- 认为轨迹越弯速度越大。追问：$r=\dfrac{mv}{qB}$，半径小说明速度大还是小？
- 认为速度大运动时间短，所以 c 时间最短就等于“a 最长是因为它慢”。追问：周期和速度有关吗？时间到底由什么决定？
- 认为路程长的时间长。追问：c 的弧长最长吗？时间看弧长还是看圆心角？
总结句：同种粒子在同一磁场中周期相同，运动时间只看圆心角（等于速度偏转角）。

## 7
本题考点：由轨迹几何关系得半径比；动能与速度的关系；$B=\dfrac{mv}{qr}$。
已知：上方轨迹以 $PQ$ 为直径，下方轨迹以 $QO$ 为直径，$O$ 为 $PQ$ 中点；穿过铝板动能减半。
提问路线：
1. 问：上方和下方轨迹都是半圆，它们的直径分别是哪段？半径之比是多少？ → 期望：上方直径 $PQ$，下方直径 $QO=\dfrac12PQ$，$r_1:r_2=2:1$。
2. 问：动能减为一半，速度变为原来的多少倍？ → 期望：$v_2=\dfrac{v_1}{\sqrt2}$。
3. 问：由 $qvB=m\dfrac{v^2}{r}$，$B$ 用 $v$、$r$ 怎样表示？ → 期望：$B=\dfrac{mv}{qr}$。
4. 问：$\dfrac{B_1}{B_2}$ 等于多少？ → 期望：$\dfrac{v_1}{v_2}\cdot\dfrac{r_2}{r_1}=\sqrt2\times\dfrac12=\dfrac{\sqrt2}{2}$，选 D。
常见错误：
- 认为动能减半速度也减半。追问：动能与速度是一次方关系还是平方关系？
- 比值倒过来得 $\sqrt2:1$。追问：$B$ 与 $r$ 成正比还是反比？上方半径大，上方 $B$ 应更大还是更小？
总结句：同一粒子穿过不同区域：先由几何得半径比，再由能量得速度比，最后用 $B=\dfrac{mv}{qr}$ 求比值。

## 8
本题考点：垂直边界射入、垂直边界射出时轨迹为半圆，直径等于入射点到出射点的距离；临界值（最大、最小半径）。
已知：下方通道长 $2a$（入口），上方通道长 $a$（出口），两通道近端相距 $b$；粒子垂直 $CD$ 射入，从上方通道射出。
提问路线：
1. 问：粒子垂直边界射入，又从同一边界射出，轨迹是什么形状？入射点和出射点的距离等于什么？ → 期望：半圆，距离等于直径 $2R$。
2. 问：入射点和出射点相距最远是多少？对应的最大半径呢？ → 期望：从入口最下端到出口最上端，距离 $2a+b+a=3a+b$，$R_{\max}=\dfrac{3a+b}{2}$。
3. 问：相距最近是多少？最小半径呢？ → 期望：两近端相距 $b$，$R_{\min}=\dfrac{b}{2}$。
4. 问：由 $v=\dfrac{qBR}{m}$，速度差是多少？ → 期望：$\Delta v=\dfrac{qB}{m}(R_{\max}-R_{\min})=\dfrac{3qBa}{2m}$，选 A。
常见错误：
- 最大距离只算 $2a+b$。追问：出射点最远可以到出口通道的哪一端？
- 把距离当成半径。追问：半圆轨迹的入射点到出射点，是半径还是直径？
总结句：同边界垂直进出时轨迹是半圆，弦长 = 直径；找最大最小距离就得到半径范围。

## 9
本题考点：左手定则判断电性；沿半径射入圆形（正多边形）区域的几何；周期相同时时间与圆心角成正比。
已知：正六边形边长 $L$，磁场向里；$a$ 从 $A$ 沿 $AO$ 射入、从 $B$ 射出；$b$ 从 $D$ 沿 $DO$ 射入、从 $F$ 射出；比荷相同。
提问路线：
1. 问：$a$ 向右射入后向下偏到 $B$，$b$ 向左射入后向上偏到 $F$，分别用左手定则判断电性。 → 期望：两者都带负电，A 错。
2. 问：$a$ 粒子速度偏转了多少度？由几何关系它的半径是多少？ → 期望：在 $A$ 点速度沿 $AO$，在 $B$ 点速度方向偏转 $120^\circ$；$r_a=\dfrac{L}{2\cos30^\circ}=\dfrac{\sqrt3}{3}L$，B 错。
3. 问：$b$ 粒子偏转多少度？半径是多少？ → 期望：偏转 $60^\circ$；$r_b=2L\cos30^\circ=\sqrt3L$。
4. 问：比荷相同时速度之比等于什么？ → 期望：$v_1:v_2=r_a:r_b=1:3$，C 对。
5. 问：两者周期相同，时间之比等于什么？ → 期望：$t_a:t_b=120^\circ:60^\circ=2:1$，D 错。选 C。
常见错误：
- 把 $a$ 判成正电。追问：速度向右、受力指向下方圆心，负电荷用左手定则时四指朝哪？
- 时间比用速度比或路程比算。追问：比荷相同，周期相同吗？时间由什么决定？
总结句：沿半径方向射入，必沿半径方向射出；同种比荷的粒子周期相同，时间之比等于圆心角之比。

## 10
本题考点：轨迹几何（四分之一圆、半圆）；半径与速率成正比；时间与圆心角；加速度 $a=\dfrac{evB}{m}$。
已知：正方形容器，电子从 $A$ 孔垂直磁场射入，从 $C$ 孔射出的轨迹为四分之一圆，从 $D$ 孔射出的轨迹为半圆，$R_C=2R_D$。
提问路线：
1. 问：从 $C$ 射出和从 $D$ 射出的电子，轨迹各是几分之几圆？半径之比是多少？ → 期望：$C$ 为四分之一圆，$D$ 为半圆；$R_C=2R_D$。
2. 问：半径与速率什么关系？速率之比？ → 期望：$R=\dfrac{mv}{eB}$，$v_C:v_D=2:1$，A 对。
3. 问：周期相同，时间之比由什么决定？ → 期望：由圆心角，$90^\circ:180^\circ$，$t_C:t_D=1:2$，B 对。
4. 问：加速度 $a=\dfrac{F}{m}=\dfrac{evB}{m}$，与速率什么关系？之比多少？ → 期望：与速率成正比，$a_C:a_D=2:1$，D 对，C 错。选 ABD。
常见错误：
- 认为速度大的时间长。追问：周期与速度有关吗？
- 加速度比用 $\sqrt2:1$。追问：加速度由什么力产生？它与 $v$ 是几次方关系？
总结句：同种粒子：$r\propto v$，$a\propto v$，周期相同，时间 $\propto$ 圆心角。

## 11
本题考点：洛伦兹力与支持力不做功（机械能守恒）；沿杆方向只有重力分力；洛伦兹力随速度变化对弹力的影响。
已知：光滑绝缘杆，倾角 $\theta$，小球带 $-q$，以 $v_0$ 沿杆向上运动后又回到出发点。
提问路线：
1. 问：小球受哪些力？哪些力做功？机械能怎样变？ → 期望：重力、洛伦兹力、弹力；洛伦兹力和弹力都垂直于杆（速度），不做功，只有重力做功，机械能守恒，A 错。
2. 问：沿杆方向的合力是多少？上滑和下滑加速度大小相同吗？ → 期望：都是 $mg\sin\theta$，加速度都是 $g\sin\theta$，上滑时间等于下滑时间，B 错。
3. 问：上滑的最大位移是多少？ → 期望：$x=\dfrac{v_0^2}{2g\sin\theta}$，C 对。
4. 问：下滑时洛伦兹力朝哪、怎样变？如果它一直小于 $mg\cos\theta$，弹力怎样变？ → 期望：洛伦兹力垂直杆向上，随速度增大而增大；若始终小于 $mg\cos\theta$，弹力一直减小，不一定先减小后增大，D 错。选 C。
常见错误：
- 认为洛伦兹力会让小球“飘起来”导致上下时间不同。追问：洛伦兹力有沿杆方向的分量吗？
- 认为 D“一定”成立。追问：题目给了 $v_0$ 足够大使 $qv_0B>mg\cos\theta$ 吗？“一定”的说法有没有反例？
总结句：光滑杆上洛伦兹力与弹力都垂直于杆，沿杆只有重力分力，运动规律和没有磁场时一样；弹力变化要看 $qvB$ 与 $mg\cos\theta$ 的大小关系。

## 12
本题考点：由出射速度方向和几何条件找圆心；勾股定理求半径；圆心角与时间；离开磁场后匀速直线运动。
已知：磁场只在第一象限，向外；粒子从 $A\left(0,\dfrac{\sqrt3}{2}L\right)$ 射入，最终到达第四象限 $B\left(\dfrac32L,-L\right)$，在 $B$ 点速度大小 $v$、方向沿 $-y$。
提问路线：
1. 问：粒子在第四象限有没有磁场？从 $x$ 轴到 $B$ 点做什么运动？在哪里离开磁场？ → 期望：没有磁场，做匀速直线运动（竖直向下）；在 $x$ 轴上 $\left(\dfrac32L,0\right)$ 离开磁场，此时速度竖直向下。
2. 问：离开磁场时速度竖直向下，圆心在哪条线上？设半径为 $r$，圆心坐标是什么？ → 期望：圆心在 $x$ 轴上，坐标 $\left(\dfrac32L-r,0\right)$。
3. 问：圆心到 $A$ 的距离也等于 $r$，列方程求 $r$。 → 期望：$r^2=\left(\dfrac{\sqrt3}{2}L\right)^2+\left(\dfrac32L-r\right)^2$，$r=L$。
4. 问：由 $qvB=m\dfrac{v^2}{r}$ 求 $B$。 → 期望：$B=\dfrac{mv}{qL}$。
5. 问：（2）圆心在 $\left(\dfrac L2,0\right)$，粒子在磁场中转过的圆心角是多少？ → 期望：由 $\sin(\pi-\theta)=\dfrac{\sqrt3}{2}$，结合图中轨迹，$\theta=\dfrac{2\pi}{3}$。
6. 问：总时间等于磁场中的时间加上第四象限匀速运动的时间，各是多少？ → 期望：$t_1=\dfrac{\theta r}{v}=\dfrac{2\pi L}{3v}$，$t_2=\dfrac{L}{v}$，$t=\dfrac{(2\pi+3)L}{3v}$。
常见错误：
- 以为 $B$ 点在磁场中，直接把 $B$ 点当作出射点找圆心。追问：磁场分布在哪个象限？$B$ 点在第几象限？
- 圆心角取 $\dfrac{\pi}{3}$。追问：圆心在 $\left(\dfrac L2,0\right)$，$A$ 点相对圆心在哪个方向？从 $A$ 转到 $x$ 轴上的出射点转了多少度？
- 漏掉第四象限的匀速运动时间。追问：从出射点到 $B$ 点还要走多远？
总结句：带电粒子出入磁场时，要分清磁场内（圆周）和磁场外（直线）两段；圆心在速度方向的垂线上，时间 $=\dfrac{\theta}{2\pi}T$ 加上直线段时间。
