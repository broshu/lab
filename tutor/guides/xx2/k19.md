# 选修二 k19 · 问答脚本

## 1
本题考点：电磁阻尼；楞次定律“增缩减扩”；相对速度为零时无感应电流；能量守恒（最终平衡位置相同）。
已知：磁铁 N 极向下，从弹簧原长处由静止释放；线圈固定在磁铁正下方桌面上。
提问路线（每次只问一个问题）：
1. 问：有线圈时，磁铁上下运动会让线圈中产生电流吗？这个电流对磁铁起什么作用？停下所用时间和没有线圈时一样吗？ → 期望：产生感应电流，阻碍磁铁运动（电磁阻尼），停得更快，A 错。
2. 问：磁铁靠近线圈时，线圈中磁通量增大还是减小？线圈有扩张还是收缩的趋势？ → 期望：磁通量增大，线圈有收缩趋势（增缩减扩），B 错。
3. 问：磁铁离线圈最近时，它的速度是多少？此时感应电流和安培力是多少？ → 期望：在最低点速度为零，磁通量变化率为零，感应电流为零，安培力为零，C 错。
4. 问：磁铁最终停在哪里？有无线圈时最终弹簧伸长量一样吗？损失的机械能等于什么？ → 期望：都停在弹力等于重力的平衡位置，伸长量相同；损失的机械能 = 减少的重力势能 − 弹簧弹性势能，两次相同，D 对。选 D。
常见错误：
- 认为离线圈最近时安培力最大。追问：安培力来源于感应电流，感应电流取决于磁通量的“变化快慢”，此时磁铁在动吗？
- 认为有线圈损失的机械能更多。追问：两次最终停在同一位置吗？机械能的损失只看初末状态还是看过程？
总结句：电磁阻尼让振动更快停下，但不改变最终的平衡位置；损失的机械能只由初末状态决定。

## 2
本题考点：楞次定律；感应电流方向与电势高低（线圈作为电源，内部电流从低电势流向高电势）；由电压正负反推磁极。
已知：薄膜在空心圆管右端，呼气时薄膜向右（远离线圈），吸气时向左（靠近线圈）；$U$ 为正表示 $b$ 点电势高于 $a$ 点；图 2 中 $P$ 点电压为正，$Q$ 点为负。
提问路线：
1. 问：若薄膜 N 极在右侧，S 极就朝向线圈，线圈中的磁场朝哪个方向？ → 期望：磁感线进入 S 极，线圈中磁场向右。
2. 问：吸气时薄膜向左靠近线圈，向右的磁通量增大还是减小？感应电流的磁场朝哪？ → 期望：增大，感应磁场向左。
3. 问：感应磁场向左，结合绕向，线圈中电流从 $a$ 到 $b$ 还是从 $b$ 到 $a$？线圈相当于电源，哪端电势高？ → 期望：电流由 $a$ 到 $b$，电源内部电流流向高电势端，$b$ 点电势高，A 错 B 对。
4. 问：$P$ 点电压为正，即 $b$ 点电势高，感应电流和感应磁场方向如何？若此时是呼气（薄膜远离、磁通量减小），原磁场应朝哪？哪个极在右侧？ → 期望：电流由 $a$ 到 $b$，感应磁场向左；磁通量减小时感应磁场与原磁场同向，原磁场向左，说明 N 极朝向线圈、S 极在右侧，C 对。
5. 问：$Q$ 点电压为负，同样分析，若此时是呼气，S 极在哪一侧？ → 期望：感应磁场向右，原磁场向右，S 极朝向线圈即在左侧，D 错。选 BC。
常见错误：
- 用外电路规律判断电势。追问：此时线圈是电源还是用电器？电源内部电流从高电势流向低电势吗？
- 把“N 极在右侧”理解成线圈中磁场向左。追问：磁体外部磁感线从 N 极出发进入 S 极，朝向线圈的是哪个极？
总结句：先由磁极定原磁场，再由靠近/远离定磁通量增减，用楞次定律定电流；线圈作电源时电流流出的一端电势高。

## 3
本题考点：感生电场；楞次定律；电流正向减小与反向增大时感应电流方向相同。
已知：图（a）标出 CS 线圈电流正方向；图（b）中电流从正值先减小到零，再反向增大。
提问路线：
1. 问：开始阶段 CS 线圈电流为正且在减小，用右手螺旋定则，中心柱处的磁场朝上还是朝下？磁通量怎样变？ → 期望：磁场向下（下端为 N 极），向下的磁通量在减小。
2. 问：向下的磁通量减小，等离子体所在处感生电场（俯视）沿什么方向？等离子体电流呢？ → 期望：感应磁场要向下，感生电场俯视为顺时针，等离子体电流顺时针。
3. 问：后来电流反向增大，磁场变为向上且增大，感生电场方向与前一阶段相同吗？ → 期望：向上增大与向下减小效果相同，仍为顺时针，选 A。
常见错误：
- 认为电流过零后等离子体电流反向（选 C）。追问：电流图像的斜率在过零前后符号变了吗？磁场的变化趋势变了吗？
总结句：感应电流方向由原电流的“变化趋势”（图像斜率）决定，斜率不变号，感应电流就不反向。

## 4
本题考点：电容器放电驱动导体棒；欧姆定律求瞬时电流；牛顿第二定律；反电动势使加速度减小，最终匀速。
已知：电容 $C$、初始电荷量 $Q$，导轨间距 $L$，磁场 $B$ 竖直向下，棒质量 $m$、电阻 $R$，无摩擦。
提问路线：
第（1）问
1. 问：闭合开关前电容器两端电压是多少？闭合瞬间棒的速度为零，有没有反电动势？电流多大？ → 期望：$U=\dfrac QC$，无反电动势，$I=\dfrac UR=\dfrac{Q}{CR}$。
第（2）问
2. 问：闭合瞬间棒受的安培力多大？加速度多大？ → 期望：$F=BIL$，$a=\dfrac{BIL}{m}=\dfrac{BQL}{CRm}$。
第（3）问
3. 问：棒运动后电容器在放电、电压下降，棒切割磁感线产生反电动势 $BLv$。电流 $I=\dfrac{U-BLv}{R}$ 怎样变？加速度呢？ → 期望：$U$ 减小、$BLv$ 增大，电流减小，加速度减小。
4. 问：什么时候电流变为零？之后棒做什么运动？$v-t$ 图线是什么形状？ → 期望：$U=BLv$ 时电流为零，此后匀速；图线从原点出发、斜率逐渐减小，最后变为水平线。
常见错误：
- 闭合瞬间考虑反电动势。追问：闭合瞬间棒的速度是多少？
- 认为电容器放电完毕棒才匀速，或认为棒一直加速。追问：反电动势与电容器电压相等时，回路中还有电流吗？
- 画成直线。追问：加速度在变吗？
总结句：电容器驱动的导体棒：开始电流最大、加速度最大，之后电流随“电压差”减小，最终电容器电压与反电动势相等时匀速。

## 5
本题考点：$q=\dfrac{\Delta\Phi}{R_总}$；末态 $B=0$ 时磁通量为零，与面积如何变化无关。
已知：两棒电阻均为 $R$，初始间距 $x_0$，$t=0$ 时 $B=B_0$，$t=T$ 时 $B=0$；$cd$ 在运动，回路面积在变。
提问路线：
1. 问：求流过回路的电荷量，哪个公式不需要知道电流怎样变化？ → 期望：$q=\dfrac{\Delta\Phi}{R_总}$。
2. 问：$t=0$ 时回路的磁通量是多少？$t=T$ 时呢？（$cd$ 在运动，面积变了，影响末态磁通量吗？） → 期望：初态 $\Phi_0=B_0Lx_0$；末态 $B=0$，无论面积多大磁通量都为 0。
3. 问：回路总电阻是多少？电荷量等于多少？ → 期望：$R_总=2R$，$q=\dfrac{B_0Lx_0}{2R}$，选 B。
常见错误：
- 总电阻只取 $R$（选 C）。追问：回路中有几根棒，各有电阻吗？
- 纠结 $cd$ 运动后的面积。追问：末态磁感应强度是多少？磁通量 $BS$ 等于多少？
总结句：求电荷量用 $q=\dfrac{\Delta\Phi}{R_总}$，只看初末磁通量；末态 $B=0$ 时磁通量必为零。

## 6
本题考点：匀变速运动的判断（电压随时间均匀增加）；$F=kv+b$ 与安培力 $\dfrac{B^2d^2v}{R}$ 的对比；无磁场区仍有边在切割；动量定理与运动学联立。
已知：正方形框边长 $d$，磁场区与无磁场区交替、边长都为 $d$；$gh$ 在磁场中时拉力 $F=kv+b$，在无磁场区时 $F=0$；$gh$ 每次进入磁场时速度为 $v_0$（$v_0<\dfrac bk$）。
提问路线：
1. 问：$gh$ 两端电压 $U\propto v$，电压随时间均匀增加说明 $gh$ 在磁场中做什么运动？ → 期望：速度随时间均匀增加，做匀加速直线运动。
2. 问：写出 $gh$ 在磁场中时小车的牛顿第二定律方程。要让加速度恒定，和 $v$ 有关的项必须怎样？由此求总电阻 $R$。 → 期望：$kv+b-\dfrac{B^2d^2v}{R}=ma$，须 $kv=\dfrac{B^2d^2v}{R}$，得 $R=\dfrac{B^2d^2}{k}$，且 $ma=b$，B 对。
3. 问：$gh$ 在无磁场区时，哪条边在磁场中切割？小车受什么力？用动量定理写出速度从 $v_{max}$ 减到 $v_0$ 的式子。 → 期望：$ef$ 边在磁场中切割，受安培力减速；$-\dfrac{B^2d^2}{R}\cdot d=mv_0-mv_{max}$，即 $kd=m(v_{max}-v_0)$。
4. 问：在磁场中匀加速 $d$：$v_{max}^2-v_0^2=2ad$，$a=\dfrac bm$，与上式联立求 $m$ 和 $v_{max}$。 → 期望：$m=\dfrac{k^2d}{2(b-kv_0)}$，C 对；$v_{max}=\dfrac{2b}{k}-v_0$，D 错。
5. 问：在磁场中运动的时间 $t=\dfrac{v_{max}-v_0}{a}$ 等于多少？ → 期望：$t=\dfrac{kd}{b}$，A 错。选 BC。
常见错误：
- 认为在无磁场区小车匀速。追问：$gh$ 不在磁场里时，金属框的另一条边 $ef$ 在哪里？
- 由“电压均匀增加”想到匀速。追问：$U=Bdv$，$U$ 均匀增加说明 $v$ 怎样变？
总结句：“某量随时间均匀变化”往往暗示匀变速；变力 $kv+b$ 中与速度有关的部分恰与安培力抵消。减速阶段用动量定理，位移 $d$ 藏在 $\bar v\Delta t$ 里。

## 7
本题考点：整体法求最大静摩擦力（支持力含杆的重力）；临界条件：安培力等于最大静摩擦力；相对切割 $E=Bl(v-u)$；功率 $P=Fv$。
已知：U 形框质量 $m$、电阻不计，与桌面动摩擦因数 $\mu$；金属杆 $JK$ 质量 $m$、电阻 $R$，光滑地放在导轨上；弹簧劲度系数 $k$；磁场竖直向上；$JK$ 匀速向右。
提问路线：
第（1）问
1. 问：杆 $JK$ 压在 U 形框的导轨上，桌面对 U 形框的支持力是多少？最大静摩擦力多大？ → 期望：$F_N=2mg$，$F_{fm}=2\mu mg$。
第（2）问
2. 问：$JK$ 向右运动，U 形框受到的安培力朝哪？弹簧保持原长，即 U 形框不动，靠什么平衡安培力？ → 期望：U 形框受安培力向右（与杆受力等大反向），由静摩擦力平衡。
3. 问：速度最大时对应什么临界状态？列式求 $v_m$。 → 期望：安培力等于最大静摩擦力，$\dfrac{B^2l^2v_m}{R}=2\mu mg$，$v_m=\dfrac{2\mu mgR}{B^2l^2}$。
第（3）问
4. 问：U 形框也以速度 $u$ 运动时，回路电动势取决于什么速度？写出电动势和安培力。 → 期望：取决于相对速度，$E=Bl(v-u)$，$F_A=\dfrac{B^2l^2(v-u)}{R}$。
5. 问：外力 $F$ 等于安培力，$u$ 越大安培力越小。外力功率最小对应 U 形框速度最大，此时 U 形框的加速度是多少？列式求 $u$。 → 期望：加速度为零，安培力等于弹力加滑动摩擦力，$\dfrac{B^2l^2(v-u)}{R}=kx_0+2\mu mg$，$u=v-\dfrac{(kx_0+2\mu mg)R}{B^2l^2}$。
6. 问：$JK$ 匀速，外力等于什么？外力功率最小值是多少？ → 期望：外力等于安培力 $kx_0+2\mu mg$，$P=(kx_0+2\mu mg)v$。
常见错误：
- 支持力只取 $mg$。追问：金属杆压在谁身上？它的重量最终由谁承担？
- 第（3）问电动势仍用 $Blv$。追问：导轨也在动时，回路面积的变化快慢由什么决定？
总结句：两个都在动的导体组成回路时，电动势取决于相对速度；找临界状态时注意整体受力（支持力包含上面物体的重力）。
