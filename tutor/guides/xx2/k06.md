# 选修二 k06 · 问答脚本

## 1
本题考点：直线边界磁场的对称性（射入、射出时速度与边界夹角相等）；周期相同时时间与圆心角成正比。
已知：第Ⅰ象限磁场向里，正、负粒子质量、电荷量、速率都相同，从原点沿与 $x$ 轴成 $30^\circ$ 的方向射入。
提问路线（每次只问一个问题）：
1. 问：两粒子的周期相同吗？为什么？ → 期望：$T=\dfrac{2\pi m}{qB}$，$m$、$q$、$B$ 都相同，周期相同。
2. 问：用左手定则，正粒子向哪边偏？会从哪条坐标轴射出？负粒子呢？ → 期望：正粒子向左上偏，从 $y$ 轴射出；负粒子向右下偏，从 $x$ 轴射出。
3. 问：正粒子入射速度与 $y$ 轴夹角 $60^\circ$，射出时与 $y$ 轴夹角也是 $60^\circ$，它转过的圆心角是多少？负粒子入射速度与 $x$ 轴夹角 $30^\circ$，转过的圆心角是多少？ → 期望：正粒子 $120^\circ$，负粒子 $60^\circ$。
4. 问：时间之比是多少？ → 期望：$t_正:t_负=120^\circ:60^\circ=2:1$，选 B。
常见错误：
- 认为两者对称所以时间相同（选 D）。追问：正粒子从哪条边界出去？负粒子呢？它们入射时与各自出射边界的夹角一样吗？
- 圆心角算反。追问：从直线边界射入又射出，圆心角等于速度偏转角，等于入射方向与边界夹角的 2 倍——分别用哪个边界？
总结句：直线边界磁场中，粒子射入和射出时速度与边界的夹角相等，圆心角 = 2 × 速度与边界的夹角。

## 2
本题考点：平行边界磁场的临界条件（轨迹与另一边界相切）；几何关系 $R+R\cos\theta=d$。
已知：磁场宽度 $d$、方向向里，电子从 $CD$ 射入，速度与 $CD$ 夹角 $\theta$。
提问路线：
1. 问：电子恰好能（或恰好不能）从 $EF$ 射出时，轨迹与 $EF$ 是什么关系？ → 期望：轨迹与 $EF$ 相切。
2. 问：画出圆心，圆心到 $CD$ 的距离是多少？到 $EF$ 的距离是多少？ → 期望：圆心到 $CD$ 的距离为 $R\cos\theta$，到 $EF$ 的距离为 $R$（相切），所以 $R+R\cos\theta=d$。
3. 问：临界半径和临界速度是多少？ → 期望：$R=\dfrac{d}{1+\cos\theta}$，$v_0=\dfrac{eBR}{m}=\dfrac{Bed}{m(1+\cos\theta)}$。
4. 问：要从 $EF$ 射出，速度要比临界值大还是小？ → 期望：大于临界值，选 A。
常见错误：
- 几何关系用 $\sin\theta$（选 C）。追问：$\theta$ 是速度与 $CD$ 的夹角，半径与 $CD$ 的夹角是多少？圆心到 $CD$ 的垂直距离用正弦还是余弦？
- 认为速度小才能射出。追问：速度越大，半径越大还是越小？越容易穿过还是越难？
总结句：“恰好穿出/恰好不穿出”的临界轨迹与边界相切，找出圆心到两边界的距离列方程。

## 3
本题考点：粒子电性不确定导致的多解；轨迹到边界的最大距离；几何关系。
已知：$x$ 轴上方磁场向里，粒子从 $O$ 射入，速度与 $x$ 轴正方向成 $120^\circ$（即斜向左上，与 $x$ 轴负方向成 $60^\circ$），到 $x$ 轴的最大距离为 $a$。
提问路线：
1. 问：如果粒子带正电，用左手定则，它向哪边偏？圆心在速度方向的哪一侧？ → 期望：由左手定则判断偏转方向，圆心在过 $O$ 点且垂直于速度的直线上（画出两种电性对应的圆心）。
2. 问：正电荷时，圆心到 $x$ 轴的距离是多少？最高点到 $x$ 轴的距离 $a$ 等于什么？ → 期望：按图中几何关系，最高点到 $x$ 轴的距离 $a=r(1-\sin30^\circ)=\dfrac r2$，所以 $r=2a$，$B=\dfrac{mv}{2aq}$，B 对。
3. 问：如果带负电，向哪边偏？$a$ 等于什么？ → 期望：向右偏，圆心在 $x$ 轴上方，$a=r(1+\sin30^\circ)=\dfrac{3r}{2}$，$B=\dfrac{3mv}{2aq}$，C 对。选 BC。
常见错误：
- 只考虑一种电性。追问：题目说电荷“正、负可能是”，告诉你电性了吗？
- 正负对应关系弄反。追问：正电荷向左偏时，大半个圆还是小半个圆在 $x$ 轴上方？哪种情况离 $x$ 轴更远？
总结句：电性未知时要分别讨论；最大距离等于圆心到边界的距离加（或减）半径。

## 4
本题考点：左手定则；半径 $r=\dfrac{mv}{qB}$ 随 $B$、$v$ 的变化；时间由圆心角决定。
已知：正方形磁场向里，粒子从 $a$ 点垂直边界射入，向下偏转从 $b$ 点射出。
提问路线：
1. 问：粒子向下偏，用左手定则判断电性。 → 期望：带负电，A 错。
2. 问：仅增大 $B$，半径怎样变？出射点向哪边移？ → 期望：半径减小，可能从 $b$ 点左侧射出，B 对。
3. 问：仅减小 $B$ 呢？ → 期望：半径增大，出射点向右移，C 错。
4. 问：仅增大速率，半径和圆心角怎样变？周期变吗？时间呢？ → 期望：半径增大、圆心角减小，周期不变，时间变短，D 错。选 B。
常见错误：
- 认为速度大时间长。追问：周期与速度有关吗？速度大时轨迹更弯还是更直？
- $B$ 增大时半径判成增大。追问：$r=\dfrac{mv}{qB}$，$B$ 在分子还是分母？
总结句：$r=\dfrac{mv}{qB}$ 定半径，周期 $T=\dfrac{2\pi m}{qB}$ 与速度无关，时间只看圆心角。

## 5
本题考点：沿半径射入圆形磁场的几何关系；周期与比荷；判断哪些量可求（未知量分析）。
已知：无磁场时沿直径穿过的时间为 $t$；有磁场 $B$ 时偏转 $\dfrac{\pi}{3}$；圆柱半径未知。
提问路线：
1. 问：设圆柱截面半径为 $R_0$，无磁场时速度怎样表示？ → 期望：$v=\dfrac{2R_0}{t}$。
2. 问：沿半径射入、偏转 $60^\circ$，轨迹半径 $R$ 与 $R_0$ 有什么关系？ → 期望：$\tan30^\circ=\dfrac{R_0}{R}$，$R=\sqrt3R_0$。
3. 问：由 $R=\dfrac{mv}{qB}$，把 $v$ 和 $R$ 代入，比荷能求出来吗？ → 期望：$\dfrac{q}{m}=\dfrac{v}{BR}=\dfrac{2}{\sqrt3Bt}$，$R_0$ 约掉了，可求，D 对。
4. 问：周期 $T=\dfrac{2\pi m}{qB}$ 能求吗？ → 期望：能，$T=\sqrt3\pi t$，C 对。
5. 问：初速度和轨迹半径都含 $R_0$，题目给了 $R_0$ 吗？ → 期望：没给，求不出，A、B 错。选 CD。
常见错误：
- 认为速度能求。追问：$v=\dfrac{2R_0}{t}$ 中 $R_0$ 已知吗？
- 几何关系写成 $R=R_0$ 或 $R=\dfrac{R_0}{\sqrt3}$。追问：偏转 $60^\circ$ 时，圆心角是多少？磁场半径与轨迹半径构成的直角三角形中哪个角是 $30^\circ$？
总结句：判断“能求哪些量”时，把每个量用已知量表示，未知量（如磁场半径）能约掉就能求，约不掉就求不出。

## 6
本题考点：圆形磁场中非径向射入（不能用“径向进径向出”）；反向射出时轨迹为半圆；磁场反向后的轨迹。
已知：圆形磁场半径 $R$、向里，电荷从 $A$ 点水平射入，速度与半径 $AO$ 夹角 $30^\circ$，最后从 $C$ 点反向射出。
提问路线：
1. 问：“径向射入必径向射出”这条结论能用在这里吗？出射速度反向延长线过 $O$ 吗？ → 期望：不能，入射不是沿半径方向，出射反向延长线也不过 $O$，A 错。
2. 问：反向射出说明速度转过了多少度？轨迹是什么形状？ → 期望：转过 $180^\circ$，轨迹是半圆，$AC$ 是轨迹直径。
3. 问：$AC$ 是磁场圆的一条弦，它与 $AO$ 夹角为 $60^\circ$（垂直于入射速度），弦长是多少？轨迹半径呢？ → 期望：$AC=2R\cos60^\circ=R$，轨迹半径 $r=\dfrac R2$。
4. 问：运动时间和比荷是多少？ → 期望：$t=\dfrac{\pi r}{v_0}=\dfrac{\pi R}{2v_0}$，B 对；$\dfrac qm=\dfrac{v_0}{Br}=\dfrac{2v_0}{BR}$，C 对。
5. 问：磁场反向，电荷向另一侧偏，轨迹对应的圆心角比 $90^\circ$ 大还是小？时间与 $\dfrac{\pi R}{4v_0}$ 比较？ → 期望：由几何计算 $\tan\theta=\dfrac{\sqrt3}{2}<1$，圆心角 $2\theta<90^\circ$，时间小于 $\dfrac{\pi R}{4v_0}$，D 错。选 BC。
常见错误：
- 套用“径向进出”结论选 A。追问：入射速度沿半径吗？
- 半径取成 $R$。追问：弦 $AC$ 有多长？它是轨迹的直径还是半径？
总结句：非径向射入圆形磁场时要直接画轨迹、找圆心；反向射出时轨迹为半圆，弦长等于直径。

## 7
本题考点：从同一直线边界射出的粒子圆心角相同；半径、向心加速度与速度的关系；周期和角速度与速度无关。
已知：直角三角形 $ABC$ 内有磁场，比荷相同的两个粒子沿 $AB$ 方向射入，分别从 $AC$ 边上的 $P$、$Q$ 射出（$P$ 离 $A$ 较近）。
提问路线：
1. 问：两个粒子都从 $A$ 沿 $AB$ 射入、从 $AC$ 边射出，射出时速度与 $AC$ 的夹角有什么关系？圆心角呢？ → 期望：都相同（弦切角相同），圆心角相等。
2. 问：哪个粒子轨迹半径大？速度呢？ → 期望：$Q$ 离 $A$ 更远，$r_Q>r_P$，$v_Q>v_P$，A 错。
3. 问：向心加速度 $a=\dfrac{qvB}{m}$，谁的大？ → 期望：$Q$ 的大，B 对。
4. 问：角速度 $\omega=\dfrac{qB}{m}$ 与速度有关吗？时间呢？ → 期望：无关，角速度相等，C 错；圆心角相等、周期相等，时间一样长，D 对。选 BD。
常见错误：
- 认为速度大的角速度也大。追问：$\omega=\dfrac vr$，$v$ 和 $r$ 都与什么成正比？比值还与速度有关吗？
- 认为路程长时间长。追问：时间看路程还是看圆心角？
总结句：同一点、同一方向射入，从同一直线边界射出的同种粒子，圆心角相同、时间相同，只是半径不同。

## 8
本题考点：沿径向射入圆形磁场；偏转角与半径的几何关系 $r=\dfrac{R}{\tan(\varphi/2)}$；时间与圆心角；磁场改变后的新轨迹。
已知：比荷相同，沿 $AO$ 射入，a 偏转 $120^\circ$，b 偏转 $60^\circ$；磁场向里；a 向下偏、b 向上偏（按图）。
提问路线：
1. 问：根据偏转方向，用左手定则判断 a、b 电性。 → 期望：b 向上偏带正电，a 向下偏带负电，A 错。
2. 问：偏转 $120^\circ$ 和 $60^\circ$，用磁场半径 $R$ 表示两者的轨迹半径。 → 期望：$r_a=R\tan30^\circ$，$r_b=\dfrac{R}{\tan30^\circ}$。
3. 问：速率之比是多少？ → 期望：$v_a:v_b=r_a:r_b=\tan^230^\circ=1:3$，B 对。
4. 问：周期相同时，时间之比是多少？ → 期望：$t_a:t_b=120^\circ:60^\circ=2:1$，C 对。
5. 问：（D）$B$ 变为原来的 $\dfrac{\sqrt3}{3}$，a 的半径变为多少？圆心角变为多少？周期变为多少？时间变为原来的几倍？ → 期望：$r_a'=\sqrt3r_a=R$，圆心角 $90^\circ$；$T'=\sqrt3T$；$t_a'=\dfrac{\sqrt3}{4}T$，是原来 $\dfrac{T}{3}$ 的 $\dfrac{3\sqrt3}{4}$ 倍，D 错。选 BC。
常见错误：
- D 中忘记周期也随 $B$ 变化。追问：$T=\dfrac{2\pi m}{qB}$，$B$ 变小，周期变不变？
- 半径与偏转角关系写反。追问：偏转越大，轨迹越弯，半径越大还是越小？
总结句：沿径向射入圆形磁场：$\tan\dfrac{\varphi}{2}=\dfrac{R}{r}$；磁场改变时，半径和周期都要重新算。

## 9
本题考点：三角形区域内的临界轨迹（垂直边射出、过顶点射出）；从同一边射出时圆心角相同。
已知：等边三角形边长 $L$，磁场 $B_0$ 向里，$D$ 是 $AB$ 中点；粒子带 $-q$，从 $D$ 平行 $BC$ 射入，向下偏转。
提问路线：
1. 问：粒子向下偏，能到达 $B$ 点吗？ → 期望：不能，$BC$ 边挡住了，粒子会先从 $BC$ 或 $AB$ 边射出，A 错。
2. 问：垂直 $BC$ 边射出时，圆心在哪？半径等于什么？ → 期望：圆心在 $BC$ 上，半径等于 $D$ 到 $BC$ 的距离 $\dfrac L2\sin60^\circ=\dfrac{\sqrt3}{4}L$，B 错。
3. 问：从 $C$ 点射出时，用勾股定理列方程求半径，圆心角是多少？时间多少？ → 期望：$r_2=\dfrac{\sqrt3}{2}L$，圆心角 $60^\circ$，$t=\dfrac16\cdot\dfrac{2\pi m}{qB_0}=\dfrac{\pi m}{3qB_0}$，C 对。
4. 问：从 $AB$ 边射出的粒子，射出时速度与 $AB$ 的夹角都一样吗？圆心角呢？时间呢？ → 期望：都一样，圆心角相同、时间相同，D 对。选 CD。
常见错误：
- 半径取 $D$ 到 $B$ 的距离。追问：垂直 $BC$ 射出时，圆心在哪条线上？
- 认为速度不同时间就不同。追问：从同一条直线边界射出，圆心角由什么决定？
总结句：有界磁场找临界轨迹：垂直某边射出时圆心在该边上；过顶点时用勾股定理；同一直线边界射出的粒子圆心角相同。

## 10
本题考点：粒子源发射的多方向粒子；$R=a$ 的特殊情况；弦长与时间（弦越长、圆心角越大、时间越长，当 $R$ 一定且圆心角小于 $180^\circ$）。
已知：直角三角形 $AOC$，$\angle A=60^\circ$，$AO=a$；粒子带负电，$v_0=\dfrac{qBa}{m}$ 即 $R=a$；发射方向用 $\theta$ 表示。
提问路线：
1. 问：粒子的轨迹半径是多少？ → 期望：$R=\dfrac{mv_0}{qB}=a$。
2. 问：$\theta=60^\circ$ 射入的粒子会从哪里射出？对应的弦长和圆心角是多少？ → 期望：恰好从 $A$ 点射出，弦长 $a$，圆心角 $60^\circ$，A 错。
3. 问：半径一定时，弦越长圆心角越大、时间越长。$\theta=60^\circ$ 的粒子弦长最大，时间最长还是最短？ → 期望：最长，B 错。
4. 问：$\theta<30^\circ$ 的粒子都从 $AC$ 边射出，它们的弦长相同吗？时间相同吗？ → 期望：弦长不同，时间不同，C 错。
5. 问：$\theta=0^\circ$ 的粒子从 $AC$ 上哪点射出？$AC$ 上有粒子射出的范围是多大？ → 期望：恰好从 $AC$ 中点射出；从中点到 $A$ 有粒子射出，只占一半，D 对。选 D。
常见错误：
- 认为从 $A$ 点射出的粒子时间最短。追问：半径相同时，弦长和圆心角是什么关系？
- 认为 $AC$ 全部有粒子射出。追问：$\theta=0^\circ$ 时射出点在哪？还有比它更靠近 $C$ 的射出点吗？
总结句：半径一定时，弦长决定圆心角和时间；找射出范围要找两个临界方向的轨迹。

## 11
本题考点：粒子源向各方向发射；由过某点的轨迹求半径；轨迹与挡板相切、经过挡板端点的临界情况；用角度范围求粒子比例。
已知：挡板 $MN$ 长 $a$，$ON\perp MN$，$ON=\sqrt3a$；粒子带 $+q$，速率相同；与 $ON$ 成 $60^\circ$ 发射的粒子恰好经过 $N$ 点。
提问路线：
1. 问：（1）与 $ON$ 成 $60^\circ$ 射出的粒子经过 $N$，$ON$ 是轨迹的一条弦，弦长与半径、弦切角有什么关系？ → 期望：弦切角 $60^\circ$ 对应圆心角 $120^\circ$，$ON=2R\cos30^\circ=\sqrt3R$，所以 $R=a$。
2. 问：（2）粒子打到挡板左侧最远的位置，对应轨迹和挡板是什么关系？ → 期望：轨迹与挡板相切（临界轨迹 2）。
3. 问：设此时速度与 $ON$ 夹角为 $\theta$，列几何关系求 $\sin\theta$。 → 期望：$R\sin\theta+R=\sqrt3a$，$\sin\theta=\sqrt3-1$。
4. 问：切点到 $N$ 的距离是多少？ → 期望：$R\cos\theta=a\sqrt{1-\sin^2\theta}=\sqrt{2\sqrt3-3}\,a$，即左侧被击中的长度。
5. 问：（3）能绕过挡板打到右侧的粒子有哪两个临界轨迹？对应的初速度方向与 $ON$ 的夹角各是多少？ → 期望：一条恰好经过 $N$ 点（$60^\circ$），一条恰好经过 $M$ 端（$120^\circ$）。
6. 问：两临界方向夹角多大？占全部方向的比例是多少？ → 期望：$60^\circ$，比例 $\dfrac{60^\circ}{360^\circ}=\dfrac16$。
常见错误：
- 半径直接取 $ON$ 的一半。追问：$ON$ 是轨迹的直径吗？粒子在 $O$ 点速度与 $ON$ 垂直吗？
- 第（2）问把最远点当成 $M$ 点。追问：粒子能打到 $M$ 点吗？轨迹再往外会与挡板怎样？
- 比例用长度比。追问：粒子是向各个“方向”均匀发射的，比例应按角度还是按长度算？
总结句：粒子源问题的关键是“旋转圆”：半径不变，转动初速度方向，找相切和过端点的临界轨迹，再用角度求比例。
