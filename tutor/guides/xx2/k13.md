# 选修二 k13 · 问答脚本

## 1
本题考点：$E=\dfrac{\Delta\Phi}{\Delta t}=kS$；电源与外电路的电阻分配；楞次定律判断电流方向与电势高低。
已知：两个边长为 $L$ 的正方形用同一根均匀金属丝连成，$A$、$B$ 在中间且相距很近（相当于一个开口回路的两端）；只有右侧正方形内有均匀增强的磁场（垂直纸面向里），$\dfrac{\Delta B}{\Delta t}=k$。
提问路线（每次只问一个问题）：
1. 问：哪部分相当于电源？电动势多大？ → 期望：右侧正方形，$E=kL^2$。
2. 问：左右两个正方形电阻一样吗？$A$、$B$ 两点间电压是电动势的几分之几？ → 期望：一样，左侧是外电路，$|U|=\dfrac{E}{2}=\dfrac{kL^2}{2}$。
3. 问：磁场向里增强，右侧正方形中电流沿什么方向？ → 期望：感应磁场向外，逆时针。
4. 问：右侧正方形是电源，电流在电源内部从低电势流向高电势。按图中位置，逆时针电流在右侧正方形中从 $B$ 端流向 $A$ 端，哪点电势高？ → 期望：电流从 $A$ 端流出电源，$A$ 是正极，$A$ 点电势高，$U_{BA}=-\dfrac{kL^2}{2}$，选 D。
常见错误：
- 认为 $U_{BA}=kL^2$。追问：右侧正方形自身有没有电阻？内电压是多少？
- 正负号判反。追问：电源内部电流从哪个极流向哪个极？
总结句：磁场变化的那部分线圈是电源；两点间电压是路端电压；电势高低看电源内部电流方向（流出端为正极）。

## 2
本题考点：感生电动势；路端电压的分配。
已知：磁场只穿过大圆环，小圆环电阻是大圆环的 $\dfrac12$，大圆环中电动势为 $E$。
提问路线：
1. 问：哪个圆环是电源？哪个是外电路？ → 期望：大圆环是电源（内阻 $2R$），小圆环是外电路（电阻 $R$）。
2. 问：$a$、$b$ 两点间电压是什么电压？外电阻占总电阻的几分之几？ → 期望：路端电压；$\dfrac{R}{2R+R}=\dfrac13$，$U_{ab}=\dfrac13E$，选 B。
常见错误：
- 认为 $U_{ab}=E$。追问：大圆环本身有电阻吗？
- 认为是 $\dfrac23E$。追问：$a$、$b$ 间电压等于电源两端电压，还是内电压？
总结句：感生电动势问题中，处在变化磁场中的线圈是电源，两端电压按“外电阻/总电阻”分配。

## 3
本题考点：楞次定律；左手定则；磁通量与匝数无关；$n$ 匝线圈的电动势和安培力。
已知：线圈 $n$ 匝、面积 $S$，磁场向外，从 0 均匀增大到 $B_0$，用时 $t_0$；$AB$ 是线圈右边。
提问路线：
1. 问：磁场向外增大，感应电流沿什么方向？ → 期望：感应磁场向里，顺时针，A 错。
2. 问：$AB$ 边（右边）中电流朝哪？用左手定则，安培力朝哪？ → 期望：顺时针时右边电流向下，磁场向外，安培力向左，B 对。
3. 问：磁通量 $\Phi=BS$ 与匝数有关吗？ → 期望：无关，C 错。
4. 问：$n$ 匝线圈的电动势、电阻和 $AB$ 边受的安培力与 $n$ 有什么关系？ → 期望：$E=n\dfrac{B_0S}{t_0}$，$R\propto n$，$I$ 与 $n$ 无关，但 $AB$ 边有 $n$ 根导线，$F=nBIL$ 与 $n$ 有关，D 错。选 B。
常见错误：
- 认为磁通量与匝数成正比。追问：磁通量是穿过“一个面”的磁感线条数，与绕几圈有关吗？
- 安培力方向判反。追问：先确定 $AB$ 边中电流方向再用左手定则。
总结句：磁通量与匝数无关，电动势 $E=n\dfrac{\Delta\Phi}{\Delta t}$ 与匝数有关。

## 4
本题考点：动生电动势 $E=BLv$；右手定则判断电势高低。
已知：卫星在航天飞机正上方 5 km，系统自西向东运动，速度 8 km/s，地磁场水平由南指向北，$B=5\times10^{-5}$ T。
提问路线：
1. 问：缆绳的长度、速度、磁场三者相互垂直吗？电动势多大？ → 期望：垂直；$E=BLv=5\times10^{-5}\times5000\times8000\ \text{V}=2000\ \text{V}$。
2. 问：缆绳向东运动、磁场向北，用右手定则，缆绳中电流（或正电荷）朝哪个方向？ → 期望：向上，指向卫星。
3. 问：缆绳相当于电源，电流在电源内部流向正极，哪端电势高？ → 期望：卫星端电势高，选 D。
常见错误：
- 单位没换算得 2 V 或 2×10⁶ V。追问：5 km、8 km/s 换成国际单位各是多少？
- 电势高低判反。追问：电源内部，电流从低电势流向高电势还是相反？
总结句：$E=BLv$ 要求三者两两垂直；右手定则得到的电流方向在导体内部指向高电势端。

## 5
本题考点：有效切割长度；感应电动势与内外电阻分配。
已知：圆环半径 $R$、电阻均匀，以 $v$ 进入磁场，图示位置 $\angle aOb=90^\circ$，$a$、$b$ 是圆环与磁场边界的交点；磁场中的是劣弧 $ab$（四分之一圆环）。
提问路线：
1. 问：在磁场中切割磁感线的是哪段？有效切割长度是多少？ → 期望：劣弧 $ab$，有效长度是弦 $ab=\sqrt2R$。
2. 问：电动势多大？ → 期望：$E=\sqrt2BRv$。
3. 问：电源（劣弧）的电阻占总电阻的多少？外电阻呢？ → 期望：内阻占 $\dfrac14$，外电阻占 $\dfrac34$。
4. 问：$a$、$b$ 间电压是多少？ → 期望：路端电压 $U_{ab}=\dfrac34E=\dfrac{3\sqrt2}{4}BRv$，选 D。
常见错误：
- 有效长度用弧长或半径。追问：弯曲导体切割时有效长度怎么取？
- 认为 $U_{ab}=E$ 或 $\dfrac14E$。追问：$a$、$b$ 间电压是电源两端的路端电压，等于外电阻上的电压还是内阻上的电压？
总结句：切割磁感线的那段是电源，有效长度取首尾连线在垂直速度方向的投影；两端电压是路端电压。

## 6
本题考点：由 $\Phi-t$ 图像求 $\dfrac{\Delta\Phi}{\Delta t}$；$E=n\dfrac{\Delta\Phi}{\Delta t}$；楞次定律判断电势；路端电压。
已知：10 匝线圈，$R=4.5$ Ω，线圈电阻 0.5 Ω，磁场向里，$\Phi$ 由 0.10 Wb 在 0.1 s 内均匀增大到 0.15 Wb。
提问路线：
1. 问：磁通量变化率是多少？电动势多大？ → 期望：$\dfrac{0.05}{0.1}=0.5$ Wb/s，$E=10\times0.5=5$ V，A 对。
2. 问：磁场向里增大，线圈中电流方向？结合接线，$M$、$N$ 哪端电势高？ → 期望：感应磁场向外，逆时针；电流从 $N$ 经线圈流到 $M$，$M$ 是正极，$\varphi_M>\varphi_N$，B 错。
3. 问：$U_{MN}$ 和电压表读数各是多少？ → 期望：$U_{MN}=\dfrac{4.5}{5}\times5=4.5$ V，为正值，C 错；电压表读 4.5 V，D 对。选 AD。
常见错误：
- 忘乘匝数。追问：线圈有几匝？
- 电压表读数写成 5 V。追问：线圈有内阻吗？电压表测的是电动势还是路端电压？
总结句：图像题先求斜率 $\dfrac{\Delta\Phi}{\Delta t}$，再乘匝数得电动势，最后按闭合电路求路端电压并判断正负。

## 7
本题考点：转动导体棒的电动势（用中点速度）；含环形电阻的电路；路端电压。
已知：金属环半径 $a$，总电阻 $R$；导体棒 $AB$ 长 $2a$、电阻 $\dfrac R2$，$A$ 端铰接在环的最高点，摆到竖直位置时 $B$ 端线速度为 $v$。
提问路线：
1. 问：棒绕 $A$ 转动，棒上各点速度不同，电动势怎样计算？ → 期望：用平均速度（中点速度 $\dfrac v2$），$E=B\cdot2a\cdot\dfrac v2=Bav$。
2. 问：棒竖直时，与环接触于最高点和最低点，环被分成两个半圆，它们怎样连接？等效电阻是多少？ → 期望：两个半圆（各 $\dfrac R2$）并联，等效 $\dfrac R4$。
3. 问：棒的电阻是内阻 $\dfrac R2$，$A$、$B$ 两端电压是多少？ → 期望：$U=\dfrac{E}{\frac R2+\frac R4}\cdot\dfrac R4=\dfrac{Bav}{3}$，选 A。
常见错误：
- 电动势用 $B\cdot2a\cdot v$。追问：棒上各点的速度都等于 $v$ 吗？
- 环的电阻按串联算成 $R$。追问：电流从环的最高点到最低点有几条路径？
总结句：转动切割用中点速度求电动势；环形外电路要先分析是串联还是并联。

## 8
本题考点：由 $B-t$ 图像求电动势；楞次定律；左手定则；路端电压。
已知：磁场竖直向上，$t_0$ 内从 $2B_0$ 均匀减小到 $B_0$；线框面积 $S$、电阻 $\dfrac R2$，开口处接灯泡 $R$（$a$、$b$ 两端）。
提问路线：
1. 问：磁场向上减小，从上往下看线框中电流方向？经小灯泡是 $a\to b$ 还是 $b\to a$？ → 期望：感应磁场向上，逆时针；按图中接线电流由 $a$ 经灯泡流向 $b$，A 错。
2. 问：$cd$ 边中电流方向和所受安培力方向？（也可以用“减扩”判断） → 期望：磁通量减小，线框有扩张趋势，$cd$ 边受力向右（向外），B 错。
3. 问：电动势多大？ → 期望：$E=\dfrac{(2B_0-B_0)S}{t_0}=\dfrac{B_0S}{t_0}$，C 错。
4. 问：$a$、$b$ 间电压多大？ → 期望：$U=\dfrac{R}{R+\frac R2}E=\dfrac{2B_0S}{3t_0}$，D 对。选 D。
常见错误：
- 电动势用 $\dfrac{2B_0S}{t_0}$。追问：$\Delta B$ 是末值减初值，等于多少？
- 安培力方向判反。追问：磁通量减小时，线框有扩张还是收缩的趋势？
总结句：$E=\dfrac{\Delta B}{\Delta t}S$ 中的 $\Delta B$ 是变化量；磁通量减小时线框各边受力向外。

## 9
本题考点：斜放导体的有效长度；$E=BLv$（$L$、$v$、$B$ 两两垂直）；安培力与电功率比较。
已知：导轨间距 $d$，第一次杆垂直导轨，第二次杆与导轨成 $60^\circ$，两次都以 $v$ 沿垂直于杆的方向运动；只有 $R$ 有电阻。
提问路线：
1. 问：第二次接入电路的杆长是多少？杆的速度与杆垂直，电动势是多少？ → 期望：$L_2=\dfrac{d}{\sin60^\circ}=\dfrac{2}{\sqrt3}d$，$E_2=BL_2v=\dfrac{2}{\sqrt3}Bdv$。
2. 问：两次电阻两端电压相等吗？电流之比？ → 期望：电压等于电动势，不相等，A 错；$I_1:I_2=E_1:E_2=\sqrt3:2$，B 对。
3. 问：两次安培力各多大？比值是多少？ → 期望：$F_1=\dfrac{B^2d^2v}{R}$，$F_2=BI_2L_2=\dfrac{4B^2d^2v}{3R}$，比值 $\dfrac34$，C 错。
4. 问：电功率之比？ → 期望：$P\propto E^2$，比值 $\dfrac34$，D 错。选 B。
常见错误：
- 认为两次电动势相同（都用 $d$）。追问：第二次速度是沿导轨方向还是垂直于杆的方向？此时切割长度是多少？
- 安培力只换电流不换长度。追问：$F=BIL$ 中的 $L$ 是杆接入电路的长度，第二次是多少？
总结句：$E=BLv$ 中 $L$ 必须与 $v$ 垂直；安培力 $F=BIL$ 中的 $L$ 是导体在电流方向上的有效长度。

## 10
本题考点：楞次定律；感生电动势 $E=\dfrac{\Delta B}{\Delta t}S$；电阻定律；安培力方向。
已知：螺线管内磁场竖直向上，$B=kt$；金属薄圆管半径 $r$、高 $h$、厚 $d$、电阻率 $\rho$，与螺线管共轴。
提问路线：
1. 问：磁场向上增大，从上往下看圆管中感应电流方向？ → 期望：感应磁场向下，顺时针，A 错。
2. 问：圆管的感应电动势是多少？与高度 $h$ 有关吗？ → 期望：$E=k\pi r^2$，与 $h$ 无关，B 错。
3. 问：把圆管展开成长条，电流方向的长度和横截面积各是多少？电阻多大？ → 期望：长度 $2\pi r$，横截面积 $dh$，$R=\rho\dfrac{2\pi r}{dh}$。
4. 问：热功率是多少？ → 期望：$P=\dfrac{E^2}{R}=\dfrac{\pi dhk^2r^3}{2\rho}$，C 对。
5. 问：圆管中的电流沿圆周，磁场竖直，安培力沿什么方向？会影响绳的拉力吗？ → 期望：沿水平径向（指向轴线），竖直方向不受力，拉力不变，D 错。选 C。
常见错误：
- 电阻的长度和截面用错。追问：电流沿圆周流动，电流方向的长度是多少？
- 认为安培力有竖直分量。追问：电流水平、磁场竖直，两者叉乘的方向是水平还是竖直？
总结句：感生电动势只与磁通量变化率有关；计算环形导体电阻时，长度沿电流方向、横截面垂直于电流。

## 11
本题考点：转动导体棒的电动势 $E=\dfrac12BL^2\omega$；右手定则；电源内部电流从负极到正极；路端电压。
已知：圆环半径 $L$，磁场向里；导体棒 $OA$ 绕 $O$ 逆时针转动，电阻 $r$；$O$ 与圆环间接 $R$。
提问路线：
1. 问：用右手定则，棒中电流从 $A$ 流向 $O$ 还是从 $O$ 流向 $A$？哪点电势高？ → 期望：从 $A$ 流向 $O$；棒是电源，电流从 $O$ 端流出，$O$ 点电势高，A 对。
2. 问：转动导体棒的电动势是多少？ → 期望：$E=\dfrac12BL^2\omega$，B 错。
3. 问：$O$、$A$ 间电压是路端电压，等于多少？ → 期望：$U=\dfrac{R}{R+r}E=\dfrac{BL^2\omega R}{2(R+r)}$，C 对。
4. 问：增大角速度，电流怎样变？ → 期望：$I=\dfrac{BL^2\omega}{2(R+r)}$ 增大，D 对。选 ACD。
常见错误：
- 电动势漏掉 $\dfrac12$。追问：棒上各点速度从 0 到 $\omega L$，平均速度是多少？
- 认为电流从高电势流向低电势，所以 $A$ 高。追问：在电源内部，电流从哪个极流向哪个极？
总结句：转动棒电动势 $E=\dfrac12BL^2\omega$；电源内部电流从低电势流向高电势。

## 12
本题考点：切割长度随时间变化的瞬时电动势；平均电动势 $\overline E=\dfrac{\Delta\Phi}{\Delta t}$。
已知：$\angle MON=30^\circ$，$AB\perp ON$，$AB$ 从 $O$ 点以 5 m/s 向右匀速运动，$B=0.2$ T。
提问路线：
1. 问：（1）第 3 s 末 $AB$ 离 $O$ 多远？夹在导轨间的长度是多少？ → 期望：$x=15$ m，$l=x\tan30^\circ=5\sqrt3$ m。
2. 问：此时的瞬时电动势是多少？ → 期望：$E=Blv=0.2\times5\sqrt3\times5=5\sqrt3$ V。
3. 问：（2）0～3 s 内回路围成的三角形面积是多少？磁通量变化多少？ → 期望：$S=\dfrac12\times15\times5\sqrt3=\dfrac{75\sqrt3}{2}\ \text{m}^2$，$\Delta\Phi=BS=\dfrac{15\sqrt3}{2}$ Wb。
4. 问：平均电动势是多少？ → 期望：$\overline E=\dfrac{\Delta\Phi}{\Delta t}=\dfrac{5\sqrt3}{2}$ V。
常见错误：
- 平均电动势用瞬时电动势除以 2 以外的方法乱算，或直接用 $Blv$。追问：平均电动势的定义式是什么？
- 长度用 $x\sin30^\circ$。追问：$AB$ 垂直 $ON$，$AB$ 与 $x$ 构成的直角三角形中，$\tan30^\circ$ 是哪两条边之比？
总结句：瞬时电动势用 $E=Blv$（$l$ 取该时刻的长度），平均电动势用 $\overline E=\dfrac{\Delta\Phi}{\Delta t}$。
