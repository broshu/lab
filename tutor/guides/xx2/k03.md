# 选修二 k03 · 问答脚本

## 1
本题考点：直线电流的磁场方向（安培定则）；洛伦兹力同时垂直于速度和磁场；受力与运动的关系。
已知：竖直导线电流向上，带正电小球在光滑水平面上以 $v_0$ 水平运动；四个选项是从上往下看的轨迹（A 是直线，B、C、D 是弯曲的）。
提问路线（每次只问一个问题）：
1. 问：竖直导线周围的磁感线是什么形状？在小球所在的水平面内，磁场是水平的还是竖直的？ → 期望：以导线为圆心的水平圆周，磁场是水平的。
2. 问：洛伦兹力的方向与速度、磁场是什么关系？速度和磁场都水平时，洛伦兹力只能朝哪个方向？ → 期望：同时垂直于速度和磁场，只能沿竖直方向（或为零）。
3. 问：竖直方向的力会让小球在水平面内拐弯吗？水平方向还有别的力吗？ → 期望：不会，竖直方向的力被支持力平衡；水平面光滑，水平方向不受力。
4. 问：所以小球在水平面内做什么运动？选哪个轨迹？ → 期望：匀速直线运动，选 A。
常见错误：
- 认为小球会绕导线做圆周运动或被吸引（选 B、C）。追问：洛伦兹力能指向导线吗？它必须垂直于哪两个方向？
- 把磁场方向当成竖直方向。追问：直线电流的磁感线围绕导线，是在与导线垂直的平面内还是沿着导线？
总结句：洛伦兹力总垂直于速度和磁场决定的平面；速度、磁场都在水平面内时，洛伦兹力竖直，不能改变水平面内的运动。

## 2
本题考点：地磁场分布；洛伦兹力大小与速度、磁场夹角的关系；左手定则判断偏转方向。
已知：宇宙射线竖直射向地球表面；地磁场在赤道处水平由南指向北，在两极附近接近竖直。
提问路线：
1. 问：赤道附近地磁场朝什么方向？两极附近呢？ → 期望：赤道附近水平由南指向北；两极附近几乎竖直。
2. 问：粒子竖直射来时，在哪里速度与磁场接近垂直、哪里接近平行？哪里洛伦兹力大、阻挡作用强？ → 期望：赤道处垂直，洛伦兹力大，阻挡最强；两极处接近平行，阻挡最弱。A、B 错。
3. 问：在赤道，正电荷竖直向下运动、磁场向北，用左手定则受力朝哪？负电荷呢？ → 期望：正电荷向东，负电荷向西，C 对。
4. 问：赤道平面内射来的粒子受力在东西方向，会向两极偏吗？ → 期望：不会，D 错。选 C。
常见错误：
- 认为两极磁场最强，所以阻挡最强（选 B）。追问：洛伦兹力大小除了与 $B$ 有关，还与速度和磁场的什么有关？两极处粒子速度与磁场是什么关系？
- 负电荷受力方向直接用左手判断没有反过来。追问：负电荷运动方向与等效电流方向是相同还是相反？
总结句：$F=qvB\sin\theta$，速度与磁场越接近垂直，洛伦兹力越大；负电荷用左手定则时四指指向其运动的反方向。

## 3
本题考点：电流的微观表达式 $I=neSv$；洛伦兹力 $F=evB$；左手定则（电子带负电）。
已知：导线 $ab$ 中电流向右，磁场垂直纸面向里，导线长 $l$、截面积 $S$、单位体积自由电子数 $n$。
提问路线：
1. 问：电流的微观表达式是什么？电子定向移动速率 $v$ 等于多少？ → 期望：$I=neSv$，$v=\dfrac{I}{neS}$。
2. 问：一个电子受的洛伦兹力多大？把 $v$ 代进去。 → 期望：$F=evB=\dfrac{BI}{nS}$，与 $l$ 无关（排除 B、D）。
3. 问：电流向右，电子实际向哪运动？用左手定则判断电子受力方向。 → 期望：电子向左运动；四指指向电流方向（向右），磁感线垂直穿入掌心，拇指向上，电子受力沿纸面向上，选 A。
常见错误：
- 把导线长度 $l$ 也乘进去（选 B）。追问：问的是每个电子受的力，还是整段导线受的力？
- 方向判成向下。追问：用左手定则时，四指应对着电子运动方向还是电流方向？
总结句：单个电子受的洛伦兹力与导线长度无关；整段导线的安培力就是所有自由电子洛伦兹力的宏观表现。

## 4
本题考点：左手定则判断负电荷受力；由受力方向反推磁场方向。
已知：电子沿 $x$ 轴正方向射出，要使亮线向下（沿 $z$ 轴负方向）偏。
提问路线：
1. 问：亮线向下偏，电子受的洛伦兹力朝哪？ → 期望：向下（$z$ 轴负方向）。
2. 问：电子沿 $+x$ 运动，相当于电流沿哪个方向？ → 期望：沿 $-x$ 方向。
3. 问：四指指向 $-x$、拇指指向 $-z$，磁感线从掌心穿入，磁场沿哪个方向？ → 期望：沿 $y$ 轴正方向，选 B。
常见错误：
- 直接把电子运动方向当电流方向，得到 $-y$（选 A）。追问：电子带什么电？负电荷运动形成的电流方向是怎样的？
- 选 $z$ 方向的磁场。追问：磁场如果沿 $z$ 轴，洛伦兹力会沿 $z$ 轴吗？洛伦兹力与磁场是什么关系？
总结句：已知力的方向求磁场方向，同样用左手定则，注意电子要把四指反过来。

## 5
本题考点：通电螺线管的磁场（安培定则）；左手定则判断电子偏转。
已知：偏转线圈可等效为左右两个通电螺线管；电子束沿轴线从纸内射向纸外。
提问路线：
1. 问：这个线圈可以看成什么？用安培定则判断它的上、下两端哪端是 N 极？ → 期望：看成两个通电螺线管，下端都是 N 极、上端都是 S 极。
2. 问：所以中心 $O$ 点的磁场朝哪个方向？ → 期望：竖直向上（从下面的 N 极指向上面的 S 极）。
3. 问：电子从纸内射向纸外，等效电流朝哪？用左手定则，电子受力朝哪？ → 期望：等效电流从纸外向纸内；受力向右，向右偏转，选 B。
常见错误：
- 认为电子沿磁场方向偏（向上偏）。追问：洛伦兹力与磁场是什么关系？
- 电子按正电荷处理得到向左。追问：电子带负电，用左手定则时四指指向哪里？
总结句：先用安培定则找磁场方向，再用左手定则（负电荷四指反向）找偏转方向。

## 6
本题考点：洛伦兹力与重力的平衡；用左手定则判断电性。
已知：油滴以 $v_0$ 水平向右进入垂直纸面向里的磁场，恰好做匀速直线运动。
提问路线：
1. 问：油滴受哪两个力？要匀速直线运动，洛伦兹力必须朝哪？ → 期望：重力和洛伦兹力；洛伦兹力必须竖直向上。
2. 问：速度向右、磁场向里、受力向上，用左手定则，油滴带正电还是负电？ → 期望：带正电（排除 B、D）。
3. 问：由 $qv_0B=mg$，电荷量多大？ → 期望：$q=\dfrac{mg}{v_0B}$，选 C。
常见错误：
- 认为带什么电都行（选 D）。追问：带负电时洛伦兹力朝哪？还能和重力平衡吗？
- 电荷量多算一个 2（选 A）。追问：平衡时洛伦兹力等于重力还是重力的两倍？
总结句：带电体在磁场中做匀速直线运动，洛伦兹力与其他力平衡；由平衡所需的力的方向判断电性。

## 7
本题考点：洛伦兹力不做功；运动的分解；类平抛运动。
已知：$B=0.2$ T（向里），杆长 $l=0.1$ m，$m=0.04$ kg，$q=+0.5$ C，杆以 $v=2$ m/s 向右匀速运动，小环从顶端由静止释放。
提问路线：
1. 问：洛伦兹力的方向与小环速度方向是什么关系？它对小环做功吗？ → 期望：始终垂直，不做功，A 错。
2. 问：小环水平速度 $v=2$ m/s 不变，由它产生的洛伦兹力朝哪？多大？ → 期望：由左手定则竖直向上，$qvB=0.5\times2\times0.2=0.2$ N。
3. 问：竖直方向合力和加速度多大？小环做什么运动？ → 期望：$mg-qvB=0.4-0.2=0.2$ N，$a=5\ \text{m/s}^2$，竖直方向匀加速，水平匀速，类平抛，B 错。
4. 问：在杆上运动的时间多长？ → 期望：$l=\dfrac12at^2$，$t=0.2$ s，C 错。
5. 问：离开杆时竖直速度和合速度多大？ → 期望：$v_y=at=1$ m/s，$v_{\text{合}}=\sqrt{2^2+1^2}=\sqrt5$ m/s，选 D。
常见错误：
- 认为小环受到的洛伦兹力会把它向上推、所以洛伦兹力做正功。追问：小环实际速度是什么方向？洛伦兹力和实际速度垂直吗？（竖直速度产生的洛伦兹力分量由杆的弹力平衡。）
- 时间用自由落体算出 0.14 s 或用 $a=g$。追问：竖直方向除了重力还有什么力？
总结句：洛伦兹力永远不做功；可以把运动分解，由水平速度产生的竖直洛伦兹力改变竖直方向的加速度。

## 8
本题考点：洛伦兹力存在的条件（$v\neq0$）；洛伦兹力与支持力不做功；机械能守恒。
已知：轨道光滑绝缘，滑块带正电，由 $a$ 点静止滑下，下降高度 $h$ 到 $b$。
提问路线：
1. 问：在 $a$ 点滑块速度是多少？受洛伦兹力吗？ → 期望：速度为零，不受洛伦兹力，A 错。
2. 问：洛伦兹力和支持力与速度方向是什么关系？做功吗？ → 期望：都垂直于速度，都不做功，B 错。
3. 问：只有重力做功，机械能怎样变？到 $b$ 点速度多大？ → 期望：机械能守恒，C 错；$v=\sqrt{2gh}$。
4. 问：$b$ 点洛伦兹力多大？ → 期望：$F=qvB=qB\sqrt{2gh}$，选 D。
常见错误：
- 认为洛伦兹力使机械能增大。追问：一个始终与速度垂直的力能改变速度大小吗？能做功吗？
- 用 $v=gh$ 或 $\sqrt{gh}$。追问：$mgh=\dfrac12mv^2$ 解出 $v$ 是多少？
总结句：洛伦兹力只改变速度方向不改变大小；只有重力做功时机械能守恒。

## 9
本题考点：直线电流磁场方向；磁感应强度矢量叠加；洛伦兹力 $F=evB$ 与 $B$ 成正比。
已知：$M$ 处电流垂直纸面向里，$N$ 处电流垂直纸面向外，电流大小相等，$\angle MOP=60^\circ$，电子束在 $O$ 处垂直纸面向里运动。
提问路线：
1. 问：$M$、$N$ 到 $O$ 距离相等，它们在 $O$ 处产生的磁场方向分别朝哪？ → 期望：都竖直向下，大小相等，设各为 $\dfrac{B_1}{2}$，合磁场 $B_1$。
2. 问：电子速度方向垂直纸面，与磁场垂直吗？$F_1$ 等于什么？ → 期望：垂直，$F_1=evB_1$。
3. 问：把 $M$ 处导线移到 $P$ 处，它在 $O$ 处的磁场方向转过了多少度？两个磁场的夹角是多少？ → 期望：转过 $60^\circ$，两磁场夹角 $60^\circ$。
4. 问：合磁场多大？$F_2:F_1$ 是多少？ → 期望：$B_2=2\times\dfrac{B_1}{2}\cos30^\circ=\dfrac{\sqrt3}{2}B_1$，$F_2:F_1=\sqrt3:2$，选 B。
常见错误：
- 认为 $O$ 处两磁场方向相反、抵消。追问：$M$ 中电流向里、$N$ 中电流向外，分别用安培定则看在 $O$ 处的磁场方向。
- 夹角算成 $120^\circ$ 得 1∶2。追问：导线从 $M$ 移到 $P$，绕 $O$ 转了多少度？它的磁场方向随之转多少度？
总结句：多根导线的磁场先逐个定方向再按平行四边形合成；洛伦兹力与合磁感应强度成正比。

## 10
本题考点：左手定则（负电荷）；洛伦兹力随速度变化引起的变加速运动；收尾速度。
已知：物块带 $-q$，贴墙由静止下滑，磁场垂直纸面向里，动摩擦因数 $\mu$。
提问路线：
1. 问：物块向下运动、带负电，等效电流朝哪？洛伦兹力朝哪？ → 期望：等效电流向上，洛伦兹力水平向左，压向墙壁，A 错。
2. 问：墙对物块的支持力和摩擦力各多大？摩擦力与速度什么关系？ → 期望：$F_N=qvB$，$F_f=\mu qvB$，与速度成正比，C 对。
3. 问：写出加速度表达式，什么时候加速度最大？ → 期望：$a=\dfrac{mg-\mu qvB}{m}$，刚释放 $v=0$ 时最大为 $g$，B 对。
4. 问：速度增大时加速度怎样变？最大速度多大？ → 期望：加速度减小，$\mu qvB=mg$ 时速度最大，$v_m=\dfrac{mg}{\mu qB}$，D 错。选 BC。
常见错误：
- 洛伦兹力判成向右，认为物块离开墙。追问：负电荷向下运动，相当于电流朝哪？
- 最大速度写成 $\dfrac{\mu mg}{qB}$。追问：平衡式 $\mu qvB=mg$ 中解出 $v$，$\mu$ 在分子还是分母？
总结句：洛伦兹力随速度变化，会使正压力、摩擦力随之变化，物体做加速度变化的运动，最后达到收尾速度。

## 11
本题考点：洛伦兹力与重力的比较；摩擦力随速度变化；由受力分析判断 $v-t$ 图像形状。
已知：圆环带 $+q$，套在水平粗糙杆上，磁场向里，初速度 $v_0$ 向右；A 为水平直线，B 为匀减速直线到零，C 为加速度逐渐减小的减速到零，D 为减速到某一值后匀速。
提问路线：
1. 问：圆环向右运动，洛伦兹力朝哪？大小是多少？ → 期望：竖直向上，$qv_0B$。
2. 问：如果 $qv_0B=mg$，杆对环有弹力吗？有摩擦吗？环做什么运动？ → 期望：没有弹力和摩擦，匀速直线运动，A 可能。
3. 问：如果 $qv_0B>mg$，弹力朝哪？速度减小时摩擦力怎样变？最后会怎样？ → 期望：杆对环的弹力向下，$F_N=qvB-mg$；速度减小摩擦力减小，加速度减小，直到 $qvB=mg$ 后匀速，D 可能。
4. 问：如果 $qv_0B<mg$，速度减小时弹力和摩擦力怎样变？加速度变大还是变小？ → 期望：$F_N=mg-qvB$ 增大，摩擦力增大，加速度增大，图线越来越陡，直到停止；B（加速度不变）和 C（加速度减小）都不符合。所以选 AD。
常见错误：
- 认为 C 正确。追问：$qv_0B<mg$ 时速度越小，摩擦力越大还是越小？$v-t$ 图线应越来越陡还是越来越平？
- 认为摩擦力不变（选 B）。追问：正压力与速度有关吗？
总结句：带电体在粗糙面上运动时，洛伦兹力改变正压力和摩擦力，要分 $qvB$ 大于、等于、小于 $mg$ 三种情况讨论。

## 12
本题考点：洛伦兹力随速度变化；弹力方向改变的临界点；最大加速度与最大速度。
已知：小球带 $-q$，沿倾角 $37^\circ$ 的杆下滑，$\mu=0.5$，$\dfrac{mg}{qB}=10$ m/s，磁场向里。
提问路线：
1. 问：小球沿杆向下运动，带负电，洛伦兹力朝哪？ → 期望：垂直杆向上（背离杆）。
2. 问：开始速度很小，杆对球的弹力朝哪？写出垂直杆方向的平衡式和沿杆的牛顿第二定律。 → 期望：弹力垂直杆向上；$F_N+qvB=mg\cos\theta$，$mg\sin\theta-\mu F_N=ma$。
3. 问：速度增大时弹力怎样变？什么时候摩擦力为零、加速度最大？最大加速度多少？ → 期望：弹力减小，弹力为零时摩擦为零，$a_{\max}=g\sin37^\circ=6\ \text{m/s}^2$。
4. 问：（2）此时 $qvB$ 等于什么？速度多大？ → 期望：$qvB=mg\cos37^\circ$，$v=10\times0.8=8$ m/s。
5. 问：（3）速度再增大，弹力朝哪？摩擦力怎样变？什么时候速度最大？ → 期望：弹力反向（垂直杆向下），$F_N'=qvB-mg\cos\theta$，摩擦力增大，加速度减小；$a=0$ 时速度最大。
6. 问：列出最大速度时的平衡式，解出 $v_m$。 → 期望：$mg\sin\theta=\mu(qv_mB-mg\cos\theta)$，$v_m=10\times(1.2+0.8)=20$ m/s。
常见错误：
- 认为开始时加速度最大。追问：开始时摩擦力是最大还是最小？加速度呢？
- 最大速度时仍用 $F_N=mg\cos\theta-qvB$。追问：$qvB$ 超过 $mg\cos\theta$ 后，杆对球的弹力还朝原来的方向吗？
- 洛伦兹力方向判错。追问：负电荷沿杆向下运动，等效电流沿哪个方向？
总结句：洛伦兹力随速度增大，弹力先减小到零再反向增大，所以加速度先增大后减小；弹力为零时加速度最大，加速度为零时速度最大。
