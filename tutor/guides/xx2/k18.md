# 选修二 k18 · 问答脚本

## 1
本题考点：互感；能量传输中的损耗；感生电场驱动电子。
提问路线（每次只问一个问题）：
1. 问：基座线圈通的是变化的电流，手表线圈里为什么会有电流？这叫什么现象？ → 期望：基座线圈电流变化产生变化的磁场，手表线圈磁通量变化产生感应电流，是互感，A 对。
2. 问：基座线圈的磁感线能全部穿过手表线圈吗？传输过程有没有能量损失？ → 期望：有漏磁，还有线圈发热等，存在能量损失，B 错。
3. 问：塑料薄膜会挡住磁场吗？包起来还能充电吗？ → 期望：塑料不影响磁场，仍能充电，C 错。
4. 问：手表线圈中的电子静止，磁场对静止电荷有力吗？真正驱动电子的是什么？ → 期望：磁场对静止电荷无洛伦兹力，是变化磁场产生的感生电场驱动电子，D 错。选 A。
常见错误：
- 认为无导线就没有损耗。追问：基座线圈产生的磁场是不是全部穿过了手表线圈？
- 认为磁场直接推动电子。追问：电子在手表线圈里原本静止，洛伦兹力 $qvB$ 中 $v$ 是多少？
总结句：无线充电靠互感：变化的电流 → 变化的磁场 → 感生电场 → 另一个线圈中的感应电流；过程中有漏磁和发热损耗。

## 2
本题考点：互感中的楞次定律；磁场先减小后反向增大时感应电流方向不变。
已知：开关原接 1，扳到 2 后线圈 A 中电流反向（两个电源方向相反），线圈 B 接电阻 $R$。
提问路线：
1. 问：开关接 1 时线圈 A 中的磁场朝哪？扳到 2 后呢？ → 期望：接 1 时向右，接 2 后两电源极性相反，A 中电流反向，磁场变为向左。
2. 问：磁场从向右变为向左，经历了哪两个阶段？穿过 B 的磁通量怎样变？ → 期望：先向右减小，后向左增大。
3. 问：向右的磁通量减小时，B 中感应电流的磁场朝哪？向左的增大时呢？两次一样吗？ → 期望：都向右，感应磁场方向相同，所以电流方向始终相同。
4. 问：结合 B 的绕向，$R$ 中电流始终是哪个方向？ → 期望：始终由 $Q$ 到 $P$，选 C。
常见错误：
- 认为电流先后反向（选 A、B）。追问：“向右减小”和“向左增大”，原磁场的变化趋势在楞次定律看来是不是同一种？
总结句：原磁场“减小后反向增大”时，感应磁场方向始终不变，感应电流方向也不变。

## 3
本题考点：互感中频率不变；漏磁使两个线圈磁通量变化率不等；金属板中的涡流损耗与屏蔽；耦合程度影响电压比。
提问路线：
1. 问：接收线圈中电流的频率由什么决定？跟两线圈距离有关吗？ → 期望：由发射线圈电流的频率决定，与距离无关，A 错。
2. 问：发射线圈的磁感线能全部穿过接收线圈吗？两线圈的磁通量变化率相等吗？ → 期望：有漏磁，不相等，B 错。
3. 问：在接收线圈下加金属板，金属板里会产生什么？对充电有利吗？ → 期望：产生涡流消耗能量，还会削弱磁场，充电效果变差，C 错。
4. 问：两线圈靠得更近，穿过接收线圈的磁通量怎样变？接收线圈电压怎样变？电压之比会变吗？ → 期望：磁通量增大，接收线圈电动势增大，两线圈电压之比改变，D 对。选 D。
常见错误：
- 认为距离会改变频率。追问：感应电流跟着谁的变化而变化？
- 按理想变压器认为电压比只由匝数决定。追问：两线圈之间隔着空气，有没有漏磁？
总结句：互感传输的频率不变；线圈间的耦合程度（距离、漏磁）会影响接收端电压；附近的金属会产生涡流损耗。

## 4
本题考点：自感的本质；自感电动势的方向（阻碍电流变化）、大小（与电流变化快慢有关）；铁芯增大自感系数。
提问路线：
1. 问：自感现象是由什么引起的？本质上属于什么现象？ → 期望：线圈自身电流变化引起，本质是电磁感应，A 对。
2. 问：电流增大时自感电动势与原电流同向还是反向？电流减小时呢？ → 期望：增大时反向，减小时同向，不总是相反，B 错。
3. 问：自感电动势大小与磁通量变化的“大小”有关，还是与变化的“快慢”有关？ → 期望：与变化快慢有关，C 错。
4. 问：线圈加铁芯后自感系数变大还是变小？ → 期望：变大，D 错。选 A。
常见错误：
- 认为自感电动势总与原电流反向。追问：断电时线圈要“阻碍电流减小”，它产生的电动势是帮原电流还是反对原电流？
- 混淆变化量和变化率。追问：法拉第电磁感应定律中电动势与 $\Delta\Phi$ 成正比还是与 $\dfrac{\Delta\Phi}{\Delta t}$ 成正比？
总结句：自感电动势总是阻碍电流的变化：增大时反向、减小时同向，大小与电流变化率成正比，铁芯使自感系数增大。

## 5
本题考点：双线绕法使回路磁通量为零，因而没有自感。
提问路线：
1. 问：双线绕法中，同一时刻相邻两股导线里的电流方向有什么关系？ → 期望：大小相等、方向相反。
2. 问：两股反向电流产生的磁场叠加后，穿过回路的磁通量是多少？电流变化时磁通量变吗？ → 期望：相互抵消，磁通量始终为零，不随电流变化。
3. 问：磁通量不变，会产生自感电动势吗？所以双线绕法的原理是哪一项？ → 期望：不会产生自感电动势，原理是两股导线产生的磁通量相互抵消，选 C。
常见错误：
- 选 A，认为先产生电动势再抵消。追问：磁通量一直是零，还会产生自感电动势吗？
- 选 D，认为电流变化量抵消。追问：电路中电流变化了，变化量会消失吗？
总结句：消除自感的关键是让电流产生的磁通量相互抵消，磁通量不变就没有自感电动势。

## 6
本题考点：通电自感（线圈所在支路电流逐渐增大）；断电自感（线圈与灯组成回路，电流从原值逐渐减小）。
已知：$L$ 与 B 灯串联，A 灯单独一条支路，两支路并联接电源；$L$ 自感系数大、直流电阻可忽略，两灯相同。
提问路线：
1. 问：闭合 S 瞬间，哪个灯所在支路有线圈？那条支路的电流能立即增大吗？哪个灯先亮？ → 期望：B 与 $L$ 串联，电流逐渐增大，A 灯先亮、B 灯逐渐变亮，A、B 错。
2. 问：稳定后线圈相当于导线，两条支路电阻相同吗？最后两灯亮度相比如何？ → 期望：相同，最后一样亮，C 错。
3. 问：断开 S 后，线圈、B、A 组成什么回路？回路中电流从多大开始减小？两灯会怎样熄灭？ → 期望：组成闭合回路，电流从线圈原来的电流（等于两灯原电流）开始逐渐减小，两灯同时慢慢熄灭，不闪亮，D 对。选 D。
常见错误：
- 认为断开时 A 灯会闪亮。追问：断开前通过 A 的电流与线圈中的电流哪个大？
- 认为闭合时两灯同时亮。追问：线圈会阻碍哪条支路的电流增大？
总结句：通电自感看线圈所在支路“慢慢变亮”；断电自感看线圈原电流，电流从线圈原电流开始减小，比灯原电流大才会闪亮。

## 7
本题考点：通电、断电自感；断电时线圈相当于电源，电流方向不变；电源内部电流从低电势流向高电势；自感电动势可大于电源电动势。
已知：B、C 两灯串联为一支路；$L$ 与 A 串联为另一支路；三灯相同，$L$ 直流电阻不计，电源内阻不计。
提问路线：
1. 问：闭合瞬间，哪条支路的电流会被线圈阻碍？A 灯是立即亮还是逐渐变亮？稳定后 A 与 B、C 比哪个亮？ → 期望：A 逐渐变亮，稳定后 A 支路只有一个灯，电流更大，A 比 B、C 亮，不会熄灭，A 错。
2. 问：断开瞬间，线圈中的电流方向会立即改变吗？A 灯电流方向变吗？ → 期望：线圈阻碍电流减小，电流方向不变，A 灯电流不反向，B 错。
3. 问：此时线圈相当于电源，电流在线圈内部从 $a$ 流向 $b$，电源内部电流从低电势流向高电势，哪点电势高？ → 期望：$b$ 点电势高于 $a$ 点，C 错。
4. 问：断开瞬间线圈电流仍为 $I_A=\dfrac ER$，这个电流要流过 A、B、C 三个灯，需要多大的电动势？和 $E$ 比？ → 期望：需要 $3I_AR=3E$，大于电源电动势，D 对。选 D。
常见错误：
- 认为断开时线圈电流反向。追问：自感电动势阻碍的是电流的什么？
- 用外电路的规律判断线圈两端电势。追问：断开时线圈是用电器还是电源？电源内部电流的方向与电势高低有什么关系？
总结句：断电自感时线圈是电源，电流方向保持、大小从原值开始减小；它可以产生比原电源更大的电动势。

## 8
本题考点：电容单位换算；$Q=CU$；自感系数的单位；自感电动势与电流变化率有关。
提问路线：
1. 问：1 μF 等于多少法拉？4.7 μF 呢？ → 期望：$1\ \mu\text{F}=10^{-6}\ \text{F}$，$4.7\ \mu\text{F}=4.7\times10^{-6}\ \text{F}$，A 错。
2. 问：自感线圈外壳上“1 H”表示什么？ → 期望：自感系数为 1 H，B 对。
3. 问：电容器加 20 V 电压时带电荷量多少？ → 期望：$Q=CU=4.7\times10^{-6}\times20\ \text{C}=9.4\times10^{-5}\ \text{C}$，C 对。
4. 问：自感电动势 $E=L\dfrac{\Delta I}{\Delta t}$，与电流本身大小有关吗？ → 期望：只与电流变化率有关，与电流大小无关，D 错。选 BC。
常见错误：
- μ 当成 $10^{-12}$。追问：μ、n、p 分别是 10 的负几次方？
- 认为电流越大自感电动势越大。追问：电流很大但不变时，有自感电动势吗？
总结句：μ 是 $10^{-6}$；$Q=CU$；自感电动势 $E=L\dfrac{\Delta I}{\Delta t}$，只看电流变化快慢。

## 9
本题考点：断开开关时 b 线圈中的感应电流阻碍磁通量减小，使铁芯保持磁性（延时）。
已知：a 线圈接电源和开关 S，b 线圈自身闭合，两线圈绕在同一铁芯上；衔铁 d 被铁芯吸住时触头 c 接通。
提问路线：
1. 问：断开 S 时 a 线圈电流消失，铁芯中的磁通量要减小。b 线圈中会发生什么？ → 期望：b 线圈磁通量减小，产生感应电流，其磁场阻碍磁通量减小，铁芯仍保持一段时间磁性，所以衔铁延时释放。
2. 问：电源正负极颠倒或 a 线圈绕向反向，只改变了什么？b 线圈的阻碍作用还在吗？ → 期望：只改变磁场方向，b 仍会阻碍磁通量减小，不影响延时，A、B 错。
3. 问：b 线圈绕向反向，感应电流还会阻碍磁通量减小吗？ → 期望：仍然阻碍，延时效果不变，C 错。
4. 问：如果 b 线圈不闭合，还有感应电流吗？还有延时吗？ → 期望：没有感应电流，铁芯磁性立即消失，没有延时，D 对。选 D。
常见错误：
- 认为改变绕向会让感应电流“帮倒忙”。追问：楞次定律中感应电流的效果与绕向有关吗？
- 认为延时是 a 线圈的自感造成的。追问：S 断开后 a 线圈所在电路还闭合吗？
总结句：延时继电器靠闭合的 b 线圈产生感应电流阻碍磁通量减小；只要 b 闭合就有延时，与绕向、电源方向无关。

## 10
本题考点：通电时线圈支路电流逐渐增大 → 总电流增大 → 路端电压减小；断电时线圈电流流过灯泡 D，方向与原来相反、大小从 $I_L$ 开始减小。
已知：$L$ 与 $R$ 串联为一支路，灯 D 为另一支路，$U_{AB}$ 即 D 两端电压；$L$ 电阻不计，$R$ 大于灯泡电阻。
提问路线：
1. 问：闭合瞬间线圈支路相当于断路还是通路？之后线圈支路电流怎样变？外电路总电阻怎样变？ → 期望：开始相当于断路，之后电流逐渐增大，外电阻逐渐减小。
2. 问：外电阻减小，总电流和路端电压 $U_{AB}=E-Ir$ 怎样变？ → 期望：总电流增大，$U_{AB}$ 从较大值逐渐减小到稳定值。
3. 问：稳定后，$R>R_D$，线圈支路电流 $I_L$ 与灯泡电流 $I_D$ 哪个大？ → 期望：$I_L<I_D$。
4. 问：断开 S 后，线圈电流 $I_L$ 流过灯 D 的方向与原来相同还是相反？$U_{AB}$ 变为正还是负？大小怎样变？对应哪个图？ → 期望：反向流过 D，$U_{AB}$ 变为负值，大小从 $I_LR_D$（小于原来）开始逐渐减小到零，选 B。
常见错误：
- 认为闭合后 $U_{AB}$ 逐渐增大。追问：线圈支路电流增大，相当于外电路多了一条通路，总电流和内电压怎样变？
- 认为断开后 D 中电流方向不变。追问：断开后线圈的电流从 $A$ 端还是 $B$ 端流入灯泡？
- 认为断开时 $U_{AB}$ 绝对值先变大。追问：$I_L$ 与 $I_D$ 哪个大？
总结句：通电自感看线圈支路电流逐渐增大带来的电路变化；断电自感看线圈电流流过另一支路的方向和起始大小。

## 11
本题考点：通电自感；断电时两支路串成回路，电流相等，电流表指针方向一个不变一个反向。
已知：$L$ 与 A 灯、电流表 $\mathrm{A_1}$ 串联；$R$ 与 B 灯、电流表 $\mathrm{A_2}$ 串联；调节后两灯亮度相同（稳定时两支路电流相等）。
提问路线：
1. 问：闭合 S 瞬间，哪个灯立即亮，哪个灯逐渐变亮？两个电流表示数相等吗？ → 期望：B 立即亮，A 逐渐变亮；此时 $\mathrm{A_1}$ 示数小于 $\mathrm{A_2}$，A 对 B 错。
2. 问：稳定后两支路电流相等。断开 S 后，两支路组成什么回路？通过 B 的电流从多大开始减小？B 会闪亮吗？ → 期望：组成闭合回路，电流从原来的 $I$ 开始减小，B 不会闪亮，C 错。
3. 问：断开后，$\mathrm{A_1}$ 中电流方向变吗？$\mathrm{A_2}$ 中电流方向呢？指针偏转方向相同吗？ → 期望：$\mathrm{A_1}$ 方向不变，$\mathrm{A_2}$ 反向，指针偏转方向相反，D 错。选 A。
常见错误：
- 认为断开时 B 灯闪亮。追问：断开前通过 B 的电流与线圈电流哪个大？
- 认为两表都不反向。追问：断开后电流在回路中绕一圈，经过 $\mathrm{A_2}$ 时与原来同向吗？
总结句：断电自感中，线圈所在支路电流方向不变，另一支路电流反向；闪不闪亮看线圈原电流是否大于灯的原电流。

## 12
本题考点：通电时传感器支路电流先大后减小；断电时线圈电流反向流过传感器，起始值为 $I_L<I_D$。
已知：$R$ 与 $L$ 串联为一支路，电流传感器与灯 D 串联为另一支路；规定电流向左经过传感器为正；$R>R_D$。
提问路线：
1. 问：闭合瞬间，线圈支路电流很小，传感器支路电流怎样？之后线圈支路电流增大，传感器支路电流怎样变？ → 期望：开始传感器电流较大，之后（因总电流增大、路端电压下降）逐渐减小到稳定值，为正值。
2. 问：稳定时 $I_L$ 与 $I_D$ 哪个大？ → 期望：$R>R_D$，$I_L<I_D$。
3. 问：断开 S 后，线圈电流流过传感器的方向与原来相同还是相反？起始值多大？ → 期望：相反，为负值，起始大小为 $I_L$，小于原来的 $I_D$，然后逐渐减到零。
4. 问：哪个图符合“正值逐渐减小、断开后突变为较小的负值再趋于零”？ → 期望：选 D。
常见错误：
- 认为闭合后传感器电流逐渐增大（选 A、B）。追问：线圈支路电流增大后，路端电压怎样变？灯泡支路电流呢？
- 认为断开后负值大小大于原来正值（选 C）。追问：断开后流过传感器的电流等于哪条支路原来的电流？
总结句：断电自感中，另一支路的电流突变为反向的线圈电流 $I_L$，再逐渐减小；闪不闪、跳多大都由 $I_L$ 决定。

## 13
本题考点：利用断电自感产生高电压（升压电路）；二极管的单向导电性。
已知：回收系统输出电压 $U$ 低于电池充电电压 $U_0$；四个电路中线圈、开关、二极管的位置不同。
提问路线：
1. 问：要把电充进电压更高的电池，需要在电池两端得到比 $U$ 更高的电压。线圈在什么时候能产生很大的电动势？ → 期望：电流突然减小（开关断开）时，线圈产生自感电动势阻碍电流减小。
2. 问：A 中开关断开时整个电路都断了，线圈的电流还能流向电池吗？ → 期望：不能，A 错。
3. 问：B 中开关闭合时，线圈和开关构成回路，线圈中储存电流；断开时线圈电流去哪？电池两端的电压是谁提供的？ → 期望：线圈电流经二极管流入电池，$U$ 与自感电动势串联叠加，能给高压电池充电，B 对。
4. 问：C 中开关断开时线圈也被断开，D 中开关断开时电源 $U$ 被断开，能实现 $U$ 与自感电动势叠加吗？ → 期望：都不能，C、D 错。选 B。
常见错误：
- 只看有没有线圈，不看开关断开后线圈电流能不能流到电池。追问：开关断开后，线圈中的电流有通路吗？经过哪些元件？
- 忽略二极管方向。追问：二极管允许电流从哪个方向通过？开关闭合时电池会不会反向放电？
总结句：升压的关键是开关断开时线圈的自感电动势与电源串联，并有通路（经二极管）流向高压电池。
