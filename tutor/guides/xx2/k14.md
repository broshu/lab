# 选修二 k14 · 问答脚本

## 1
本题考点：转动切割的电动势 $E=\dfrac12B\omega r^2$；楞次定律；总电阻的计算；电功率。
已知：$MN$ 上方磁场 $B_0$ 向里，半圆形线框（半圆弧 + 直径，同种材料，单位长度电阻 $R_0$）绕圆心 $O$ 逆时针匀速转动半周，开始时直径在 $MN$ 上、半圆在上方。
提问路线（每次只问一个问题）：
1. 问：转动半周的过程中，线框在磁场中的面积怎样变？磁通量呢？ → 期望：在磁场中的部分越来越少，磁通量减少，A 错。
2. 问：磁场向里减少，感应电流方向？ → 期望：感应磁场向里，顺时针，B 错。
3. 问：哪部分在切割磁感线？电动势多大？ → 期望：直径中位于 $MN$ 上方的那半条半径在磁场中转动切割，$E=\dfrac12B_0\omega r^2$，C 对。
4. 问：线框总电阻是多少？发热功率呢？ → 期望：$R=(2r+\pi r)R_0$，$P=\dfrac{E^2}{R}=\dfrac{B_0^2r^3\omega^2}{4(\pi+2)R_0}$，D 错。选 C。
常见错误：
- 电动势用 $B_0\omega r^2$ 或用整条直径算。追问：转动过程中，直径的哪部分在磁场里？绕端点转动的导体棒电动势公式是什么？
- 总电阻只算半圆。追问：线框由哪两部分组成？
总结句：转动切割取在磁场中那段导体，$E=\dfrac12B\omega L^2$；电阻要算整个回路。

## 2
本题考点：电荷量 $q=N\dfrac{\Delta\Phi}{R}$；翻转 180° 时磁通量的变化量。
已知：$N$ 匝线圈，面积 $S$，电阻 $R$，开始时线圈平面与磁场垂直。
提问路线：
1. 问：通过导线横截面的电荷量用什么公式？推导一下。 → 期望：$q=\overline I\Delta t=\dfrac{\overline E}{R}\Delta t=N\dfrac{\Delta\Phi}{R}$。
2. 问：翻转 180° 前后，磁通量分别是多少？变化量是多少？ → 期望：从 $BS$ 变为 $-BS$，$\Delta\Phi=2BS$。
3. 问：电荷量多大？ → 期望：$q=\dfrac{2NBS}{R}$，选 B。
常见错误：
- $\Delta\Phi$ 取 0 或 $BS$。追问：翻转后磁感线从线圈的哪一面穿过？磁通量的正负怎样？
- 漏掉匝数。追问：$N$ 匝线圈的电动势是单匝的几倍？
总结句：电荷量 $q=N\dfrac{\Delta\Phi}{R}$ 只与磁通量变化量有关，与快慢无关；翻转 180° 时 $\Delta\Phi=2BS$。

## 3
本题考点：$E=Blv$；$I=\dfrac ER$；焦耳热 $Q=I^2Rt$；电荷量 $q=\dfrac{\Delta\Phi}{R}$ 与速度无关。
已知：$v_1=2v_2$，两次都匀速把线圈拉出磁场。
提问路线：
1. 问：电动势和电流之比各是多少？ → 期望：都与 $v$ 成正比，都是 $2:1$，A、B 错。
2. 问：拉出所用时间之比？焦耳热之比？ → 期望：时间 $1:2$；$Q=I^2Rt\propto v^2\cdot\dfrac1v=v$，$Q_1:Q_2=2:1$，C 对。
3. 问：电荷量与速度有关吗？比值是多少？ → 期望：$q=\dfrac{\Delta\Phi}{R}$ 相同，$1:1$，D 错。选 C。
常见错误：
- 认为焦耳热之比是 $4:1$。追问：电流变成 2 倍，时间变成多少？
- 认为电荷量与电流成正比。追问：电荷量等于电流乘以什么？时间变了吗？
总结句：拉出同一线圈：$E$、$I$、$F$、$Q$ 都与 $v$ 成正比（$P$ 与 $v^2$ 成正比），电荷量与 $v$ 无关。

## 4
本题考点：磁场只在部分区域时用磁场面积求磁通量；$E=n\dfrac{\Delta B}{\Delta t}S$；楞次定律判断电流正负；闭合电路欧姆定律。
已知：线圈 100 匝、半径 $r_1=0.5$ m、电阻 10 Ω；磁场只在半径 $r_2=0.4$ m 的区域内；$R=6$ Ω；向里为正，$B$ 在 $0\sim2\pi$ s 内从 $-2$ T 均匀增大到 $2$ T（之后变化见图）；电流由 $a$ 到 $b$ 为正。
提问路线：
1. 问：在 $t=\pi$ s 附近，磁场先是向外减小、后是向里增大，感应电流方向变不变？经过 $R$ 是正还是负？ → 期望：感应磁场都向外，方向不变；按接线为由 $a$ 到 $b$，为正，A 错。
2. 问：计算磁通量时面积用 $\pi r_1^2$ 还是 $\pi r_2^2$？电动势多大？ → 期望：用有磁场的面积 $\pi r_2^2$；$\dfrac{\Delta B}{\Delta t}=\dfrac{4}{2\pi}$ T/s，$E=100\times\dfrac{2}{\pi}\times0.16\pi=32$ V。
3. 问：电流和 $R$ 两端电压各是多少？ → 期望：$I=\dfrac{32}{6+10}=2$ A，B 错；$U=IR=12$ V，C 对。
4. 问：$0\sim2\pi$ s 内磁通量的变化量是多少（单匝）？ → 期望：$\Delta\Phi=2\times0.16\pi\times2=0.64\pi$ Wb，D 错。选 C。
常见错误：
- 面积用线圈面积。追问：线圈外圈到 $r_2$ 之间有磁场穿过吗？
- 认为 $B=0$ 时电流为零。追问：电流取决于 $B$ 还是 $B$ 的变化率？
总结句：磁通量只算有磁场穿过的面积；$B$ 过零时只要变化率不变，电流就不变。

## 5
本题考点：线框进入磁场的减速过程；动量定理得 $v$ 随 $x$ 线性减小；各物理量图像；$U_{ad}$ 是外电压。
已知：光滑桌面，正方形线框 $abcd$（电阻 $R$，边长设为 $L$），$bc$ 边在 $t=0$ 时与边界重合，以足够大的初速度沿 $x$ 正方向进入；A 为 $F-x$ 曲线，B 为 $q-t$ 先直线后水平，C 为 $I-v$ 过原点的直线，D 为 $U_{ad}-x$ 先下降的直线后突变为水平线。
提问路线：
1. 问：进入过程中，对线框用动量定理，$v$ 与 $x$ 是什么关系？ → 期望：$-\dfrac{B^2L^2}{R}x=mv-mv_0$，$v=v_0-\dfrac{B^2L^2}{mR}x$，$v$ 随 $x$ 线性减小。
2. 问：安培力 $F=\dfrac{B^2L^2v}{R}$ 随 $x$ 怎样变？A 图对吗？ → 期望：随 $x$ 线性减小（直线），完全进入后为 0；A 是曲线，错。
3. 问：$I$ 与 $v$ 是什么关系？完全进入后呢？ → 期望：$I=\dfrac{BLv}{R}$，成正比；完全进入后 $I=0$（$v$ 不变），C 对。
4. 问：$q-t$ 图像的斜率表示什么？进入过程中斜率怎样变？ → 期望：斜率是电流，逐渐减小，图线应是弯曲的，B 错。
5. 问：进入时 $bc$ 是电源，$ad$ 两端电压是多少？完全进入后呢？ → 期望：进入时 $U_{ad}=\dfrac14BLv$，随 $x$ 线性减小；完全进入后无电流，$ad$ 边切割，$U_{ad}=BLv$，突然变大后不变，D 对。选 CD。
常见错误：
- 认为 $v$ 随时间线性减小。追问：加速度不变吗？$v$ 随 $x$ 线性，随 $t$ 呢？
- 认为完全进入后 $U_{ad}=0$。追问：没有电流时，切割磁感线的边两端还有电压吗？
总结句：线框在磁场中只受安培力减速时，$v$ 随位移线性减小；完全进入后无电流但两边都有电动势。

## 6
本题考点：转动切割电动势 $E=\dfrac12BL^2\omega$；扇形线框进出磁场的时间；楞次定律判断方向。
已知：扇形半径 $L$、圆心角 $45^\circ$、电阻 $R$，绕磁场边界上的 $O$ 轴匀速转动（方向按图），周期 $T$；顺时针电流为正；四个选项是不同的 $i-t$ 图像。
提问路线：
1. 问：线框从一条半径进入磁场到另一条半径进入磁场要多长时间？这段时间内电动势大小变吗？ → 期望：转过 $45^\circ$，用时 $\dfrac T8$；只有一条半径在切割，$E=\dfrac12BL^2\omega$ 不变，电流大小不变。
2. 问：进入磁场时磁通量增加，感应电流是顺时针还是逆时针？正还是负？ → 期望：逆时针，为负。
3. 问：完全在磁场中时有电流吗？离开磁场时呢？方向如何、持续多久？ → 期望：完全在磁场中磁通量不变，无电流；离开时用时 $\dfrac T8$，磁通量减小，顺时针，为正。
4. 问：哪个图像符合“负 $\dfrac T8$ — 零 — 正 $\dfrac T8$ — 零”的规律？ → 期望：A。
常见错误：
- 认为电流大小随时间变化（选 C、D）。追问：转动时切割磁感线的那条半径长度变吗？电动势变吗？
- 方向判反。追问：进入磁场时磁通量增加还是减少？
总结句：扇形线框绕圆心转动，进出磁场时只有一条半径切割，电动势恒定；进出时电流方向相反。

## 7
本题考点：由 $B-t$ 图像斜率判断电流大小；楞次定律判断方向；最大发热功率；电荷量 $q=\dfrac{\Delta\Phi}{R}$。
已知：圆环面积 0.1 m²，电阻 0.2 Ω；第 1 s 内电流从上往下看为顺时针；$B-t$ 图像 $0\sim4$ s 为曲线（2 s 时达最大 0.1 T，斜率为 0），$4\sim5$ s 为直线，从 0 到 $-0.1$ T。
提问路线：
1. 问：感应电流大小由什么决定？0～5 s 内斜率的绝对值怎样变？电流呢？ → 期望：由 $\dfrac{\Delta B}{\Delta t}$ 决定；斜率绝对值先减小（2 s 时为零）再增大，4～5 s 不变，所以电流先减小再增大最后不变，A 错。
2. 问：第 1 s 内电流顺时针，说明原磁场方向朝哪？（$B$ 为正、增大） → 期望：感应磁场向下，原磁场增大，所以原磁场向上，向上为正。
3. 问：2～4 s 内 $B$ 向上减小、4～5 s 内向下增大，感应磁场朝哪？电流方向？ → 期望：感应磁场都向上，从上往下看为逆时针，B 错。
4. 问：最大电流出现在哪段？最大发热功率多少？ → 期望：4～5 s，$\dfrac{\Delta B}{\Delta t}=0.1$ T/s，$I_m=\dfrac{0.1\times0.1}{0.2}=0.05$ A，$P_m=I_m^2R=5.0\times10^{-4}$ W，C 对。
5. 问：0～2 s 内的电荷量是多少？ → 期望：$q=\dfrac{\Delta BS}{R}=\dfrac{0.1\times0.1}{0.2}=5.0\times10^{-2}$ C，D 错。选 C。
常见错误：
- 认为 $B$ 最大时电流最大。追问：2 s 时图线的切线斜率是多少？
- 电荷量算错数量级。追问：$q=\dfrac{\Delta\Phi}{R}$，$\Delta\Phi$ 等于多少？
总结句：电流看 $B-t$ 图像斜率的大小，方向看磁通量是增是减；电荷量只看磁通量变化量。

## 8
本题考点：只有半个圆环在磁场中的感生电动势；电荷量；安培力的有效长度。
已知：圆环半径 $r=2$ m、电阻 $R=2$ Ω，圆心 $O$ 在磁场边界上，直径 $AB$ 与边界重合，磁场在边界右侧（半个圆环在磁场中）；向下为正，$B$ 在 0～2 s 从 $-2$ T 均匀变为 2 T，2～4 s 从 2 T 均匀变为 $-2$ T。
提问路线：
1. 问：（1）0～2 s 内磁感应强度变化率是多少？有磁场的面积是多少？电动势多大？ → 期望：$\dfrac{\Delta B}{\Delta t}=2$ T/s；$S=\dfrac12\pi r^2=2\pi\ \text{m}^2$；$E=4\pi$ V。
2. 问：电流和 0～2 s 内的电荷量各是多少？ → 期望：$I=\dfrac ER=2\pi$ A，$q=It=4\pi$ C。
3. 问：（2）$t=2.5$ s 时电流大小变了吗？此时 $B$ 是多少？ → 期望：2～4 s 变化率大小相同，电流仍为 $2\pi$ A；$B=1$ T。
4. 问：在磁场中的半圆环受安培力的有效长度是多少？安培力多大？ → 期望：有效长度为直径 $2r=4$ m，$F=BIL=8\pi$ N。
5. 问：2.5 s 时 $B>0$（向下）且在减小，磁通量减小，圆环受力会使它向哪边运动以阻碍磁通量减小？ → 期望：圆环有更多部分进入磁场的趋势，即向右运动，安培力方向垂直 $AB$ 向右（也可先判断电流方向再用左手定则）。
常见错误：
- 面积用整个圆。追问：圆环有多少面积在磁场里？
- 安培力长度用半圆弧长。追问：弯曲导线受的安培力怎样求有效长度？
总结句：部分在磁场中的线圈：电动势用磁场中的面积算，安培力用磁场中导线首尾连线的长度算。

## 9
本题考点：两侧反向磁场中同时切割的电动势叠加；楞次定律；安培力与加速度；电荷量；电功率。
已知：$PQ$ 左侧磁场向外、右侧向里，大小都是 $B$；圆环半径 $r$、质量 $m$、电阻 $R$，直径与 $PQ$ 重合时速度为 $\dfrac23v$。
提问路线：
1. 问：此时圆环左半在向外的磁场中、右半在向里的磁场中，向里的磁通量在增加还是减少？感应电流方向？ → 期望：向里的增加（向外的减少），感应磁场向外，逆时针，A 错。
2. 问：左右两半都在切割，有效长度各是多少？两个电动势是相加还是抵消？总电动势多少？ → 期望：各为直径 $2r$，相加，$E=2B\cdot2r\cdot\dfrac23v=\dfrac83Brv$。
3. 问：电流和安培力多大？加速度多大？ → 期望：$I=\dfrac{8Brv}{3R}$；两半各受 $B\cdot2r\cdot I$，同向相加，$F=\dfrac{32B^2r^2v}{3R}$，$a=\dfrac{32B^2r^2v}{3mR}$，B 错。
4. 问：从开始到此时磁通量的变化量是多少？电荷量呢？ → 期望：从 $B\pi r^2$（向外）变为 0，$\Delta\Phi=B\pi r^2$，$q=\dfrac{\pi Br^2}{R}$，C 错。
5. 问：此时电功率是多少？ → 期望：$P=I^2R=\dfrac{64B^2r^2v^2}{9R}$，D 对。选 D。
常见错误：
- 只算一半的电动势。追问：左右两半分别在哪个磁场中？各自的电动势方向在回路中是同向还是反向？
- 电荷量中 $\Delta\Phi$ 算成 $2B\pi r^2$。追问：直径与 $PQ$ 重合时，净磁通量是多少？
总结句：线圈跨越两个反向磁场时，两部分电动势叠加、安培力叠加；净磁通量为零时 $\Delta\Phi$ 只算到零。

## 10
本题考点：有效切割长度随位置变化；楞次定律判断方向；分段分析 $i-t$ 图像。
已知：等腰梯形线框，左边长 $L$、右边长 $3L$，水平宽 $2L$；磁场宽度 $L$；线框向右匀速穿过；逆时针为正；四个选项是 $i-t$ 图像。
提问路线：
1. 问：右边刚进入磁场时，有效切割长度是多少？右边走过磁场的过程中，在磁场中切割的有效长度怎样变？ → 期望：开始为 $3L$；磁场宽 $L$，右边进入后，磁场中的斜边部分越来越多，有效长度从 $3L$ 减小到 $2L$。
2. 问：这段时间磁通量增加还是减少？电流方向？ → 期望：增加，逆时针，为正。
3. 问：右边出磁场后到左边进磁场前，有效切割长度是多少？电流方向？ → 期望：只有两条斜边在磁场中，有效长度为 $L$（上下斜边切割效果相减后的净长度），磁通量减少，电流为顺时针（负）。
4. 问：左边进入磁场到离开的过程中，有效长度怎样变？方向？ → 期望：从 $2L$ 减小到 $L$，磁通量继续减少，顺时针（负）。
5. 问：哪个图像符合：正向电流由 3 份减到 2 份，然后反向 1 份不变，再反向由 2 份减到 1 份？ → 期望：A。
常见错误：
- 把斜边在磁场中的长度当成有效长度。追问：有效切割长度要取在垂直于速度方向上的投影，斜边怎么投影？
- 第二段方向判断错误。追问：右边离开磁场后，线框在磁场中的面积增加还是减少？
总结句：有效切割长度取导线在垂直速度方向上的投影（同一回路中同向切割的相加、反向的相减），方向看磁通量增减。
