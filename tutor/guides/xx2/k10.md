# 选修二 k10 · 问答脚本

## 1
本题考点：电流与磁场平行时不受安培力；$F=BIL$。
已知：磁场水平向右，折线 $abcd$ 中 $ab$、$cd$ 与磁场平行，$bc$ 与磁场垂直，各段长 $L$。
提问路线（每次只问一个问题）：
1. 问：$ab$、$cd$ 两段与磁场平行，受安培力吗？ → 期望：不受。
2. 问：$bc$ 段与磁场垂直，受力多大？ → 期望：$BIL$。
3. 问：整根导线受力多大？ → 期望：只有 $bc$ 段受力，总力 $BIL$，选 A。
常见错误：
- 三段都按 $BIL$ 相加得 $3BIL$。追问：电流与磁场平行时 $\sin\theta$ 等于多少？
- 用有效长度 $ad$ 得 $\sqrt5BIL$。追问：首尾连线 $ad$ 与磁场垂直吗？有效长度应取它在垂直磁场方向上的投影，是多少？
总结句：安培力 $F=BIL\sin\theta$，与磁场平行的导线不受力；有效长度要取垂直于磁场方向的投影。

## 2
本题考点：地磁场的分布；洛伦兹力与夹角的关系；左手定则。
提问路线：
1. 问：地磁场的磁感线是闭合曲线吗？在地球外部从哪里出发回到哪里？ → 期望：闭合；外部从地理南极附近出发回到地理北极附近，内部再回去，不是“终止于”北极，A 错。
2. 问：两极附近和赤道附近，地磁场方向与竖直射来的粒子速度分别是什么关系？ → 期望：两极接近平行，赤道接近垂直。
3. 问：哪里洛伦兹力大、阻挡作用强？ → 期望：赤道附近最强，两极最弱，C 对、B 错。
4. 问：赤道平面内射来的粒子受力在什么方向？会向两极偏吗？ → 期望：受力在东西方向，向东或向西偏，不会向两极偏，D 错。选 C。
常见错误：
- 认为两极磁场强所以阻挡强。追问：$F=qvB\sin\theta$，两极处 $\theta$ 接近多少？
- 认为磁感线有起点终点。追问：磁感线是闭合曲线还是像电场线那样有起点终点？
总结句：粒子速度与磁场越接近垂直，洛伦兹力越大，地磁场的阻挡作用在赤道附近最强。

## 3
本题考点：磁电式电流表的辐向磁场；左手定则；安培力大小不变但方向改变。
已知：导线 a 电流垂直纸面向里，受到的安培力竖直向上（图乙）。
提问路线：
1. 问：a 中电流向里、安培力向上，用左手定则，a 处磁场朝哪？ → 期望：水平向左，A 错。
2. 问：圆柱内的磁感线能全部穿过圆心吗？磁感线能相交吗？ → 期望：磁感线不能相交，不可能都过圆心，B 错。
3. 问：线圈转过一个小角度，导线处的磁场大小和方向变吗？安培力呢？ → 期望：大小不变（辐向磁场大小相等），方向随位置改变，所以安培力大小不变方向改变，C 错（力是矢量）。
4. 问：线圈平面与所在处磁场总是什么关系？安培力与线圈平面呢？ → 期望：线圈平面总与磁场平行，安培力总垂直于线圈平面，D 对。选 D。
常见错误：
- 认为安培力大小不变就是“不变”。追问：力是矢量，方向变了算不变吗？
- 磁场方向判反。追问：已知力和电流求磁场，左手定则怎样摆手？
总结句：辐向磁场让线圈平面始终与磁场平行，安培力始终垂直线圈平面、大小与转角无关。

## 4
本题考点：左手定则（负电荷）；速度平行磁场不受力；$r=\dfrac{mv}{qB}$；洛伦兹力不做功。
已知：磁场水平向右，虚线上方 $2B$、下方 $B$；a、b 带负电，c 带正电；a 速度大小 $v$、垂直磁场，b 速度 $v$、平行磁场，c 速度 $2v$、垂直磁场。
提问路线：
1. 问：a 带负电，受力大小是多少？用左手定则（四指反向）判断方向。 → 期望：$qvB$，方向垂直纸面向外，A 错。
2. 问：b 的速度与磁场平行，受力吗？做什么运动？ → 期望：不受力，匀速直线运动，B 错。
3. 问：c 从下方（$B$）进入上方（$2B$），半径怎样变？ → 期望：$r=\dfrac{m\cdot2v}{qB'}$，$B'$ 变为 2 倍，半径变为原来的一半，C 错。
4. 问：c 的动能会变吗？ → 期望：洛伦兹力不做功，动能不变，D 对。选 D。
常见错误：
- 负电荷方向没反过来。追问：负电荷运动方向与等效电流方向的关系？
- 半径变化判反。追问：$r$ 与 $B$ 成正比还是反比？
总结句：洛伦兹力不做功；速度与磁场平行不受力；$B$ 加倍半径减半。

## 5
本题考点：$B=\dfrac{kI}{r}$；直线电流磁场方向；矢量合成；左手定则求安培力。
已知：a、b、c 位于等腰直角三角形三个顶点（按图），电流方向如图；b 在 a 处产生的磁场为 $B_1=\dfrac{kI_0}{L}$（$ab=L$）。
提问路线：
1. 问：a、b 连线中点到 a、b 的距离是多少？a、b 各自在中点产生的磁场多大？方向一样吗？ → 期望：$\dfrac L2$，各 $2B_1$；按图中电流方向两者同向，合起来 $4B_1$，再加上 c 的磁场，合场大于 $2B_1$，A 错。
2. 问：b、c 连线中点处，b、c 的磁场关系如何？a 在该点的磁场多大、朝哪？ → 期望：b、c 在该点的磁场等大反向抵消；a 到该点距离 $\dfrac{\sqrt2}{2}L$，磁场 $\sqrt2B_1$，方向竖直向上（不是水平向右），B 错。
3. 问：b、c 在 a 处产生的磁场各多大？合磁场多大、朝哪？a 受力多大、朝哪？ → 期望：各 $B_1$，互相垂直，合为 $\sqrt2B_1$，方向向上；$F_a=\sqrt2B_1I_0L$，由左手定则向左，C 对。
4. 问：c 处合磁场多大？受力朝哪？ → 期望：$B_c=\dfrac{\sqrt2}{2}B_1$，$F_c=\dfrac{\sqrt2}{2}B_1I_0L$，方向水平向右，D 错。选 C。
常见错误：
- 磁场方向沿两导线连线。追问：直线电流在某点的磁场方向与该点到导线的连线是什么关系？
- 距离代错（直角边与斜边混淆）。追问：哪两根导线之间是斜边？斜边长度是多少？
总结句：多导线问题：先用 $B=\dfrac{kI}{r}$ 求每根导线的磁场大小，用安培定则定方向（垂直于连线），再矢量合成。

## 6
本题考点：直线边界磁场中的弦长与半径；同一弦对应优弧和劣弧两条轨迹；周期相同时时间差由圆心角差决定。
已知：磁场在边界上方，向里；粒子源 $O$ 同时沿两个方向发射速率相同的粒子，都经过边界上 $P$ 点，$OP=\dfrac{\sqrt3mv}{qB}$。
提问路线：
1. 问：轨迹半径是多少？$OP$ 与半径什么关系？ → 期望：$r=\dfrac{mv}{qB}$，$OP=\sqrt3r$。
2. 问：弦长 $\sqrt3r$ 对应的圆心角是多少？两条轨迹分别是劣弧和优弧，圆心角各是多少？ → 期望：$2r\sin\dfrac\alpha2=\sqrt3r$，$\alpha=120^\circ$；另一条为 $360^\circ-120^\circ=240^\circ$。
3. 问：周期是多少？时间差是多少？ → 期望：$T=\dfrac{2\pi m}{qB}$，$\Delta t=\dfrac{240^\circ-120^\circ}{360^\circ}T=\dfrac{2\pi m}{3qB}$，选 C。
常见错误：
- 只想到一条轨迹。追问：经过同一条弦的半径相同的圆有几个？在边界上方的轨迹分别对应多大的圆心角？
- 由弦长求圆心角时用 $\cos$。追问：弦长等于 $2r\sin$ 还是 $2r\cos$ 半个圆心角？
总结句：同一边界上两点间的弦，半径一定时对应一大一小两段圆弧，圆心角互补为 $360^\circ$。

## 7
本题考点：霍尔效应；由电势高低判断载流子电性；$U=\dfrac{BI}{nqd}$ 的推导。
已知：元件长 $a$、宽 $c$（前后表面间距）、厚 $d$（磁场方向的尺寸），电流向右，磁场垂直上表面向下，前表面电势高。
提问路线：
1. 问：假设载流子带正电，向右运动、磁场向下，受洛伦兹力偏向哪个表面？哪个表面电势高？与题意符合吗？ → 期望：偏向后表面，后表面电势高，与“前表面电势高”不符，所以载流子带负电，A 错。
2. 问：载流子定向移动速率由什么决定？与磁场有关吗？ → 期望：$I=nqcdv$，$v=\dfrac{I}{nqcd}$，与磁场无关，B 错。
3. 问：稳定时满足什么关系？$U$ 的表达式是什么？ → 期望：$q\dfrac Uc=qvB$，$U=Bvc=\dfrac{BI}{nqd}$。
4. 问：$U$ 与 $d$、$c$ 的关系？ → 期望：与 $d$ 成反比，与 $c$ 无关，C 对，D 错。选 C。
常见错误：
- 用 $U=Bvc$ 就认为 $U$ 与 $c$ 成正比。追问：$v$ 本身与 $c$ 有关吗？代入后 $c$ 还在吗？
- 横截面积取错。追问：电流向右，垂直于电流的截面由哪两个尺寸组成？
总结句：霍尔电压 $U=\dfrac{BI}{nqd}$（$d$ 为沿磁场方向的厚度），由电势高低可以判断载流子的电性。

## 8
本题考点：粒子源向各方向发射；旋转圆法找临界轨迹；平行边界的射出范围。
已知：边界 $MN$、$PQ$ 间距 $d$，磁场向里；$A$ 处粒子源向各方向射入正粒子，$v=\dfrac{2qBd}{3m}$。
提问路线：
1. 问：轨迹半径是多少？和 $d$ 比较呢？ → 期望：$R=\dfrac{mv}{qB}=\dfrac23d<d$。
2. 问：从 $PQ$ 射出的范围两端各是什么临界轨迹？ → 期望：一端是沿 $AN$ 方向（贴着边界）射入的粒子到达 $PQ$ 的点；另一端是轨迹与 $PQ$ 相切的切点。
3. 问：两端到 $A$ 的竖直距离各是多少？$PQ$ 上射出区域长度是多少？ → 期望：都等于 $\sqrt{R^2-(d-R)^2}=\dfrac{\sqrt3}{3}d$，总长 $\dfrac{2\sqrt3}{3}d$。
4. 问：从 $MN$ 射出的最远点离 $A$ 多远？ → 期望：轨迹直径 $2R=\dfrac43d$。
5. 问：两长度之比是多少？ → 期望：$\dfrac{2\sqrt3}{3}d:\dfrac43d=\sqrt3:2$，选 C。
常见错误：
- $MN$ 上的范围也用勾股定理算。追问：粒子回到 $MN$ 时，离 $A$ 最远的情况弦长是多少？
- 不知道 $PQ$ 上的两个端点怎么找。追问：把入射方向从贴着 $AN$ 逐渐转动，轨迹圆怎么变？什么时候刚好碰到 $PQ$？
总结句：粒子源问题用“旋转圆”：半径不变，转动入射方向，找贴边界入射和与边界相切两种临界轨迹。

## 9
本题考点：质谱仪；静电力做功 $W=qU$；速度和半径与质量的关系；电压波动的影响。
提问路线：
1. 问：静电力对两种离子做的功各是多少？ → 期望：都是 $qU$，相等，A 对。
2. 问：进入磁场的速度与质量什么关系？谁的速度大？ → 期望：$v=\sqrt{\dfrac{2qU}{m}}$，质量大的氖 22 速度小，B 错。
3. 问：半径与质量什么关系？ → 期望：$r=\dfrac1B\sqrt{\dfrac{2mU}{q}}$，氖 22 半径大，C 错。
4. 问：如果加速电压波动，两种离子的落点范围可能重叠吗？ → 期望：可能，电压大时氖 20 的半径可以等于电压小时氖 22 的半径，D 错。选 A。
常见错误：
- 认为质量大的速度大。追问：动能相同时，质量大的速度大还是小？
- 认为质量大半径反而小。追问：把 $v$ 代入 $r=\dfrac{mv}{qB}$，$r$ 与 $m$ 是什么关系？
总结句：质谱仪中 $r\propto\sqrt{\dfrac{mU}{q}}$，同种电荷量下质量越大半径越大。

## 10
本题考点：同种粒子周期相同，时间由圆心角决定；从图中判断各点对应的圆心角。
已知：正粒子从 $A$ 垂直 $AB$ 向上射入向外的磁场，速度不同，分别第一次到达 $B$、$C$、$D$、$E$（$AB=DE$，$AB\parallel DE$，$C$ 是 $BD$ 中点）。
提问路线：
1. 问：同种粒子在同一磁场中周期一样吗？时间由什么决定？ → 期望：周期相同，时间由圆心角决定。
2. 问：到达 $B$ 的粒子从 $A$ 垂直 $AB$ 射入，到 $B$ 时转过多少度？ → 期望：半圆，$180^\circ$，时间最长。
3. 问：结合轨迹图，到 $C$ 和到 $E$ 的轨迹圆心角有什么关系？到 $D$ 呢？ → 期望：到 $C$ 和到 $E$ 的圆心角相等且小于 $180^\circ$；到 $D$ 的圆心角最小。
4. 问：所以四个时间的关系是？ → 期望：$t_B>t_C=t_E>t_D$，选 B。
常见错误：
- 认为路程长时间长或速度大时间短。追问：周期与速度有关吗？
- 认为离 $A$ 越远时间越长。追问：时间看距离还是看转过的角度？
总结句：同种粒子在同一磁场中，运动时间之比等于圆心角之比，与速度、路程无关。

## 11
本题考点：回旋加速器最大动能；磁流体发电机正负极；速度选择器的方向性；质谱仪半径与比荷。
提问路线：
1. 问：回旋加速器的最大动能表达式是什么？增大 $B$ 能增大最大动能吗？ → 期望：$E_k=\dfrac{q^2B^2R^2}{2m}$，能，A 对。
2. 问：磁流体发电机中，用左手定则判断正离子向哪块板偏？A、B 哪块是正极？ → 期望：正离子向下偏到 B 板，B 是正极、A 是负极，B 错。
3. 问：速度选择器中粒子从右侧进入，静电力和洛伦兹力还是反向吗？能沿直线通过吗？ → 期望：洛伦兹力反向后与静电力同向，不能沿直线通过，C 错。
4. 问：质谱仪中三种氢核速度相同，半径与比荷什么关系？谁的半径最大？ → 期望：$r=\dfrac{mv}{qB}$，比荷最小的 $_{1}^{3}\mathrm{H}$ 半径最大，D 对。选 AD。
常见错误：
- 认为速度选择器两个方向都能用。追问：速度方向反过来，洛伦兹力方向怎样变？静电力变不变？
- 磁流体发电机正负极判反。追问：正离子的偏转方向用左手定则怎样判断？
总结句：速度选择器有方向性；回旋加速器 $E_{km}\propto B^2R^2$；质谱仪中速度相同时 $r\propto\dfrac mq$。

## 12
本题考点：磁场中的圆周运动与边界夹角；电场中的减速返回与类平抛；分段计时。
已知：分界线与电场方向成 $45^\circ$，磁场 $B_0$ 向里，电场向上；粒子 $+q$、$m$ 从 $P$ 以 $v_0$ 沿垂直电场方向射入磁场，最后回到 $P$。
提问路线：
1. 问：粒子从 $P$ 进入磁场时速度与分界线夹角多大？第一次回到分界线时转过多少度？与分界线夹角多大？ → 期望：入射与分界线成 $45^\circ$，转过 $90^\circ$，射出时与分界线成 $45^\circ$，A 对。
2. 问：第一次进入电场时速度方向与电场方向什么关系？在电场中怎样运动？ → 期望：与电场方向相反，先减速到零再反向加速，以原速率返回磁场。
3. 问：第二次在磁场中转过多少？第二次进入电场的点 $S$ 到 $P$ 的距离是多少？ → 期望：转过 $\dfrac34$ 圈（$270^\circ$）；$PS=2\sqrt2R=\dfrac{2\sqrt2mv_0}{qB_0}$，B 对。
4. 问：第二次进入电场时速度与电场垂直，做类平抛回到 $P$。两个方向的位移都是 $2R$，列式求 $E$。 → 期望：$2R=v_0t_3$，$2R=\dfrac12\cdot\dfrac{qE}{m}t_3^2$，得 $E=B_0v_0$，C 对。
5. 问：总时间由哪几段组成？各多少？ → 期望：磁场中共转一整圈 $t_1=\dfrac{2\pi m}{qB_0}$；电场中往返 $t_2=\dfrac{2v_0}{a}=\dfrac{2m}{qB_0}$；类平抛 $t_3=\dfrac{2R}{v_0}=\dfrac{2m}{qB_0}$；总 $\dfrac{(2\pi+4)m}{qB_0}$，D 错。选 ABC。
常见错误：
- 漏掉电场中往返的时间。追问：第一次进入电场后粒子立刻回到磁场了吗？
- 类平抛中两个方向位移取错。追问：从 $S$ 到 $P$ 沿电场方向和垂直电场方向的距离各是多少？
总结句：多过程问题按“磁场—电场—磁场—电场”逐段分析，每段的末速度是下一段的初速度，时间逐段相加。

## 13
本题考点：叠加场中匀速圆周运动（重力与静电力平衡）；$r=\dfrac{mv}{qB}$；分裂时动量守恒；左手定则判断转向。
已知：电场 $E$ 竖直向下，磁场 $B$ 向里，油滴 $a$ 做半径 $R$ 的圆周运动；在最低点 $P$ 分成质量、电荷量均相同的Ⅰ、Ⅱ，Ⅰ与 $a$ 同向，半径 $3R$。
提问路线：
1. 问：油滴能做匀速圆周运动，重力和静电力是什么关系？电场向下，油滴带什么电？电荷量多大？ → 期望：二者平衡，静电力向上，带负电，$q=\dfrac{mg}{E}$，A 对。
2. 问：由 $R=\dfrac{mv}{qB}$ 求 $a$ 的速度。 → 期望：$v=\dfrac{qBR}{m}=\dfrac{gBR}{E}$，B 对。
3. 问：小油滴Ⅰ的比荷变了吗？半径 $3R$ 时速度多大？周期多大？ → 期望：比荷不变；$v_1=\dfrac{3gBR}{E}$；$T=\dfrac{2\pi\cdot3R}{v_1}=\dfrac{2\pi E}{gB}$，C 错（周期不是 $\dfrac{4\pi E}{gB}$）。
4. 问：分裂瞬间动量守恒，求Ⅱ的速度。 → 期望：$mv=\dfrac m2v_1+\dfrac m2v_2$，$v_2=-\dfrac{gBR}{E}$，与原方向相反。
5. 问：Ⅱ仍是重力与静电力平衡，速度反向后，绕行方向怎样？ → 期望：与 $a$ 相反；由左手定则判断为顺时针，D 对。选 ABD。
常见错误：
- 周期计算错，或认为周期随半径变化。追问：$T=\dfrac{2\pi m}{qB}$，比荷变了吗？
- 忽略动量守恒，认为Ⅱ与Ⅰ速度相同。追问：分裂前后动量守恒，Ⅰ的速度变大了，Ⅱ的速度应怎样？
总结句：叠加场中匀速圆周运动意味着重力与静电力平衡；分裂问题用动量守恒求速度，再用半径公式和左手定则判断轨迹。

## 14
本题考点：洛伦兹力的功与冲量；回旋加速器中不同粒子周期不同；动能定理。
已知：电场按 $_{1}^{1}\mathrm{H}$ 的回旋周期变化，两核同时从 $O$ 处释放（先在缝隙中被加速一次）。
提问路线：
1. 问：（1）洛伦兹力做功吗？它的冲量为零吗？ → 期望：不做功，$W=0$；它改变动量方向，冲量不为零，选 D。
2. 问：（2）两种核的周期之比是多少？ → 期望：$T=\dfrac{2\pi m}{qB}$，电荷相同、质量 $1:3$，周期 $1:3$。
3. 问：$_{1}^{1}\mathrm{H}$ 完成 3 次加速，在磁场中转了多少圈？用了多长时间？ → 期望：转了 2 个半圈，即一个周期 $T_1$。
4. 问：这段时间 $_{1}^{3}\mathrm{H}$ 转了多少圈？它被加速了几次？ → 期望：转了 $\dfrac13$ 圈，还没回到缝隙，只在开始时被加速 1 次。

常见错误：
- 认为洛伦兹力不做功所以冲量也为零。追问：冲量等于动量的变化，粒子的动量方向变不变？

总结句：洛伦兹力不做功但冲量不为零；回旋加速器只能对周期与电场同步的粒子持续加速。

## 15
本题考点：通电导体棒的平衡；安培力方向随电流反向而反向；两只弹簧的合力。
已知：棒长 $l=0.5$ m，$m=0.01$ kg，磁场向里；$I=0.4$ A 时弹簧恰好不伸长；$0.2$ A 由 $a$ 到 $b$ 时伸长 1 cm。
提问路线：
1. 问：（1）弹簧不伸长时棒受哪些力？安培力朝哪？ → 期望：重力和向上的安培力，$IlB=mg$。
2. 问：$B$ 等于多少？ → 期望：$B=\dfrac{mg}{Il}=\dfrac{0.1}{0.2}=0.5$ T。
3. 问：（2）0.2 A 由 $a$ 到 $b$ 时，安培力朝哪？写出平衡式。 → 期望：方向与 0.4 A 时相同（向上）：$2kx_1+I_1lB=mg$。
4. 问：电流反向后安培力朝哪？写出平衡式。 → 期望：向下：$2kx_2=mg+I_2lB$。
5. 问：两式相比，$x_2$ 等于多少？ → 期望：$x_2=\dfrac{mg+I_2lB}{mg-I_1lB}x_1=\dfrac{0.1+0.05}{0.1-0.05}\times1\ \text{cm}=3$ cm。
常见错误：
- 只用一只弹簧的拉力。追问：棒由几只弹簧挂着？
- 0.2 A 由 $a$ 到 $b$ 时安培力方向判反。追问：（1）中 0.4 A 的电流方向是哪边？由“弹簧不伸长”能推出安培力朝哪？
总结句：电流反向安培力反向；列出两次平衡式相比，可以消去劲度系数。

## 16
本题考点：匀加速直线运动；牛顿第二定律求安培力；$F=BId$；闭合电路欧姆定律。
已知：导轨间距 $d$，炮弹质量 $m$、电阻 $R$，滑行 $l$ 后速度 $v$，不计导轨电阻、内阻和感应电动势。
提问路线：
1. 问：（1）炮弹做什么运动？加速度多大？ → 期望：匀加速，$v^2=2al$，$a=\dfrac{v^2}{2l}$。
2. 问：水平方向受什么力？安培力多大？ → 期望：只有安培力，$F_A=ma=\dfrac{mv^2}{2l}$。
3. 问：（2）由 $F_A=BId$ 求电流。 → 期望：$I=\dfrac{mv^2}{2Bdl}$。
4. 问：（3）回路只有炮弹的电阻，电动势等于多少？ → 期望：$E=IR=\dfrac{mv^2R}{2Bdl}$。（原书答案漏了 2，本站已改正。）
常见错误：
- 加速度写成 $\dfrac{v^2}{l}$。追问：$v^2=2al$ 中 $a$ 等于多少？
- 有效长度用 $l$（滑行距离）。追问：安培力公式中的长度是通电导线在磁场中的长度还是滑行的距离？
总结句：电磁炮：先由运动学求加速度，再由牛顿第二定律求安培力，最后由 $F=BId$ 和欧姆定律求电流和电动势。

## 17
本题考点：直线运动条件（合力沿运动方向）；叠加场中匀速圆周运动（重力与静电力平衡）；动能定理；几何关系求半径。
已知：区域Ⅰ电场 $E_1$ 与水平成 $45^\circ$，宽 $d_1$；区域Ⅱ有磁场 $B$（向里）和竖直向下的电场 $E_2$，宽 $d_2$；微粒从静止水平向右直线运动，在区域Ⅱ偏转 $30^\circ$ 后从 $Q$ 射出。
提问路线：
1. 问：（1）在区域Ⅰ由静止开始水平直线运动，竖直方向合力为零，列式求 $E_1$。 → 期望：$qE_1\sin45^\circ=mg$，$E_1=\dfrac{\sqrt2mg}{q}$。
2. 问：在区域Ⅱ做匀速圆周运动，重力与静电力是什么关系？$E_2$ 多大？ → 期望：平衡，$E_2=\dfrac{mg}{q}$。
3. 问：（2）进入区域Ⅱ时的速度多大？ → 期望：水平方向合力 $qE_1\cos45^\circ=mg$，由动能定理 $mgd_1=\dfrac12mv^2$，$v=\sqrt{2gd_1}$。
4. 问：在区域Ⅱ中偏转 $30^\circ$ 后从右边界射出，半径与 $d_2$ 什么关系？ → 期望：$R\sin30^\circ=d_2$，$R=2d_2$。
5. 问：由 $R=\dfrac{mv}{qB}$ 求 $B$。 → 期望：$B=\dfrac{mv}{qR}=\dfrac{m\sqrt{2gd_1}}{2qd_2}$。
6. 问：（3）区域Ⅰ和区域Ⅱ中的时间各多少？ → 期望：$a_1=g$，$t_1=\sqrt{\dfrac{2d_1}{g}}$；$t_2=\dfrac{30^\circ}{360^\circ}\cdot\dfrac{2\pi R}{v}=\dfrac{\pi d_2}{3\sqrt{2gd_1}}=\dfrac{\pi d_2}{\sqrt{18gd_1}}$；总时间为两者之和。
常见错误：
- 区域Ⅰ中用 $qE_1=mg$。追问：电场方向斜向上，竖直方向的分力是多少？
- 半径几何关系写成 $R=d_2$ 或 $R\cos30^\circ=d_2$。追问：粒子垂直左边界进入，偏转 $30^\circ$ 后到右边界，圆心在左边界上，水平距离 $d_2$ 对应半径的哪个分量？
总结句：区域Ⅰ由直线运动条件求场强；区域Ⅱ匀速圆周运动意味着重力与静电力平衡，再用几何关系求半径。

## 18
本题考点：临界条件（轨迹与筒壁相切）；螺旋线运动的分解（垂直轴线的圆周 + 沿轴线的匀速直线）；对称性求面积。
已知：圆筒半径 $R$，电子源 $O$ 在轴线上，向各方向发射速率 $v_0$ 的电子，磁场沿轴线向下；$B_0$ 时恰好没有电子落到筒壁上。
提问路线：
1. 问：（1）哪个方向射出的电子最容易打到筒壁？为什么？ → 期望：垂直轴线射出的，它在横截面内的速度最大，圆周半径最大。
2. 问：“恰好没有电子落到筒壁”时，这个电子的轨迹与筒壁是什么关系？轨迹半径是多少？ → 期望：内切，轨迹过轴线上的点，直径等于筒半径，$R_0=\dfrac R2$。
3. 问：由 $ev_0B_0=m\dfrac{v_0^2}{R_0}$ 求比荷。 → 期望：$\dfrac em=\dfrac{2v_0}{B_0R}$。
4. 问：（2）磁场减半后，把速度分解成垂直轴线的 $v_x$ 和沿轴线的 $v_y$，电子做什么运动？ → 期望：横截面内匀速圆周运动，沿轴线匀速直线运动（螺旋线）。
5. 问：打到筒壁上离电子源最远的电子，横截面内的轨迹满足什么条件？$v_x$ 多大？ → 期望：轨迹与筒壁相切，半径仍为 $\dfrac R2$；$e\dfrac{B_0}{2}v_x=m\dfrac{v_x^2}{R/2}$，$v_x=\dfrac{v_0}{2}$。
6. 问：从射出到碰到筒壁用时多少？沿轴线前进多远？ → 期望：半个周期 $t=\dfrac{\pi R}{v_0}$；$v_y=\dfrac{\sqrt3}{2}v_0$，$y=v_yt=\dfrac{\sqrt3\pi}{2}R$。
7. 问：落有电子的区域是什么形状？面积是多少？ → 期望：上下对称、高 $2y$ 的圆柱侧面，$S=2\pi R\cdot2y=2\sqrt3\pi^2R^2$。
常见错误：
- 把轨迹半径取成 $R$。追问：电子从轴线出发，轨迹圆既过轴线上的点又与筒壁相切，直径等于多少？
- （2）中直接用 $v_0$ 做圆周运动。追问：斜着射出的电子，哪个分速度决定横截面内的圆周半径？
- 面积只算一侧。追问：电子向上、向下射出的情况对称吗？
总结句：速度与磁场斜交时，分解为垂直磁场的圆周运动和平行磁场的匀速直线运动；临界条件是横截面内的轨迹与筒壁相切。
