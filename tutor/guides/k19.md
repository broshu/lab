# k19 · 问答脚本

## 1
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：横轴x是刻度读数，零拉力时读数为x0，伸长量怎样写？ → 期望：x-x0。
2. 问：F=k(x-x0)中，图线斜率和横截距分别表示什么？ → 期望：斜率为k，横截距为x0；零点偏移不改变k。
3. 问：两直线用两点求斜率，各是多少？ → 期望：a为100 N/m，b为50 N/m，选D。
常见错误：
- 用F/x算k。追问：读数为零时弹簧是否就是原长？
总结句：F与位置读数的图线，用斜率求劲度系数。

## 2
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：图甲40 cm对应8 N，F与以cm计的x怎样关联？ → 期望：F=0.2x。
2. 问：0.2 N/cm换成N/m是多少？ → 期望：20 N/m。
3. 问：图乙示数多少？用x=F/k求伸长量。 → 期望：3.0 N；0.15 m，即15 cm。
常见错误：
- k填0.2却标N/m。追问：1 m包含多少cm？
总结句：关系式的数值随长度单位变化，求k时统一单位。

## 3
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：弹簧原长怎样放置测量？尺零点一定要对齐上端吗？ → 期望：竖直悬挂；不必，长度用差值，操作选CD。
2. 问：毫米尺应估读到哪位？图乙读多少？怎样拟合数据点？ → 期望：0.01 cm，14.60 cm；作直线，不逐点折线连接。
3. 问：直线上3.0 N对应12.6 cm，k是多少？ → 期望：约24 N/m。
4. 问：两根相同弹簧串联，每根拉力和总伸长怎样？ → 期望：每根受G，总伸长2G/k，等效k/2，选C。
常见错误：
- 串联时每根受力G/2。追问：中间连接点要平衡，两边拉力应是多少？
总结句：斜率求k；串联受力相同、伸长相加。

## 4
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：同一弹簧的劲度系数由负载还是自身结构决定？ → 期望：由材料、粗细、圈数等自身性质决定。
2. 问：压力增大而k不变，F=kx说明压缩量怎样？ → 期望：增大。
3. 问：哪项只改变压缩量、没有把k说成改变？ → 期望：C。
常见错误：
- 力大则弹簧变硬、k变大。追问：同一直线F-x图的斜率会因选点改变吗？
总结句：弹性限度内，负载增大改变形变量，不改变k。

## 5
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：F-l图中F=0对应什么长度？ → 期望：原长5 cm。
2. 问：求k该用直线段还是弯曲段？15 cm时形变量是多少？ → 期望：直线段；10 cm，即0.10 m。
3. 问：30 N除以0.10 m是多少，选哪项？ → 期望：300 N/m，选A。
常见错误：
- 用25 cm、45 N的弯曲段数据。追问：这段还遵循胡克定律吗？
总结句：先减去原长，再用弹性范围内的斜率求k。

## 6
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：两端各以600 N拉，单个端部承受600 N还是1200 N？ → 期望：600 N。
2. 问：四根相同弹簧并联，每根承受多少？ → 期望：150 N。
3. 问：长度从30 cm到150 cm，形变量是多少？每根k是多少？ → 期望：1.2 m；125 N/m，选B。
常见错误：
- 先把两手拉力相加。追问：测力计两端各拉600 N，示数会翻倍吗？
总结句：并联伸长相同，端部总拉力由各弹簧分担。

## 7
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：毫米刻度尺指针对着6 cm，要怎样记录？ → 期望：6.00 cm。
2. 问：n个钩码平衡时，nmg=k(l-l0)，整理成l-n关系，斜率a是什么？ → 期望：l=(mg/k)n+l0，a=mg/k。
3. 问：图上5个钩码使长度增加2.95 cm，k是多少？ → 期望：a=0.0059 m，k≈83.1 N/m。
4. 问：摩擦让弹簧伸长偏小，用nmg算k会偏大还是偏小？ → 期望：偏大。
常见错误：
- 把l-n斜率当k。追问：斜率单位是长度还是力除以长度？
总结句：先推图线方程，再解释斜率与误差方向。

## 8
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：人停在空中时，橡皮绳拉力是多少？ → 期望：mg=500 N。
2. 问：原长15 m、静止长17.5 m，k怎样求？ → 期望：500/2.5=200 N/m。
3. 问：最低点拉力3000 N时，绳的伸长和总长各是多少？ → 期望：15 m、30 m，悬点至少高30 m。
常见错误：
- 最低点v=0就令拉力等于重力。追问：这一瞬间是一直静止，还是即将反向运动？
总结句：形变量是绳长减原长；瞬时速度为零不等于平衡。

## 9
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：开始时弹簧压缩多少？由A平衡可写哪个式子？ → 期望：x1=L0-L，kx1=mg，k=mg/(L0-L)。
2. 问：B刚离地时哪个力为零？弹簧伸长多少？ → 期望：地面支持力为零，kx2=Mg，x2=M(L0-L)/m。
3. 问：A上升距离只等于x2吗？ → 期望：还需先恢复压缩量，x=x1+x2=(M+m)(L0-L)/m。
常见错误：
- 漏掉恢复原长过程。追问：从压缩状态到原长，A是否已经上升？
总结句：从压缩到伸长，总位移等于两段形变量之和。
