# k22 · 问答脚本

## 1
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：合力单独作用与几个分力共同作用的效果怎样？ → 期望：相同，等效替代。
2. 问：能把合力与这些分力一起再算一遍受力吗？ → 期望：不能，合力替代分力而非额外的力。
3. 问：重力与弹力性质不同，还能合成吗？选择哪些？ → 期望：同一物体同一时刻的力可以合成，选BD。
常见错误：
- 只有同性质的力能合成。追问：一个物体受重力与支持力，不能求合力吗？
总结句：合力是效果等效的替代，合成不要求分力性质相同。

## 2
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：题目要求找正确说法还是错误说法？ → 期望：错误说法。
2. 问：甲小矩形求面积、乙一人替两人、丁光点放大形变分别是什么方法？ → 期望：微元法、等效替代法、放大法。
3. 问：把各部分重力集中到重心，是等效替代还是理想化模型？ → 期望：等效替代，C说错，选C。
常见错误：
- 看见抽象图就称理想模型。追问：这里是忽略次要因素，还是用一个力替代很多力？
总结句：按操作目的区分微元、等效替代、理想模型与放大。

## 3
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：一个力替代两个力时，如何保证橡皮条形变相同？ → 期望：把圆环拉到同一位置。
2. 问：力的图示除了大小还需要什么？ → 期望：方向。
3. 问：需额外记录哪两项？夹角要单独记录吗？ → 期望：圆环位置、两力方向，选AB；夹角可由方向得到。
常见错误：
- 只记伸长量。追问：伸长相同而方向不同，作用效果仍完全相同吗？
总结句：记录结点位置保证等效，记录力方向支持作图。

## 4
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：把F1、F2的横竖格数分别相加，得到什么？ → 期望：水平7格，竖直0格。
2. 问：每格1 N，合力图示应该多长、朝哪？ → 期望：7格，向右，合力7 N。
3. 问：作图合力更偏向F1，若仅F1大小有误差，它偏大还是偏小？ → 期望：偏大。
常见错误：
- 把对角线画成分力末端连线。追问：合力是否从两力共同起点出发？
总结句：平行四边形对角线表示合力，偏向某分力可提示其测量偏大。

## 5
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：单力替代双力、结点回同一点，体现什么方法和条件？ → 期望：等效替代，橡皮条大小与方向形变均相同，前两问BC。
2. 问：记录哪些量才足够比较？ → 期望：结点位置及各次拉力大小和方向，第3问BCD。
3. 问：图中哪个力与橡皮条共线？测力计与木板、方向标记如何安排？ → 期望：F为实测，F′为理论；平行木板，标记点远些，第4问CD。
常见错误：
- 固定把F称理论值。追问：哪条箭头是平行四边形对角线，哪条与橡皮条共线？
总结句：按作图与实测的实际来源辨别符号，操作兼顾方向与读数误差。

## 6
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：一个或两个测力计都把结点拉到O，为什么可比较？ → 期望：弹簧形变相同，等效替代，选C。
2. 问：纵轴Δx、横轴F，斜率是k还是1/k？ → 期望：1/k。
3. 问：拟合直线上10 N对应10 cm，换成SI单位后k多少？ → 期望：100 N/m。
常见错误：
- 斜率直接填k。追问：图线的纵横轴单位相除是什么？
总结句：先看坐标轴，再用F=kΔx识别斜率。

## 7
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：用钩码重力作合力标准的甲方案，木板在哪个平面？每次结点必固定吗？ → 期望：竖直平面，不必固定。
2. 问：乙方案要让各部分怎样相对木板？有结点后需再记几个点确定方向？ → 期望：贴近并平行；一个远点，第2问D。
3. 问：只有一个测力计，怎样取得F1、F2和替代力F？ → 期望：同方向同结点交换测量，再单力替代，至少3次。
常见错误：
- 两方案都要求所有次数同一O点。追问：甲直接与重力比较，是否要复现橡皮条的原形变？
总结句：区分直接三力平衡方案与复现形变的等效替代方案。

## 8
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：水壶静止时电子秤示数代表什么？ → 期望：水壶重力F。
2. 问：第一轮除结点与F1，还要记录什么？第二轮测F2要复现什么？ → 期望：三根线方向；结点O与方向都相同。
3. 问：作图求F1、F2合力F′后，与什么比较？ → 期望：与F比较大小和方向。
常见错误：
- 换测线时任意改变结点。追问：若方向变了，所测F2仍属于上一组受力吗？
总结句：一个电子秤分次测分力，需复现同一受力几何。
