# 选修一 k03 · 问答脚本

## 1
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：从开始到停止，初末动量各是多少？ → 期望：都为零，全过程合冲量为零。
2. 问：推力、摩擦力各持续多久，如何列代数和？ → 期望：$F\cdot2\Delta t-\mu mg\cdot5\Delta t=0$。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为C。不要提前向学生展示其他小问的答案。
常见错误：
- 给两个力相同时间。追问：停止前摩擦力在哪些阶段存在？
总结句：都为零，全过程合冲量为零。再$F\cdot2\Delta t-\mu mg\cdot5\Delta t=0$。

## 2

2. 问：只研究入泥阶段，阻力冲量为何不等于动量变化量大小？ → 期望：还要计入重力冲量，向上为正时$I_f-mg\Delta t=m\sqrt{2gH}$。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为BD。不要提前向学生展示其他小问的答案。
常见错误：

总结句：减少$mg(H+h)$，转为阻力消耗。再还要计入重力冲量，向上为正时$I_f-mg\Delta t=m\sqrt{2gH}$。

## 4
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：每个分子反弹前后，速度方向怎样改变？ → 期望：初速度向上$v$，末向下$v/2$，动量变化大小$3mv/2$。
2. 问：一小段时间内撞击多少分子，怎样求顶盖条件？ → 期望：共有$n\Delta t$个，$F=3nmv/2$，临界时$F=Mg$。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为C。不要提前向学生展示其他小问的答案。
常见错误：
- 用速率差。追问：反弹前后的速度符号一样吗？
总结句：初速度向上$v$，末向下$v/2$，动量变化大小$3mv/2$。再共有$n\Delta t$个，$F=3nmv/2$，临界时$F=Mg$。

## 5
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：时间$\Delta t$内被加速的空气质量怎样表示？ → 期望：$\Delta m=\rho Sv\Delta t$。
2. 问：悬停与匀速上升时，升力分别要平衡哪些力？ → 期望：空气受力$F=\rho Sv^2$，悬停平衡$mg$，上升平衡$mg+F_f$。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为AC。不要提前向学生展示其他小问的答案。

总结句：$\Delta m=\rho Sv\Delta t$。再空气受力$F=\rho Sv^2$，悬停平衡$mg$，上升平衡$mg+F_f$。

## 6
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：

2. 问：这些微粒由静止加速到飞船速度，增加的牵引力怎样求？ → 期望：$F\Delta t=\rho Sv\Delta t\,v$，即$F=\rho Sv^2$。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为B。不要提前向学生展示其他小问的答案。
常见错误：

总结句：$\rho=2\times10^{-7}$，体积$Sv\Delta t$。再$F\Delta t=\rho Sv\Delta t\,v$，即$F=\rho Sv^2$。

## 7

提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：时间$t$内吹过的空气质量和获得的动量怎样表示？ → 期望：$m=\rho Svt$，$\Delta p=mv$。
2. 问：推力、压强与单位时间动能分别怎样求？ → 期望：$F=\rho Sv^2$，$p=\rho v^2$，动能流率$\rho Sv^3/2$。

总结句：$m=\rho Svt$，$\Delta p=mv$。再$F=\rho Sv^2$，$p=\rho v^2$，动能流率$\rho Sv^3/2$。
