# 选修一 k05 · 问答脚本

## 1
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：对心碰撞和避免入射球反弹，对两球有什么要求？ → 期望：半径相同且入射球质量较大，每次同位置由静止释放。
2. 问：为什么三次平抛可以用水平距离代替速度？ → 期望：抛出高度相同，飞行时间相同，把$v=x/t$代入动量式可约去$t$。
3. 问：请把关系式逐个代入各小问，注意单位和方向。当前这一小问的结果是什么？ → 期望：完成相应小问的推导后，结果分别为（1）C　（2）A　（3）$m_1x_2=m_1x_1+m_2x_3$。不要提前向学生展示其他小问的答案。
常见错误：
- 认为斜槽必须光滑。追问：怎样保证每次入射速度相同？
总结句：半径相同且入射球质量较大，每次同位置由静止释放。再抛出高度相同，飞行时间相同，把$v=x/t$代入动量式可约去$t$。

## 2
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：怎样使A碰后继续向右，光电门测速式是什么？ → 期望：选$m_A>m_B$，各速度由$d/t$求。
2. 问：$t_2$、$t_3$分别属于谁，如何写检验式？ → 期望：$t_2$属于B，$t_3$属于A，代入$m_Av_A=m_Av_A'+m_Bv_B'$。
3. 问：请把关系式逐个代入各小问，注意单位和方向。当前这一小问的结果是什么？ → 期望：完成相应小问的推导后，结果分别为（1）大于　（2）$d/t_1$　（3）$\dfrac{m_A}{t_1}=\dfrac{m_A}{t_3}+\dfrac{m_B}{t_2}$。不要提前向学生展示其他小问的答案。
常见错误：
- 交换遮光时间。追问：哪个滑块先到光电门2？
总结句：选$m_A>m_B$，各速度由$d/t$求。再$t_2$属于B，$t_3$属于A，代入$m_Av_A=m_Av_A'+m_Bv_B'$。

## 3
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：同一水平距离撞竖直挡板，速度越大落点越低吗？ → 期望：越大飞行时间越短，竖直下落更少。
2. 问：怎样用竖直落差表示速度，再代入动量守恒？ → 期望：$v=d\sqrt{g/(2y)}$，公共因子约去后比较质量和$1/\sqrt y$。
3. 问：请把关系式逐个代入各小问，注意单位和方向。当前这一小问的结果是什么？ → 期望：完成相应小问的推导后，结果分别为（1）C、A　（2）$\dfrac{m_1}{\sqrt{OB}}=\dfrac{m_1}{\sqrt{OC}}+\dfrac{m_2}{\sqrt{OA}}$；$m_1/m_2=6$。不要提前向学生展示其他小问的答案。
常见错误：
- 直接用竖直落差代速度。追问：速度与落差是正比还是反平方根关系？
总结句：越大飞行时间越短，竖直下落更少。再$v=d\sqrt{g/(2y)}$，公共因子约去后比较质量和$1/\sqrt y$。

## 4
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：游标卡尺主尺读数和第5条对齐应怎样相加？ → 期望：$L=1+5\times0.05\,\mathrm{mm}$。
2. 问：粘连前后遮光速度如何列动量式，降低释放高度如何影响$t_2$？ → 期望：$mL/t_1=(m+M)L/t_2$；高度降低使$t_2$增加、比值减小。
3. 问：请把关系式逐个代入各小问，注意单位和方向。当前这一小问的结果是什么？ → 期望：完成相应小问的推导后，结果分别为（1）$1.25\,\mathrm{mm}$　（2）$\dfrac{t_1}{t_2}=\dfrac{m}{m+M}$　（3）偏小。不要提前向学生展示其他小问的答案。
常见错误：
- 高度变小反而说时间变小。追问：遮光片速度变慢时挡光多久？
总结句：$L=1+5\times0.05\,\mathrm{mm}$。再$mL/t_1=(m+M)L/t_2$；高度降低使$t_2$增加、比值减小。

## 5
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：两球怎么选，多次落点的代表位置怎么确定？ → 期望：等直径、入射球更重，以最小包络圆圆心代表落点。
2. 问：$OP$、$OM$、$ON$如何对应三种速度？ → 期望：分别对应碰前入射、碰后入射、碰后被碰速度；检验$m_1OP=m_1OM+m_2ON$。
3. 问：请把关系式逐个代入各小问，注意单位和方向。当前这一小问的结果是什么？ → 期望：完成相应小问的推导后，结果分别为（1）A、B　（2）C　（3）$m_1OP=m_1OM+m_2ON$　（4）守恒。不要提前向学生展示其他小问的答案。
常见错误：
- 要求实验数据完全相等。追问：实际测量允许多大的误差？
总结句：等直径、入射球更重，以最小包络圆圆心代表落点。再分别对应碰前入射、碰后入射、碰后被碰速度；检验$m_1OP=m_1OM+m_2ON$。
