# 选修一 k10 · 问答脚本

## 1
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：嵌入后两者什么速度关系，碰撞用什么守恒？ → 期望：共同速度，水平动量守恒。
2. 问：总质量是哪个量，怎样算出共同速度？ → 期望：$mv_0=(M+m)v$，统一质量单位。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为B。不要提前向学生展示其他小问的答案。
常见错误：
- 用动能守恒。追问：嵌入过程是否产生内能？
总结句：共同速度，水平动量守恒。再$mv_0=(M+m)v$，统一质量单位。

## 2
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：木块受摩擦力做功、子弹受冲量分别怎样写？ → 期望：木块$F_fL=\Delta E_{k,木}$，子弹$-F_ft=m(v-v_0)$。
2. 问：系统内能增加应乘哪个位移？ → 期望：相对位移$s$，$F_fs=E_{k,前}-E_{k,后}$。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为AB。不要提前向学生展示其他小问的答案。
常见错误：
- 用木块对地位移求热。追问：子弹相对木块前进了多远？
总结句：木块$F_fL=\Delta E_{k,木}$，子弹$-F_ft=m(v-v_0)$。再相对位移$s$，$F_fs=E_{k,前}-E_{k,后}$。

## 3
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：两次嵌入的初末总动量与共同速度有区别吗？ → 期望：无，初末质量和速度相同，共同速度相同。
2. 问：热量相同但穿入深度不同，摩擦作用力必须相同吗？ → 期望：不，$Q=fs_相对$，位移不同则力不同；选不正确项。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为D。不要提前向学生展示其他小问的答案。
原题要求选择不正确或不可能的说法时，必须按原题要求选择；不要把正确命题选入。
常见错误：
- 深度不同就说热量不同。追问：系统初末动能有没有变化？
总结句：无，初末质量和速度相同，共同速度相同。再不，$Q=fs_相对$，位移不同则力不同；选不正确项。

## 4
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：两物体初速度反向时，总动量如何带符号？ → 期望：$mv-(m/3)v$，最终共同速度向右。
2. 问：共同速度确定后，初始向左的物体速度经历怎样的变化？ → 期望：先减速到零再反向加速；初始向右的木板先减速后匀速。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为AC。不要提前向学生展示其他小问的答案。
常见错误：
- 把速度大小减少当全程减速。追问：速度过零以后方向怎样？
总结句：$mv-(m/3)v$，最终共同速度向右。再先减速到零再反向加速；初始向右的木板先减速后匀速。

## 5
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：最终共速怎样由整体初动量求？ → 期望：$mv=(m+M)v_1$。
2. 问：撞壁N次后回到中央，相对总路程是多少？ → 期望：两端半程加中间全程，共$NL$；热量$N\mu mgL$等于总动能损失。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为BD。不要提前向学生展示其他小问的答案。
常见错误：
- 只算净位移。追问：摩擦生热取决于位移还是路程？
总结句：$mv=(m+M)v_1$。再两端半程加中间全程，共$NL$；热量$N\mu mgL$等于总动能损失。

## 6
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：图像斜率、面积差分别对应什么？ → 期望：加速度和两物体相对位移。
2. 问：共同速度如何反求质量，之后怎样比较动能损失和最小长度？ → 期望：整体动量定质量，总动能差定热，面积差定最小长度。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为AB。不要提前向学生展示其他小问的答案。
常见错误：
- 用物块单条面积当板长。追问：板本身也移动了多少？
总结句：加速度和两物体相对位移。再整体动量定质量，总动能差定热，面积差定最小长度。

## 7
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：两物体末速为$2v_0/5$和$v_0/5$，如何求木块质量？ → 期望：$mv_0=m\cdot2v_0/5+M\cdot v_0/5$。
2. 问：用何种位移求摩擦力，又如何求相互作用时间？ → 期望：内能$F_fL$对应穿入相对厚度；再对木块用$F_ft=Mv_木$。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为AC。不要提前向学生展示其他小问的答案。
常见错误：
- 把子弹损失动能全部当热。追问：木块获得的动能要不要扣除？
总结句：$mv_0=m\cdot2v_0/5+M\cdot v_0/5$。再内能$F_fL$对应穿入相对厚度；再对木块用$F_ft=Mv_木$。

## 8
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：A、B碰撞后的共速与C的方向各是什么？ → 期望：AB向右1 m/s，C仍向左2 m/s。
2. 问：全体最后是否静止，如何求滑动时间与相对路程？ → 期望：总动量零故最终静止；C动量定时间，总能量损失$Q=\mu mgx_相对$定路程。
3. 问：按刚才的推理，逐项核对选项，你会保留哪些，理由是什么？ → 期望：完成相应小问的推导后，结果分别为D。不要提前向学生展示其他小问的答案。
常见错误：
- 碰撞后立刻改变C速度。追问：C是否直接参加AB的瞬时碰撞？
总结句：AB向右1 m/s，C仍向左2 m/s。再总动量零故最终静止；C动量定时间，总能量损失$Q=\mu mgx_相对$定路程。

## 9
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：子弹嵌入后水平共同速度怎样求？ → 期望：$mv_0=(M+m)v$。
2. 问：平抛从桌面到地面，动量变化来自哪种冲量？ → 期望：只有重力，$\Delta p=(M+m)gt$，$t=\sqrt{2h/g}$。
3. 问：请把关系式逐个代入各小问，注意单位和方向。当前这一小问的结果是什么？ → 期望：完成相应小问的推导后，结果分别为（1）$\dfrac{m{v}_{0}}{m+M}$ （2）（$m+M)\sqrt{2gh}$。不要提前向学生展示其他小问的答案。
常见错误：
- 用末动量大小减初动量大小。追问：平抛的水平分量有没有改变？
总结句：$mv_0=(M+m)v$。再只有重力，$\Delta p=(M+m)gt$，$t=\sqrt{2h/g}$。

## 10
提问路线（逐问推进；复合题按原书小问顺序，每次只问一个问题）：
1. 问：车可动时，分离前用哪两条关系求两个末速度？ → 期望：整体动量守恒，机械能减少$\mu mgl$。
2. 问：落地间距与车固定时的摩擦功，各怎样求？ → 期望：间距用相对速度乘飞行时间；固定车时用摩擦因数图像面积求功。
3. 问：请把关系式逐个代入各小问，注意单位和方向。当前这一小问的结果是什么？ → 期望：完成相应小问的推导后，结果分别为（1）0.2 m （2）1 m/s。不要提前向学生展示其他小问的答案。
常见错误：
- 车固定仍用整体动量守恒。追问：固定装置有没有提供外力？
总结句：整体动量守恒，机械能减少$\mu mgl$。再间距用相对速度乘飞行时间；固定车时用摩擦因数图像面积求功。
