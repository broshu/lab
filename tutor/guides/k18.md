# k18 · 问答脚本

## 1
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：桶稍微偏转后，重力让它回到原位还是继续翻转，取决于什么？ → 期望：整体重心与转轴的相对位置。
2. 问：重心在轴下方和上方时，稳定性分别怎样？ → 期望：下方稳定，上方易翻转。
3. 问：积水增多主要改变哪个条件？据此选哪项？ → 期望：水桶与水整体重心升高，选A。
常见错误：
- 只看桶自身的重心。追问：加入的水是否也属于一起转动的系统？
总结句：翻转由桶与水整体的重心相对转轴的位置决定。

## 2
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：均匀足球的重心在外皮还是球心？ → 期望：球心，重心可以在物体外部空间。
2. 问：球离脚后，哪个施力物体还在？重力方向随轨迹改变吗？ → 期望：地球还在；重力始终竖直向下。
3. 问：若形状和质量分布不变，飞行会改变重心在球中的位置吗？哪项正确？ → 期望：不会，选D。
常见错误：
- 离脚后不受力。追问：脚的接触力与地球的重力是同一个力吗？
总结句：重心由形状和质量分布决定，重力与球是否接触脚无关。

## 3
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：重力方向是竖直向下还是垂直斜面？ → 期望：竖直向下。
2. 问：A、D的每段标度和总段数各是多少？ → 期望：A为5 N、4段；D为2.5 N、8段，都表示20 N。
3. 问：B、C错在方向还是大小？最终选哪些？ → 期望：方向错误，选AD。
常见错误：
- 重力垂直斜面。追问：改变斜面倾角，地球吸引的方向会跟着转吗？
总结句：力的图示同时检查作用点、方向和按标度表示的大小。

## 4
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：板静止悬挂时，重心与悬线的延长线有什么关系？ → 期望：重心位于这条竖直线上。
2. 问：一次悬挂能确定一个点吗？第二次应怎样操作？ → 期望：只能确定一条线；换悬挂点，再画竖直线，交点即重心。
3. 问：同形状的两块均匀材料，质量不同会改变重心位置吗？据此判断选项。 → 期望：不会；不规则物体重心未必在几何中心，选C。
常见错误：
- 重力只作用在重心。追问：板上其他部分是否也受地球吸引？
总结句：两次悬挂的竖直线交点确定重心。

## 5
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：松鼠与树枝的接触面是哪一个？ → 期望：树枝表面。
2. 问：树枝对松鼠的支持力与接触面有什么关系？箭头指向哪边？ → 期望：垂直接触面，指向松鼠，斜向上。
3. 问：静止是否要求支持力单独与重力平衡？选哪项？ → 期望：还可能有摩擦力，选C。
常见错误：
- 支持力必竖直向上。追问：倾斜的接触面法线还是竖直的吗？
总结句：支持力方向由接触面决定。

## 6
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：球反弹时，桌面对球的弹力方向由速度还是接触面决定？ → 期望：接触面。
2. 问：水平桌面的法线是什么方向？弹力指向哪个物体？ → 期望：竖直方向，指向球，即竖直向上。
3. 问：四幅图中哪幅符合这个方向？ → 期望：A。
常见错误：
- 把弹力画成沿球的运动方向。追问：球斜着飞来，桌面是否也变斜了？
总结句：弹力垂直接触面，与球的入射方向无关。

## 7
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：判断弹力来源，先找施力物体还是受力物体？ → 期望：施力物体。
2. 问：脚对球、球对脚、地面对球、球对地面，分别是谁形变产生的？ → 期望：脚、足球上部、地面、足球下部。
3. 问：哪项把力的施力物体与形变来源对应正确？ → 期望：B。
常见错误：
- 认为受力物体的形变产生它所受的力。追问：足球恢复形状时，是推脚还是推自己？
总结句：某个弹力由它的施力物体形变产生。

## 8
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：若图A两球互相推，两根绳还能都竖直吗？ → 期望：不能；水平力无法平衡，故没有弹力。
2. 问：图B绳倾斜、图C斜绳有水平分量，分别需要什么力平衡？ → 期望：都需要a、b之间的接触弹力。
3. 问：图D重力与竖直拉力已平衡，再加斜面的弹力会怎样？选择哪些图？ → 期望：会失衡，D无弹力，选BC。
常见错误：
- 接触就必有弹力。追问：假设有这个力，水平方向还能平衡吗？
总结句：有无弹力可用假设法结合平衡条件判断。

## 9
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：玉壶对台面的压力与台面对玉壶的支持力，施力物体各是谁？ → 期望：玉壶、台面。
2. 问：这两个弹力分别由谁的形变产生？重力的施力物体是谁？ → 期望：玉壶、台面；重力由地球施加。
3. 问：坚硬台面是否完全不形变？据此判断选项。 → 期望：只是形变很小，选B。
常见错误：
- 支持力由玉壶形变产生。追问：谁在对玉壶施力？
总结句：逐个写出施力物体，才能判断弹力来源。

## 10
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：瓶与水整体的重心由什么决定？ → 期望：形状和质量分布。
2. 问：水快流尽时，整体重心应接近哪里？与中途剩少量水时相比呢？ → 期望：接近空瓶重心；会重新升高，因此不会一直下降。
3. 问：地球吸引瓶时，瓶是否也吸引地球？哪个选项符合这些判断？ → 期望：也吸引，选D。
常见错误：
- 水越少重心必越低。追问：空瓶的重心会在瓶底吗？
总结句：加水或放水要比较整体质量分布，不能只追踪水面。

## 11
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：若竖直弹簧拉力恰好等于重力，还需要斜面和挡板的弹力吗？ → 期望：不需要，两处可接触而不挤压。
2. 问：若斜面与挡板的弹力合力能平衡重力，弹簧可处于什么状态？ → 期望：原长，所以弹簧不一定形变。
3. 问：挡板弹力是一定有、一定没有还是可能有？ → 期望：可能有，选C。
常见错误：
- 看到接触就数一个弹力。追问：只靠弹簧与重力能否已平衡？
总结句：接触处的弹力应由受力和平衡判断。

## 12
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：画50 N拉力的图示，先选什么？若每格10 N要画几格？ → 期望：选标度，画5格。
2. 问：拉力从哪里出发，沿哪个方向？ → 期望：从A出发，沿细绳与水平成30°斜向上。
3. 问：重力示意图从哪里出发、朝哪？需要按标度画长度吗？ → 期望：从重心竖直向下；示意图不要求按比例。
常见错误：
- 图示与示意图混用。追问：题目哪一个力要求明确标度和长度？
总结句：图示体现大小比例，示意图突出作用点和方向。

## 13
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：细线对杆的拉力沿哪里？ → 期望：沿AO，由A指向O。
2. 问：B端与地面属于点与面的接触，弹力垂直于杆还是地面？ → 期望：垂直地面，竖直向上。
3. 问：斜向拉力的水平分量由什么平衡？哪项正确？ → 期望：地面静摩擦力，选C。
常见错误：
- 把支持力沿杆画。追问：此处接触的面是杆的轴线还是水平地面？
总结句：点与面接触时，弹力垂直于接触面。
