# k25b · 问答脚本

## 1
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：人体姿态变化时，重心在身体中的位置一定不变吗？ → 期望：不一定，质量分布相对形状会改变。
2. 问：腾空后还受重力吗？脚与地面的相互作用力大小怎样？ → 期望：仍受重力；等大。
3. 问：软垫对人的弹力由谁的形变产生？ → 期望：软垫，选D。
常见错误：
- 起跳靠脚对地的力更大。追问：第三定律在起跳瞬间是否仍成立？
总结句：重心看质量分布，弹力找施力物体，反作用力始终等大。

## 2
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：B端对桌面的压力应垂直笔杆还是桌面？ → 期望：桌面，竖直向下。
2. 问：笔搁给笔的支持力应指向笔还是离开笔？ → 期望：指向笔，垂直接触面斜向上。
3. 问：笔搁支持力由谁形变产生？哪项正确？ → 期望：笔搁，选A。
常见错误：
- 一律沿笔杆法线画B端压力。追问：B端接触的面是哪一个？
总结句：弹力垂直接触面，其来源是施力物体形变。

## 3
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：同一光滑绳两侧张力都等于F，球在最低点时绳与竖直夹角多少？ → 期望：45°。
2. 问：竖直平衡怎样写？增大F时凹槽支持N怎样？ → 期望：2Fcos45°+N=G，N减小。
3. 问：F最大对应什么临界条件？得到多少？ → 期望：N=0，Fmax=G/√2，选B。
常见错误：
- 支持力可以继续变为负。追问：光滑凹槽能向下拉住球吗？
总结句：接触支持力降为零是保持接触的临界条件。

## 4
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：弹簧压5 cm、k=100 N/m，弹力多大？两块摩擦上限各多少？ → 期望：5 N；A为8 N、B为10 N。
2. 问：B受向右4 N与弹簧5 N，能否仍静止？实际摩擦多少？ → 期望：9 N小于10 N，可静止，摩擦9 N向左。
3. 问：A所需摩擦多少、朝哪，哪项正确？ → 期望：5 N向右，选C。
常见错误：
- 实际静摩擦直接用最大值。追问：平衡实际外力只需要多大的摩擦？
总结句：先算弹力与静摩擦上限，再按平衡求实际摩擦。

## 5
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：蜗牛静止，叶片对它所有作用的合力与重力是什么关系？ → 期望：等大反向，竖直向上。
2. 问：由第三定律，蜗牛对叶片的总作用朝哪？ → 期望：竖直向下，选C。
3. 问：支持力为何不一定等于Gcosθ？ → 期望：还有吸附力；法向平衡中应同时考虑吸附与支持。
常见错误：
- 把吸附力与压力配成反作用力。追问：吸附力对应的反作用是否也应属于吸附？
总结句：接触总作用与单个支持、吸附、摩擦分开判断。

## 6
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：同一绳绕光滑轻滑轮，两段张力与水平分量如何？ → 期望：张力相等，水平分量抵消，α=β。
2. 问：竖直平衡得到T表达式是什么？ → 期望：2Tcosα=mg，T=mg/(2cosα)。
3. 问：α减小时T与两绳合力各怎样？ → 期望：T减小，总作用仍mg，选D。
常见错误：
- 绳合力和单根张力都随α增大。追问：静止重物的mg改变了吗？
总结句：滑轮上的两绳合力固定，单段张力随夹角变化。

## 7
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：两手张开时钩码静止，两绳合力与单段张力怎样？ → 期望：合力仍G，单段张力增大。
2. 问：断裂时，每半段长L、半水平距d/2，竖直高度是多少？ → 期望：√(L²-d²/4)。
3. 问：用2Tcosθ=G得到最大张力怎样写？ → 期望：T=GL/√(4L²-d²)，选C。
常见错误：
- 认为合力随张力增大。追问：两绳夹角增大是否也抵消更多分力？
总结句：用几何求投影，恒定合力可对应增大的绳张力。

## 8
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：货物尚未滑动，随倾角α增加，静摩擦与支持各怎样？ → 期望：mgsinα增大，mgcosα减小。
2. 问：滑动后摩擦μmgcosα又怎样？μ会随倾角改变吗？ → 期望：摩擦减小，μ不变。
3. 问：滑动前车厢总作用与重力怎样？ → 期望：始终等大反向，不变，选D。
常见错误：
- 全程摩擦一直增大。追问：滑动前后分别应使用什么公式？
总结句：分清静摩擦与滑动摩擦阶段，再判断倾角影响。

## 9
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：上方A受两对称支持，法线与竖直成30°，每个支持N多少？ → 期望：2Ncos30°=mg，N=mg/√3。
2. 问：由第三定律，A给C的压力水平分量多少？ → 期望：Nsin30°=√3mg/6。
3. 问：C静止，地面实际摩擦等于哪个量？ → 期望：等于上述水平分量，选C。
常见错误：
- 用μ乘C的地面压力算实际摩擦。追问：C滑动了吗，还是只需平衡水平推力？
总结句：先隔离上管求压力，再隔离下管求静摩擦。

## 10
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：把五球整体，总重量多少？三底球对称，地面各给多大支持？ → 期望：(M+4m)g，各(M+4m)g/3。
2. 问：隔离b，杆2作用与地面支持、自重怎样平衡？ → 期望：F2=N-mg=(M+m)g/3。
3. 问：顶球d与中心O各自所受杆的总作用应该平衡什么？ → 期望：各自重力mg、Mg，选C。
常见错误：
- 地面只承担M+3m的重量。追问：顶球d的重量是否也传到桌面？
总结句：整体求外支持，再减去单球自重求杆作用。

## 11
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：沿BD下滑，摩擦方向是什么？正方形对角线与坡内两边夹多少？ → 期望：沿BD向上，45°。
2. 问：重力沿坡分量多少？与横向拉力合成后怎样由摩擦平衡？ → 期望：5 N；两分量相等，F=5 N，f=5√2 N。
3. 问：法向支持N多少，μ=f/N是多少？ → 期望：5√3 N，μ=√6/3，选ABC。
常见错误：
- 只用重力沿坡分量当整个摩擦力。追问：横向拉力的分量也需摩擦平衡吗？
总结句：斜面内仍可二维分解，摩擦应反向于实际滑动方向。

## 12
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：隔离5号蛋，斜面支持和4号给它的力各是多少？ → 期望：mgcos30°与mgsin30°，即√3mg/2、mg/2。
2. 问：4号的法向支持会因上方蛋压力而变为mg/2吗？ → 期望：不会，蛋间力沿斜面，法向支持仍√3mg/2。
3. 问：5蛋整体，挡板水平力沿坡分量如何平衡？ → 期望：Ncos30°=5mgsin30°，N=5√3mg/3，选BD。
常见错误：
- 求挡板力直接写5mgsin30°。追问：挡板法线水平，其力沿坡分量是多少？
总结句：隔离求蛋间力，整体求挡板力时保留投影。

## 13
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：滑块缓慢右移，球所受滑块支持与竖直夹角α怎样？ → 期望：增大。
2. 问：竖直与水平平衡给N和墙力什么表达式？ → 期望：N=mg/cosα，墙力=mg tanα，两者增大。
3. 问：球块整体的地面支持与水平推力怎样变化？ → 期望：支持不变；推力等于墙力，增大，选AD。
常见错误：
- 小球上升就认为地面支持增大。追问：整体处于缓慢平衡时，总重改变了吗？
总结句：隔离分析变向支持，整体分析外支持与推力。

## 14
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：毫米尺读弹簧原长，要记录到哪位，图乙读多少？ → 期望：0.01 cm，18.00 cm。
2. 问：包含托盘质量M，平衡式如何写成m-x直线关系？ → 期望：(m+M)g=kx，m=(k/g)x-M。
3. 问：两数据点0.2、0.6 kg对应3、7 cm，斜率与k是多少？ → 期望：10 kg/m，k=98 N/m。
4. 问：直线m=0时x=1 cm，托盘质量多少？ → 期望：M=kx/g=0.10 kg。
常见错误：
- 认为图必须过原点。追问：没有砝码时托盘自身会使弹簧伸长吗？
总结句：托盘质量改变截距，劲度系数由斜率乘g得到。

## 15
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：测力计最小分度0.1 N，指针在4 N处怎样记录？ → 期望：4.00 N。
2. 问：测力计与细线怎样贴近木板才能减小方向误差？ → 期望：贴近并平行，选A。
3. 问：B水平拉力增大而结点仍平衡，A示数与两力合力怎样？ → 期望：A增大；两力合力仍等于重物重力，选AD。

常见错误：
- 把B增大当作合力也增大。追问：重物的重力在过程中是否改变？
总结句：分力可以变化，平衡固定重力的合力保持不变。

## 16
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：图b在x=11.60 cm处对应质量多少？ → 期望：约107 g，106至108 g可接受。
2. 问：绳1方向固定，橡皮筋何时张力最小？偏离垂直后读数误差怎样？ → 期望：与绳1垂直时最小；张力与长度增大，读质量偏大。

## 17
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：BC水平时，AB需提供弹力吗，BC支持多少？ → 期望：AB可无挤压，BC支持mg。
2. 问：顺时针转30°后，两板支持关于竖直对称吗？每个支持是多少？ → 期望：对称，2Ncos30°=mg，N=mg/√3。
3. 问：求棉包对AB压力要用什么关系？ → 期望：第三定律，等于√3mg/3。
4. 问：转45°后支架总作用多少、朝哪？ → 期望：始终mg竖直向上；不要与单块支持混淆。
常见错误：
- 把第3问当作求某一块板的支持。追问：“支架的作用力”是否包含两板的合力？
总结句：逐状态求单板支持，支架总作用由整体平衡直接确定。

## 18
提问路线（逐问推进，学生完成当前推理后再进入下一问）：
1. 问：先看结点O，向下绳力多大？OD张力及水平弹簧力多少？ → 期望：15 N；Tcos53°=15，T=25 N；F=Tsin53°=20 N。
2. 问：弹簧伸4 cm，k是多少？ → 期望：20/0.04=500 N/m。
3. 问：A静止所需摩擦20 N，法向支持50 N，μ至少多少？ → 期望：0.4。
4. 问：绳对人竖直向上分量多少，地面支持多少、方向？ → 期望：15 N，500-15=485 N，竖直向上。
常见错误：
- 人的支持力仍取500 N。追问：绳是否也在向上提人？
总结句：先解结点张力，再分别求物块摩擦上限与人的地面支持。
